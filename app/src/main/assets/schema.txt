# ---------- 读取顺序（同一个字/词必须按这个顺序，否则不同页面会给不同答案） ----------
点字：
  1 char_dict（本义/拼音/部首/笔画）
  2 char_shuowen（说文 + 反切）
  3 char_usage（书证用例）
  4 char_pinyin（多音，仅当 1 的拼音与正文语境冲突时展示）
  全缺 → 「此字未收，只按字形显示」，不编释义。

点词：
  1 allusion（典故，有出处）
  2 zh_ci.bin（普通词义）
  3 ci_pinyin.bin（词级读音）
  全缺 → 不弹词气泡，退回单字。

点地名：
  1 place_name 拉候选（可能几十条）
  2 place_entity 按 起/止年 与锚点年筛
  3 命中 tier 高优先 → 区间窄优先 → 点优先
  锚点为空 → hit=null，把候选全列进「还有 N 个同名」，不猜
  全缺 → PlaceDict/PlaceGeo 旧表兜底；再缺 → 「坐标未收录」

点人名：
  1 person_l1（83 人人工档案）
  2 person_alias 双引擎（全名正则 + 短称谓桶）
  3 锚点年 + 所属国 消歧（楚子 → 当年楚君）
  锚点为空且无国别 → 短称谓一律不命中
  4 person.txt CBDB 兜底，同名走 person_dup 分组

# ---------- 空状态 / 错误状态（每种都要有兜底行为） ----------
不认识的字        → sheet 内一行「此字未收，只按字形显示」
查不到的年份      → 「此年无考，不给对照」
空地图（无坐标）  → sheet 内文字说明，不弹空 WebView
章节无人物数据    → 关系图页「本章未抽出人物，可切整本再看」
字表加载失败      → 气泡降级为「释义暂不可用」，不闪退
远程瓦片失败      → 保留本地底图 + 顶部一行「离线底图」
