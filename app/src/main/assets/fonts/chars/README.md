# 子集裁字字表（占位）

`common2500.txt`：古籍阅读常用字表，目标 2500 字量级（切片-14 / 切片-08：
正文常用 2500 字首屏子集 ≤ 200KB）。

## 当前状态

**字表未随仓库打包**，`subset_generate.py` 在缺少字表时只保留 ASCII 可打印字符与
常用中文标点，仅用于管线自检；真机读物所需汉字须在 CI / 本地补入字表后再裁子集。

## 字表口径

- 一字一行或纯文本均可，脚本按非空白字符去重收集；
- 来源优先级：内置读物高频字统计 → 《现代汉语常用字表》一级字 → 古籍高频补字；
- 生僻字不进首屏子集，留待后续 unicode-range 分片按需补包；
- 字表与字体资产同口径登记出处，不引入 CC-CEDICT / OSM / Wikipedia 派生数据。
