### 3.1 脚本与用法

判定口径（脚本头注释逐字在库）：
- 纯黑 / 纯白只数「不透明且三通道严格等于 0 / 255」的像素；半透明黑、白与 AA 过渡像素不计入禁色（边缘混合不是绘制字面量）。
- 主题色数量 ≠ 抗锯齿过渡像素：落在「某调色板色 ↔ 夜空底」连线上的凸混合像素判为 AA blend，不计越界；调色板之外、饱和且成簇（≥150 px）的实色块才记「候选第 14 色」。低饱和暖灰归 neutral 残色簇，只登记不判红。
- 调色板逐条回源：四锚星色 `SkySpecColor.kt:23/26/29/32`；12 色 token `ComponentPalette.kt:19/22/28/31/34/37/40/43/59`；地表数据色 `GlobeTokens.kt:109-125`；夜空派生底 `skyNightBase = darken(TEXT_PRIMARY 1A1410, 0.60) = #100C0A`（`GlobeTokens.kt:62/80-87`）。

### 3.4 四锚色聚类口径（必须如实说明的缺口）

四锚近邻命中在帧内为 0，原因不是锚色越界，而是：星点 sprite 在夜空底上经 alpha 叠暗，落帧像素亮度远低于锚色原值，精确锚色 hex（容差 RGB 距离 18）无法在帧内直接匹配；亮部抽样（态 1）显示帧内亮像素全部落在暖金 / 暖灰族（色相 39–44°，最近邻 `BRAND_GOLD`/`TEXT_SECONDARY`/`TEXT_PRIMARY` 一侧），未出现冷蓝或高饱和异色簇。锚色是否逐色在位，像素侧**不能独立复核**；该结论仍由静态锚色闸背书（`check-sky-spec.py` §六.12：四锚色逐字落 `SkySpecColor.kt`，PASS）。

### 3.5 字号像素旁证与换算过程

换算式（脚本注释同口径）：
- k = 帧宽 / 设备宽 = 562 / 1080 = 0.52037；
- 设备像素 = 帧像素 / k；sp = 设备像素 / D = 帧像素 / (k · D)，D = 2.625。

帧内检出的最大非背景条带高 10 px，折算 10 / (0.52037 × 2.625) ≈ 7.32 sp。**该条带是星点 / sprite 行，不是文字行**：八态帧内标签稀疏，软渲染未留出可独立测量的文字字形条带，故像素侧字号结论**不可下**。≥14sp 结论以静态常量闸为准（`check-sky-spec.py` §五.5：`STAR_LABEL_FONT_SP=14`、`CONSTELLATION_NAME_FONT_SP=14`、`SHEET_TITLE_FONT_SP=16`、`SHEET_BODY_FONT_SP=14`、`SHEET_SOURCE_FONT_SP=14`，PASS）。

旁证口径警告：截图夹具 `SkyRenderView.density = 1f`（`SkyStateFixtures.kt:119`），layoutlib 内 `textSize = sp × 1`；上面的反算按设备密度 D 回推，仅作量级参考。真机字号观感归未验证项。

## 七、反例与边界（假设本方案错了会怎样）

1. **空数据 / 目录缺失**：`reloadFromDisk` 在目录不存在时返回空视图，全部落兜底；例 1 覆盖。
2. **缓存损坏**：0 字节截断文件不计缓存；例 2 覆盖。其它损坏形态（半截 JSON、标记内容乱码）当前按「非空即缓存」处理，未解析标记内容——属边界缺口，记入交接。
3. **权限 / 不可写**：路径占用模拟目录创建失败；沙箱 / CI 若以 root 跑，`chmod` DAC 不生效，故未依赖 chmod；真机权限拒绝语义仍待真机用例。
4. **帧缺席**：脚本默认目录无 PNG 时退出码 2（未收集到任何帧），不假绿；本地 build 输出与 artifacts 都缺席时点名报错。
5. **非星空帧混入**：默认滤 `SkyEight`；显式目录递归时同样过滤，`--all` 才放开。
6. **锚色叠暗导致近邻 0**：脚本不把「近邻 0」误判成越界；越界只认饱和成簇实色，避免 AA / 叠暗像素造成假红。
