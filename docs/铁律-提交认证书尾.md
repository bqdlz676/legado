# 铁律 · 提交认证书尾（F-111）

## 一、由来（两条纪律打架，K-20 实证）
1. 纪律 A「代码槽永不空、验收未过也先上云留槽」：未验收的产物也要能进云端，不能压在本地。
2. 纪律 B「攒批一次推、少触发 CI」：一次 push 触发主 run + 截图 run 两个 run，连环 push 会把在飞 run 打成 cancelled（本棒 3 分钟连推 3 次打掉两对，记 K-20 / 事故清单）。
3. 冲突根因是——**"这个 commit 到底验没验"没有写在 commit 本身里**，只能翻台账、翻回执、靠记忆对。认证书尾解决"可查"，不解决"拦不拦"。

## 二、定位：轻量可查，事后追溯，不作 push 闸门
- trailer 只作为事后追溯证据：`git log --format=%B` 即可看出每条提交是独立验收通过、未验收保槽、还是纯文档，回源不依赖台账是否同步。
- **不设为 push 硬阻断**：验收没过的 commit 也要能进云端保槽；若缺 trailer 就 FAIL 拦推，会把"保槽"这条铁律顶掉。缺 trailer 只在门禁 ㊴ 打 WARN 提示补登。
- 与 F-108（写码/验收分人）衔接：`Verified-by` 必须是独立验收代理的 id，写码代理自评无效。

## 三、trailer 规范（建议每个进 main 的 commit 末尾一行）
commit message 末尾空一行后，写下列认证书尾之一：

| trailer | 含义 | 适用 |
| --- | --- | --- |
| `Verified-by: <验收代理id>` | 独立验收代理逐字对照锚点卡判通过的证据；id 须能回查到验收报告 | 代码/接线/实现类提交，验收已过 |
| `Wip: <未验收原因>` | 未过验收、但按纪律 A 仍要保槽上云；原因一句话写清缺什么验收 | 未验收提交 |
| `Docs-only: <说明>` | 纯文档 / 规则 / 台账 / 流水单，无代码产物，免验收代理 | 文档与规则类提交 |

细则：
- 一个 commit 原则上只写一种 trailer；trailer 写在 message 末尾（正文与 trailer 之间空一行），写在标题行或正文中间不算数。
- `Verified-by` 不许自评：写码代理给自己签的 `Verified-by` 无效，追溯时按未验收看待。
- 缺 trailer 不阻断 push，门禁 ㊴ 只打印短号与建议补法，调度层/下一棒回填即可。

## 四、推送节拍（与 trailer 解耦，`data_scripts/pre-push.sh` 唯一 push 入口）
- 时间窗攒批：距上次 push ≥ 15 分钟才允许一次 push，窗口内所有本地 commit 一起推；未到窗口脚本退出 0，打印"窗口未到，本地继续 commit"，**不返回非零、不阻塞**。
- 唯一真阻断：工作区不干净且有未提交改动时不许推（避免漏文件）。
- 上次 push 时间戳落盘 `docs/.last_push_epoch`；取不到时间戳时退化为"队列 PENDING=0"守卫。
- trailer 状态不参与分流：Verified / Wip / Docs-only 都走同一个 main 推送节拍。

## 五、机械守卫
- 门禁 ㊴ `data_scripts/check-commit-trailer.py`（**WARN 型**）：扫 `git log origin/main..HEAD`（远端 ref 不可解析时回退最近 5 条）；缺 trailer 只打印短号与建议，退出码恒 0，不 FAIL。
- 推送窗口提示 `data_scripts/check-push-window.py`（**提示型**）：输出在飞 run 与是否建议推，退出码恒 0；门禁 ㉟ 仅 `say` 展示，不 bad。

## 六、二阶 / 三阶自查
1. **节拍推送会不会让"红反馈"延后？**
   会，窗口内最长延后约 15 分钟：先写好的 commit 要等下一个窗口才触发 CI。取舍结论：可接受——代价换 push 次数与 runner 分钟数整体下降，且窗口内尚未定稿的提交本来也不该触发一轮完整 CI；红反馈的时延被限制在一个窗口内，不累积。
2. **窗口内连推两次的极端情况怎么防？**
   上次 push 成功后把 epoch 时间戳写进 `docs/.last_push_epoch`；窗口内第二次调用先读该文件，未到 15 分钟直接退出 0。时间戳文件即唯一节拍判据，不依赖调度器记忆；文件丢失时退化为队列 PENDING=0 守卫，不硬拦。

## 七、不适用
- 纯文档 / 规则 / 台账 / 流水改动：用 `Docs-only:` 代替验收 trailer，不派验收代理。
- 紧急回滚：可先推 main 再补 trailer 与事故登记（沿用 F-109 豁免口），事后回填认证书尾。
