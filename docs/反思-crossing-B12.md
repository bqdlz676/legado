## 2. 踩的坑 / 教训

- **白名单路径与实际落点不符**：工单写 `engine/Enums.kt`，实际枚举都在 `model/Enums.kt`，而 model/** 又在禁碰列。绕法：新枚举放 controller 同文件顶层，既不碰 model，也不新建无关文件。下任遇到同类路径漂移，先 `find` 定位真实文件再决定落点。
- **双栈先核对再动手**：开工先 grep `help/sim`，确认那边自有 fireAttack 分支后按止损只改 crossing；若上来就抽共享函数会越界。
- **既有测试口径要回归核对**：B15 事件测试的 fireAttack 用例无 weather 块，归一后走静风常温 CONTAINED，仍降级士气、折损 0.35，旧断言不破；改规则前先算清默认天气下的旧期望值。

## 3. 我可能判断错的地方

- 三态阈值（静风 2 m/s、大风 10 m/s、干热 28℃、寒冷 0℃）与倍率（1.35 / 0.40 / 1.15 / 0.65）全是经验标定，无实测依据；CI 若有既有战役快照数值断言，可能需要按新口径回校。
- 「强风 = 反噬」是标量近似，真实反噬取决于风向与攻方相对方位；字段补齐前这个映射可能被验收方否定。
- 行军侧风 / 温折减与 B2 标签档相乘，是否算重复计罚，留给架构裁决。
