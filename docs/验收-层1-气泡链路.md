## P01 · D1 字典 → C2 气泡（字 / 词 Provider 按长词优先命中）

- 契约维度（矩阵 §1）：接口参数 / 空值兜底。
- 判定：**已验-PASS**（静态契约核对；编译 / 运行未实测，等 CI）。

### 接口参数核对

- Provider 冻结接口：`BubbleProvider.query(token: String, anchor: ContextAnchor): BubbleContent?`，`hitAt` / `matchAllusion` / `matchWord` 为槽位扩展口。

- 单字 Provider `CharProvider` 覆写 `query` / `hitAt`，入参出参与接口一致。
  - 锚点：`help/bubble/CharProvider.kt:17`（`hitAt`）、`:24`（`override fun query(token: String, anchor: ContextAnchor): BubbleContent?`）。
- 多字词 Provider `WordProvider` 覆写 `matchWord` / `query`。
  - 锚点：`help/bubble/WordProvider.kt:39`（`matchWord`）、`:51`（`query`）。

### 长词优先核对

- `wordAt` 窗口长度从 `maxLen` 降到 `MIN_WORD_LEN`，先命中长词；同长度取最靠左起点。
  - 锚点：`help/dict/ChineseDict.kt:88-104`（`val maxLen = minOf(MAX_WORD_LEN, ...)`；`for (len in maxLen downTo MIN_WORD_LEN)`）。
- 段落词窗 `windows` 同样按长度降序、起点靠左稳定排序。
  - 锚点：`help/bubble/BubbleSupport.kt:55-69`（`for (len in maxLen... downTo 1)`）。
- 装配：默认解析链 `char = CharProvider`、`word = WordProvider`。
  - 锚点：`help/bubble/BubbleResolver.kt:135`（`char = CharProvider`）、`:136`（`word = WordProvider`）。

### 空值兜底核对

- 字典侧：`getChar` / `getShuowen` 未收返回 `null`；`getUsage` 无载返回空列表，永不返回 `null`。
  - 锚点：`ChineseDict.kt:50`（`?.entry`）、`:57`（`?.shuowen`）、`:64-65`（`.usage.orEmpty()`）。
- Provider 侧：字 / 说文 / 用例三者全空时 `CharProvider` 返回 `null`，不猜义、不编说文；三路查询均 `runCatching` 兜异常。
  - 锚点：`CharProvider.kt:28-32`（`runCatching` 三路；`if (entry == null && shuowen == null && usage.isEmpty()) return null`）。
- 解析链侧：任一路异常 `safe { runCatching... }` 兜住，全空由 `MissingProvider` 兜出一张结构完整气泡，`resolve` 不返回 `null`。
  - 锚点：`BubbleResolver.kt:64-66`（`runCatching { dispatch(...) }.getOrNull() ?: missing(...)`）、`:102-115`（`missing` 兜底气泡字段齐全）、`:117-118`（`safe`）。

### 缺陷与最小返工建议

- 未发现阻断本对咬合面的缺陷。
- 观察项（不阻断）：`WordProvider.query` 整词回退路径对 2~5 字汉字词调 `wordAt(clean, clean.length / 2)`（`WordProvider.kt:59-63`），中点下标在偶数长度词上的命中表现属运行期行为，静态无法判定，留 CI 单测覆盖。

- 字 / 词真实命中、长词优先在真实种子词表上的排序结果未跑单测；DEF-06 `BubbleResolverTest:516/527` 2 条 failed 待重写。
