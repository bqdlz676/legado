## 一、目的与适用范围

### 1.1 覆盖哪三页

- 3D 沙盘：WebView + Three.js，宿主 `ui/main/PlaceMapActivity.kt`，页面 `app/src/main/assets/map/three.html`，陀螺仪脚本 `app/src/main/assets/map/gyro.js`。
- 战役推演：WebView + Three.js，宿主 `ui/main/BattleActivity.kt`，页面 `app/src/main/assets/map/battle.html`，共用 `gyro.js`。
- 3D 地球仪：原生 Compose Canvas 程序化舆图，宿主 `app/src/main/java/io/legado/app/ui/map/globe/host/GlobeScreenHost.kt:58`，门面与参数在 `app/src/main/java/io/legado/app/ui/map/globe/`（契约常量见 `app/src/main/java/io/legado/app/ui/map/globe/contract/GlobeParams.kt:43`）。
- 陀螺仪接管跨前两页（桥 `help/sensor/GyroBridge.kt`，事实锚点见 `docs/锚点/Q439-陀螺仪接管.md`）；地球仪当前未接陀螺仪，本机制不替它补接线。

### 1.2 不覆盖什么

- 2D Leaflet 二维图（`app/src/main/assets/map/index.html`）、阅读页 / 卡片 / 组件观感：归 `docs/工序-观感打磨.md` 既有七维工序，本机制不重复立判据。
- 纯 JVM 模型层正确性（球面剖分、LOD、投影、深度缓冲）：归既有单测与 `docs/验收-U13地球仪3D渲染核心.md` 那条静态验收线；本机制只补画面与行为层。

### 1.3 为什么「代码能跑」不等于「画面可交付」

编译通过、单测全绿只证明结构与契约成立，不证明剪影可读、材质身份成立、光影层次分明、动效节奏合格。同构教训见验收代理必读 §9：编译面验收无权判 PASS；L2 编译绿不构成画面证据。典型反例：太阳方位算对了但画面死黑；棋子投影悬浮无接触；辉光过曝把主体吃掉；标签被近裁切或 UI 压住。这些问题词法与签名层面全绿，只有对着真实帧逐帧核才能发现。

判定主体固定为独立验收代理逐帧核；自动门禁只管「帧在不在、动作有没有发生」（见第九节），美术判断不许写成自动打分。

## 二、十步工作流的本仓改编

外部仓十步工作流是「先定方向再出帧、跑真实产物、按证据精修、诚实汇报」的顺序。每步在本仓落地时对应一个既有产物（报告小节 / 锚点 / 帧存 / 门禁），不许跳过直接写码。

1. **意图与视觉方向**：落点＝派单任务书「视觉方向」小节 + 锚点卡「判据」节。方向冻结后写码方不得自行改换物料语言；要改方向走 F-73 退回设计段，不在实现单里顺手改。
2. **关键物件形体推理**：落点＝报告「形体推理」小节。先写剪影、比例、负空间、地标特征、部件关系，再谈装饰；对照规格切片逐字核，不凭记忆转述。
3. **表征方式（插画 / 离散状态 / 仿真 / 回放）**：落点＝报告「表征归属」小节。逐件标明是程序化几何、顶点色、回放事件还是装饰动效；装饰动效不得当仿真汇报（外部清单第 13 条同义）。
4. **构造路线**：落点＝报告「构造路线」小节。写明现有几何复用 / 新建 / 数据驱动，并列二阶三阶影响（受影响文件、调用方、用户行为与维护成本）。
5. **三距离质量目标（总览 / 检视 / 特写）**：落点＝帧存三组视角（见第四节），每组视角各挂对应判据；不要求一张帧同时扛三个距离的细节。
6. **首视图**：落点＝home 视角帧，命名 `*_home.png`，对应命名视角契约 `views[0]`（见第六节）。
7. **行为归属权威状态**：落点＝报告「行为归属」小节。状态源必须单一（控制器 / 门面 / 回放事件）；发现双源或状态漂移，写进交接节登记，不在本单顺手改。
8. **跑真实产物并检查**：落点＝CI 帧存或可运行产物。没出帧、没打开过的帧不许写「已验证」；未渲染项一律进「未验证项」，不许用静态 grep 结论冒充画面证据。
9. **按证据精修**：落点＝返工要求逐条可复验。先修最高影响问题，修完再出帧复核；重复改动仍不改善就换表征 / 构造路线，不死磕（子代理必读 E12 止损口径）。
10. **诚实汇报**：落点＝报告「未验证项」逐条 + 反思文件。没打开过的帧不许描述；外部实验式自评不构成证明；性能数据只在实测且授权后报。

## 三、条件性判据集

> 保留外部原意：以下是**条件性提示，不是评分表**。只套用与主体、视觉方向、交付形态相关的条目；空白背景、居中相机、静止场景、有限色板、规律网格都可能恰好正确。常规条目中不适用的条目无需写豁免文档，不凑条数、不打分。
>
> 外部 17 条按本仓口径分三段落：形与身份（外部 1–3、16）、材质与光（外部 4–7）、构图与传达（外部 8–12、17）；行为与真值（外部 13–15）归第六节运行时契约。每条写清「判什么 / 最便宜的检查方法 / 什么情况下不适用（无需豁免）」。

### 3.1 形与身份

- **判 1 · 重要物件是否读得出身份**：先看剪影、比例、负空间、地标特征、部件关系，再看装饰；一个套了精致纹理的通用替身仍是通用替身。最便宜检查：总览帧看剪影轮廓，再抽一张灰度帧看形状是否仍成立。不适用：抽象示意图、纯几何编码——这类要的是精度与干净边界，不需要磨损或纹理。
- **判 2 · 构造是否贴合物件**：厚度、附着、空腔、关节、连续性在主体需要处必须成立；这些错了就该换 kit 或建模路线。最便宜检查：近景帧看连接点与支撑处。不适用：离散符号、图示、爆炸视图——悬浮抽象物是合法表征，单靠接触阴影不证明物理支撑。
- **判 3 · 细节是否在实际观看尺度上有目的**：总览与特写分别看；生物、机械、建筑需要的特征不同；数学几何要的是精度与干净边界。最便宜检查：两组距离帧对比，放大后才出现的细节在总览不可见即不欠。不适用：远距 LOD 档位本就省略细节的场景；外部细节阶梯是有范围的样例，不是「每档两个特征」或「三米观看距离」的硬指标。
- **判 16 · 事实对应是否保住**：坐标、单位、拓扑、方程、方向、标签、限值对照规格原文；源几何不证明作者形变，平滑动画不证明求解器正确，不许为填满画面编造缺失结构。最便宜检查：锚点回规格切片逐条对标签与方向。不适用：无事实主张的纯装饰场景。

### 3.2 材质与光

- **判 4 · 材质身份是否成立**：看对真实光的响应——软质、缎面、金属、石、玻璃、图示色或有意的抽象；粗糙度变化在物件需要时才用，不设材质数 / 粗糙度数量下限。最便宜检查：近景帧看高光走向与粗糙度分区。不适用：平涂图示、单色编码等故意抽象的方案。
- **判 5 · 表面处理是否支撑形体**：细节的尺度与方向要合适；噪声、倒角、烘焙分辨率、PBR 标签、面数本身不证明工艺精湛。最便宜检查：特写帧看细节方向是否顺着结构走。不适用：矢量平涂、线稿风。
- **判 6 · 光照是否揭示重点**：查裁剪高光、压死阴影、填充过度、反射发浑、边界可读；每盏灯要有目的。影棚平光、图示平光、emissive 自发光、环境光方案都合法，单灯不自动判错。最便宜检查：总览 + 近景帧看高光是否过曝成块、暗部是否死黑成一片。不适用：故意平光的信息图。
- **判 7 · 特效是否承认成本**：雾、辉光、景深、透明、反射都有帮助但都非必需；不许用特效掩盖源结构、移动感知边界，或把不发光物件变成看似光源（除非这是有意美术决定）。最便宜检查：设计一张关特效对照帧比对（接入帧存后执行）。不适用：刻意扁平的图示场景。

### 3.3 构图与传达

- **判 8 · 构图是否引导注意**：焦点对比、尺度、叠压、节奏、留白、色阶建立层级；不要求主角必须是最亮区域，不限定固定色数；以比较为目的时各组等权对比。最便宜检查：总览帧看视线第一落点。不适用：并列比较图，必须等权。
- **判 9 · 纵深是否有用可读**：环境可加大气层次；孤立器官、图示、雕塑可用空背景；不为了凑检查硬加布景。最便宜检查：总览帧看前后层次是否服务主体。不适用：孤立主体页。
- **判 10 · 尺度解读是否正确**：需要时用单位、比例尺、熟悉参照物或显式放大；门和人不是通用尺度线索；物理模型单位与显示夸张分开标注。最便宜检查：帧内参照物与规格单位对读。不适用：无物理尺度的抽象关系图。
- **判 11 · 相机是否贴合表征**：透视与正交都合法；取景、镜头、控件按主体选；在实际视口尺寸下查裁切与 UI 遮挡；对称与居中视角可能传达最好。最便宜检查：交付尺寸帧查边缘裁切、UI 压字。不适用：无 UI 的全幅演示场景。
- **判 12 · 重复与变化是否有意**：合适处实例化重复几何；抖动利于自然场景，但会伪造晶格、解剖、齿轮、精确网格。最便宜检查：网格类帧查规整度。不适用：自然地貌允许扰动。
- **判 17 · 成稿是否服务任务**：正确性检查过后再判艺术本身；换一种剪影、材质、相机或构造路线是否会更好；工具通过或本清单通过都不能证明美术方向好。最便宜检查：验收代理对照任务书视觉方向逐条销项。不适用：纯机械正确性验收单。

## 四、每帧检查清单

### 4.1 一个场景欠哪些捕获

按外部 `inspection-per-frame` 改编，三页各自对照清点，不要求每张帧都有天空、三层纵深、表面噪声或真实尺度道具；选材省略部分必须与损坏、缺件、加载失败可区分。

- **总览**：交付实际尺寸，含周围 UI。
- **近景**：每个重要物件族一张；身份、结构、材质、精度与主体相称，无通用距离与特征数下限。
- **交互 / 动作态**：有动效期望时取代表运动态，含接触与附着关系。
- **控制转移与边界**：零值、极值、离散态、打断播放、可见性变化、复位，按页面实际承担的控件取。
- **错误 / 加载 / 导航**：异步状态归本页负责时才欠；不归本页的不硬凑。
- **夜景 / 暗态**：有明暗两套时各一张；无夜景档的页用加载态 / 空态兜底帧代替，不硬凑夜景帧。
- **极端视角**：极角与距离限值边界各一张。

### 4.2 每张帧查什么

- **运行错误**：console / 页面日志与可见报错；捕获日志随帧存一起留档。
- **取景**：重要几何与标签可读；近平面裁切、意外遮挡不盖主体；有意剖切面可识别为剖切。
- **纵深与材质**：z-fighting、透明排序、阴影一致性；高光 / 反射不遮形体；阴影 pass 内被裁的几何也要查。
- **空间关系**：支撑物贴合、附着件不掉、运动留 clearance；悬浮抽象与爆炸图合法。
- **行为**：模型状态按承诺变化；求解结果、源回放、作者插画、装饰动效不得混为一谈。
- **控件**：可见与数值反馈到位；控件允许某些像素不变，验的是预期效果，不是要求像素全变。
- **复位与恢复**：复位语义成立，播放 / 控件 / 相机 / 报错回到连贯态；跨场景不带陈旧状态。
- **动作 / 可达**：减弱动效起步即可读；暂停与完成可停车；交互必须唤醒停车视图；不要求常驻环境动效。
- **事实对应**：源 / 方程 / 状态对照渲染形态、标签、单位、变化方向；数值测试不证明场景接线或解剖正确。
- **成本**：几何材质尽量复用；帧循环避免重分配与无谓重绘；性能数据只在实测且授权后报。
- **单帧画面六项（本仓观感口径接入）**：高光是否裁剪成块；阴影是否压死；填充是否过度发灰；边界是否可读；材质身份是否成立；特效是否承认成本。

## 五、参数化美术口径

### 5.1 口径声明

- 下列数值是外部仓作者校对过的**起点值**，不是质量天花板。本仓物料语言是绢帛、墨、暖金辉光；落地须整组重调，不许单片改一个数。
- 外部已知限制：原档数值按 ACESFilmic 色调映射、曝光 0.9 调校；换色调映射曲线或曝光后，强度与雾密度必须重新推导，不可照抄。本仓 renderer 的色调映射与曝光未对齐前，这些数值只作组间比例参照。
- 本仓既有暖金 token 是物料基准：`CardTokens.warmGold` 与 `ComponentPalette.COLOR_GLOW`；外部 hex 落地时回挂 token 派生，不新造裸 HEX（对齐 T6 候选既有口径）。

### 5.2 黄昏基准组（起点值，整组替换）

- 主光：色 `#ffb46b`，强度 3.2，仰角 6°，方位 250°，投影开。
- 轮廓光：色 `#ffd9a8`，强度 0.8，仰角 12°，方位 70°，投影关。
- 天空 / 地面半球补光：天 `#6f8fc9`，地 `#4a3a2a`，补光强度 0.5。
- 主补比约 6:1。
- 阴影：shadowExtent 20，mapSize 2048，bias -0.0002，normalBias 0.03，distance 30。
- 因果句（外部 principles 留档，落地时对照本仓物料复核，不许只记数值）：
  - 低角度太阳是形体工具：6° 仰角下阴影数倍于物高且互相平行，比任何纹理都更能描述地面起伏。
  - 暖调必须用冷调对位，否则只是一层橙色滤镜；暖主光配冷天空补光才读得出时辰。
  - 太阳盘是画面最亮物，其余一切相对它分级，所以压的是曝光不是主光。
  - 雾色属地平线带，不属地平天顶；雾色对齐地平线带，距离才溶进暮色而不是溶进灰霾。

### 5.3 阴天软光整块替代组（换风格时整组换，不许拆用）

- 主光：`#e8edf2`，强度 0.6，仰角 70°，方位 180°，`castShadow: false`。
- 天空 `#cfd8e6`，地面 `#6a6f66`，补光强度 1.2。
- 雾 `#cfd6dd` 密度 0.035，environmentIntensity 0.35，曝光 1.0。
- 口径：阴天组云盖即光源，半球承载光，阴影关闭；它与黄昏组是两套完整方案，不许把阴天的天光色配到黄昏的主光上。

### 5.4 夜景降档路径

- 基准结构：月亮 + 半球补光 + 上限受控的实用灯 + 发光材质兜底。月亮只勾剪影；实用灯按物理衰减（decay 2）走，光池才读得出夜。
- 性能掉档时：超过点光上限后，网格仍发光但不再加 PointLight；金点改为 emissive 材质独撑，**数量不减**，只减实时光。
- 兜底顺序：先砍实时光数量（留 emissive）→ 再降阴影贴图分辨率 → 最后才减粒子 / 金点数量；不许一上来砍粒子。
- 夜景刻意暗景与加载失败必须可区分：暗是设计，近黑无结构是故障，两者在帧存日志里分开登记。

### 5.5 换组硬规

- 要换风格就整块换参数组（黄昏 / 阴天 / 夜景三组之一），不许只改一个色值或一个强度；单片改数会破坏组内比例（主补比、冷暖对位、阴影方向一致性）。
- 组内调整顺序（外部 rig 注释口径）：先改仰角 / 方位角（它们决定所有阴影指向），再改强度，最后改色；顺序反了阴影与光向先脱节。

## 六、运行时契约

每条写清契约与违反时用户会看到的症状，便于验收时按症状反查。

1. **需求驱动渲染（脏帧 / invalidate）**：静止检视视图只在相机、数据或控件变化时重绘；输入或状态变化必须调 `invalidate` 唤醒停车循环。症状：不传 `invalidate`，轨道输入唤不醒停车循环，相机「看起来是死的」——拖动无反应、视角停在原地；反方向的症状是静止场景常驻 rAF 空转，耗电掉帧。
2. **命名视角**：视角表记录命名位姿，`views[0]` 为 home；复位回 home。症状：复位落到随机角度；视角没有名字，帧存无法按名取帧。
3. **聚焦补间 0.9 秒**：命名视角切换走 0.9s 平滑补间（smoothstep 缓动）。症状：视角瞬移跳变；或补间过长、拖泥带水抢交互。
4. **阻尼与禁用平移**：`enableDamping = true`，`enablePan = false`；极角与距离有 limits。症状：双指平移把场景甩出视野；阻尼关闭时拖动发涩、惯性突兀；距离 / 极角越界穿地或翻到天顶。
5. **用户输入即让跟随让位**：用户触摸输入即取消跟随 / 补间，跟随不再抢回控制权；松手后按本仓既有回弹口径回位（陀螺仪松手 600ms 回弹、进模式 / 回前台 800ms lerp 过渡，见 `docs/锚点/Q439-陀螺仪接管.md`）。症状：跟随态持续把相机拽回目标，用户拖不动；或输入与跟随打架造成抖动。
6. **行为归属（外部 14 / 15）**：运动中支撑、关节、间隙、附着保持；控件改的是被表征状态并给出反馈；可见性控件不许偷改物理参数；复位恢复声明默认值，或明确保留所选设置。症状：棋子离座悬浮；开关只换贴图不改状态；复位后参数陈旧。
7. **事实归属（外部 13 / 16）**：只在期望运动的区间验动作；静止场景、播完动画正确停车；仿真结果、源回放、作者插画、装饰动效不得混称。症状：把装饰粒子当仿真结果汇报；静止帧被 motion 闸误判（motion 判据只在标记为期望运动的区间开）。

## 七、知识记录写法规范

外部知识记录体例值得抄：`defaults` 数值 + 因果句 + `not_for` / `negative_signals` 明确写出不适用场景。本仓在 `docs/` 下新增 3D 相关知识记录时，按本节模板段落写，不另造文件格式。

- **记录标识**：id、标题、状态（active / 待裁 / 作废）。
- **defaults.values**：可复算数值（色值 / 强度 / 角度 / 距离 / 贴图尺寸 / bias），标 provenance（外部起点 / 本仓拍板 / 规格切片）与 tunable 是否可调。
- **principles 因果句**：每条数值后跟一句「为什么」。留档范例：暖调必须用冷调对位，否则只是一层橙色滤镜；太阳盘是画面最亮物，压的是曝光不是主光；雾色属地平线带，不属地平天顶。
- **observable_checks**：逐条可观测的核对现象。范例：灰度截图仍能分开受光面与背光面；关掉雾只改纵深分离、不改前景曝光。
- **not_for**：明确写出不适用场景。范例：室内受控灯具照明的场景；需要按日期纬度给出真实太阳高度角的场景（那需要有源太阳模型）。
- **negative_signals**：触发本记录不适用的反信号。范例：室内棚拍产品照；某日期纬度的定量太阳位置。
- **known_limits**：调校前提（色调映射 / 曝光 / 档位）与「未跑渲染、仅作者起点」声明。
- **反例纪律**：记数值必须记前提；脱离前提搬数值等于编参数。外部原档已知限制一条样例：数值按 ACESFilmic、曝光 0.9 调校，换曲线或曝光后强度与雾密度必须重新推导。

## 九、门禁接口设计（只设计判据，不实施）

### 9.1 3D 帧存门禁（拟新增，挂既有帧清单 / 观感基线体系，不另造平行脚本）

- 覆盖三页：sandbox（`three.html`）/ battle（`battle.html`）/ globe（`GlobeScreenHost.kt`）。
- 每页欠帧（设计值，接入时按页实际状态复核）：
  - sandbox：home 总览、地形近景、落兵交互态、拖动旋转动作态、极端视角（倾角 / 距离限值）共 5 帧；夜景档未实现，登记 DEFER，不欠夜景帧。
  - battle：home 总览、兵种近景、回合动作态、控件转移态（回合结束 / 复位）、极端视角共 5 帧。
  - globe：整球 home、半球近景标签、自转惯性动作态、暗半球夜景态、极角极端视角共 5 帧。
- 命名规则：`3d_<page>_<view>[_<state>].png`；page ∈ sandbox / battle / globe，view ∈ home / closeup / motion / edge / night。例：`3d_sandbox_home.png`、`3d_battle_motion.png`、`3d_globe_night.png`。
- 帧存目录：收集进 `screenshot/build/outputs/screenshots/3d/<page>/`；清单仍由 `data_scripts/frame-manifest.py` 同一 schema 出 frames.json（屏名 / 尺寸 / sha256 / 字节 / 时间）；仓内基线登记走 `data_scripts/check-visual-baseline.py` 既有源码层 + 帧层双层口径。
- CI 判缺帧：帧清单登记的期望帧在产物目录缺席 → FAIL，点名页与帧名（对齐 `screenshot.yml` 既有 `if-no-files-found: error` 兜底口径）；基线复核期帧本地缺席只 WARN，同门禁 52 既有口径，不静默跳过。
- 动作判 `--expect-motion`：仅在标记为 motion 的帧区间开；按 `--motion-check 2000` 间隔 2000ms 取两帧，完全相同且该区间期望运动 → FAIL（外部 capture.py 退出码 5 同义；2000ms 是调用取值，不是脚本内置默认）；静止 / 播完停车态不开此判。
- `--expect-usable` 只挡明显不可见：近黑、近平面墙、无对比度；不判美术；刻意暗景与加载失败分开诊断，不许把数值标志直接当缺陷。
- 捕获工具路线（设计，不实施）：外部 `scripts/capture.py` 模式——命名视角 + 点击 + PNG + capture-log.json。本仓 CI 现栈为 Paparazzi 纯 JVM，出不了 WebView / WebGL 帧；WebView 两页需无头浏览器或 WebView 驱动路线，地球仪 Compose 页可评估并入既有 `:screenshot` 模块。路线未接通前，3D 帧门禁条目登记 DEFER，不伪造帧、不拿编译绿抵画面证据。禁止引入 Blender。

### 9.2 美术判据不进自动打分

- 自动门禁只判两件：帧在不在、动作有没有发生。
- 美术判断（剪影、材质、光影、构图、特效成本、传达）由独立验收代理逐帧人工核，按第三节 / 第四节判据逐条销项；不许把第三节条件性提示写成自动评分表，不许像素分高就算美术过。
- 自动可做的像素辅助：近黑 / 近白 / 对比度 / 裁切粗筛，只作 WARN 线索，不作 FAIL 美术结论。
