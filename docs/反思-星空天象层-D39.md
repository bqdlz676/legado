# 反思复盘 D39 反向链路 + 判据 2 三缺口（2026-11-28）

本单根因复盘与可复用规则。每条含：机制、根因、反例、沉淀规则。

## 1. 做了什么

- 新增纯 JVM `RegionHitResolver`：经纬度 → 州域锚点最近邻命中（带半径、并列先现者、非有限 / 空表回落 null），13 州域内联示意锚点表。
- `FieldAllocationLayer` 补 `regionForCodes` / `focusRegion`，异说条目不进主表；`GlobeController` 补 `focusFieldRegion/aimSkyTo/setObservationTime`，既有签名只增不改；`SkyInputHandler` 地球 tap 分支接反查并把选点经纬度写回 `setObserver`。
- 补三时刻天狼 / 织女 alt/az ≤1° 投影反演契约断言、观测点钳制与时刻注入单测。

## 2. 踩到的坑

- **空帧 NPE**：控制器用例初版忘了先 `enterSky` 建 `SkyFrame`；`nextFrame` 只在 `scene.sky != null` 时才写回 observer/LST，直接调 `nextFrame` 快照里 `sky!!` 空指针。046244b CI 分片 2 实测红在 `GlobeControllerTest.kt:50` 与 `:70`，修复提交 `8986a4f` 给两个用例补 `enterSky(SKY_HEAVEN)`。
- **根因**：测试先写断言路径，后想帧驱动前置条件；门面「未入星空不凭空建帧」是有意口径（`focusFieldRegion` 内部才建帧），纯状态测试必须先满足该前置。
- **沉淀规则**：门面 / 状态类单测先列「进入被测路径所需的帧前置」（sky 帧、观测点、注入时刻），再写断言；快照可空的字段一律先 `assertNotNull` 再取非空。

## 3. 可能错处

- 锚点表是 tier3 示意近似，半径与代表点未做地理拟合；触点落在两锚点覆盖带交界时归属可能偏差，一期口径已在注释与报告声明，不冒充真实州界。
- `focusFieldRegion(regionName, …)` 的 `regionName` 本期只存参数未参与计算；若后续投影反算接入时漏读该参数，聚焦州域可能与反查结果脱节。
- 注入时刻只改 LST 与弹簧起算时刻，未并入太阳方位驱动；回放场景下日月与星空时刻可能短暂不一致，属已知边界而非修完。

## 4. 遗留

- renderer 桥接（`SkyCanvasRenderer.focusRegion` 转发 layer + `asterismLayer.select`）与 host 视图尺寸注入（`setViewport`）在另一代理文件域，本单未接；运行时闭环待两域联调。
- N1 正向 starId→code 反查索引、N4 `exitSky` 反向弹簧、真实州域多边形数据沿用施工图 2.6 交接，不在本单。
- 沙箱禁编译，本单代码未在本地跑过编译；真值以 CI 为准（已在报告 §8 显式声明未验证项）。

## 5. 给下任一句话

反向链路先接通「经纬度→州域→视角」半条，选中高亮的最后一棒在 renderer 桥接；接手时先 grep `focusRegion` / `focusFieldRegion` 两侧消费方是否都在位，再补投影反算，不要先动 `SkyFrame` 字段。
