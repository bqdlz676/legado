## 1. 缺陷与本单结论

- 缺陷原文（`docs/问题清单.md` B18 行）：legacy `CardTokens.kt:109 disabledAlpha=0.30f` 与 `ComponentPalette.kt:77 DISABLED_OPACITY` 双源；`EmptyStateCard` 自持 `CardState` 无 Empty/Offline 档、Offline 仅文字压 0.35；书架 `ShelfState` 独立状态机不读 `contentAlpha/eventsAllowed`，`BookshelfScreen.kt:476/574/628-636` 与 `HandleFileSheet.kt:52` 裸 `clickable` 无状态闸；`componentStateOf`（`ComponentSystemContract.kt:65`）渲染零消费。
- 本单结论：
  1. 压淡系数收敛到 `ComponentPalette.DISABLED_OPACITY` 单源；`CardTokens.disabledAlpha` 改为转发常量，代码行不再内联 `0.30f`。

  5. 0.35 离线局部压淡**裁决移除**：契约 `OFFLINE.contentAlpha=1f` 为整组件唯一透明度口径（枚举语义不动），离线不可交互性只由事件闸表达。
- 视觉不变优先：禁用压淡数值维持 0.30；本单只收敛来源与补闸，不重新设计卡片外形 / 圆角 / 动效。
