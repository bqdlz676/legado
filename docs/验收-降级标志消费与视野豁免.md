口径分层核对（对照 `Pathfinder.kt` 三个 `degraded = true` 分支）：

- 第二级加价路径（`:107-112`，reason「敌军视野封锁全部绕行通路…仍可能暴露」）：路径实际穿越被加价的视野格，置 `exposed=true` 与「被看见是物理事实」一致，口径成立。
- 第一级落点兜底（`:97-102`，reason「目标周边无可通行落点」）：触发原因是目标及周边全不可通行，整条链路不涉及敌军视线；此时置 `exposed=true` 缺乏「被看见」依据。
- 第三级双封锁折线（`:114-118`）：reason 为「视野与地形双重封锁」，地形成分与视野成分混在同一布尔里；本单测试用例 16（`PathfinderTest.kt:227-250`）正是无敌军、纯地形水带横断，若该军在控制器层走 FLANK，按 `:574` 同样会被置 `exposed=true`。

反例推演：一支无敌军在场、仅被地形堵到折线兜底的侧翼军，旧口径下保留隐蔽、下回合仍可触发关隘设伏加成；新口径下它在未穿越任何视野环的情况下丧失伏击资格。侧翼的目的是隐蔽接敌，此情形属过度标记。

正确口径建议（供别单裁决，本单不要求返工编译）：暴露入账应按降级分级区分——只有第二级「加价穿越视野环」分支置 `exposed=true`；纯地形兜底（第一级，及第三级中无敌军视线参与的部分）只挂 `routeDegraded` 标识与事件日志，不废掉隐蔽姿态。寻路层可在 `FlankRoute` 上补一个区分「视野降级 / 地形降级」的字段，而不是让控制器按 `reason` 字符串反推。

缓解事实：`exposed` 当前只影响伏击闸门（`IntentResolver.kt:58`、`CampaignController.kt:602`），无直接兵力 / 士气 / 移动力扣减，过度标记的伤害上限是丢失伏击加成，不是直接战败；且 `docs/验收-复核-B8侧翼通视.md` R4 行原本就把「按 degraded 置 `corps.exposed`」列为可选消费口径之一。故不判硬性 FAIL，记判低项。
