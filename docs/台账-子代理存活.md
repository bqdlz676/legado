## 维护规则

1. 每派一单，若该代理在 24 小时内出现"零工具调用 / 首轮无 ANCHOR-ACK / 跑题内容"，调度层必须在本账登记一行并写清处置，否则门禁 ㉗ FAIL。
2. "判废"的代理一律不得再 send_message 唤醒续跑（写码与验收代理一次性用完即弃）。
3. 同一任务重派最多 2 次；第 3 次仍跑题，改为调度层自己做或拆成更小单（小单一次一问，降低退化面）。
4. 登记不代表免责：判废必须在 `docs/派单台账.md` 同步把该行的代理 id 改成重派后的 id，避免两条记录并存造成"在飞计数"虚高。
