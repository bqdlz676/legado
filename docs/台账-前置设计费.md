# 台账 · 前置设计费记账（F-85 净收益验证）

> 用途：用数据决定锚点卡投入强度。每次返工记一行；某类返工率 <5% 时，该类锚点卡可降级为"参数表版"（≤10 行）。
> 列：缺陷号 / 根因类 / 返工实际耗时 / 若前置设计预估耗时 / 是否本可避免。耗时为代理自报或调度层估时，不许编造精确值。

## 口径

- 根因类枚举：凭记忆转述规格 / 锚点缺失 / 参数表漏项 / 判据不可测 / 跨域接口漂移 / 其它。
- "是否本可避免"＝若前置锚点卡三件套齐全，该返工是否不会发生；填"是/否/部分"并在备注说明。
- 返工率统计口径：同类功能交付数为分母，本台账记行为分子；每收口一个大模块复盘一次。
