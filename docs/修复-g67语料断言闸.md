## 三、判据实现

扫描域：`app/src/test/**`、`screenshot/src/test/**` 下全部 `*.kt`。四类判据：

1) LITERAL-ENTRY：断言期望值（assertEquals 首参或断言体内字面量）是汉字串且精确命中种子条目——`CHAR_TSV` 字头、`WORD_TSV` 词目、典故词目、人物名/别名、地名/别名、名物名/别名（种子表见 `DictSeedData.kt:22` 字表、`:510` 词表；其余内存种子在 `AllusionSeed.kt`、`PersonDirectory.kt`、`PlaceSeedData.kt`、`ArtifactSeedTable.kt`）。
2) LITERAL-TSV：断言字面量是制表符分隔的语料行形态（字头 `\t` 拼音 `\t` 部首 `\t` 笔画，或词目 `\t` 训释 `\t` 标签），即把 TSV 行整行搬进断言。
3) API-EXPECTED：断言期望值取自语料查询 API 返回值再比较。直接形态：比较型断言体内出现 `ChineseDict.wordAt(...)` / `getChar(...)` / `getShuowen(...)` / `getUsage(...)` / `counts()` / `queryToken(...)` / `.shu(...)` / `.collate(...)`；绑定形态：`val expected = <语料 API 调用>` 后该绑定名进入比较型断言。
4) CORPUS-WORDING：断言带「必须在种子内 / 应命中 / 未收录 / 不应命中 / 必须收录 / 未被收录」之类数据依赖字样，且同文件引用了语料常量或语料 API。

五类放行（SKIP 标签计数进末行，可审计）：

- SKIP:NONHAN：字面量不在汉字区间（`※` U+203B、ASCII、标点、数字、表情），机制上不可能进任何汉字种子索引。
- SKIP:ECHO：该字面量同时是同一用例里被测函数调用的入参，断言的是入参透传一致性，不是种子收录现状。
- SKIP:SELF：断言两边都是被测函数自身输出的派生表达式（如 `assertEquals(atLast.token, clamped.token)`），无字面量参与。
- SKIP:STRUCT：非空 / 非崩 / 不空白 / 列表空这类结构完整性断言（assertNotNull、`body.isNotBlank()`、`actions.isEmpty()` 等）。
- SKIP:INVARIANT：纯函数不变量断言（数值上下界、长度区间、下标夹取范围），与种子收录与否无关。

口径：默认 `--changed` 只判相对 `origin/main` 的改动面（历史存量不判红）；`--audit` 全仓只登记计数与清单，不从 0 变红墙。空集（无待检测试文件）报 EMPTY、退出码 2，不表述为 PASS（同 ㊾ / check-triple-anchor / check-report-fields 空集口径）。

## 六、自查反例（改坏推演）

- 反例一：若把「断言体内出现汉字」一律判红，正常的结构断言与不变量断言会成片误杀。实现按五类放行分流：非汉字符号、输入回显、输出自洽对比、结构完整性、纯不变量各打 SKIP 标签计数，放行可审计；`※` 与夹取一致性两例独立夹具打绿。
- 反例二：若种子表只收 `DictSeedData.kt`，典故词目、人物别名、地名别名、名物别名这类同样会漂移的专名就漏判。实现把 `AllusionSeed` / `PersonDirectory` / `PlaceSeedData` / `ArtifactSeedTable` 的 `word/name/canonicalName/preferred/courtesy/style/aliases` 字段一并入表（`:246`）；种子文件缺失时降级为空表，不误报、不崩。
- 反例三：若把语料 API 调用出现在 assertNotNull/assertNotNull 结构断言里也判 API-EXPECTED，「种子条目非空」这类结构核验会被误红。实现只在比较型断言（assertEquals/assertNotEquals/assertThat）体内或绑定名进入比较型断言时才落 API-EXPECTED；纯非空/不空白结构断言走 SKIP:STRUCT。
- 反例四：若全仓存量一上来就 blocking 红，31 个存量文件 171 处候选会把闸压成红墙。实现默认只判改动面，全仓走 `--audit` 清单只登记不判红；空集 EMPTY rc=2 不表述为合规，也不记失败。
- 反例五：若注释面里写着「未收录字」字样也被当判据，KDoc 自证会假红。实现先剥 `//` 与 `/* */` 注释面再判代码面（`:109`），字符串字面量原样保留，断言消息文案与代码调用分列。
