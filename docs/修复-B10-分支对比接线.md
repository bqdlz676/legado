### 4.1 对比行数与差异项计算（模型层）

- 暴露差异：`BranchCompareAssemblyTest.kt` `exposed posture difference is flagged as exposed field`——两侧 exposed 一真一假，期望字段集恰为 `{EXPOSED}`；反向同姿态例 `exposed same posture is not flagged` 期望空集。
  - 改坏推演：若把 `CampaignModels.kt:447` 暴露比较删掉，正例期望 `{EXPOSED}` 立即变红；若改成恒标暴露，反向同姿态例变红。
- 单侧事件：`events present on only one side are split into one-sided lists`——事件只在左线，期望 `eventOnlyLeft` 含该条、`eventOnlyRight` 为空，双侧 events 列表分别落位。
  - 改坏推演：若集合差键改成只比 `text` 或漏掉 `attribution`，同文案异归属事件会被误判一致，本例两侧 only 列表断言变红。
- 胜负档位：`result diff flags status mismatch and winner mismatch`——状态不同、胜方不同各标 `resultDiff=true`，同档位同 null 胜方为 false。
  - 改坏推演：若 `resultDiff` 误写成只比 status，胜方不同例变红；若 null 与非 null 被误判相等，缺胜方差例变红。
- 告警透传：`warnings null stays unknown while populated lists pass through`——null 保持 null（未知），有值列表原样透传。
  - 改坏推演：若装配 / diff 把 null 兜底成空表，`assertNull` 变红，壳层将不再显示「未知」。
- 回合一致：`turn identical requires no corps diff no one-sided event and same result`——全一致 `turnIdentical=true`，单侧事件即 false。

### 4.2 装配三态行为锁（纯函数，无 Compose 运行时）

- `no archived branch resolves to NeedArchive`：存档 null → NeedArchive，条数 0、本线回合数透传；`empty archived line also resolves to NeedArchive` 空表同态。
  - 改坏推演：若装配把空存档当成失效或就绪，两例的态断言变红。
- `empty current line resolves to Invalidated with current-empty reason` / `archive line with no visible corps resolves to Invalidated`：两类失效原因常量逐字锁定。
  - 改坏推演：原因常量被改写或两类失效路径互换，`assertEquals(REASON_...)` 变红。
- `two equal lines resolve to Ready identical` / `two differing lines resolve to Ready non-identical` / `different line lengths are not identical`：就绪态透传两侧线与告警；同线 identical=true，兵力差 / 线长不同 identical=false。
  - 改坏推演：若 identical 判定只比军队不比事件 / 胜负，事件差例或线长例变红；若线长不同时截断对齐，长度例变红。

### 4.3 入口接线行为锁

- `entry disabled when current battlefield has no visible corps`：无军队时存档 / 对比均禁用，原因「当前战场无可视军队」。
- `compare disabled until at least one branch archived`：有本线无存档时可存档、对比禁用，原因「先存档一条分支再对照」。
- `both actions enabled with alive battlefield and one archive`：本线在册且 ≥1 存档，两按钮可用、原因为 null。
  - 改坏推演：若壳层绕过 `CompareEntry.decide` 另写启用口径，或判定把存档条数门槛改成其它值，三例的 `canSave / canCompare / reason` 断言变红。

### 4.4 壳层可判定状态（纯函数抽出）

- `render mode placeholder / empty note / rows`：null → PLACEHOLDER，空军队 → EMPTY_NOTE，有军 → ROWS。
