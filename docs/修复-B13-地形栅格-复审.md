### 4.2 内存（F-04 ≤100MB 三档口径）

- 正常路径：1024² 灰度 → raw 1MB + 灰度 IntArray 4MB + FloatArray 4MB，瞬态约 9MB。
- 护栏路径：超 2048 见方或 4MP 先降采样；IHDR 声明超 8MP / 8192 单维直接拒绝回落合成，不分配像素缓冲。8MP 上限下三态峰值估算 ≤96MB（raw ≤32MB + IntArray ≤32MB + FloatArray ≤32MB），贴线但不越 100MB；常规战役图远低于此。
- 推演网格侧仍由桥接重采样到 32×32（`GRID_N`），常驻栅格仅 1KB 级。

### 4.3 反例与边界（至少 3 条，均有兜底）

1. **空数据 / 断网 / 资产缺失**：reader 返回 null 或抛异常 → `decode` 回落 `synthesize(heightMap 串哈希)`，`degraded=true`，不空白、不崩。
2. **非 PNG / 损坏字节 / 截断 IDAT / 非法 filter 码 / 畸形 chunk 长度**：`decodeBytes` 逐级返回 null → 合成场；不把异常抛到 UI。
3. **超大图 / 恶意头声明天文尺寸**：硬上限先拦（8MP、8192），软上限降采样（2048、4MP）；最近邻采样确定性可复算。
4. **字段类型错位**（对象 / 数组 / JsonNull）：仍走原 `strOrNull` 守卫回落 null，本单未改该口径。
5. **同名消歧 / 同名资产**：本层不做同名消歧，按字符串原样交 reader；查不到即合成兜底，不假装解码成功。
6. **16-bit 深 / Adam7 隔行 / 非支持色彩类型**：显式回落合成（能力边界，非崩溃路径）。

### 4.4 认知成本

- 新增概念两层：`SourceKind`（来源分类）+ `HeightMapRaster`（0..1 FloatArray 栅格）。与既有 `HeightRaster`（0..255 IntArray）并存，命名与值域在类注释里互相指明换算关系，避免接手人混用。
- 解码器把「字节→栅格」抽成零依赖纯函数，BitmapFactory 不进引擎层；单测可在普通 JVM 跑，无需 Android 环境。
- 遗留易混点：parser 暴露的 `decodeHeightMap` 与桥接 `RasterDecoder.decode` 是上下游关系（前者纯 JVM 装配入口，后者平台接口），报告交接节已注明；建议下一单在 controller 接线时把两条路径合并表述。

### 7.5 二阶三阶影响（补）

- 直接效果：装配链在壳层未显式传栅格时按 `heightMap` 字符串解码；0..1 栅格在 `toHeightRaster` 单点换算为 0..255 `HeightRaster`，`TerrainMap` / 通视 / 坡度消费口径不变。
- 连带影响：`CampaignController.definition` 在解码失败时被 `copy` 追加 warning；既有 `warnings` getter `CampaignController.kt:153` 只读 `definition.warnings`，故并入后壳层同一通道可读，未新增第二条警告通道。
- 二阶：内联 base64 成功解码后 `raster.degraded=false`，控制器 `degraded` 判定（`definition.degraded || raster.degraded || corps.isEmpty()`）不再因无图置降级；资产 / 路径类因引擎层无 reader 仍回落合成，行为与旧兜底一致。
- 三阶：模型层仍无栅格字段，0..1 原始产物暂挂 internal 属性；待 model 单接纳后可直接消费该属性，无需再经桥接二次解码。

### 7.6 反例与边界（补）

1. **多块 deflate / 大 IDAT 短读**：M3 循环充气到 `finished()`；`needsInput()` 为真而未结束按截断判 null，回落合成，不把短读误判为合法栅格。
2. **含 `/` 或 `+` 的裸 base64**：字符集判定先于路径分隔符，不会再被误判 ASSET；反之含 `/` 的短相对路径（`assets/map/x.png`）仍走资产通路。
3. **解码失败 / reader 缺失 / 断网**：回落确定性合成场，warning 并入既有 `warnings`，`degraded=true`，不空白、不崩。
4. **天文尺寸恶意头**：硬护栏在 inflate 前拦截（>8192 单维 / >8MP），不分配像素缓冲；软护栏超限走最近邻降采样。
5. **字段类型错位 / 空白串**：仍走原 `strOrNull` 守卫；空白时不重复记 warning，保持旧合成兜底口径。

### 7.7 认知成本（补）

- 新增概念两处：`resolveHeightMap`（装配点解码 + warning 回写）、`toHeightRaster`（值域换算单点）；命名与注释标明 0..1 / 0..255 两套值域边界。
- 遗留易混点：internal `heightMapRaster` 是 model 接纳前的临时挂载位，注释已标「待 D24」；接手人不应把它当公开稳定 API。
