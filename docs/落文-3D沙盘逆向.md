# 长安 · 3D 沙盘 —— 逆向拆解

> 对象：`app/src/main/assets/map/three.html`（单文件，17 KB 级）
> 技术栈：Three.js（`three.min.js` 本地内置 670 KB）+ 一块灰度高程 + 纯 Canvas/SVG 自制 UI
> 无后端、无地图瓦片服务、无网络请求 —— `file://` 直接可开

---

## 一句话结论

**它不是地图，是一块被涂了色的 3D 高程网格。**
地表颜色不是灯光照出来的，是开机时按海拔逐顶点烘焙好的顶点色；三盏灯基本不参与（地形用 `MeshBasicMaterial`）。

## 一、画面七层，从后往前

| 层 | 内容 | 实现 | 关键参数 |
|---|---|---|---|
| L0 | 深底 + 雾 | `scene.background` / `Fog` | `#1C1A14`，雾 240–640 |
| L0.5 | 纸纹噪点 | 128×128 canvas 随机灰 → `toDataURL` → CSS `background-repeat` | 灰度 128±22，alpha 22，整层 opacity .5 |
| L1 | 地形 | `PlaneGeometry(300,300,SEG,SEG)` + 顶点色 | SEG=160（旧）/288（现）；`MeshBasicMaterial({vertexColors:true})` |
| L2 | 势力面 | `ShapeGeometry` 由疆域多边形生成，`rotateX(π/2)` | opacity 0.18–0.25 正弦呼吸，`depthWrite:false` |
| L3 | 疆域边线 | 每个面再套 `EdgesGeometry` | 暗金线，比填充略亮 |
| L4 | 城池 | `SphereGeometry(1.4)` 金点 + `Sprite` 文字 | 点 #D4A54A；字用 256×64 canvas 纹理，`depthTest:false`，scale 26×6.5 |
| L5 | 光柱 | `Points`，每城 8 点 | size 0.9，色 #B0863C，y 随时间 `(t*1.6+phase)%9` 循环上升 |
| L6 | UI | HTML/CSS 绝对定位 | 左上地名+今名、右上"二维图"、右下四键、左下操作提示 |

## 二、坐标：把经纬度摊平到 300 单位

```js
var SIZE = 300;
var HG = { w:104, e:122, s:24, n:42, px:1024 };   // 覆盖 104–122°E / 24–42°N

function lonU(lng){ return (lng - HG.w)/(HG.e - HG.w) * SIZE - SIZE/2; }
function latV(lat){ return (HG.n - lat)/(HG.n - HG.s) * SIZE - SIZE/2; }  // 现版：等经纬度
```

- 300 单位 ≈ 18° × 18° ≈ **1730 km** → **1 单位 ≈ 5.8 km**（行军里程就是按这个换的：`km=(d/300)*1730`）
- 旧版 `latV` 用的是墨卡托 `log(tan(π/4+φ/2))`，而高程栅格是等经纬度 —— 两套投影不一致，山脊和城池整体错位。现版已改为线性。

## 三、地形怎么起来的

```js
var geo = new THREE.PlaneGeometry(SIZE, SIZE, SEG, SEG);   // 300 × 300 的网格，SEG×SEG 顶点
geo.rotateX(-Math.PI/2);

function hAt(x, z){                        // 双线性采样高程栅格
  var u = (x + SIZE/2)/SIZE * (HG.px - 1);
  var v = (z + SIZE/2)/SIZE * (HG.px - 1);
  ...                                    // 四点加权
  return h / 255 * TOP;                  // 旧版 TOP=3000，现版 7000
}

function yOf(x, z){ return hAt(x, z) * K; }  // 垂直夸张：旧 0.015 / 现 0.009
```

每个顶点 `y = yOf(x,z)`，法线由网格自算，然后**逐顶点烘焙**：

```js
var LIGHT = new THREE.Vector3(-0.42, 0.80, 0.42).normalize();   // 左上暖光方向
var nd = Math.max(0, nx*LIGHT.x + ny*LIGHT.y + nz*LIGHT.z);
var k  = 0.5 + 0.62 * nd;                                        // 0.5~1.12 的明暗系数
colors.push(col.r*k, col.g*k, col.b*k);
```

**这是整张图的灵魂**：山体的"金顶 + 暗沟"完全来自这一乘法，与 Three.js 灯光无关。所以换灯不换色，改 `LIGHT` 才有效果。

色带（按海拔米数分段 lerp，旧版标尺）：

```
   < 20 m   0x394852  深蓝灰（水面）
 < 480 m   0x49545C → 0x5E6050   平原草黄
 <1100 m   0x5E6050 → 0x77684A   丘陵褐
 <2200 m   0x77684A → 0xB8A88A   山地暖灰
 ≥2200 m   0xB8A88A → 0xCEC2A8   山顶米白
```

## 四、相机：绕着地块做球面漫步

```js
var camera = new THREE.PerspectiveCamera(46, W/H, 0.1, 2000);
var rotY = 0, rotX = 0, dist = 300;      // dist 可拉 90–560

var cx = TARGET.x + Math.sin(rotY) * dist * Math.cos(rotX + 0.28);
var cz = TARGET.z + Math.cos(rotY) * dist * Math.cos(rotX + 0.28);
var cy = TARGET.y + 135 + Math.sin(rotX + 0.28) * dist * 0.5;
```

- 固定仰角偏移 `+0.28 rad`（≈16°）—— 这是"低机位掠射"的来源，山才有纵深
- `rotX` 限 -0.55 ~ 0.5 rad，`rotY` 无限制
- 自转 0.0016 rad/帧 ≈ 每圈 65 s

光照三盏只是氛围（环境 `0x7A6444` 0.55 / 主光 `0xFFDCA8` 1.3 在 -140,205,70 / 轮廓光 `0x2F3A44` 0.38 在 155,60,-150）—— 地形不吃，只为以后换 `MeshLambert` 留的。

## 五、交互

| 动作 | 实现 | 参数 |
|---|---|---|
| 单指拖动 | pointerdown/move | `rotX += dy*0.004`，`rotY += dx*0.003` |
| 双指缩放 | touchmove 两指距差 | `dist -= Δ*0.8`，钳 90–560 |
| 滚轮缩放 | wheel | `dist += deltaY*0.35` |
| 点地形落兵 | raycaster 打 terrain | `CylinderGeometry(0.5,0.5,9)`，朱砂 `#B33A2B`，插在 `p.y+4.5` |
| 落点扩散环 | `RingGeometry(0.92,1.0,64)` | 1.5 s 内 scale 1→16，opacity 0.9→0，AdditiveBlending |
| 行军线 | 逐点 `THREE.Line` | 色 `0xE0B459`，贴地 +1.2 |
| 里程 | 两点距离 / 300 × 1730 | 按日行 30 里推天数 |

## 八、要复用到别处，只需要四样

1. `china_height.png`（1024 灰度，0–255 ↔ 0–7000 m）
2. `cities.js`（158 城 `[lat,lng]`）
3. 两个换算函数 `lonU` / `latV` + 一个采样 `hAt`
4. 顶点色烘焙那一行 `k = 0.5 + 0.62 * nd`
