- **⑤ 出处**：

### 条文 2.1 · 缺字回退——工程推定，需用户拍板

- **① 触发条件**（可观测）：待排字形不在首屏 2500 字子集的 unicode-range 内（子集范围见 `切片-14:7`「CJK subset：unicode-range 分片，正文常用 2500 字首屏子集 ≤ 200KB」）；或字形取到 `.notdef`（推定检测口径：绘制后字形度量 / 字形 ID 命中 notdef 即为缺字）。
- **② 降级动作**（回退链，参数为推定默认顺序）：
  - 正文汉字：Noto Serif SC 子集 → 系统衬线（serif）→ 系统默认字体；
  - 注音字：Noto Sans SC Light 缺失时回退系统无衬线（sans-serif）；
  - 数字 / 年份：Inter Tabular Nums 缺失时回退系统等宽数字，再退比例数字；
  - 等宽编号：JetBrains Mono 缺失时回退系统等宽字体；
  - 回退字沿用当前字号与基线，不做单字缩放、不换颜色。
- **③ 不许降的底线**：
  - 正文可读字号不缩小（正文 18sp 规格归 S-09，本规格不动字号）；注音 10sp 不缩（`切片-14:7`「注音小字Noto Sans SC Light 10sp延迟加载」）；
  - 缺字不得渲染 `.notdef` 方框 / 豆腐块；
  - 单字缺字不得拖垮整段排版，不允许整段文字不显示。
- **④ 判据**：构造含子集外生僻字 / 异体字的文本用例，断言无 notdef 字形、回退命中系统字体族、段落行数与基线不塌；回退链常量可 grep 回源；五枚子集各自的回退目标可枚举。
- **⑤ 出处**：
  - 2500 字子集范围、五枚分工：`切片-14-字体系统.md:7`「CJK subset：unicode-range 分片，正文常用 2500 字首屏子集 ≤ 200KB。」；
  - 回退链顺序、notdef 检测口径、基线对齐细则：**工程推定，需用户拍板**；
  - 零命中证据：附录 A.2（缺字 / 回退 / fallback / 系统字体 / 豆腐 / notdef 在切片-14 均 0 命中）。

### 条文 2.2 · 字体包加载失败——工程推定，需用户拍板

- **① 触发条件**（可观测）：子集文件缺失 / 损坏 / sha 校验失败 / 读取被拒；或 `InkFontLoader.init`（`规格登记册.md:109`）加载回调异常或超时。超时阈值为推定默认 800ms（理由：`切片-08:52`「首屏渲染 < 400ms」，字体等待不得阻塞首屏，超时上限取首屏口径的两倍留余量）。sha 校验为推定兜底手段，切片未要求校验。
- **② 降级动作**：
  - 按 font-display: swap 口径先用系统字体排版，子集后台到位后再替换字形（`切片-14:7`「正文（宋体）Noto Serif SCfont-display: swap，预载首屏子集 ≤ 200KB」）；
  - 标题 SemiBold 虽为首屏阻塞档，加载失败也必须落系统粗体，不允许 FOIT 白屏等待（`切片-14:7`「标题思源宋体 SemiBold首屏阻塞，swap 不允许 FOIT」）；
  - 单枚子集失败隔离：其余四枚（注音 / 数字 / 等宽 / 正文或标题中未失败的一枚）继续各自加载，不被失败项拖垮；
  - 子集回补后仅做字形替换，不动布局位置（推定：避免就位后整页 reflow 跳动）。
- **③ 不许降的底线**：
  - 首屏必须可见文字，不允许 FOIT 白屏等待（`切片-14:7`「swap 不允许 FOIT」）；
  - 已排布局不因子集到位二次跳动；
  - 注音 10sp、数字等宽对齐口径在系统回退下尽量保持；单枚失败不允许拖垮其余子集。
- **④ 判据**：逐个摘除 / 损坏五枚子集文件，首屏均以系统字体可见、无白屏等待；子集回补后字形可替换且文字位置不跳；加载失败日志记录子集名与失败原因（缺失 / 损坏 / 校验失败 / 读取被拒 / 超时可区分）。
- **⑤ 出处**：
  - swap 口径、FOIT 禁令、五枚分工、200KB 上限：`切片-14-字体系统.md:7` 逐字引文（见上）；
  - sha 校验、超时 800ms、失败隔离、回补不 reflow：**工程推定，需用户拍板**；
  - 零命中证据：附录 A.2（校验 / 加载失败 / 损坏 / 回退 在切片-14 均 0 命中）。

### 条文 3.1 · spring 刚度 / 阻尼逐项数值——工程推定，需用户拍板

- **① 触发条件**：本条文是参数缺口，不是运行时边界；触发场景为七项动效任一项以 spring 物理模型实现时，刚度（stiffness）与阻尼比（dampingRatio）取值须按下列七项逐条落位。
- **② 降级 / 取值动作**：七项逐一列推定默认值（切片无原文，全部为**工程推定，需用户拍板**；下列「现状值」仅为 `app/` 既有代码常量，供对照，不构成规格出处）：
  1. **点触反馈（InkButton）**：切片 `:7`「点触反馈（InkButton）120ms—」；推定 stiffness 400、dampingRatio 0.85（理由：120ms 微交互需快速回位，近临界阻尼、不留回弹）；现状无独立常量可对照。
  2. **气泡弹入**：切片 `:7`「气泡弹入250mscubic-bezier(0.34,1.56,0.64,1) overshoot」；推定 stiffness 300、dampingRatio 0.55（理由：overshoot 过冲对应欠阻尼，阻尼比 <1）；现状 `ComponentPalette.kt:116-117` BUBBLE 0.55 / 300f 同档。
  3. **卡片浮入 stagger**：切片 `:7`「卡片浮入 stagger350ms eachcubic-bezier(0.22,0.61,0.36,1)」；推定 stiffness 360、dampingRatio 0.80（理由：减速入、稳落不晃，接近临界阻尼）；现状 `ComponentPalette.kt:124-125` REVEAL 0.80 / 360f 同档。
  4. **翻页掀角**：切片 `:7`「翻页掀角400mscubic-bezier(0.4,0,0.2,1)」；推定 stiffness 220、dampingRatio 0.75（理由：掀角位移行程大，刚度取低、留轻微回弹）；现状 `InkTokens.kt:227` PEEL_SPRING_STIFFNESS 220f、`:230` PEEL_SPRING_DAMPING_RATIO 0.75f 同档。
  5. **遮罩淡入淡出**：切片 `:7`「遮罩淡入淡出200mscubic-bezier(0.4,0,0.6,1)」；推定 stiffness 320、dampingRatio 0.72（理由：对称进出，跟 Sheet 同档）；现状 `ComponentPalette.kt:120-121` SHEET 0.72 / 320f 同档。
  6. **Sheet 弹起**：切片 `:7`「Sheet 弹起250ms默认 ease-out」；推定 stiffness 320、dampingRatio 0.72（理由：面板跟手弹起，临界偏欠阻尼）；现状同 SHEET 常量。
  7. **加载三点 600ms 循环**：切片 `:7`「三个竖排云灰小点依次亮灭 600ms 循环，不放菊花」；不适用 spring（循环指示动画走插值器 / 相位交替，不取 stiffness / dampingRatio）。
- **③ 不许降的底线**：
  - 七项时长与曲线必须逐项对片（`规格登记册.md:110`）；spring 只替换运动模型，不改 `:7` 给定时长；
  - 推定值拍板前不得覆盖既有冻结 token；现状常量与推定表不一致时，列入待拍板清单，不静默改值；
  - 加载三点循环不得改成菊花（`切片-15:7`「不放菊花」）。
- **④ 判据**：静态断言七项时长 / 曲线与 `:7` 一致；spring 常量表逐项可 grep 回源（每项动效 ↔ stiffness ↔ dampingRatio 一一对应）；现状代码常量与推定表的差异有台账记录；加载三点无弹簧常量引用。
- **⑤ 出处**：
  - 时长 / 曲线：`切片-15-全局动效铁律.md:7` 逐字引文（见上七项）；
  - 全部 stiffness / dampingRatio 数值：**工程推定，需用户拍板**；
  - 现状代码值：`app/src/main/java/io/legado/app/ui/components/ComponentPalette.kt:116-117`、`:120-121`、`:124-125`；`app/src/main/java/io/legado/app/ui/book/read/ink/InkTokens.kt:227`、`:230`（现状，非规格原文）；
  - 零命中证据：附录 A.3。

### 条文 3.2 · 系统动画关闭 / 无障碍 reduce-motion 降级——工程推定，需用户拍板

- **① 触发条件**（可观测，检测口径为推定）：系统「移除动画」开关开启（推定读取 `Settings.Global.ANIMATOR_DURATION_SCALE` = 0）；或无障碍 reduce-motion 通道开启（推定；本仓切片与既有落文均无该通道表述，附录 A.3 0 命中）。
- **② 降级动作**：
  - 位移 / 旋转 / 缩放类 spring 与 tween 动效时长置 0，直接落到终态；
  - 淡入淡出类保留最短淡入：推定默认 80ms（理由：完全无淡入会造成元素突现，80ms 低于 `:7` 微交互 120ms 下限）；
  - stagger 逐张延迟取消，屏内项同帧入画（对照 `切片-15:7`「卡片浮入 stagger350ms each」）；
  - 加载三点 600ms 循环：reduce-motion 下退为静态三点或极简明暗交替，不做循环位移；
  - 省电模式并入本路径处理（`立项草案-批次B.md:32`「低帧率/省电动效降级边界无原文」）：省电档先停 stagger 与悬浮微粒装饰，再按本条收敛。
- **③ 不许降的底线**：
  - 交互功能不降级：点按仍有状态反馈（朱砂浸染 0→8% 保留为静态色变，色值口径归 S-04）；
  - 页面内容完整可见，翻页仍必须完成，只是无掀角过渡（对照 `切片-15:7`「翻页掀角400ms」）；
  - reduce-motion 下不允许动画帧空转耗电；遮罩 / Sheet 进出状态正确，不留半透明残留。
- **④ 判据**：模拟 duration scale = 0，断言无位移 / 旋转 / 缩放动画播放、stagger 延迟为 0；点按态变色可用；列表 / Sheet / 遮罩内容完整；主线程无动画帧堆积；降级开关读取路径可 grep 回源。
- **⑤ 出处**：
  - 降级行为、80ms 淡入默认值、检测口径：**工程推定，需用户拍板**；
  - 七项时长基线 `切片-15-全局动效铁律.md:7`；点触反馈 `:7`「点触反馈（InkButton）120ms」；掀角 `:7`「翻页掀角400ms」；三点循环 `:7`「三个竖排云灰小点依次亮灭 600ms 循环，不放菊花」；
  - 零命中证据：附录 A.3。
