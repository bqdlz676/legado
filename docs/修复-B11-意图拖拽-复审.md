## ④ 三节分析

### 二阶三阶影响

- **与 B10 双栏共存**：`BranchCompareShell` 是纯展示子组件，不持有引擎状态、不回写控制器；本单只改单壳 `CorpsRoster` 交互，两者无共享状态、无交叉入参。B10 的 diff 高亮弹簧（348）与本单意图弹簧（538/646）各自独立 `animateFloatAsState` 实例，互不串扰。
- **与 B14 过渡动画的关系**：意图切换/面板选中态全部走 `compareSpring()`（REVEAL 阻尼 0.80、刚度 360，与 B10 同口径），未引入新弹簧参数；文件内残留的 `delay(600ms)`（80）是自动推演回合节拍，属 B14「固定 delay 改 spring」范围，本单按域未动。
- **拖拽对阅读页手势的全局冲突**：本单 `pointerInput` 只挂在 roster 行与面板芯片两个局部节点；地图画布的双指手势在纯函数层直接 `Ignored`（预留给地图缩放/平移）。阅读页翻页手势位于 `ui/book/read/**` 独立组合层，不经过本修饰链，无全局抢占。
- **连带接口**：`overrides` 写入口径（`Map<String, Intent>`）与 `host.step(overrides)` 签名均未变；引擎/模型/地形零改动。

### 反例与边界

1. **手指出界**：拖拽向量累积在 `dragVector`，抬手 `onDragEnd` 才解析；手指滑出行范围不产生额外命中区；`onDragCancel` 复位向量，不留脏状态。
2. **中途取消**：`detectDragGestures` 取消回调清空向量；长按判定后位移超过 `longPressCancelPx`(18px) 即作废长按、转入拖拽通道（纯函数 `resolveGesture` 已覆盖该分支）。
3. **连拖**：每次 `dragEnd` 清零向量；弹簧按当前目标值自然衰减，快速连续切换不叠帧、不丢帧闪烁。
4. **空列表 / 全灭**：`aliveCorps` 为空 → 显式「该回合无可选意图」态 + 无障碍描述；后端下发未知意图字符串时，`Intent.fromLabel` 兜底 HOLD（既有口径），解析层未知区码返回 `Ignored`，不改写意图。
5. **超短拖**：位移 < `minDragPx`(24px) 判误触 `Ignored`；**超长拖**：> `maxDragPx`(160px) 不归零、不产生越界意图，仍按角度归最近八向；**斜向**：45° 等长向量落对应象限；**双指**：`pointerCount > 1` 直接 `Ignored`。以上均有表驱动用例。

### 认知成本

- 新增概念 3 个：`IntentGestureChannel`（手势通道）、`IntentGestureSpec`（意图-手势契约）、`GestureResult`（解析结果密封类）；纯函数入口 `resolveGesture` 无 Compose 依赖，可直测。
- 映射表集中在 `IntentGestureMap`：新增意图只改这张表 + 必要时补罗盘八向；交互文案、无障碍语义、单测区码都从表里取，不存在第二套口径。
- 阈值收口在 `GestureThresholds`，调手感只改一处；`dial`（罗盘方位）与 `zone`（面板区码）命名区分两条通道。
- 待澄清：罗盘八向在窄 roster 行内纵向行程有限，真机若误触率偏高，后续可把长按展开物改为径向罗盘；当前面板 12 枚直选已兜底可达性。
