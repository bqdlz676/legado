## 二、历史参考要点（对照用，不照搬）

1. **点字交互**：旧版"点击先逐字命中 → 命中汉字弹字义气泡 → 落空才判左右边缘翻页"。仅作交互顺序的历史对照，当前按冻结契约 `VerticalLayoutEngine.hitTest` / `BubbleResolver.resolve` 独立实现。

3. **长文防 OOM**：旧版"单章压 3000 字 + StaticLayout 1.2 万字截断"。当前走 legado 排版层的真分页，兜底策略按当前边界红线自定。
