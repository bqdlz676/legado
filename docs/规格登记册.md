# 落文 · 规格登记册（完整性唯一权威）

> 每一项规格在此登记**唯一编号 + 立项缺陷号 + 验收档位**；`data_scripts/spec-check.sh` 每轮机械检查，保证不漏项。
> **状态机**：`[待立项]` → `[已立项]` → `[已验收]`；`[已否决]` = 显式废弃（不再追）。
> **完整性判据**（spec-check.sh 机械判，非人工）：① 切片编号连续；② 本册无 `[待立项]` 硬遗留（每条要么立项、要么显式否决）；③ 每条 `[已立项]` 都有缺陷号、每个缺陷号都能回源到本册某条规格。

## 新规格怎么进来（铁律 E13，每轮必做）

1. 用户**新增**要求 → 当轮抽成一条规格 → 给唯一编号（新增用 `N-001` 递增）→ 登记进「四、新增规格」分区，状态 `[待立项]` → 立项到 `docs/问题清单.md`（立缺陷号）。
2. 用户**修改**既有规格 → 更新对应那一行（改规格描述 + 标注变更），**不重复登记新行**。
3. 每轮结束前 + 每次 commit 前跑 `bash data_scripts/spec-check.sh`；有 `[待立项]` 遗留就当场立项或显式否决，不许拖着。
