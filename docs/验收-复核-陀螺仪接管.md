## 九、判据 9：写码方自报三处疑点逐条定裁

### 疑点一：四金点五档（0.04–0.20）与「第四点亮 = 0.08」自相矛盾 — 裁定：规格本身矛盾；实现取舍可接受，残留 UI 粒度限制登记 N4

- 代码事实：`gyro.js:38` 档位表 `[0.04, 0.08, 0.12, 0.16, 0.20]` 五档；`app/src/main/assets/map/gyro.js:254` 金点循环 `for (var i = 0; i < 4; i++)` 仅四点；`app/src/main/assets/map/gyro.js:39` 默认 `weightIndex = 1`（0.08，第二点亮）；`app/src/main/assets/map/gyro.js:284` `dots[i].className = 'gd' + (i <= weightIndex ? - 算术反证矛盾：四枚金点按 0.04 步进，第四点只能落在 0.16；若第四点 = 0.08，步进须为 0.02；而 §三区间 0.04–0.20 按 0.04 步进须五档。「四点 / 每点 0.04 / 第四点 0.08 / 区间到 0.20」四个条件不能同时成立，属规格内部互斥，非写码方实现错误。
