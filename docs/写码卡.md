# 写码卡（W 卡 · 项目本体）

> 这张表就是项目本身：整个项目切成多少张写码卡，它就有多大。不另建台账、不另设队列。
> 卡先冻结，代理按需创建；执行时从"前置卡已过且状态待取"的卡里取，5 槽里 3 写。
> 每张 W 卡有一张 V 卡与它同号（`docs/验收卡.md` 里的 V-0NN），别人不许验。

## 卡上字段

1. 名称：模块 ID + 名字。
2. 文件域（独占）：只有这张卡能写这些文件或目录，越界即冲突（父子目录也算重叠）。
3. 触及文件清单（glob）：由文件域机械生成——目录补 `/**`，具体文件原样放，已有 glob 原样保留；不凭空加路径。
4. 判据条数：对应锚点卡"判据"段的条目数（整数）；锚点卡未写的填 3。
5. 前置卡：必须先落成的 W 号，无则 `—`。
6. 判据锚点：`docs/锚点/` 下真实路径；不存在则卡不可冻结。
7. 配对验收卡：同号 V。
8. 状态：`待取` / `在写` / `已交活` / `过` / `不过` / `待拆卡`。
9. 批次 / 车道 / 失败归因：调度列，初始态全填 `—`；车道可选值只允许 `验证` / `打包`，未定时写 `—`。

## 判废链

判不过只在下方加 `W-0NN-R1`（配对 `V-0NN-R1`），原排保留记 `不过`；三次不过退回重拆卡。
