# 规格候选-启动图标-B · 暖金金星

> 流水线位置：F-73 三段流水线第①段「设计候选」。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；现有 `res/mipmap-*/ic_launcher*` 资产维持作废状态，待选型通过后由新链路替换。
> 与既有图标的区分：77 枚功能图标中的书签 `ic_bookmark.xml` 是带 8° 断口的线性五角星；本候选的星为**实心填充、立体倒角**的应用主标识，语义不同、线型不同，不构成雷同（详见 §8）。

## 1. 目的与用户可感效果

- **设计主张**：深墨玉底上一颗暖金五角星压阵，星芒四周金粉迸开——把启动动画「金粉爆」的辉煌瞬间收成一枚庄重的黑金器物标识。
- **第一眼像什么**：在桌面/设置列表里，像一枚嵌在黑漆木托上的鎏金铜星徽章，黑金对比强、识别距离远，是三候选中最「醒目」的一枚。

## 2. 画布几何

| 项 | 口径 |
|---|---|
| 自适应图标画布 | 108×108dp，背景层铺满整幅，不留透明角 |
| 安全区 | 前景全部内容约束在中央 72×72dp（x/y ∈ [18, 90]dp）；星体外接圆与光环收进圆心 (54,54)、r=33dp 可见圆内，粒子允许外扩到 r=38dp 但不越出 [14, 94]dp |
| 掩膜口径 | 兼容 squircle / 正圆 / 圆角方；深墨玉背景铺到四边，掩膜外沿不露壁纸 |
| 密度实拍尺寸 | mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 px；矢量坐标按 108dp 等比缩放 |
| 圆角 | 外形圆角由系统掩膜决定；星体倒角在前景内自绘，不画外框 |

## 3. 造型逐部件坐标（108dp 画布，原点左上）

**背景层（background）**
- B1 墨玉底：整幅 108×108 矩形，填 `iconJadeBlack`（§4 派生色）；表面覆极细磨砂颗粒：`CardTokens.cloudGray` @ `CardTokens.noiseAlpha`，2dp 网格、固定种子复用 `CardTokens.noiseSeed`。

**前景层（foreground）**
- F1 金星主体：正五角星，圆心 (54, 54)，外接圆半径 R=26dp，内接圆半径 r=11.5dp（标准五角星内外径比 0.44）；顶角朝正上（-90°）。五个外角方位角：-90°、-18°、54°、126°、198°；五个内点方位角：-54°、18°、90°、162°、234°。星体外包络宽/高均 52dp，落在安全区内。
- F2 星面分面：五角星十个三角面按左上受光、右下背光分两档——左上五个面填 `iconGoldHighlight`，右下五个面填 `iconGoldShade`，受光/背光分界过圆心沿 45° 斜线；不画描边。
- F3 光环：正圆 cx=54 cy=54 r=34dp，线宽 1dp，`CardTokens.warmGold`，alpha 0.55，圆角端头（环为闭合路径，无端点）。
- F4 金粉粒子：12–16 粒，分布在星体外侧 r∈[30, 38]dp 的环带上；圆粒半径 0.7–1.8dp（固定种子随机），填 `CardTokens.warmGold`；其中 3–4 粒带 2–4dp 短拖尾，拖尾 alpha 0.4。粒子总量对齐启动动画金粉口径（全屏 60–80 粒，图标内按比例缩到 ≤16 粒）。
- F5 底部辉光：星体下方一片径向柔光晕，中心 (54, 66)，半径 20dp，色 `CardTokens.shadowHover`（`0x73D4A54A`），向外衰减到 alpha 0；不画硬边投影。

## 4. 色值（全部挂既有 token；新增色写明派生关系）

| 部件 | 色名 / token | 取值与派生关系 |
|---|---|---|
| 墨玉底 B1 | **新增** `iconJadeBlack` | 由 `CardTokens.ink`（`0xFF1A1410`）向 `CardTokens.stoneBlue`（`0xFF3A6B66`）lerp 15% 得到：比纯墨偏一点青绿，呼应石青色板，不新造裸 HEX |
| 磨砂颗粒 B1 | `CardTokens.cloudGray` @ `CardTokens.noiseAlpha` | 既有 `0xFF9B9687`，alpha 0.03f |
| 星主体 F1 | `CardTokens.warmGold` | 既有 `0xFFD4A54A`，作为星面基色 |
| 受光面 F2 | **新增** `iconGoldHighlight` | 由 `CardTokens.warmGold` 向 `CardTokens.cardPaper` lerp 25% 得到，模拟金属高光 |
| 背光面 F2 | **新增** `iconGoldShade` | 由 `CardTokens.warmGold` 向 `CardTokens.ink` lerp 18% 得到，压出立体厚度 |
| 光环 F3 | `CardTokens.warmGold` @ 0.55 | 既有 `0xFFD4A54A` |
| 金粉 F4 | `CardTokens.warmGold` | 既有 `0xFFD4A54A`；拖尾 alpha 0.4 |
| 辉光 F5 | `CardTokens.shadowHover` | 既有 `0x73D4A54A`（暖金 45% 透明），径向衰减 |
| 禁用色 | — | 不取 `CardTokens.cinnabar`；不引入色板外的银灰、白高光、冷调金属色 |

## 5. monochrome 单色层派生规则（Android 13+ 主题图标）

- **保留形状**：F1 五角星实心剪影（F2 分面在单色层合并为单一填充，不保留明暗面）；F3 光环保留为细圆环。
- **丢弃**：F4 金粉粒子与拖尾、F5 辉光、B1 磨砂颗粒、F2 明暗分面。
- **层次用 alpha 表达**：星体 alpha 1.0；光环 alpha 0.5；单色层为中性墨色，由系统主题着色，不写死颜色。
- 单色层几何与前景层一致；系统着色后五角星外轮廓仍须完整可辨。

## 6. 三态

| 态 | 处理 |
|---|---|
| 正常态 | 按 §3/§4 全量绘制 |
| 长按/按压态 | 启动器系统自动压暗，本候选不另画按压造型；声明：星体暖金在整体压暗 10% 后仍与墨玉底分离，不依赖描边补救 |
| 主题图标单色模式 | 形状不变（§5 单色层），颜色全部由系统主题提供 |

## 7. 边界与降级

- **mdpi 48px 坍缩处理**：F4 金粉整组丢弃（小尺寸下是噪点）；F3 光环丢弃；F2 明暗分面合并为单色实心星；F5 辉光丢弃；只保留墨玉底 + 实心金星。对照预览 `B-preview-72.png`。
- **超小尺寸（通知栏 24px）**：不复用本全量图标；副图标 `ic_launcher_small` 按 F-46 作废不重做；后续若需要，另立规格取实心星形单色剪影。
- **对比度下限**：暖金星 vs 墨玉底 ≥ 4.5:1（实测目标）；高光面 vs 墨玉底 ≥ 6:1；光环因 alpha 0.55，不承担识别对比，只作装饰。深浅主题下背景固定为墨玉底；系统强制浅底时由单色层轮廓兜底。
- **空数据/异常**：静态资产，无运行时数据依赖；生成失败不得回退现有作废 PNG。

## 8. 与全 App 的一致性对照

| 对照项 | 结论 |
|---|---|
| CardTokens 六色 | 复用 `ink / stoneBlue / cloudGray / warmGold` 四色 + `shadowHover` 暖金辉光；`cardPaper` 仅参与高光面 lerp；`cinnabar` 不取用。三个派生中间色均写明源色与 lerp 比例 |
| 77 枚功能图标风格 | 复用圆角端点口径（光环/拖尾端头）；与 `ic_bookmark` 五角星的区分已在文首声明：书签是 24dp 线性、8° 断口、暗铜/暖金描边；本星是实心填充、立体分面、无断口，二者不混用同一组路径参数 |
| 启动动画口径 | 金粉粒子形态与数量呼应切片-01「金粉爆 60–80 粒」；底部辉光呼应「40dp 金色辉光」口径，图标内收为 20dp 径向光晕 |
| 卡片基座材质 | 磨砂颗粒复用 `noiseGrid / noiseAlpha / noiseSeed`，与卡片宣纸颗粒同参数；辉光色直接取 `shadowHover`，不另造投影色 |
| 动效血缘 | 静态图标不自带动画；后续入场 spring 沿用 `cardSpringDamping 0.80f / cardSpringStiffness 360f` |
| 不冲突项 | 主体色不用 77 图标默认暗铜 `#8B6914`；星体不出现任何文字字母；黑金组合不与三 Tab 线性图标抢视觉重量 |

## 9. 逐条可测验收判据

1. 星体外接圆（R=26dp）外包络 ≤ 72dp 安全区；光环 r=34dp、粒子最外 r=38dp 均不越出 [14, 94]dp 画布边界。
2. 五角星顶角朝正上（-90°），内外径比 11.5/26 ≈ 0.44，十个顶点方位角符合 §3 列表。
3. 全图色值仅取自 §4 表：既有 token 五个 + 派生 token 三个；逐色可回查 `CardTokens.kt`；无表外裸 HEX。
4. 五档密度图尺寸精确为 48 / 72 / 96 / 144 / 192 px，正方形。
5. 背景层铺满 108×108dp，三种掩膜下四角不透透明底。
6. monochrome 层只含星体实心剪影 + 圆环，无粒子、无辉光、无分面；环 alpha 0.5 可量。
7. 48px 档预览（`B-preview-72.png`）中实心五角星轮廓可辨，光环/粒子/辉光已按 §7 丢弃。
8. 暖金星面 vs 墨玉底对比度 ≥ 4.5:1，高光面 ≥ 6:1。
9. 全图无被否决元素：无红日、无月牙、无印刷体/楷体字标、无圆形印章、无 A~M 字母标、无副图标。
10. 光环与粒子拖尾端头为圆角；星面不描边，分面分界沿 45° 过圆心斜线。
