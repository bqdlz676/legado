## 一、地形（实测，非生成）

| 文件 | `china_height.png`（1024×1024 L 灰度）· `china_height.js`（base64 内嵌） |
|---|---|
| 覆盖 | 104–122°E / 24–42°N |
| 源 | Mapzen Terrarium DEM 瓦片 z7（真实卫星高程） |
| 编码 | 8 bit，`0–255 ↔ 0–7000 m`；负值（海）钳 0 |
| 处理 | σ=6 px（≈11 km）高斯平滑，去掉高频毛刺、保留山系走向 |
| 用法 | `hAt(x,z)` 双线性采样；**`latV` 必须等经纬度线性**，改墨卡托会与栅格错位 |

## 复用约定

1. 页面 `file://` 直接载入，所有数据挂在 `window`
2. 新增城池只追加，不改既有键名
3. 改投影 → 必须同时改 DEM 栅格与 `latV`
4. `1 单位 = 5.8 km`（300 单位 / 1730 km），所有距离、行军天数按此换算
5. 详细实现见 `落文-3D沙盘逆向.md`
