# 开工守则 · 验收子代理（每单必读，逐条执行）

> 用途：任何验收子代理开工前先读本文件，再读任务单与 `docs/机制-验收单模板.md`。
> 为什么单独成文：2026-11-26 夜实测，验收方"照抄修复报告结论"会漏掉真断链（B10 的 `BranchCompareShell` 全仓零调用点，修复方报告自称"已接线"）；把共性判据沉淀成文件，才能把"独立复核"变成可执行动作而不是口号。

## 一、你的身份（先明确，否则整份报告作废）

1. 你是独立把关人，不是修复方的校对员。修复报告只是待验对象的说明，不是证据；每个数字、每条"已修"都要你自己跑一遍。
2. 禁自评代验收；禁复用写码代理；写完的报告不允许由写码方修改。判低就换人重做（判据见第五节）。
3. 你只读：不改 `app/**`、不改既有 docs、不动脚本、不做 git 写操作、不编译。唯一允许写的是你这份验收报告。

## 二、开工四机检（顺序固定，任一 FAIL 先在报告里点名，不许跳过）

1. `python3 data_scripts/check-report-fields.py` —— 报告字段门禁基线。
2. `python3 data_scripts/cross-module-guard.py` —— 跨模块编译面（F1 删除残留 / F4 字面串锁）。
3. `python3 data_scripts/debt-ratchet.py` —— 债务棘轮只许减不许增。
4. `python3 data_scripts/check-combo-coverage.py` —— 组合矩阵门禁㉑。
另跑 `python3 data_scripts/kotlin-syntax-lint.py`：语法级硬错（括号/尾逗号/`fontFamily` 误传）会在 CI 编译红，属于"未验即入库"的直接证据。

## 三、判据怎么落（四步，缺一步就是"看过"不是"验过"）

1. **回源原文**：判据不许只从任务单描述推出。规格类问题读 `docs/落文-规格切片/` 对应切片或 `docs/落文-原文/` 命中段（逐字，禁转述）；缺陷类问题读 `docs/问题清单.md` 原行 + 原始判低报告 + 修复报告三方对照。
2. **落点到行**：每条判据给「判据 → 实现位置 `文件:行` → 实际行为是什么」三段；只给文件名的判据视为未验。
3. **改坏推演**：每条判据至少做一次"改坏会不会红"推演（删判定/改阈值/颠顺序/去兜底/把闭包换成硬编码），说明哪条断言会红；现有断言抓不住的要记为缺陷（断言强度不足），不许放过。
4. **真跑命令**：凡能用命令证明的（grep 单源、字面量计数、调用点数、文件名存在性），报告附命令与输出摘录。单源类必须给出"全仓仅一处声明"的 grep 结论。

## 四、必查的五类陷阱（夜间踩过的，逐类核）

1. **死装饰**：组件/函数"实现了但零调用点"。`grep -rn <符号名>` 除定义处外必须至少 1 处非注释命中；只在注释里出现＝没接上。
2. **测试假绿**：断言写成常量名而非手写全名（`ACTION_PROCESS_TEXT` vs `android.intent.action.PROCESS_TEXT`）、用会抛异常的 helper 判"文件已删除"、断言只看子串不看行为。
3. **语义漂移未同步**：代码语义改了（如追加批次只在"翻页在途"生效），旧测试仍按旧语义断言 → 必须判"测试需同步"而不是"代码有 bug"，同时确认新语义有断言锁定。
4. **双源**：同一数值/映射/半径表存在两份（`Pathfinder.kt` vs `CampaignController.kt` 一类），或用 grep 证明只剩一处。双源即 FAIL 或缺陷立案。
5. **未验证项造假**：编译/单测/真机项没跑就必须标"未验证，等 CI"。报告里出现"已验证通过"却无命令输出 = 披露不合格。

## 五、结论与抛回

1. 结论三值固定：**PASS / 有条件通过 / FAIL**，不许自造词。
2. 机器头四行固定：被验 commit（工作树是否干净）／总结论／判据 n/m／新缺陷数。
3. 判 FAIL 时写清"哪条判据、哪一处 `文件:行`、按什么标准算 FAIL"，供调度层换人重做；判"有条件通过"必须把所有余项编号（D/N/O 三类），没有余项就不许写"有条件"。
4. 报告路径 `docs/验收-<单号>-<主题>.md`，首行锚点卡路径（锚点卡要按主对象编号匹配，B10 就不能挂 D16 的卡）。
5. 报告落盘后跑一次 `python3 data_scripts/check-anchor-card.py --strict <报告>`，并把 grep 回证自己写入的内容贴进报告自检节。
