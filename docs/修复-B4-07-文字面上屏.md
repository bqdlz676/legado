## 三、边界清单（每条给 文件:行 落点）

- 空书（`ReadBook.book == null`）：`textPageState()` 入参 `bookPresent = book != null`（InkReadController.kt:154）；解析器归 `NoBook`（InkTextPageState.kt:56）；上屏层展示 `book_not_exist`（InkTextPageSurface.kt:92）；不崩、不白屏。
- 无章（书在但 `curTextChapter == null`）：`chapterPresent = chapter != null`（InkReadController.kt:155）；归 `NoChapter`（InkTextPageState.kt:57）；`currentTextPage()` 返回 null（:141-142），update 不调 `setContent`，展示 `content_empty`。
- 内容为空（章在、页在、正文空白）：`pageText.isNullOrBlank()` 归 `EmptyContent`（InkTextPageState.kt:59）；空串 / 纯空白 / null 三类输入单测均覆盖（InkTextPageStateTest.kt `页正文空白归类为 EmptyContent`）。
- 排版失败（章在但可用页数 0 或 `hasBodyContent` 假）：`!layoutOk || pageCount <= 0` 归 `LayoutFailed`（InkTextPageState.kt:58）；展示 `unknown_error`，不把失败章伪装成有正文页。
- 索引越界：就绪态 `currentIndex` 夹取到 `0..pageCount-1`（InkTextPageState.kt:61）；负索引 / 超末页单测覆盖（`索引超出末页夹取到末页 负索引夹取到首页`）。
- 章未加载完成时序：首屏章正文未就绪期间走 NoChapter 空态；正文回调到达后 `refreshFromReadBook()` 回源，下一次重组重取状态（时序细节见 §六问题 1）。
- 翻到首 / 末页：页通道落空后 `||` 续接翻章通道（B4-06 在位）；末章 `moveToNextChapter` 返回 false，`turnPage` 不崩；边界可达性判定沿用 B4-06 现状（见 §六问题 2）。
- 配置变更 / 进程重建：书 / 章序号 / 位置真值在 `ReadBook` 持久化；重建后 `register(readCallback)` + `initData` 重载，挂载效应回源（B4-06 在位）；阅读态 Bundle 桥接归 B4-29 复核。
