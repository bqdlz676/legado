## 五、二阶 / 三阶影响推演

### 5.1 二阶（本单改动直接传导到的相邻模块）

1. **快照下发口径**：盟约方棋子由「未观测敌军（坐标置空）」改为「友方可见（实时坐标下发）」。壳层 `CrossingShell` 按 `role` 着色（ALLY 铜色），此前盟友棋子可能因 `observed=false` 被雾隐藏；改动后盟友棋子按友军正常绘制。角色 `role` 在 `instantiateCorps`（`:74-76`）已按盟约计算，与本单快照口径一致，无着色冲突。
2. **情报侦察集**：盟友不再进入 `observedIds`；既有 F8 雾测（`CampaignControllerTest:155-161`，无外交关系）路径不变——`isFriendlySide("a","b")` 在无盟约时返回 false，行为与旧 `sideId` 比较等价。
3. **可见性扩面**：盟友实时坐标对玩家可见。这是友军协同的必要信息（支援裁决本来就需要知道盟友位置），不构成对敌情报泄漏；B9 要做的「未观测敌军模糊半径」不受影响。

### 5.2 三阶（长期维护 / 后续战役 / 边界）

1. **联军战役可落地**：后续孙刘联军类战役中，盟约两方不会自相残杀、会互相支援、溃逃不把友军当追兵；新增战役只填 JSON `diplomacy`，不改引擎。
