## 三、B8R5 裁决：二选一的选择理由与被否决方案

### 3.1 争议点

`Pathfinder.kt` KDoc（改前 :86）称「起点 / 目标格不受视野剪枝」；实现 `astar` 只把起点无条件入队，目标格作为 `next` 展开时仍受严格模式视野剪枝（改前 :156 `enemies.any { watchedBy(...) }`）。另：第三级 `straightPath` 折线兜底无专门用例。

### 3.2 真实意图判读

- A* 端点豁免是标准语义：起点与目标必须可被展开，否则搜索在终点处自我封死。
- 侧翼目标格来自意图裁决 / 军目标（夺隘、接战、推进落点）；若目标格恰在某敌军视野环内，严格模式把终点剪掉，A* 到不了目标只能误降级——此时暴露判定收到的 `degraded` 是「剪枝剪出来的假降级」，不是真无路可绕。
- 敌军所在格仍由 `enemySet` 排除（:153），豁免落点不等于允许踏上敌阵。

### 3.3 本单选择：改实现豁免目标格（方案①）

- `astar` 闸门（Pathfinder.kt:159）：`val watched = next != to && enemies.any { watchedBy(it.position, next, it.radiusCells) }`。目标格跳过视野闸门；敌军格排除、可通行性闸门、加价模式惩罚全部不变。
- KDoc 补足（:86-87）：注明目标格与起点同享豁免、敌军格不在豁免内，注释与实现对齐。
- 第三级折线兜底专门用例：见第四节用例 16。

### 3.4 被否决方案

1. **否决：只改 KDoc 说真话（方案②）。** 把注释改成「目标格在严格模式被剪枝时降级绕行」会把一个端点封死的实现缺陷写成既定口径；后果是目标落进视野环时一律假降级，`degraded` 信号被污染，B8R4 刚接上的暴露判定会被假降级反复误触发。文档迁就代码等于保留缺陷本体。
2. **否决：起点也纳入剪枝。** 起点是当前所在格，剪枝起点会让路径无从起步，违反兜底铁律；现状起点豁免正确，不动。
3. **否决：豁免放宽到目标格周边邻格。** 豁免只应作用于终点本身；放宽到邻格会让最后两步全程贴视野走，破坏严格模式「视野内格剪枝」的语义，也会让加价链的泄压阀失去意义。
4. **否决：把目标格豁免写成寻路层之外的二次判断。** 豁免是闸门语义的一部分，必须留在 `astar` 一处；上层再补豁免条件会形成第二套剪枝口径，与单源原则冲突。

## 五、二阶 / 三阶影响推演

### 5.1 数值平衡：暴露入账会不会把能赢的推演打成必败

- **暴露的直接效果只有两处**：伏击条件 `!corps.exposed` 失效（`IntentResolver.kt:58`、`resolveEncounters` 伏击判定），以及接战口径一致的姿态标记。暴露本身**不扣兵力、不扣士气、不改移动力**。
- 反例自查：一支被视野封锁逼到降级绕行的侧翼军，旧口径下仍算「隐蔽」，可能下回合在关隘触发设伏加成；但它本轮实际穿越了敌军视野环，敌军感知到它是物理事实，旧口径的「隐蔽」本就是虚高。入账暴露是把虚高的隐蔽修正为真值，不是新增惩罚。
- 双重追责边界已守住：加价 1.8 倍（寻路层）+ 暴露（本单）之外，不再自动扣士气（见 2.4）；若后续规格要求降级接士气，应单独立项标定扣减档位与每回合节流，不复用 `moraleDowngradedThisRound` 的交战节流口径直接套。
- 粘性提示：`exposed` 现状是回合间粘性标志（全仓无复位点：初始化 false、佯退置真、接战置真、降级置真）。本单沿用粘性语义；降级置真后不会在下一回合自动回假。若规格要求「暴露只维持一回合」，属 `exposed` 语义层别单，本单不改。

### 5.2 UI 语义：新标识会不会与既有「侧翼 / 包抄」徽标冲突

- 既有「包抄」是**意图标签**（`Intent.FLANK -> "包抄"`，:1135），回答「这支部队打算干什么」；新标识「降级·绕行」是**路线状态**，回答「这条侧翼路是不是硬绕出来的」。两者并列：意图仍显示包抄，标识只补充路线成色，不覆盖意图。
- 与顶栏「演示降级」的作用域已隔离：后者战役级（载入兜底：JSON 残缺 / 合成高程 / 空军），前者军队回合级；文案前缀不同（「演示降级」 vs 「降级·绕行」），数据源分别是 `host.degraded` 与 `CorpsView.routeDegraded`。
- 配色：标识用 `textAccent` 朱砂，与意图标签的 `brandGold` 暖金错开；既有 token 注释已把朱砂定为「遭遇 / 警示 / 降级标识」，不是新立色。
- 盲区单位不显示本标识：名册盲区分支（:740-748）只挂盲区占位文案，决策信息不透传；视图层 `blurRoute` 已二次清零。

### 5.3 链路联动（三阶）

- **情报表**：`IntelRecord` 只记录敌军目睹 / 接触条目，是面向观察者的敌情表；本方降级状态不进这张表。本方降级事实的上送通道是事件日志（`_eventLog` → 快照 `events` → 壳层 `EventLog`），与触发事件、遭遇战汇报同一通道，不新增第二套情报表。
- **快照 / 回放**：`CorpsView.routeDegraded` 进快照，回放逐回合可见；`BranchSnapshot` 深拷贝 `Corps`，回滚带回旧标志；旧档（无该字段概念）由缺省 false 兜底，不崩。
- **寻路链**：三级兜底结构未动；目标格豁免只影响严格模式闸门，加价模式与折线兜底的输入不变。豁免后严格模式成功率上升，部分旧口径下的「假降级」会转为 `degraded = false`，`FlankRoute.reason` 文案分布相应变化；既有 14 条寻路用例断言未受影响（目标格均不在敌环内）。
- **help/sim 旧包**：独立静态实现，无 `FlankRoute`、无 `exposed` 消费；本单改动不传导过去，是否同口径复核留别单。
