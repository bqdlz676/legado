## 判据5：观感维度（可读性 / 对比度 / 可发现性）静态估算

**结论：当前实现不压淡，空态文字走云灰 tertiary，静态对比度中等偏低；若真按观察口径压到 0.30，静态估算对比度会跌到几乎不可辨。以下均为静态估算，未做真实渲染验证。**

### 静态对比度估算（WCAG 相对亮度，纸白底）

- 当前实现：tertiary `#9B9687` 于纸白 `#F7F1E6`，对比度 **≈ 2.63:1**。低于正文 AA 4.5:1，也低于大字 AA 3:1；作为占位 / 引导灰可接受，但不适合承载需精读的信息。
