# 卷一 · 体系地基（为什么要这么设计）

## 一、总判断

国学宇宙观不是一堆零散概念，是一张"月令式"的一体网：同一个时节，天象（日在何宿）、五行（盛德在某）、干支（其日某某）、音律（律中某律）、物候（某物候现象）、方位、服色、食物全部联动。古人在《吕氏春秋·十二纪》与《礼记·月令》里把它写成了完整图式，在《淮南子·天文训》里把它算成了律历，在孟喜卦气说里把它配进了卦爻。

设计必须长在这张网上。早期方案错在：网没研究透，就自造"树、火焰纹、日晷、候牌"去填补——象是发明出来的，不是体系里长出来的。这条教训是本层全部裁决的源头。

## 二、五张网（全部有出处）

原稿标题作"三张网"，正文实列五节，本稿统一为五张网。

### 网一：五行全谱（《月令》系统表）

《月令》把万事万物纳入五行系统，每月一套完整对应（中科院自然科学史研究所《与农时有关的一些文献》表 2；原文见《礼记·月令》/《吕氏春秋·十二纪》）。全谱五条：

1. 木：方位东；十日甲乙；帝太皞，神句芒；虫鳞；音角，孟春律中太蔟；数八；味酸，臭膻；色青；谷麦，牲羊；祀户；脏肝。
2. 火：方位南；十日丙丁；帝炎帝，神祝融；虫羽；音徵，孟夏律中中吕；数七；味苦，臭焦；色赤；谷菽，牲鸡；祀灶；脏心。
3. 土：方位中；十日戊己；帝黄帝，神后土；虫倮；音宫，律中黄钟之宫；数五；味甘，臭香；色黄；谷稷，牲牛；祀中霤；脏脾。
4. 金：方位西；十日庚辛；帝少皞，神蓐收；虫毛；音商，孟秋律中夷则；数九；味辛，臭腥；色白；谷麻，牲犬；祀门；脏肺。
5. 水：方位北；十日壬癸；帝颛顼，神玄冥；虫介；音羽，孟冬律中应钟；数六；味咸，臭朽；色黑；谷黍，牲彘；祀行；脏肾。

校正说明：金之脏原稿误作"肝"，本稿改"肺"（肝已属木，五行配五脏为肝心脾肺肾），见附录 A-2。

五行之性（《尚书·洪范》，五行说最早出处）：水曰润下、火曰炎上、木曰曲直、金曰从革、土爰稼穑。

每月还有一套星象（孟春"日在营室，昏参中，旦尾中"）、物候（"东风解冻，蛰虫始振，鱼上冰，獭祭鱼，鸿雁来"）、政令（"禁止伐木，毋覆巢……"）与天子服色居室（孟春"居青阳左个，乘鸾路，驾苍龙，载青旗，衣青衣，服苍玉，食麦与羊"）。

关键洞见：**"其虫鳞/羽/倮/毛/介"就是五行的动物物象**——鳞虫（龙鱼）、羽虫（鸟）、倮虫（人兽）、毛虫（虎豹）、介虫（龟鳖）。物象不必发明，月令自带。

### 网二：阴阳消长图式（十二消息卦）

十二消息卦（复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤）配十二月，阳爻自下而上逐月生长——这是古人画了一千年的阴阳消长图，出处为孟喜卦气说（《新唐书》卷二十七僧一行《卦议》引孟氏章句）。十二月对应：

1. 十一月子：复卦，一阳初生（冬至"一阳来复"，《汉书·五行志》"冬至阳爻起初，故曰复"）。
2. 十二月丑：临卦，二阳。
3. 正月寅：泰卦，三阳——"三阳开泰"出处即此。
4. 二月卯：大壮，四阳。
5. 三月辰：夬卦，五阳。
6. 四月巳：乾卦，纯阳。
7. 五月午：姤卦，一阴生（夏至）。
8. 六月未：遁卦，二阴。
9. 七月申：否卦，三阴。
10. 八月酉：观卦，四阴。
11. 九月戌：剥卦，五阴。
12. 十月亥：坤卦，纯阴。

卦爻与节气的精配（楚竹书周易首尾符所记，历代无异说）：复初九=冬至、临六三=大寒、泰九五=雨水、大壮初九=春分、夬九三=谷雨、乾九五=小满、姤初六=夏至、遁九三=大暑、否六五=处暑、观初九=秋分、剥六三=霜降、坤六五=小雪。

### 网三：卦气网（孟喜卦气说）

1. 四正卦主二十四节气：坎、震、离、兑各主六节气——坎主冬至至惊蛰（冬），震主春分至芒种（春），离主夏至至白露（夏），兑主秋分至大雪（秋）。四正卦初爻分别主二至二分：坎初六=冬至、震初九=春分、离初九=夏至、兑初九=秋分，余爻分主其余二十气。
2. 六十卦配七十二候：六十卦分辟（君）、公、侯、卿、大夫五组，每组十二卦；每节气分初、次、末三候，共七十二候。冬至初候配公卦中孚、次候配辟卦复、末候配侯卦屯内。
3. 六日七分：六十卦配一年 365¼ 日，每卦值六日七分。

### 网四：律历网（《淮南子·天文训》）

用户问"星宿是否对应古代雅音"，完整答案在此：律历合一，十二律配十二月配十二辰，二十四节气各有"音比"之律。

1. 十二律配月（斗建，正月建寅）：黄钟十一月、大吕十二月、太蔟正月、夹钟二月、姑洗三月、仲吕四月、蕤宾五月、林钟六月、夷则七月、南吕八月、无射九月、应钟十月。
2. 二十四节气音比十二律（《天文训》原文）：冬至音比黄钟、小寒比应钟、大寒比无射、立春比南吕、雨水比夷则、惊蛰比林钟、春分比蕤宾、清明比仲吕、谷雨比姑洗、立夏比夹钟、小满比太蔟、芒种比大吕、夏至比黄钟、小暑比大吕、大暑比太蔟、立秋比夹钟、处暑比姑洗、白露比仲吕、秋分比蕤宾、寒露比林钟、霜降比夷则、立冬比南吕、小雪比无射、大雪比应钟。此表成对对称（冬至夏至同黄钟、小寒大雪同应钟……），是《天文训》原文特征，不是抄错。
3. 十二律数（黄钟 81 起，三分损益）：黄钟 81、林钟 54、太蔟 72、南吕 48、姑洗 64、应钟 42、蕤宾 57、大吕 76、夷则 51、夹钟 68、无射 45、仲吕 60。五音正声：黄钟为宫、太蔟为商、姑洗为角、林钟为徵、南吕为羽。
4. 律名释义（《天文训》）：太蔟者"簇而未出"、夹钟者"种始荚"、姑洗者"陈去而新来"、蕤宾者"安而服"、夷则者"易其则"、黄钟者"钟已黄"……十二律各有物象释义。
5. 阴阳刑德（《天文训》）：冬至为德（阳气萌）、夏至为刑（阴气萌）；刑德七舍"室堂庭门巷术野"——十二月德居室，逐月徙居。

### 网五：干支五行（《月令》十日 + 通例）

天干五行：甲乙木、丙丁火、戊己土、庚辛金、壬癸水（《月令》"其日甲乙"等十日配五行）。地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。干支分阴阳：甲丙戊庚壬为阳干、乙丁己辛癸为阴干；子寅辰午申戌为阳支、丑卯巳未酉亥为阴支。

## 三、推演的原生形态：月令"行令"

《月令》每篇末有"孟春行夏令则……行秋令则……行冬令则……"——这是古人自己的推演系统：时令错乱会有什么后果。这是"能推能演"的国学原生形态，不是占卜（不是给用户算吉凶，是文献中的知识性推演）。

界线：展示《月令》原文的"行X令则Y"=文献知识呈现，允许；用户输入"我今年行什么令会怎样"=占验，禁止（红线不占验不变）。推演做成：拨到某节气，展示该月"行他令"的原文后果对照——拨错了令，古人告诉你会发生什么。

## 四、对早期三处"自造象"的裁决（体系层修正）

1. 阴阳消长：废"日晷影"，用十二消息卦。卦爻本身就是物象——冬至一阳生，阳爻自下而上逐月生长，六爻画出来就是消长。日晷是替身，消息卦是体系原生的正主。
2. 五行对应：废"五件孤立小像"，用月令全谱卡。五行不是五个图标，是五套完整世界。
3. 节气：候牌从"孤立物象"升级为"三连"——物候（月令原文物象句）、卦气（四正卦爻位或六十卦配候）、音律（音比某律，可听）。节气在古人体系里从来三样联动，拆开即失真。

# 卷二 · 核心命题（怎么结合地球仪）

## 五、国学层的主体是"太阳的一岁之旅"，不是道具层

月令原文早已给出答案——孟春"日在营室，昏参中，旦尾中"：古人自己就是把节气读成太阳与星宿的关系。国学宇宙观的地球仪呈现，主体只有一个：**太阳直射点在南北回归线之间的一年往复**。阴阳、节气、五行、卦气、律历、月令星象，全是这次旅程的六种读法。

实机现状（已实测）：`Sun.kt` 已完整实现 `direction(utcMillis)`（赤纬 = 地轴倾角 × 周年正弦，二至 ±23.5°；直射经度按 UTC 小时推算）、`dayFactor` 晨昏线 5° smoothstep、`terminatorSide` 日出日落侧判；`GlobeScene.kt:51,81` 已持有 `sunDir` 并每帧按 `utcMillis` 更新；地球侧尚无回归线高亮（天球侧已有天赤道基准线 `SkyParams` 先例）。

结论：**国学层的物理本体已在实机里，只差"刻度"**。

## 六、六种读法与保留／废除清单

1. 节气 = 太阳直射点的刻度。南北回归线就是地球仪自带的节气环，太阳自己走出来，不需要悬浮罗盘。
2. 阴阳消长 = 晨昏线（既有）+ 直射点纬度；消息卦做屏幕侧 UI 刻度（卦是读法不是地形，读法归 UI、球面归几何）。
3. 五行当令 = 直射点的季节段；五方方位锚点 + 当令轮亮；五行全谱走月令卡。
4. 律历 = 节气音；点律徽听音比之律（合成单音，走 D27 音效槽）。
5. 月令星象 = 天地一条线（与星空层的焊点）；地球侧直射点与天球侧太阳所在宿是同一个太阳方向向量。
6. 月令全谱卡 = 五行对应的完整呈现；点时节弹卡，看到一整套世界。

中国大地保留：季相偏移、雪线、物候线三件（地形自变）、分野联动、五方方位锚点。

**废除（道具层错误，谁再提谁返工）**：日晷、五方物象田、候牌球面件、三环悬浮罗盘（球面件）。

绘制预算：球面新增绘制 ≤4 件——回归线 2 条（`brandGold` alpha 0.35）、太阳直射点 1 件（`colorGlow` 光晕贴球面）、天球日轮 1 件（挂 `Sun.position`）。消息卦刻度是屏幕 UI、月令卡是 Sheet，不计球面。DrawBudget 上限 15、LOD0 ≤10，完全容纳。零悬浮 3D 道具。

# 卷三 · 规格（N-020 主体）

## 七、总体原则（五条，每条即裁决）

1. **状态是时间的纯函数**：`CosmoState = f(t)`，不做逐帧累积动画。为什么：能推演的前提是可复算；增量动画只能前进，拨回昨天就对不上。
2. **一层一象，象必须可算**：每个可见元素都是公式或公版表的投影。为什么：可算的才叫"形象化"，画上去的只能叫"皮肤"。
3. **全部象共用同一个时钟**：节气、卦气、五行、律、月令星象，全是同一个太阳方向向量的投影。为什么：两个时钟必然错位——冬至了卦气还在夏，一帧穿帮。
4. **观察与推演共用一套实现**，只换时钟的驱动源（系统时钟 ↔ `CosmoClock`）。为什么：两套实现违反防双轨（P-05）。
5. **国学层是刻度层，不是道具层**：太阳、晨昏线、回归线、地貌色全是地球仪既有几何，国学层只给它们配读法。禁雨雪粒子、禁贴图轮换、禁任何悬浮道具、禁旋转太极装饰。为什么：道具盖地形、悬浮毁旅程；读法不占球面一寸。

## 八、内核 `CosmoState`（一次派生，全层消费）

1. `utcMillis`——时间基准；观察模式来自系统时钟，推演模式来自 `CosmoClock`，两条源汇到同一入口。
2. `solarLongitudeDeg`——太阳视黄经 λ。
3. `declinationDeg`——太阳直射纬度 δ = arcsin(sin 23.44° · sin λ)。23.44 为历算精度，视觉沿用 `GlobeConfig.AXIAL_TILT_DEG = 23.5`。为什么：历算归历算、渲染归渲染，两处同源不打架。（原结合研究稿此处笔误作"λ 由 arcsin 反解"，本稿校正，见附录 A-8。）
4. `jieqi`——二十四节气之一（黄经 15° 等分，立春 315° 起，《中国天文年历》口径——这是定义不是近似）。
5. `hou`——七十二候之一。
6. `yearGanzhi` / `monthGanzhi` / `dayGanzhi` / `hourGanzhi`——四柱干支（仅历法牌展示，不做任何命理语义）。
7. `reigningElement`——当令五行（木春/火夏/土长夏/金秋/水冬，四立为界）。
8. `yinYangPhase`——阴阳消长相位 0..1（冬至 0、夏至 1）。
9. `guaQi`——卦气：四正卦爻位（坎震离兑二十四爻配二十四节气）+ 十二消息卦当月主。
10. `lü`——当月节气音比之律。
11. `yueLing`——当月月令条目（星象/十日/帝神/虫/音律/数/味/臭/祀/服色食谷）。
12. 干支锚点：公元 4 年 = 甲子，`(y − 4) mod 60`；自验 1984 甲子、2026 丙午。月干支以节为界（立春换寅月）；时干支以子时 23:00 换日。

## 九、六种读法细则（十二条）

以下十二条为跨小节**连续编号**（沿用 v3 原编号），小节标题只做分组、不重置序号。

### 9.1 节气 = 直射点的刻度

1. 南北回归线高亮：两条金线（`brandGold` alpha 0.35，≤2dp），挂在既有经纬网格上。为什么：回归线本来就是地球仪的节气环——冬至太阳抵南回归线、夏至抵北回归线，悬浮罗盘是替身，回归线是本体。
2. 太阳直射点标记：1 个暖金光点（`colorGlow` 光晕，贴球面，随 `Sun.direction` 逐帧移动），视觉直径 8dp、**热区悬空放大到 48dp**（校正，见附录 A-5）。为什么：节气不是贴上去的环，是太阳自己走出来的——点走到哪，就是什么节气。
3. 历法牌（屏幕 UI，一行字）："冬至 · 日在斗宿 · 复卦 · 水旺 · 音比黄钟 · 丙午年"，`textSecondary` 14sp，律徽可点。为什么：一行字是"读"的入口，球上无字。

### 9.2 阴阳 = 晨昏线（既有）

4. 晨昏线 5° 渐变带已是实机实现（`Sun.dayFactor`，切片 19/20），不加任何新绘制；图例写"昼阳夜阴"。为什么：阴阳的本体就是昼夜——冬至晨昏线最斜、昼最短夜最长，阴阳消长是地球仪自带的物理现象。
5. 十二消息卦刻度（屏幕侧 UI，非 3D）：十二卦小条（复临泰大壮夬乾姤遁否观剥坤），当令卦高亮（`brandGold`），随直射点纬度连续推进；卦配节气精确表用卷二网二末段（复初九冬至至坤六五小雪）。为什么：卦是"读法"不是"地形"；"一阳来复""三阳开泰"直接可讲。

### 9.3 五行 = 直射点的季节段

6. 直射点北移 = 春木（生）、近最高 = 夏火（长）、转折段 = 长夏土（化）、南移 = 秋金（收）、近最低 = 冬水（藏）。当令轮替就是太阳旅程的分段，无需任何道具。
7. 五方方位锚点：以中原（约 34°N、112°E）为心，四正方位 + 中央五个小圆点（直径约为地名标记 2 倍，alpha 0.35）；当令方位暖金亮起，其余灰点。为什么：方位是五行谱内一项，锚点标记方位即可，扇区衬底与物象田均已作废。
8. 五行全谱（帝神虫音数味臭祀服色食谷）走月令卡（§十二），不在球上呈现。为什么：球上放不下五套世界，卡里装得下——点开时节看全谱，比摆五件道具生动且不挡地形。

### 9.4 律 = 节气音

9. 二十四节气音比十二律表（卷二网四第 2 条，已核实）。直射点走到哪个节气，点律徽听到对应律音。
10. 律音走 D27 音效槽 `SFX_COSMO_JIEQI`（合成单音），本层不写播放器。为什么：这是"星宿对应雅音"问题的落地——节气、律、星宿是一条律历链。

### 9.5 月令星象 = 天地一条线（与星空层的焊点）

11. 十二个月月令星象表（《礼记·月令》原文，12 行）：孟春"日在营室，昏参中，旦尾中"……地球侧直射点方向与天球侧太阳所在宿是同一个太阳方向向量——地上读是节气，天上读是宿次。
12. 天球侧日轮：1 个光点挂 `Sun.position`（距离 400 已有）。推远相机入星空（连续缩放旅程，N-019），太阳正位于当月之宿，宿名标注。为什么：国学层与星空层在这条线上焊死——不是两个模块拼接，是同一个太阳的两种读法。

## 十、中国大地（地形自变，全部保留）

1. **季相偏移**：中国区域七类地貌色做乘性偏移，春偏青→夏偏翠→秋转黄→冬偏褐白，按 λ 连续插值；森林永远是森林，只是颜色在走。
2. **雪线**：`snowFactor = smoothstep(lat, snowLine(λ), snowLine(λ)+5°)`；冬至≈30°N（秦岭—淮河）、夏至≥40°N 以北。为什么：全屏最直观的"一眼四季"，公式零成本。
3. **物候线**：2° 宽、`brandGold` alpha 0.2 的推进锋线；`phenoPhase = λ − k × (lat − 23°)`，k≈3.4。立春在华南、清明过长江、立夏到华北。为什么："生动"的本质是纬度延迟，不是全国同步变。
4. **分野联动**：点星宿在地球对应州域脉冲（`FieldAllocationLayer` 已实装，1200ms），本层不加不减。
5. 中国范围掩码（256×128 灰度位图，tier 3 示意，只做区域选择永不渲染成边界线）。

# 卷四 · 接入（一球四相）

## 十八、四相与主控纪律（校正版）

一个 `GlobeActivity`、一个球、一个时钟，四个相，全部由连续状态驱动，无档、无页面跳转：

1. **地相 ⇄ 天相：一条连续缩放旅程**（相机 0.6R → 10R+，`skyBlend` 连续）：地图与星空不是两个模式，是同一旅程的两端——贴地是地图、推远入星空，线性缩放不设档（用户拍板口径；相机上限须从实机 `6.0f` 改 `10.0f`，否则星空球半径 9R 永不可达）。地相挂件=回放控制台（`ReplayConsole` 已有）；天相挂件=`SkySheet` 星卡 + 署名（`SkyAttribution` 已有），主控=天控签（视角切换 + 星官/星座切换两 chip 并一签）。
2. **道相（国学模式）：顶栏模式签显式切换**（签只有"地图 / 国学"两个，250ms spring）：国学不是缩放旅程的一段，是盖在中国大地上的一套体系，必须以专门模式呈现；地图模式零国学残留。道相内地形作底、国学层是主角。**挂件=十二消息卦条（左缘）+ 历法牌（屏幕 UI）+ 月令卡（Sheet）；球面=回归线/直射点/五方锚点。主控=节气盘（右下拇指区）。** 原整合设计稿此处写"挂件=三环罗盘（推演态）+ 五方物象 + 历法牌 + 候牌"，已于结合研究裁决作废（见附录 A-3），本稿按 v3 口径改写。
3. **史相**（时间轴拉出，地图/国学两模式皆可叠加）：制度演变层。主控=时间轴（复用 18 朝疆域层轴 + 事件聚合刻度）；挂件=事件卡。

规则：**缩放是手的旅程（地⇄天连续），模式签是主题的切换（地图/国学），史相是时间维度的正交叠加**——三个维度互不混用：星空靠手缩出来，国学靠签切进去，制度靠轴拉出来。星空再立一扇门、国学塞进缩放旅程，都是画蛇添足。

### 主控纪律

1. 任意时刻同屏主控 ≤1、挂件 ≤2（挂件=顶栏不计 + 当前相挂件）。
2. 主控触发口径：天相主控随相机跨 10R 浮出（连续旅程的伴生物），道相主控随模式签切出国学浮出（签的伴生物），两者不互相触发；切换 250ms spring。
3. 主控优先级：时间轴展开 > 当前空间相主控。为什么：时间轴是正交维度，展开时必须独占主控位。
4. 天控签 = 两个 chip 并一签：`上帝视角 / 地面视角`、`星官 / 星座`。
5. 道相主控 = 一个节气盘（观/推双态），不新增第二控件；**位置右下拇指区**（操作设计定，v3 原写"右上"已按后者校正，见附录 A-5）。注意：缩放不设档是 N-019 口径；速度三档是时间倍率不是缩放档位，两者不同维，不构成"设档"。
6. 地相主控 = 既有 `ReplayConsole`，维持现状。
7. 挂件区热区 ≥48dp；与球面手势分区裁决：挂件热区 > 球面手势，重叠时挂件优先。

## 二十、阅读器联动：冻结五子类内接线（两步走硬规则）

**气泡永不直跳观象台，永远先跳"卡"，卡上带"观"按钮跳观象台。** 为什么：气泡语义是查证、观象台语义是观演，两步走让用户在查证页自己决定要不要"观"；且五子类冻结不能增删，卡是唯一可以加按钮的自由层。

接线（全部走 `InkActionDispatcher` 唯一出口）：

1. 点星名/星官名 → 气泡 `OpenArtifact`（D16 astronomy 类型已有 star/asterism）→ 名物 Sheet（接线缺口，本期补）→ 卡上"观" → `GlobeActivity` + extra `phase=sky, starId=X` → 天相定位该星并弹星卡。
2. 点节气/干支（"冬至""丙午"）→ 气泡（DateProvider 扩节气语义，仍产 `OpenTimeline` 不变契约）→ 时间线页或历法卡 → "观" → `GlobeActivity` + extra `phase=dao, jieqi=冬至` → 道相节气盘停在该节气。
3. 点制度名（"科举""均田"）→ 气泡 `OpenArtifact`（制度条目）→ 名物 Sheet → "观" → `GlobeActivity` + extra `phase=shi, institutionId=X` → 史相时间轴停在该事件并弹事件卡。
4. 点地名 → 维持现状 `OpenMap` → 2D 古今地图，不改。
5. 未接线动作 chip 置灰规则维持（B4-05 不变式），不呈现为可点击。

`GlobeActivity` 参数化（本期改造）：新增 extras 四相入参（phase + 定位键），无 extra 时维持默认地相。为什么：观象台只有一个入口，靠 extra 定位，不新增 Activity、不新增契约子类。

## 二十一、两图分工（不合并、不互跳）

1. 2D 古今地图（`PlaceMapActivity`）：查证——"这个地名今天在哪、当时有哪些都邑山川"。气泡 `OpenMap` 全部保留去 2D。
2. 3D 观象台（`GlobeActivity`）：观演——"天怎么转、道怎么流、史怎么变"。书架"地图"入口保留去 3D。
3. 两者之间不做互跳按钮。为什么：互跳会把查证/观演两个语义搅浑，且制造第二出口（违反 B4-05 唯一出口）。
4. 用户记忆成本一句话：查证去 2D，观演去 3D。

# 卷六 · 操作（手怎么动）

## 二十五、操作总原则与五个反例

原则四条：

1. 单手可达：主控放右下拇指区，刻度条放左缘，模式签左上，卡从底部弹出。
2. 控件就是知识本体：拨盘不是抽象控件，是节气环的盘化；卦条不是装饰，是消息卦刻度——操作谁，谁就是知识本身。
3. 可逆且状态保持：任何跳走（读原文/切模式）再回来，太阳相位、节气、干支全部保持。
4. 一处操作、全屏联动：拨一下太阳，六读法同帧变。

### 五个操作反例（先行证伪，逐条修正）

1. 直射点热区反例：8dp 光点手指点不到 → 视觉 8dp、热区悬空 48dp；历法牌本身就是主入口，点牌=点太阳。
2. 卦条与拨盘抢屏反例：卦条若放右侧与拨盘打架 → 卦条左缘竖排（12 条小横线 + 卦名，14sp，热区 48dp），拨盘右下，左右分开。
3. 卡展开时拨盘抢占反例 → 卡展开即卡为主控，拨盘 alpha 降 0.3 且暂停手势，卡关闭恢复。
4. 速度档无入口反例 → 拨盘旁三枚小点竖排，点选切档，当前档 `brandGold`，其余 `textTertiary`；操作位显式，不藏长按。
5. 读原文状态丢失反例 → `CosmoClock` 相位在 `GlobeActivity` 的 ViewModel 保持，跳走返回不重建；判据强制（卷七判据 26）。

## 二十六、进入退出与屏幕分区

进入三条路径：

1. 书架：书架"地图"小签 → 地球仪地相 → 顶栏"国学"签 → 国学模式。退出：切回"地图"签。

3. 演示：首次进入国学模式自动演示（口径见 §二十七第 6 条），点停即落实时；此后每次进入默认实时。

返回语义统一：从哪进来，返回键回哪去；地球仪内切签不产生新栈层。

### 屏幕分区（单手全可达）

1. 左上：模式签"地图 / 国学"（当前态暖金）。
2. 右下：更漏式节气盘（主控）+ 三枚速度点。"更漏"取计时器之形——盘即一圈刻度的时间器，与"节气盘=纬度轴盘化"的语义同形。
3. 左缘：十二消息卦条（竖排，当令卦高亮）。
4. 底部：月令卡 / 阴阳卡（SkySheet 形态，底部弹出）。

## 二十七、节气盘 = 节气环的盘化（核心操作）

1. 盘面语义：盘就是回归线之间的纬度轴——**上端=夏至（北回归线）、下端=冬至（南回归线）、中横线=二分**，外圈 24 节气刻度，中央一根指针。为什么：往上拨=太阳往北=变暖，往下拨=太阳往南=变冷——盘与地球仪回归线空间语义一致，操作直觉零学习成本。
2. 拖指针 = 拨太阳：指针拖到哪个节气，太阳直射点就到哪个纬度，六读法同帧变。指针松开不回弹（停在所选节气），中央轻点=恢复当前真实时刻（观察态）。
3. 中央轻点 = 暂停/继续：观察态轻点暂停、再点继续；热区 48dp。
4. 速度三枚点：盘旁竖排——上"实时"、中"日"（1 天每秒）、下"甲子"（1 年 0.1 秒）；点选切换，当前档暖金。为什么：观察"流转"用甲子档、看"今天"用实时档，显式切档不藏手势。
5. 盘径 ≥96dp，盘面全 token 色，节气刻字 14sp 沿外圈。
6. 进层演示（校正）：演示用独立"演示速度"——一年 10 秒，走两圈（两年）约 20 秒；演示结束回落实时。原 v3 稿写"以甲子档演示两圈（一年 0.1 秒，约 20 秒）"，甲子档两圈实为 0.2 秒，算术不成立，本稿校正为独立演示速度（附录 A-7）。为什么需要演示：年尺度变化在实时档不可见，"自行流转"要先被看见。

## 二十八、点选与卡按钮

点选五类（全是"读"的入口）：

1. 点直射点 / 点历法牌 → 月令卡（当前节气完整月令谱 + 读原文/朗读行）。
2. 点卦条任一条 → 阴阳卡（该卦爻画 + 配节气 + 《春秋繁露》阴阳原文入口）。
3. 点五方锚点 → 五行对照行（该方位五行 + 当令与否 + 洪范原文入口）。
4. 点律徽（历法牌上）→ 律音（当前节气音比之律，合成单音 + 律名律数）。
5. 点"读原文" → 跳库内古籍对应段（《礼记·月令》《尚书·洪范》《说文解字》《春秋繁露》）；返回后相位保持。

4. 研究四件套：沿革谱系（前世今生链，每环带年代与出处——例：三公九卿→三省六部→二府三司→内阁/军机处）、空间对照（事件落图：罢黜百家落长安、改土归流落西南；全国性制度落都城 + 影响区示意 tier 3）、时间推演（拖 18 朝疆域层时间轴，事件按档聚合，朝代档每朝 ≤10 事件、同刻脉冲 ≤3）、反事实单步（只推已发生的史实分叉，2-3 个分支，标"假设"，禁百年演化）。反事实标注规范直接复用四渡赤水先例（"假设"角标与验收口径照抄），只把尺度收到"紧接着一步"，禁百年演化推演（会变成架空小说）。
