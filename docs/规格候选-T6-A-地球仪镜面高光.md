# 规格候选-T6-A · 地球仪镜面高光（离线预计算高光贴图 + 太阳角旋移 UV）

> 流水线：F-73 三段流水线第①段设计候选。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；既有 `OceanSpec`/`SoftwareRasterizer` 仅作参考、不复用（B7）。
> 硬指标归属（用户口径，非切片引文）：T6=A 档两项之一——地球仪太阳镜面高光：大西洋镜面高光随太阳移动，太阳方向驱动。
> 规格锚点（逐字）：`切片-19-3D地球仪细节.md:32`「太阳光在海面上的反射——shader 算太阳方向 × 法线，高光区一道白色镜面亮斑，位置随太阳移动」；`切片-20:40`「海洋格（覆盖图 = 水域）→ 蓝底 + 基于太阳方向的镜面高光」；`切片-19` 性能表：ocean shader 「fragment shader ≤ 15 行 GLSL」、frame 「55fps」。

## 1. 作用域与触发条件

- **屏幕**：3D 地球仪页（`GlobeScreenHost` 宿主画布），整球可见与中距档位生效；近距 LOD2 不在本候选范围（归 B 候选片元路径）。
- **时机**：进入地球仪页即挂载；每帧由 `Sun.direction(utcMillis)` 驱动高光质心；离开页面释放贴图缓存（对齐 `切片-03`「离开可见区域必须」`dispose()` 口径）。
- **生命周期**：页面可见 → 贴图解码一次 → 每帧 UV 旋移；页面不可见 → 停止重算并回收离屏缓存。

## 2. 视觉描述（形态 / 层次 / 动效曲线 / 时长）

- 洋面上一道柔边镜面亮斑，三层由内向外：核心金白亮点 → 暖金辉光环 → 远海雾青衰减环；亮斑沿太阳反射方向在可见洋面缓慢滑移，不是定点装饰。
- 层次对齐东方美学：绢帛底上的一抹水光，不做塑料高光；辉光暖而不艳，雾环淡到近看才觉。
- 动效：质心跟随太阳角连续移动，无弹跳；晨昏带内亮斑收窄变淡；淡入 200ms `cubic-bezier(0.4,0,0.6,1)`（`切片-15` 遮罩淡出同曲线），退场同曲线 200ms。
- 夜侧半球：不出现亮斑（dayFactor ≤ 0 时全层 alpha 归零）。

## 3. 逐部件参数

| 部件 | 尺寸 / 位置 | 透明度 | 色值（回挂 token） |
|---|---|---|---|
| 高光核心 | 半径 = 屏宽 ×0.06；质心 = 反射向量 R 与可见球面交点投影 | 峰值 0.85 | `CardTokens.cardPaper`（`0xFFF7F1E6`）；暖染由 `CardTokens.warmGold`（`0xFFD4A54A`）30% 向 `cardPaper` lerp 派生金白核心，不新造裸 HEX |
| 辉光环 | 半径 = 屏宽 ×0.14，柔边衰减 | 0.30 | `CardTokens.warmGold`；辉光口径对齐 `ComponentPalette.COLOR_GLOW`（`0x4DD4A54A`，暖金 30% 透） |
| 雾青衰减环 | 半径 = 屏宽 ×0.22，边缘羽化 | 0.12 | 派生远海雾青：`CardTokens.stoneBlue`（`0xFF3A6B66`）向 `CardTokens.cloudGray`（`0xFF9B9687`）lerp 40% |
| 海面底色 | 既有球面海洋层，不改 | — | 沿用 `GlobeTokens.OCEAN_DEEP`（`0x1B3A5C`）/ `OCEAN_SHALLOW`（`0x3A7A8A`）既有 token |
| 陆地压暗 | 高光落在陆地投影区时整环压暗 | ≤0.05 | `CardTokens.cloudGray` 透叠 |

- 坐标口径：质心以归一化球面经纬（lon/lat）表达，再经既有 `GlobeProjection` 投到屏幕；不写死屏幕像素坐标。
- 扰动：离线贴图提供 8 级粗糙度/微法线灰度，运行时按太阳经度做 UV 旋移，不逐像素算光照。

## 4. 与太阳 / 章节数据的绑定方式

- **数据源**：太阳方向取既有 `astro/Sun.kt` `direction(utcMillis)`（现状查证 #1 已实现，方向源复用；高光通道为新建）。海洋判别取既有覆盖图水格（`GlobeTokens.WATER` / `OceanSpec` 口径）。
- **预计算**：256×128 海洋粗糙度/微法线灰度图离线生成、随包打入 assets；进入地球仪时解码一次进既有 `TextureCache` 链路缓存，运行时只按太阳直射经度偏移采样。
- **缺数据兜底**：覆盖图缺失 → 按球面经纬泛化海洋环带（赤道 ±40° 视为洋面）；UTC 取不到 → 退回上次缓存方向并标记 `stale`，不崩溃、不空白。

## 5. 性能预算（明确上限）

- 每帧新增 draw：≤3（核心 / 辉光 / 雾环三个叠层）；不新增 GLSL 片元 pass。
- 贴图内存：256×128 RGBA ≈ 128KB；同时驻留 1 张；峰值内存增量 ≤256KB（含解码副本）。
- CPU 预算：高光层单帧 ≤2ms；粒子 0 粒；运行时零贴图解码。
- 离线预计算：粗糙度/扰动图在打包期生成，设备端不做烘焙。
- 帧率底线：球面 55fps（A8 / `切片-19`）；高光层不得拉低主线程帧预算。

## 6. 降级与兜底（四种边界，不允许空白态）

- **无网络**：贴图随包打包，纯离线可用；不请求在线卫星图。
- **无海洋 / 太阳数据**：泛化环带兜底；方向 stale 时沿用最后一次合法方向，画面仍有球面底色与星空，不留空屏。
- **低端机**（线程数 <4 或 Android ≤8，对齐 `切片-03:329`）：关闭雾环，只留核心 + 辉光；贴图降采样 128×64（内存 ≤64KB）。
- **帧率掉线**：连续 3 帧 <50fps → 高光冻结为静态光斑位，太阳角改为 1s 慢更；恢复 55fps 持续 2s 后再逐帧跟随。

## 7. 可测断言（机械核验）

- A-1 给定太阳方位角 θ 与赤纬 δ，高光质心投影落在直射点关于视点镜像的经纬窗口内，经 / 纬误差 ε ≤ 6°。
- A-2 夜侧（`Sun.dayFactor ≤ 0`）亮斑全层叠加 alpha ≤0.05。
- A-3 陆地投影区内高光覆盖像素占比 ≤8%。
- A-4 UTC 推进 6 小时，质心经度位移 ≈90° ±5°。
- A-5 贴图缺失走泛化环带时，核心仍落在可见半球朝太阳一侧；断言不抛异常。

| 色板 | 一致 | 无色板外 HEX；两个派生色均写明 token 间 lerp 比例 |

## 9. 可测判据（P1…P10，含 FAIL 条件）

- P1 质心跟随：任一合法 sunDir 下质心在镜像窗口内；FAIL = 误差 >6° 或质心钉死初始位。
- P2 夜侧熄灭：dayFactor ≤0 时 alpha ≤0.05；FAIL = 夜侧仍见亮斑。
- P3 海洋约束：陆地高光像素 ≤8%；FAIL = 陆地出现连片亮斑。
- P4 滑移连续：6 小时经度位移 90°±5°；FAIL = 位移 <75° 或 >105°。
- P5 draw 上限：每帧叠层 ≤3；FAIL = 出现第 4 个高光 draw。
- P6 内存上限：贴图驻留 ≤1 张、增量 ≤256KB；FAIL = 驻留 2 张或超限。
- P7 离线可用：断网启动地球仪，高光层照常渲染；FAIL = 断网后层消失。
- P8 低端机降级：识别低端档后雾环关闭、贴图降采样；FAIL = 降级后仍画三层 / 高分辨率贴图。
- P9 帧率掉线降级：连续 3 帧 <50fps 进入静态；FAIL = 掉线后仍逐帧重算导致帧预算溢出。
- P10 token 合规：全层无色板外 HEX；FAIL = 出现未声明 lerp 的新十六进制。

## 10. 自我论证：为什么它最符合全 App

- 方向源、海洋判别、投影链路全部接既有 `Sun`/`OceanSpec`/`GlobeProjection`，不另起坐标系；离线预计算把最重的烘焙挪出设备端，契合阅读页之外唯一 3D 页的 55fps 红线。
- 视觉语言与卡片基座同源：暖金辉光、纸白核心、石青云灰衰减，落在绢帛军图体系内，不是通用科技蓝高光。

## 11. 它最可能被否掉的地方（自证反例）

- 反例一：离线贴图是静态粗糙度，近距放大后碎闪不足，海面显塑料平滑——B 候选的逐像素扰动更强；若验收要求近距真实感，本候选可能被降级为远距档。
- 反例二：泛化环带兜底在覆盖图缺失时可能把陆地误判为洋面，误亮斑；需在验收时补一张残缺覆盖图用例。
- 反例三：UV 旋移只按经度偏移，赤纬扰动被简化，二至日高光带位置可能偏窄；极端节气下需目检。
