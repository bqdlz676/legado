## 7. 二阶三阶影响

- **与既有门禁的分工（不重复判定）**：⑪ `spec-check.sh` 管规格片段/锚点/坏链接/改写字段存在性；⑫ `check-ext-imports.py` 管扩展导入；⑬ `check-test-source.py` 管测试源陷阱；㉔ `check-rule-ledger` 管规则台账缺口；68 `check-orphan-entries.py` 管孤儿公开入口；62 `check-line-anchors.py` 管文档锚点回源；`check-design-tokens.py` 管通用 71 枚设计令牌；catalog/pyramid 管星表数据完整性。本闸只新增星空专属断言：38 条契约常量逐字比对、四锚色、星空作用域字号、渲染器行数、台账许可串、切片作废标记；数据完整性、孤儿、文档锚点一律转发既有脚本结论，不平行造第二套断言（事故三：禁平行机制）。
- **与 JVM 测试的重叠是双保险不是冲突**：`SkyContractTest.kt` 内已有常量与星点直径锚点断言，本闸静态闸在 push 体检阶段即可发现漂移，JVM 断言在 CI 运行阶段复核；两层口径一致（同一 `SkyParams.kt` 声明）。若以后常量迁成纯函数计算，静态闸会报解析失败并回源行号，不会静默放过。
- **规格改动时脚本怎么跟**：新增/修改契约数值，只改 `sky_spec_model.py` 的 `CONTRACT_CONSTANTS` 一行（符号、期望值、规格出处、类型）；新增机判条目，在 `sky_spec_checks.py` 写 `check_xxx(root)` 并挂进 `collect()`；改人判证据清单，改 `MANUAL_REGISTRY`；分级调整同步改本文件 §2 分类表。规格 §十四 新增条目时，先定级再决定落机判函数还是登记 DEFER，不许直接标 PASS。
- **三阶流程节奏**：本闸退出码三态（0 全 PASS / 2 有条件 / 1 有 FAIL），接进 `rule-gate.sh` 后只有 FAIL 应阻塞合并；UNKNOWN/DEFER 是待办提示，不阻塞。接线与门禁编号属门禁 owner 范围，本单未改 `rule-gate.sh` / `gate-levels.json`。
- **四阶防伪造**：脚本不设白名单、不读基线更新刷绿；每条结论证据都带 `文件:行号`，可被 grep 回源；复用闸只转发退出码与末尾输出，不替它改判。

## 8. 反例边界

- **阈值卡太死误判合规实现**：字号闸只扫星空作用域（`astro/**` + `host/Sky*.kt` + `render/Field*.kt`），不整扫 `host/`。实测 `GlobeScreenHost.kt` 内战役信息、时间轴、控制行、图例等既有地球 UI 沿用 10–13sp 旧字号，不属于 §五.5 星空标签口径；整扫会把既有合规实现误判红，已排除在作用域外。
- **常量重构改名/迁函数怎么办**：符号改名后闸报「声明缺失」FAIL 并回源，不会靠旧名子串命中假绿；处置是同步改 model 表符号名（期望值与出处保留）。若 RHS 从字面量改成表达式（如 `= OTHER * 2`），正则解析不到数值记 FAIL/UNPARSEABLE，不猜值；迁到纯函数（如 `starDiameterPx` 档位计算）的口径须人工确认后再调整断言方式。
- **注释与既有色表不算违规**：KDoc 与行尾注释先剥离再扫；既有地形色表在允许名单；`0xFFFFFF` / `0xFFFFFFFF` 按位掩码上下文（`and 0xFFFFFF`）排除，不判绘制色。
- **RHS 非字面量 / 解析失败**：记 FAIL 并附原文 RHS 与行号，不冒充通过；不做数值推断。
- **空数据/缺表**：星表空表、缺 CSV 由 catalog/pyramid 复用闸自身的空数据断言判红，本闸不重复造；若复用脚本缺失，本闸记 FAIL（复用脚本缺失），不静默跳过。
- **真机口径不越级**：bench 耗时、帧观感、断网流程一律 UNKNOWN/DEFER，不用沙箱静态结果替代 L2/L3 结论（总纲 B1：未验证必须明说未验证）。
- **规格文字与实现口径冲突**：如 §十四.12 称四元数、实现为 yaw/pitch 双标量，脚本不擅自统一口径，只在 DEFER 备注里标出冲突，留验收方裁定。

## 9. 认知成本

- **新人改一条判据要动几处**：
  - 改常量数值：只动 `sky_spec_model.py` 常量表一行；
