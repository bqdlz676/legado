## 四、新发现问题

1. `landSlopeDeg` 为 `private`（`TerrainMap.kt:54`），测试只能经公共面 `passable` / `slopeDeg` 间接观察陆地坡度数值，无法直接断言陆地坡度角度；若后续要直测角度，需把可见性提为 `internal` 并配同包测试，本单不扩可见性。**处置：待裁——是否把 `landSlopeDeg` 提升为 `internal` 以便直测角度，留待下一单按可见性收益裁决。**
2. 渡口坡度上限 `FORD_SLOPE_DEG=12.0`（`TerrainMap.kt:232`）与通行闸门 REGULAR 上限 45.0° 是两套独立口径；本单用例 ③ 只锁"宽水带不新生渡口"，未对具体渡口坡度阈值建断言，阈值若被改动需另单补测。**处置：已入队——下一单补渡口坡度阈值（12.0°）专用断言用例，锁住 `:232` 常量口径。**
3. 用例 ④ 经 `find` 黑盒验证 `nearestPassable`；若第三级 `straightPath` 兜底改变落点口径，本用例的"末格可通行、不踏水面"仍成立，但"钳到最近格"的最近性未被逐格锁定。**处置：待裁——加逐格最近性断言需先暴露路径摘要或落点距离口径，是否补该可见性留待裁决。**
4. 用例 ② 的陡坡由 255 与 1 两个极值像素构造，属合成 Fixture；真实 DEM 的陆内陡坡形态更平缓，本用例只验证闸门方向，不标定真实坡度分布。**处置：判废——合成 Fixture 只验证闸门方向，不在本单补真实 DEM 坡度分布用例。**
