## 三、每类不变式

- `InkReadController`：三引擎编排唯一收口在本类，壳层与手势层不经第二控制器重复编排；两级缓存只作提速，章文本 / 进度 / 样式真值在 `model/ReadBook.kt`（R5），本类不自存第二份；Context 构造期注入一次，偏好读应用上下文，View 构造 themed Context 仅存活本实例，不进任何全局单例；View 监听只在 init 挂一次，重复 `bindChapter` 幂等。
- `ReaderShellHost`：契约无 Context / Activity / View 类型；未 attach 态给安全默认（`probeChar` null、翻页 / 长按空操作或关气泡、`handleBack` 逐层消化后落退出分支）；返回裁决唯一出口在 `handleBack`。
- `InkActionDispatcher`：`startActivity` 唯一出口在 `dispatch`；路由与可分发判定纯函数无副作用；Action 四子类冻结不增删；未接通 / 拉起失败回 false，调用方不兜底跳转；对象无状态、不缓存 Context。
- `InkTokens`：冻结名（UPPER_SNAKE）与驼峰别名双写在册；副本回单源收口归 D23，期间不自造第二份裸值；阅读页专属氛围 / 物理 / 预算 token 无组件单源对应，留本对象。
- `InkModels`：不可变纯数据，无可观察态、无 Composable 回调、无框架持有；字段只透传与只读派生，不改写引擎命中结果。
- `InkSpec`：不触视图类与资源表，判定计数全纯函数；排版常量只转发冻结 token；入参边界回落安全默认，不抛异常、不产生 NaN；外部覆盖位唯一（`overrideLowSpec`）。
- `InkFonts`：Context 注入槽只在 `ensureSerifLoaded` 一处，入槽后只留 applicationContext；句柄槽位语义为内置子集已注入，null 回落系统字体；缺文件 / 损坏 / 超体积 / 未初始化全程 runCatching 收口，不抛、不阻塞首屏。
- `InkFrost`：零资源 id，纯参数判定来自 token；三档兜底按 API 档位与低配标志分流；不伪造 backdrop 采样。
- `InkReaderBook`：只装配不复制编排 / 缓存 / 裁决；控制器槽位可注入；缺省回调保留既有出口；空正文 / 空章节由引擎与渲染层兜底。

## 五、边界兜底九条（逐条迂回方案）

- 边界一：Host 为空 / 未 attach。`ReaderShellHost` 契约各方法在引擎未排版态给安全默认：`probeChar` 返回 null，`turnPage` / `onCenterTap` / `onCenterLongPress` 空操作或关气泡，`handleBack` 逐层消化后落到退出分支；控制器引擎槽为可空（`engine: VerticalLayoutEngine?`），未 attach 时探测 / 翻页不触引擎实例。
- 边界二：字体缺文件。`InkFonts.kt:120` 的 `resolve` 注册表命中失败或资产路径不存在时返回 false，对应句柄槽位留 null，取用侧回落系统对应字体；不抛异常、不阻塞首屏。
- 边界三：字体损坏 / 超体积 / 资产未初始化。`InkFonts.kt:100` 的 `ensureSerifLoaded` 与 `resolve` 全程 `runCatching`；加载异常、句柄类型不符、家族构建失败均在内部收口回退系统字体；`loadAttempted` 置位后不重复重试卡死首屏。
- 边界四：低配机降级。`InkSpec.isLowSpec` 经核数 / 堆内存启发式或外部显式覆盖；`particleCount` 低端取减半档；`InkFrost` 低端档退纯色绢帛、跳过模糊与噪点叠层；帧预算超支由 `recordFrame` / `shouldDegrade` 连续计数触发降级。
- 边界五：token 缺键。偏好自定义键码字符串缺失 / 非法时 `customKeyCodes` 逐键 `toIntOrNull` 忽略非法值，回落空集与默认按键配置；字体角色注册表缺条目回落系统字体；气泡解析缺词由 Resolver Missing 兜底回填，控制器不空气泡。`InkTokens` 静态键为编译期常量，运行期不存在缺键分支。
- 边界六：控制器重复 attach。View 监听只在 init 挂一次；重复 `bindChapter` 只刷新章 / 缓存 / 排版，不重复注册监听；`InkReadController.kt:388` 的 `release()` 摘挂后引擎与缓存按新会话重建；重复 `requestBubble` 走气泡缓存键幂等回填。
- 边界七：空正文 / 空尺寸。空正文进入引擎后排空页兜底渲染；空宽高在 `layoutIfNeeded` 内不构造非法排版；`recordProgress` 空章节长度按零进度收口。
- 边界八：越界命中 / 字典缺失。`probeChar` 越界或未命中返回 null；气泡解析缺词由 Resolver 产 Missing 兜底；翻页越界由引擎内部夹取兜底，进度回填不越界。
- 边界九：宿主销毁 / 进程重建。`release()` 清两级缓存与引擎排版缓存、复位气泡态与朗读回调、断开 View 监听闭包；状态真值在 `ReadBook`（R5），本层不持久化第二份章文本 / 进度；Bundle / saveable 桥接归 B4-07 上屏批次。
