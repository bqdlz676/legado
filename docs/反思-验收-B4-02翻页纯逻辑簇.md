## 2. 踩过的坑 / 教训

- 纯 JVM 判定不能只看 import 行：`ViewGestureBridge` 旧版三个监听字段（OnTouchListener/OnClickListener/OnLongClickListener）本身就持有 View 类型；必须 `git show f8f1b01^` 对照父提交，确认字段拆除、监听内联进 attach lambda，才算 View 依赖真降 internal。
- 弹簧 `coerceIn` 对 NaN 比较恒假，速度 NaN 不会被软夹直接消毒；要顺着下一帧 `value += velocity*dt` 推到发散复位分支才闭环。验收数值安全要追到下一帧，不能只看夹紧行。
- 全仓扫描型脚本（`acceptance-evidence.py`、`kotlin-syntax-lint.py`）在并发负载下子进程阻塞超时（124）；脚本超时是环境问题，不记成代码缺陷，负载回落后复跑取真实末行。
- 回执引文若选了原文内嵌 ASCII 直双引号的句子（如「命令 + 真实输出」），会违反「引文内无 ASCII 双引号」；选句时先 `rg` 确认原句不含直双引号。
