## 五类规则与检出能力
| 级别 | 规则 | 事故原型 → 检出口径 |
| --- | --- | --- |
| ERROR | R1 反引号名非法字符 | `` fun `…1/4/10…`() `` → `illegal characters: /`；扫 `app/src` 全部 `.kt`，`fun \`…\`` 命中 `/ \ : < > * ? | "` 即报 |
| ERROR | R2 静态调实例方法 | `Double.isNaN(x)` → `Unresolved reference`；只报 `Double/Float.isNaN(`/`isInfinite(` 四类，负向后顾排除 `java.lang.Xxx.` 合法全限定调用 |
| WARN | R3 尾随 lambda 绑错形参 | `encodePng(…){…}` lambda 落到 `palette` 而非 `pixel`；仅当同文件该函数已有 `pixel = {` 具名写法、另一处为未具名尾随 lambda 才提示，判不出不报 |
| WARN | R4 可空 map 键 | `mapOf(pointKey to 2)` 键可空，`assertNotNull` 不触发智能转型；键来自 `…firstOrNull()` 赋值或同文件 `assertNotNull(<同标识符>)` 才提示 |
| WARN | R5 泛型无法推断 | `springFor(…)` 脱离 Composable 上下文无法推断 T；仅 `src/test` 下 `springFor(` 无显式 `<…>` 提示，声明行与主源不报 |

ERROR（R1/R2）计入失败退出码 1；WARN（R3/R4/R5）仅提示退出码仍 0。定位 `文件:行:规则:原文`，末尾 `ERROR=n WARN=m`。
