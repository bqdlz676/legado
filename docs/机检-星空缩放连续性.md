## 一、任务与范围

把「星空缩放是连续曲线而不是档位制」变成可自动判的测试，防止将来有人改回档位制而无人发现。

### 落地文件（严格文件域，仅这三个新增）

1. `app/src/test/java/io/legado/app/ui/map/globe/astro/contract/SkyZoomContinuityTest.kt`
   —— 三条纯函数（`magLimitFromBlend` / `skyBlendFromDiameter` / `starDiameterPx`）的连续性契约机检，8 个测试函数。
2. `app/src/test/java/io/legado/app/ui/map/globe/astro/contract/StarCatalogBlendCoverageTest.kt`
   —— 内置真实星表随 blend 0→1 可见星数单调不减，1 个测试函数。
3. 本说明文档 `docs/机检-星空缩放连续性.md`。

### 被测真实实现（开工逐字核实，未假设）

- `SkyParams.kt:263-266` `magLimitFromBlend`：非有限输入按 blend=0 回落实体层；有限输入先
  `coerceIn(0,1)`，再 `MAG_BRIGHT_ENTITY + (MAG_DEPTH_LIMIT - MAG_BRIGHT_ENTITY) * b` 线性映射。
- `SkyParams.kt:251-257` `skyBlendFromDiameter`：非有限输入回落 0；`px ≥ 400` 返 0；`px ≤ 40` 返 1；
  中段 `(400-px)/(400-40)`。
- `SkyParams.kt:225-244` `starDiameterPx`：非有限返 0.8px 保底；`≤-1.5` 返 9px；`>6.5` 返 0.8px；
  锚点间 Pogson 线性插值，单调不增。
- `StarCatalog.kt:403` `parseRows`（internal，同模块测试可访问）；内置 `stars.csv` 星等区间
  -1.44 ~ 6.5，共 8920 行，全部 ≤6.5 等。

## 二、断言清单与「改坏会红在哪一行」推演

### 1. `magLimitFromBlend`：端点 / 单调 / 步长 / 越界回退

测试函数 `magLimit_endpointEqualsContractConstants`（`SkyZoomContinuityTest.kt:45-48`）

- 断言：`magLimitFromBlend(0f) == MAG_BRIGHT_ENTITY(6.5f)`；`magLimitFromBlend(1f) == MAG_DEPTH_LIMIT(11.5f)`。
- 改坏推演：区间若被改成 6.5 / 9.0 / 11.5 三档枚举阶梯，或端点锚被挪动，第 46 / 47 行
  `assertEquals` 取不到契约常量，对应行红。断言右侧引用常量而非字面量副本，常量源值调整不会误伤。

测试函数 `magLimit_monotonicNonDecreasingWithNoJump`（`:58-75`）

- 采样 0→1 共 40 段；等值差 `expectedStep = (11.5 - 6.5)/40 = 0.125`。
- 单调不减：`limit >= prev - MONO_EPS`（第 67 行）。曲线回退（blend 增大上限反而变小）在此行红。
- 无跳变：`delta <= expectedStep + EPS`（第 71-73 行）。阶梯制在档边单步吞下整段等值差
  （例如一步 6.5→9.0，delta=2.5 ≫ 0.125），此处超上限红。
- 反例边界：平滑曲线相邻步长本就 ≈ expectedStep；浮点 1 ULP 级误差由 EPS=1e-6 盖住。

测试函数 `magLimit_outOfFiniteRangeFallsBackDeterministically`（`:87-99`）

- 按现有实现写实的确定回退：`-1f → 6.5`（coerceIn 到 0）；`2f → 11.5`（coerceIn 到 1）；
  `NaN / +Infinity / -Infinity → 6.5`（非有限按 blend=0）。
- 改坏推演：越界若未钳制，blend=2 会推出 >11.5、blend=-1 会推出 <6.5；非有限输入若抛异常或返 NaN，
  第 88-99 行对应断言红。

### 2. `skyBlendFromDiameter`：端点 / 单调 / 外侧不震荡

测试函数 `blendFromDiameter_endpointsAndMidpointClose`（`:112-126`）

- `px=40 → blend=1`；`px=400 → blend=0`；中点 220 → 0.5（反向对称）。
- 改坏推演：若改成「到 40px 才切星空」的硬阈值，40px 一侧不会连续落到 1；映射不对称则中点取不到 0.5，
  第 113 / 118 / 125 行红。

测试函数 `blendFromDiameter_monotonicNonIncreasingAcrossSpan`（`:135-145`）

- 40→400 区间 40 段采样，blend 随 px 增大单调不增（第 142 行）。方向写反或分段曲线段间反向凸起，
  在对应采样点红。

测试函数 `blendFromDiameter_plateauOutsideEndpointsNoOscillation`（`:154-172`）

- 外侧钳平：`0/10/20/40 → 1`；`400/500/1000/2000 → 0`；`NaN / +Infinity → 0`。
- 改坏推演：外侧若按开关式来回切换，小直径侧出现 blend<1 凹陷、大直径侧出现 blend>0 凸起，
  第 161 / 169 行红；非有限输入返 NaN 在第 171-172 行红。

### 3. `starDiameterPx`：星等→直径锚点契约（尺寸，非缩放档位）

测试函数 `starDiameter_anchorMagnitudesHitSpecPixels`（`:184-191`）

- 六档命中：`-1.5→9`、`0→5`、`2→3`、`4.5→1.5`、`6.5→1`、`7→0.8`。
- 改坏推演：锚点表挪动或插值分段改口径，对应 `assertEquals` 在该星等行红；7 等暗于 6.5 进金字塔层，
  兜底 0.8px 不再变小。

测试函数 `starDiameter_nonIncreasingAcrossMagnitudes`（`:200-207`）

- `-3,-1.5,0,2,4.5,6.5,7,11.5` 序列上直径单调不增（第 205 行）。锚点间插值方向写反、或暗星段被
  错误放大，直径反增时此行红。

### 4. 端点精确性（防阶梯枚举回归）

并入 `magLimit_endpointEqualsContractConstants`：端点断言右侧直接引用
`SkyParams.MAG_BRIGHT_ENTITY` / `SkyParams.MAG_DEPTH_LIMIT` 常量，不抄字面量。若区间被改成
6.5/9/11.5 阶梯，端点取值与常量锚脱钩，第 46-47 行红；配合 `magLimit_monotonic...` 的步长上限，
档边跳变也会被抓。

### 5. 星表覆盖随 blend 单调不减（真实数据，不造星）

测试函数 `visibleCountMonotonicNonDecreasingAsBlendGrows`（`StarCatalogBlendCoverageTest.kt:44-71`）

- 从 `user.dir` 向上定位仓库根，读内置 `app/src/main/assets/astro/stars.csv`，经
  `StarCatalog.parseRows` 离线解析；blend 0→1 采 20 段，统计 `mag ≤ magLimit` 的可见星数。
- 单调不减：相邻计数 `counts[i] >= counts[i-1]`（第 65 行）；首末计数都等于目录规模（第 70-71 行）。
- 改坏推演：裁剪口径在 blend 增大时误丢亮星，或上限曲线改回档位制导致覆盖回退，对应 blend 行红。
- 数据边界（如实声明）：内置 L0 全量 ≤6.5 等，离线样本在 blend=0 即饱和，本断言锁的是「不回退」；
  暗星随 blend 放开的增量在金字塔层（L1/L2），需缓存片或远程片源，不属离线单测面。

## 五、反例与边界（连续性阈值取多严）

- **相等容差 EPS=1e-6f**：线性插值在 11.5 量级的浮点误差约 1 ULP（~1.2e-6）。取 1e-6 与仓内既有
  `SkyContractTest` / `SkyBlendCurveTest` 同口径；再严（如 1e-7）会在端点附近误红合法浮点结果，
  再松（如 1e-3）会漏掉锚点值漂移。`MONO_EPS=1e-7f` 只压浮点噪声，真实方向回退量级（整档差值）
  远大于此，不会被容差吞掉。
- **步长上限「≤1 倍等值差」**：合法单曲线相邻 delta ≈ expectedStep；粗档位制（3 档 / 5 档）档边
  delta 是等值差的数倍到数十倍，必然超限。若将来把曲线量化到 ~100 级细阶梯，步长 ≈1.25 倍等值差，
  本闸可能放行——100 级在视觉上已近连续，属可接受边界，不在本闸打击面。
- **空数据 / 坏数据**：`StarCatalogBlendCoverageTest` 对解析为空的目录有 `size > 0` 断言兜底；
  星等非有限的星在统计前 `isFinite()` 过滤，不污染计数。
- **极端输入**：`magLimitFromBlend` 的 NaN / ±Infinity、`skyBlendFromDiameter` 的 0 / 2000 /
  非有限、`starDiameterPx` 的 -3 / 11.5 都在采样或边界断言内；越界不抛异常、不返 NaN。
- **数据缺失边界**：若 CI 检出布局未把 `app/src/main/assets/astro/stars.csv` 带进测试工作目录，
  `builtinCatalog()` 向上找根时 `first { ... isFile }` 会落空抛 `NoSuchElementException`——
  与 `SkyBenchTest` 同范式；该失败是环境问题而非曲线回归，报告如实标注。
- **最强反例自检**：假设本批判断错了——若规格将来真要把缩放改成有限档位（例如三段式明显手感），
  本批测试会红，这是预期行为；届时应先改规格登记，再同步修订对应断言，而不是删测试迁就实现。
