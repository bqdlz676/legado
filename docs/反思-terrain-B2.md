## 2. 踩的坑 / 教训（下任避开）

- **前任报告说「源码零改动」不能直接采信**：必须自己 `git show 22cefd1:<path>` 对照旧 bug 快照、自己 grep 现值，确认符号方向与预算消费点后再动手。本单复核发现旧版 `marchSpeed` 连 `kind` 形参都没有，与 HEAD 已是两个形态。
- **混合 `null` 的 `Pair` 列表有类型推断漂移风险**：`listOf("a" to 1.0, null to 1.0)` 元素类型需显式标 `List<Pair<String?, Double>>`，否则不同 Kotlin 版本推断可能收窄。写表驱动时直接带显式类型标注。
