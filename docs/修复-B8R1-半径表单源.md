## 三、二阶推演：谁还在读这两份私有表（读者全量盘点）

改前逐处排查半径来源，收口后所有读者指向同一符号：

- 情报播种：`:245` `IntelRecord.radiusCells`、`:246` `seenDistCells` → 现取 `enemy.type.visionRadiusCells`。
- 情报闸门（读字段）：`:473` `distCells <= corps.visionRadiusCells && map.visible(...)`；`:683` 观察员闸门 `d <= ob.visionRadiusCells`。字段在装配时已由单源赋值，闸门间接同源。

- 情报模糊：`:831` `recordRadius` 距离项封顶 `type.visionRadiusCells`；`:1120` `fuzzyRadiusCells` 基准半径 `type.visionRadiusCells`。

- 壳层：`CorpsView` 不下发 `visionRadiusCells`，shell 无第三处半径来源。
- 未发现遗漏读者；测试中三处手构 fixture（`CampaignDiplomacyTest:68`、`TriggerEngineTest:54`、`VictoryCheckerTest:58`）均为 `REGULAR` 配半径 4，与表口径一致，属测试夹具字面量，不是声明型半径表，本单不改。
