- 内存：金字塔层增量追加为独立扁平原始类型数组，L0 锚点不变；两层加载后星数叠加，低端机

  目前仍只扫 L0 目录数组，金字塔暗星点尚未进入投影渲染（见 §9 交接项）。
- 署名组件布局：挂 `TopEnd`，14sp 三行弱色文本，不占底部回放控制台区域；地球 / 星空两态均可见，

- 进度面：外部比值优先仅在有金字塔加载时生效；无注入时既有 PENDING 半幅与兜底口径一字不变。
