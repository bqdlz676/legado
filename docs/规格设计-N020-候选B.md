# 卷二 · 体系地基与相对 v1 的重构理由

本卷逐条裁决 20 个硬冲突。每条给：v1 原口径 → 错 / 不够在哪 → 证据 → 本稿裁决。不许回避，不许原样照抄 v1。

## 2.1 冲突 1 · 天球日轮焊点（2D 投影下的「同一个太阳」）

1. v1 口径：§六 / §9.5.12 称天球侧日轮「挂 `Sun.position`（距离 400 已有）」，按世界空间距离 400 单位的圆盘实现。
2. v1 错 / 不够：N-019 §〇.9 与 §八.4 明确「天球不是世界里的固定球，是跟随相机的 2D 投影背景，不做球壳网格」；`SKY_PROJECTION_FAR = 900` 只是投影深度常量（N-019 §八.5、`SkyParams.kt:23`）。在 2D 投影模型里再挂一个距离 400 的世界圆盘，等于把已作废的固定球壳模型复活，模型本身不成立。
3. 证据：`Sun.kt:58` `fun position(utcMillis: Long): Vec3 = direction(utcMillis) * GlobeConfig.SUN_DISTANCE`；`GlobeConfig.kt:64` `SUN_DISTANCE: Float = 400f`；N-019 `docs/星空天象层-实施规格-合并定稿.md:38`（天球是跟随相机的 2D 投影背景）、`:228`（不做球壳网格）。
4. 裁决：天球日轮不是世界空间圆盘，而是把同一个 `sunDir: Vec3` 单位向量，经 N-019 同一套 `StarProjector` 投影矩阵投到屏幕坐标的一个光点，与星点同 pass 批绘。`Sun.position` / `SUN_DISTANCE` 保留给既有地球金色圆盘，国学层不新建天球太阳对象，不复用 400 距离做定位。
5. 焊点纯函数签名见卷三 3.3：地球直射点屏幕坐标与天球日轮屏幕坐标必须由同一 `sunDir` 经同一投影函数派生，单测断言两坐标同源。

## 2.4 冲突 4 · 岁差（文献宿 ≠ 今测宿）

1. v1 口径：§9.5.11 把《月令》「日在营室」直接当今天太阳所在宿；判据 4 要求「同向量」、判据 5 要求「原文逐字」，两条同时压在同一行文字上。
2. v1 错 / 不够：《月令》成文于先秦，岁差约 30°，太阳当代所在宿与文献所记差约一宿；把文献宿当今测宿，既不合天文，也使「同向量」与「逐字」两条判据互相打架。
3. 证据：v1 §8 自列「日在营室，昏参中，旦尾中」出自《礼记·月令》原文；岁差为天文常识（春分点西移，约 71.6 年 / 度）；本稿不重算宿次边界，只裁口径分层。
4. 裁决：卡内分两行——①「文献宿」行：《月令》原文逐字（日在营室 / 昏参中 / 旦尾中），标注「先秦成文口径」，判据 5 只对这行做逐字对照；②「今测宿」行：由当代太阳黄经 λ 归算到当代二十八宿（二期可接星官表定位），判据 4「同向量」只约束今测方向与 `Sun.direction` 一致。一期今测宿行若未接宿次归算，留空行不渲染（空字段不渲染，沿用 N-019 §四.10 口径），不许拿文献宿顶今测宿。

## 2.5 冲突 5 · 节气算法（真太阳黄经，非黄经等分近似）

1. v1 口径：§8.4 称「黄经 15° 等分、《中国天文年历》口径——这是定义不是近似」。
2. v1 错 / 不够：真太阳视黄经不等速（地球轨道椭圆 + 章动），把周年角均分 15° 推节气时刻，与天文年历节气时刻可差 1–2 天；盘面 24 分度可以等分，节气归属与时刻必须用真黄经算法。
3. 证据：`Sun.kt:48-49` 现有赤纬是简化正弦模型（`AXIAL_TILT_DEG * sin(2π(dayOfYear-81)/365.25)`），本身不含轨道方程；本稿不把简化模型当历算精度（v1 §8.3 已分「历算归历算、渲染归渲染」）。
4. 裁决：①节气归属（某一时刻属哪个节气）用真太阳视黄经 λ 判定：立春 315° 起，每 15° 一气，算法入纯函数层；②盘面 24 分度是 UI 等分刻度，不代表时刻均分；③容差：节气时刻与《中国天文年历》核对 ≤1 天；④2026 年 24 节气校验锚点见卷五 5.2，单测给 4 个二至二分锚点；算法精度不达标走卷五回退档 B。

## 2.6 冲突 6 · 时区与换日 / 换月边界

1. v1 口径：§8 列四柱干支，但未定干支 / 月建 / 节气 / 换日用时区；utcMillis 与北京时间混用会错日错月。
2. v1 错 / 不够：`utcMillis` 是 UTC 毫秒；干支日界以子时 23:00 换日、月建以节为界（立春换寅月），若直接按 UTC 日期算，东八区 23:00 后与节气交接日附近必错日错月。
3. 证据：`Chronology.kt:456` `dayGanzhi(date: LocalDate)` 入参已是本地 `LocalDate`；`:449` `yearGanzhi(year: Int)` 按公元年；库内无月干支 / 时干支（`grep monthGanzhi|月建` 无命中，未验证 / 不存在）。
4. 裁决：①口径入口统一：`utcMillis` 先转 `Asia/Shanghai`（UTC+8）本地日期时间，再算四柱；②年干支以立春为界还是公历 1 月 1 日，按既有 `Chronology.yearGanzhi` 冻结口径（公元年），本层不改；③月干支以节气为界（立春换寅月，惊蛰换卯月……），五虎遁推月干；④时干支以子时 23:00 换日；⑤单测锚点：1984 甲子、2026 丙午、立春换寅月、23:00 换日（卷八 C-03）。

## 2.8 冲突 8 · 单字五行词误命中

1. v1 口径：§24.2 / §23.5 把「水 / 火 / 木 / 金 / 土」进 `DictSeedData` 全局词典，产 OpenArtifact。
2. v1 错 / 不够：五字是最高频常用字，进全局词典会在任意文本误高亮（「水车」「大火」「木头」「金子」「土地」全中弹五行气泡）；`DictSeedData` 字表已收「水 / 火 / 木」等单字（`DictSeedData.kt` CHAR_TSV 水 / 火 / 木行），再叠五行词条等于双轨。

## 4.1 ① 目的与用户可感效果

### 4.1.1 功能目的

## 4.6 ⑥ 接口（契约字段 / 签名 / 只增不改项）

### 4.6.1 `CosmoState`（一次派生，全层消费；纯 JVM data）

## 7.1 phase×mode 矩阵（逐格主控 / 挂件会计）

维度说明：phase = 空间相（地相 GLOBE / 天相 SKY_HEAVEN / SKY_EARTH）；mode = 主题签（地图 / 国学）。史相为正交时间叠加，一期不启用。

2. **地相 × 国学（道相）**：主控 = 右下节气盘（观 / 推双态）；挂件 = 左缘卦条 + 历法牌（Sheet 月令卡不计常驻挂件）；球面 = 回归线 / 直射点 / 五方锚点；天相两组切换签隐藏。
3. **天相 × 地图（天外 / 地上）**：主控 = N-019 既有两组（顶部竖排星官 / 星座 + 右上天外 / 地上）；挂件 = `SkySheet` 星卡 + `SkyAttribution`；国学叠加整体隐去（冲突 13）。

1. `CosmoClock` 相位在宿主 ViewModel 保持；跳读原文 / 切模式 / 进卡返回后，太阳相位、节气、干支不变。

## 卷十一 §5 · 双向联动闭环（五入口，双向可回）

## 卷十一 §6 · 唯一事实源

## 卷十一 §9 · 红线允许 / 禁止例

1. 允许（文献知识口径）：「句芒，木正，春季佐神。《礼记·月令》孟春：『其帝大皞，其神句芒。』」；「湘君，湘水之神；王逸以为水神，刘向以为舜妃娥皇，诸说并存。」；「四渎：江、河、淮、济。《尔雅·释水》：『江河淮济为四渎……』」；「社神，《礼记·祭法》：『共工氏之霸九州也，其子曰后土，能平九州，故祀以为社。』」；「东君，日神，《九歌》篇名；职司与出处据《楚辞补注》，与国家祀典日神条目互参。」
2. 禁止（触碰即废条）：① 祈福 / 供奉引导（「拜灶神保家宅平安」「求城隍消灾解厄」「供奉三官赐福」「有求必应」）；② 禁忌 / 灵验话术（犯忌日不宜出行、祭祀方位宜忌、不灵验则降祸、显灵传说）；③ 现役宗教内容（当代宫观、民间法教、现役神职人员、皈依 / 诵经 / 法事引导）；④ 以小说为史源（《封神演义》人物不得入库；后世戏曲小说系统神祇须单独裁决史源边界）；⑤ 占验断卦（据神名起卦、纳音配神、吉凶断语、卜问吉凶、命格对照）。
3. 空数据兜底：某体系条目未入库时，气泡落既有 Missing 兜底路径，不塞假条目、不造占位神名；查无此神返回未识兜底，不猜别名凑命中。合规扫描判据见 C-38。

## 卷十一 §10 · 神仙卡八态迂回

1. 就绪：条目已入库、链已接通，卡内五项高亮与「观」按钮按事实源就位。
2. 悬停 / 按下：沿用卷四 4.4 悬停 / 按下态，热区 ≥48dp；神祇条目不另造手势。
3. 加载：条目 / 种子读取中，既有元素照常显示，缺失条目对应行不渲染（空字段不渲染），不出现空白洞、不崩。

5. 空：某神缺事实源行（五行 / 方位 / 时节 / 星宿 / 祀典任一），对应行留空不渲染，卡面其余行正常。
6. 错误：条目校验失败 / 解析异常，回退内置种子条目，卡顶一行 `textAccent` 一次性提示，不白屏。
7. 离线：已缓存条目全可用；未缓存走低层种子兜底；纯名称 / 体系 / 出处字段不依赖远程下载。
8. 边界兜底：同名消歧失败，候选进 `candidates` 一键切换，不塞假坐标 / 假关系；条目库未就位时，月令卡帝神行退为纯文本（§4.5.1 第 2 条）。
