## 五、反例与边界（按 B4 先假设方案错误，找反例复核）

1. 反例：战役 `duration` 回合数可直接当 `totalStage`。否证：规格进度语义是「阶段」（`phases`），回合数是回放节拍；`phases` 为空时用 `rounds` 只是兜底代理，文案不得写成阶段满分母。穷举三态：`phases` 非空 / `phases` 空但 `rounds>0` / 双空，三态分别取 phases 长度、rounds、0。
2. 反例：allusion 出处列前缀能推出朝代，典籍区可复用。否证：前缀属典故出处，不指向书的成书年代；60.4% 条目无前缀，朝代名未归一；直接复用会大面积错标。`bookDynastyHint()` 同为阅读页提示口径，不构成书册朝代数据源。
3. 反例：`person.txt` 88577 行足够覆盖马恩。否证：语料固定为中文历史人物，朝代列与身份口径一致；grep 0 命中马克思 / 恩格斯；1818 / 1883 是清代人物生卒年巧合。
4. 反例：`timestamp` 落库先后可代理掌握度。否证：规格掌握判定为 `review_count>=5` 或 `mastered=1`；落库久不等于复习过，仅按时间排序会把只点过一次的字排到前面。
5. 反例：阅读页 `bookDynastyHint()` 可直接作为典籍卡朝代列现成实现。否证：它是 `private` 阅读页排序提示，键表 12 朝且硬编码；发现页复用须经数据批次裁决，否则双口径回炉。
6. 数据边界穷举：空列表、坏条目列数不足、断网、大目录首帧卡顿、书源配置变更、reduce-motion、低端机内存、暗色模式——数据源侧统一按「条目可解析才入列，不可解析跳过不抛异常」口径；渲染侧边界归卡片组件既有五态与空态组件承接，本单不越界定渲染参数。
