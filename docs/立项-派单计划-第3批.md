## 四、二阶与三阶风险（本批前先想清楚）

- **token 单源被绕过**：写码代理图快直接内联十六进制 → 后续换肤/暗色全失效。对策：进 CI 静态检查（裸色值 grep 0），不只靠验收人眼。
- **S-02 契约先行、实现滞后**：气泡协议冻结但 `resolve` 未接，会导致 S-05 纪年联动拿到空候选链。对策：S-02 的 `resolve` 出口必须给"空候选也返回结构完整对象"的兜底，先接桩再接真引擎。
- **S-10 / S-09 同批并行改同一 UI 域**：书架与阅读共用卡片与手势路由（`GestureRouter` 长按改放大镜，见裁决第十八节）。对策：两者排不同批或显式切文件域（书架 `ui/main/`、阅读 `ui/book/read/`），手势改动只在阅读域。
- **粒子预算累计**：启动 130 粒 + 书架 20 粒若同帧在场，55fps 保不住。对策：S-01/S-10 各自写"页面互斥、不同时活跃"，并加一条跨页断言。
- **桌面/WebView 旧口径回流**：切片里 WebView/iOS/桌面条款若被抄进实现注释，下一棒会误判技术栈。对策：4 份切片已加"时代口径"头注（`立项-冲突裁决.md` 第几节为准），派单必须显式引用该头注。
