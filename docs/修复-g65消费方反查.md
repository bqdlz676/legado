## 三、三面判据实现

1. 删除面（DELETE，FAIL）：改动面相对 origin/main 删掉 enum entry、sealed 子类声明或伴生常量名字后，在扫描根全仓 token 边界 grep 该名字；注释剥掉、字符串保留（字符串 handler 映射算残留）；任一残留引用即红，点名 文件:行，见 `data_scripts/check-member-consumers.py:554`。
2. 新增面（ADD，WARN 不硬红）：新增 sealed 子类或 enum entry 后，找归属父类型的 when 表达式；有 else 分支或已有对应新成员候选分支即记配对；无 else 且未覆盖新成员必须 WARN 点名 文件:行 与缺哪个成员，见 `data_scripts/check-member-consumers.py:447` 与 :490。
3. 改名面（RENAME）：同文件内同类一删一增按改名判；旧名残留为零 → 通过并输出 RENAME 配对记录；旧名有残留 → 红，见 `data_scripts/check-member-consumers.py:571`。

形态覆盖：多行 when、带 subject 的 when、`when (val x = …)`、sealed 嵌套子类 `object Foo : Bar.Baz` 四种都进了解析面。归属口径：when 主体显式标注父类型，或所在文件文本提及父类型短名才纳入；静态闸拿不到接收者类型时跳过并留 INFO，不硬判。
