## 0. 三层分离 + 四条硬规则（防腐设计，最高优先级）

### 三层（各自职责不可混用）
1. **导航层（可有损）**：索引/摘要只回答"细节在哪里"——位置 + 状态 + 依赖 + 版本号。摘要丢细节无所谓，因为它**从不被用来干活**。
2. **执行层（无损）**：原文一字不动、只做物理切片；子 AI 拿到的是"读原文第 X 段到第 Y 段"的指针 + 原文本身，逐字照做。解决上下文超限靠"每次只读一小段"，**不靠把大段压成小段**。
3. **验收层（逐字对照）**：总控/验证 AI 对照的是原文全文（不是摘要）。每条规格必须被某个子 AI 的输出完整覆盖，逐条核对，不许"看着差不多"。

### 四条硬规则
1. **锚点强制**：任何摘要条目必须带原文锚点（文件 + 段落号/行号），任何环节一键回源。类比 Git：commit message 可以烂，blob 内容永远无损可查。
2. **三类内容禁止压缩**：规格说明、接口契约、验收标准——永远全量传递、逐字保留（这是"结果与规则"，不是"过程"）。
3. **只压缩过程**：允许摘要的只有"已完结的过程"——旧讨论记录、失败尝试、日志。过程可丢，结论和依据不能丢。
4. **子 AI 禁止自行摘要**：子 AI 的输入输出都走原文切片 + 结构化结果（diff/补丁），不允许"理解后转述"。转述就是丢细节的开始。

## 1. 统一规范（所有子 AI 必守，违反打回重做）
1. 文件域独占：每个模块只写自己那一个目录，越界即冲突，打回。
2. 包命名统一 `io.legado.app.<模块>`，禁止用 agent id / 任务 id / 会话 id 命名文件或目录。
3. 颜色只引用 12 色 token 常量（不硬编码十六进制）：
   bg-page #F7F1E6 · bg-surface #EFE8D8 · bg-overlay rgba(26,20,16,.45) · text-primary #1A1410 · text-secondary #5C4F3A · text-tertiary #9B9687 · text-accent #C23B2E · brand-gold #D4A54A · brand-copper #8B6914 · color-link #C23B2E · color-divider rgba(26,20,16,.08) · color-glow rgba(212,165,74,.3)
4. 关 MaterialTheme，Compose 自绘；禁用 Material 默认 ripple / elevation / shared-axis 转场。
5. 每个类配单测 + bench；bench 断言写死指标（如翻页 ≤16ms、命中 ≤80ms），跑过才算数，没跑过必须写"未验证"。
6. 已有实现绝不复用，只做参考；改动后 grep 确认真正写入；"编译通过 ≠ 功能可用"。
7. 代码注释用简体中文，解释"为什么"而非"是什么"。

## 1.5 美化与感官引导（好看 = 硬验收项，不是可选项）
> 本节是「统一规范」的美学延伸：每个 UI / 3D 子 AI 派单时，除功能契约外，还必须按本节把「好看」做对。观感不达标 = 打回重做，与功能 FAIL 同级。

### A. 美学总纲（用户原文，逐字保留，不许改写/降级）
你是落文的设计执行 AI。在实现每一个功能、每一个页面、每一个组件时，自动套用以下美学标准。不要等指令，自己主动提升。

- **气质**：东方美学。绢帛古韵。克制留白。像一个古人设计的现代 App——不是复古贴图，是骨子里的雅。
- **颜色**：纸白、墨色、朱砂、暖金。全站只用这四个色系。暗处偏暖不偏冷。金是沉金不是亮金。禁止 Material Design 色值。禁止纯黑纯白。
- **材质**：纸的纹理、磨砂玻璃的雾感、暖光在绢帛上的渐变——所有表面都有触感。不是扁平设计，是有厚度的平面。
- **动效**：弹簧质感——有弹性但不跳脱。东西出现不是弹出来，是浮上来。东西消失不是闪没，是散开。所有动画用缓动曲线，禁用 linear。
- **空间**：一层一层推进去——阅读页在最后面，气泡浮在阅读页上面，Sheet 浮在气泡上面，毛玻璃遮罩让后面那层还在但不打扰。Z 轴深度感比横向布局更重要。
- **字体**：正文竖排用宋体。数字用等宽。小字无衬线。不混用超过三种字体。
- **组件**：每一个按钮有悬浮态、点击态、禁用态。反馈是朱砂色浸染，不是机械高亮。加载是三个金点依次亮灭，不是转菊花。
- **一句话**：古典不是贴图贴出来的，是把一切拿掉之后剩下的那个字。每一个像素都要好看。

（落地锚点，3D/地图模块对齐六要素）绢帛军图、墨爆粒子、暖金辉光、磨砂毛玻璃、spring 动画、3D 地形隆起。

### B. 配色铁律（四色系 + 12 色 token 语境化）
- 四色系总原则（用户美学总纲）：纸白、墨色、朱砂、暖金，全站只用这四个色系，暗处偏暖不偏冷，金是沉金不是亮金，禁纯黑纯白。
- 颜色只引用 12 色 token 常量（四色系的落地展开），禁硬编码十六进制、禁 Material 默认色：
  - 底：bg-page `#F7F1E6`（纸白）· bg-surface `#EFE8D8` · bg-overlay `rgba(26,20,16,.45)`（遮罩）。
  - 文字：text-primary `#1A1410`（墨色正文）· text-secondary `#5C4F3A` · text-tertiary `#9B9687`（次要/灰）。
  - 强调：text-accent / color-link `#C23B2E`（朱砂——失败/删除/点击/强调）· brand-gold `#D4A54A`（暖金——有数据/可点/选中/高亮）· brand-copper `#8B6914`（古铜）· color-glow `rgba(212,165,74,.3)`（暖金辉光）· color-divider `rgba(26,20,16,.08)`。

### D. 材质与质感（原文-07 四层框架）
- 磨砂毛玻璃：backdrop-blur 茶色毛玻璃遮罩 + subtle border 暖金边框（半屏 Sheet、底部注释条 40dp、专题卡）。
- 宣纸颗粒：noise texture 宣纸颗粒底（书架、阅读页）。
- 暖金辉光：soft shadow `0 0 12px rgba(212,165,74,.3)` 暖金微光（悬浮/选中卡）。
- 墨爆粒子：字面墨爆 100ms 冲击波、删除卡片碎成墨滴、章节氛围 particle field 水墨轮廓粒子（《城濮》→战场剪影）。
- 卡片六态：默认 / 悬浮（暖金阴影增强）/ 点击（朱砂阴影）/ 禁用 / 加载 / 空数据，全要覆盖，不留空白态。

### E. 3D 质感（切片-06/17/18/19/20，沙盘/地球仪/地形）
- 绢帛军图色调：Color Grading LUT 全天候统一；Bloom 后处理阈值 0.7（都城光柱/渡口/金粉自动泛光溢出）。
- 都城暖金瓦顶 + 城内极淡暖光；金属 PBR（暖金=金材质粗糙度 0.25，敌灰青=铁材质粗糙度 0.5）；棋子投真实阴影。
- 粒子三形态：圆点 + 细长飞白丝 + 小三角碎屑；渡口金色光柱粒子（每柱 40 粒、柱高 15 单位）；箭头锋芒 + 流动金粒子。
- 势力色：己方暖金半透明 opacity 0.12、敌方灰青 0.10、盟友铜 0.08。
- 3D 地形隆起：高程决定高度、覆盖决定颜色/微地形；森林深绿 `#2D5A27` 绒布质感隆起。
- 太阳金色圆盘辉光（直径 8 单位、跟地球锁 400 单位）按真实 UTC 算位置，暖金散射到近侧大气层；星空球半径 900、大星辉光点、偶泛淡金。

### F. 「好看」验收（每个 UI / 3D 模块派单必带）
1. 任务书验收标准除功能断言外，必须含一条「观感」检查项：对照 A–E 的六要素/配色/动效/材质，列出本模块落点的美学要求，不能只写「美观」两字了事。
2. 视觉验收单独一轮（对照六要素逐项看，不是「看着差不多」）；观感不达标打回重做，与功能 FAIL 同级。
3. 不降级不砍功能：墨水屏模式 / 低端机降级分支照写，但默认路径必须满血美学。

### G. 落地细则（对总纲的优化补充——不改写 A 原文，把气质落到可执行、可防串味、可验收）
1. 字体（A「不超三种」↔ U9 五枚子集对齐）：三种 = 宋体（正文 Regular + 标题 SemiBold 同一种宋体）+ 无衬线小字（NotoSansSC-Light）+ 等宽族（数字 Inter / 典籍编号 JetBrainsMono）；不是「只能三个字体文件」。
2. 空间（A「一层一层推进去」落地）：固定 zIndex 阅读页(底) → 气泡 → Sheet → 遮罩(顶)；遮罩 bg-overlay `rgba(26,20,16,.45)`，毛玻璃 backdrop-blur 基准 12px，不另造透明度色值。
3. 组件（A 三态补全六态）：默认 / 悬浮（暖金阴影增强）/ 点击（朱砂浸染）/ 禁用 / 加载（三金点 600ms）/ 空数据（EmptyState，不留空白）。
4. 美学禁区（反例清单，防审美漂移）：禁 Material 色值与默认组件、禁纯黑纯白、禁 linear、禁菊花、禁 iOS 式大圆角、禁霓虹/镭射渐变、禁 emoji 当图标、禁系统默认 drop shadow/elevation。
5. 好看不牺牲性能：粒子/辉光/毛玻璃全在红线内（翻页≤16ms、球面 55fps 手机/120fps 桌面、内存峰值≤100MB、首开≤800ms）；低端机降级分支照写、默认满血。内存三档判据见 F-04：≤100MB 过；100–120MB 注「待优化」；>120MB 打回（2026-11-24 订正，取代旧 ≤180MB 红线）。
6. 可 grep 验收判据：UI 域无 `#` hex 硬编码（12 token 定义处除外）、无 `linear` 缓动、曲线命中切片-15 表、字体语义族 ≤3、无 Material 色值/默认组件引用。

## 2. 跨模块核心契约（FROZEN，下游按此对接）

### 气泡（切片-02，已冻结）
- `BubbleContent(kind: 字|词|典故|人名|地名|年号|干支|朔望, token, phonetic, headline, body, detail, actions, candidates, source)`
- `sealed Action(OpenMap / OpenPerson / OpenTimeline / OpenRelation / OpenArtifact)`（2026-11-24 订正，F-07/F-11）：**五子类**；新增 `OpenArtifact(artifactId: String, type: String)` 为 2026-11-24 用户拍板新增，**此后不再增删**。
  > 为什么/适用条件：Action 是气泡跳转意图的冻结枚举，新增跳转意图必须先改本冻结契约；名物详情走 OpenArtifact，详情内有地名再两级跳 OpenMap。
- `BubbleResolver.resolve(paragraph, pos, anchor): BubbleContent`
- 优先级：纪年/干支/朔望 → 典故 → 人名 → 地名 → 多字词(长词优先) → 单字 → Missing 兜底

  > 为什么/适用条件：加新类别只加数据表、不改 Provider/UI；EntityProvider 不重构 D1 字典/D2 人物/D3 地名，只对新增类别生效（F-10），旧三类仍走原有 Provider 路径、不双轨。
- **人物消歧唯一入口（B2 已收口）**：`help/bubble/PersonProvider` 初始化时把自身查询入口注册进 `ContextAnchor.personProvider`（PersonProvider.kt:37）；旧 `help/NameResolver` 扁平层不再写该总线（NameResolver.kt:44 注释），无双写。图谱/人物详情只走 `help.person.graph.PersonGraphExtractor`（D2 支撑）；旧 `help.relation/` 包（RelationExtractor 门面 + 扁平档案 / 同名分组 / 出场持久化 / 异读拼音）已整包拆除，代码内不得再 import。

### 分页引擎（横排 / 竖排双模式）（已冻结）
- `VerticalLayoutEngine.layout(text, viewWidthPx, viewHeightPx)` / `hitTest(x, y): CharHit?` / `invalidateCache()`（不许改签名）
- **保留的是分页算法**（一章文字切成一页一页），横排/竖排只是排版方向两种模式，分页逻辑相同：竖排＝从右往左走列、列从上往下填字；横排＝从左往右走行、行从上往下排。`vertical/*` 是落文自有的竖排模式实现，**不是"竖排引擎"**（2026-11-24 16:03 用户原话拍板）。横排用户完全可以用，不需要竖排就永远是横排模式。
- **横排模式入口**：分页引擎横排参数（`PageDelegate` 横排模式）为契约允许的既有能力；D20 现代文学只启用横排模式、追加现代文参数（首行缩进 2 字、横排段距、底部横线进度条），**不改引擎核心签名**。
  > 为什么/适用条件：旧标题把"竖排"误当成被保留的引擎本体，易被下游理解成横排需另开新布局；本契约只冻结分页算法与三签名，排版方向以模式参数区分。

### 组件库（M15 在做，签名完成后冻结）
- InkButton / Card / BottomSheet / Toast / EmptyState / Timeline 六件套；气泡容器不在组件库内，渲染归 U5 阅读页壳，气泡数据只认 help/bubble 冻结协议。
