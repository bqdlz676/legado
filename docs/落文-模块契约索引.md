# 落文 · 模块契约索引（v1）

> 用途：定模块边界 + 跨模块输入/输出契约 + 统一规范，避免"缝合怪"。
> 使用：子 AI 只读「自己模块那一行」+ 对应切片 + 第 0/1 节的公共契约，不必读全文。
> 版本：v1（2026-11-22）。任一模块接口变更 → 总控更新本文件、bump 版本号、通知下游子 AI 只重读受影响条目（不重读全文）。

## 0. 统一规范（所有子 AI 必守，违反打回重做）
1. 文件域独占：每个模块只写自己那一个目录，越界即冲突，打回。
2. 包命名统一 `io.legado.app.<模块>`，禁止用 agent id / 任务 id / 会话 id 命名文件或目录。
3. 颜色只引用 12 色 token 常量（不硬编码十六进制）：
   bg-page #F7F1E6 · bg-surface #EFE8D8 · bg-overlay rgba(26,20,16,.45) · text-primary #1A1410 · text-secondary #5C4F3A · text-tertiary #9B9687 · text-accent #C23B2E · brand-gold #D4A54A · brand-copper #8B6914 · color-link #C23B2E · color-divider rgba(26,20,16,.08) · color-glow rgba(212,165,74,.3)
4. 关 MaterialTheme，Compose 自绘；禁用 Material 默认 ripple / elevation / shared-axis 转场。
5. 每个类配单测 + bench；bench 断言写死指标（如翻页 ≤16ms、命中 ≤80ms），跑过才算数，没跑过必须写"未验证"。
6. 已有实现绝不复用，只做参考；改动后 grep 确认真正写入；"编译通过 ≠ 功能可用"。
7. 代码注释用简体中文，解释"为什么"而非"是什么"。

## 1. 跨模块核心契约（FROZEN，下游按此对接）

### 气泡（切片-02，已冻结）
- `BubbleContent(kind: 字|词|典故|人名|地名|年号|干支|朔望, token, phonetic, headline, body, detail, actions, candidates, source)`
- `sealed Action(OpenMap / OpenPerson / OpenTimeline / OpenRelation)`
- `BubbleResolver.resolve(paragraph, pos, anchor): BubbleContent`
- 优先级：纪年/干支/朔望 → 典故 → 人名 → 地名 → 多字词(长词优先) → 单字 → Missing 兜底
- 6 Provider：Char / Word / Person / Place / Date + ContextAnchor 共享总线

### 时空锚定（切片-05，已冻结）
- `ContextAnchor` 持「当前书 / 当前章 / 候选年代区间」，全 app 唯一消歧入口
- `Chronology.anchorFromText(text) → 候选年代`；`Chronology.timelineFor(year) → 同年多政权对照 + 干支 + 距今`
- 点晋命中：年代锚 -722~-453 → 春秋晋国（今山西晋城只作「今址参考层」候选）

### 竖排引擎（正在定义，产出后由总控冻结补录）
- 竖排引擎子代理完成时给出对外 API 签名（文本→竖排列分页 / 逐字命中 / 每字 x,y 稀疏缓存 / 翻页手势），本索引补录并 FROZEN。

### 组件库（M15 在做，签名完成后冻结）
- InkButton / Card / Bubble / BottomSheet / Toast / EmptyState / Timeline 七件套。

## 4. 差异检查与检索规则
- 子 AI 交付时，除代码外必须回传：改动文件绝对路径 + 对外 API 签名 + 单测/bench 是否真跑过。
- 总控只保留「文件路径 + API 签名 + 状态」入本索引，不保留原始代码进上下文，防总控上下文墙。
- 需要细节时按需 Read 具体文件，不一次性 dump。
