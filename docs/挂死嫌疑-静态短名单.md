## 五、反例推演：静态扫描的典型假阳性与剔除口径

1. **await() 包在自带超时的 `.use{}` / withTimeout 里**：`RE_AWAIT_TIMED` 只认带 `TimeUnit` 或数字实参的 `await(...)`；被外层 `withTimeout(...)` 包住但裸调 `await()` 的情形，脚本按文件级检查 `withTimeout` 存在即给 d 类降权标注，证据行保留原文交人工复核。外层 `.use{}` 关闭资源不等于等待超时，二者不混淆。
2. **sleep 在 `@Ignore` / 已禁用的用例里**：本仓当前 0 处 `@Ignore`；脚本检出 `@Ignore` 注解的文件整体进 `ignore` 隔离桶，不进主短名单、不进 txt 清单（优先级高于 category 判定）。
3. **被 `@Category(SlowBenchTest)` 等已隔离的类**：复用 `emit-shard-lists.py` 的 `classify()` 判桶，打标类全部进 category 桶单列（见 §四），本身就不在四分片里，不计入分片嫌疑。
4. **字符串字面量里的阻塞词**：JS 源码字符串 `"while (true) {}"`、断言串 `delay(1_000L)`、`"result.get("id")"` 等，经 `outside_mask()` 判定落在字面量区间内，不参与特征匹配；`.get()` 只认零参形式（`map.get("x")` 带参不命中）。
5. **mock / 拦截器形态的 okhttp 调用**：只构造 `Request`/`Response`、不调 `newCall().execute()` 不记 i 类；文件内存在 `Response.Builder()` 时，execute 命中行备注「mock 响应待人工确认」；真实 `openConnection()` / `URL(` 才记命中；连 `127.0.0.1` 回环的标注「非出站网络」。
6. **协程挂起与 JVM 阻塞混淆**：裸 `.await()` 按文件内声明名归类——`CountDownLatch/Semaphore` 接收器记 c 类；`.result.await()`、`launch/async` 接收器及常见 Deferred 命名记 d 类降权；其余未定型接收器降权并备注，交二分复核时按变量类型区分。
7. **注释 / KDoc 里的特征词**：行首 `*`、`//` 与行尾注释经 `code_part()` 剔除后再匹配；例如「不依赖 Robolectric」的说明文字不会记 k 类命中。
8. **原子量 / 静态 getter 同形 `.get()`**：文件内声明为 `AtomicBoolean/Integer/Reference` 等的 接收器、首字母大写的伴生对象/静态 getter，不计 h 类，误入 §七 附录留痕。
