### 判据 2 · 语义正确（2D 位移、正面朝用户、反向阴影、四元数数学） —— PASS（静态层）

- **不是 3D 旋转而是 2D 位移**：视差链路只写 `translationX/translationY`——`ShelfBookCard.kt:204` `translationX = parallaxState.translationX`、`:205` `translationY = ... + parallaxState.translationY`；`parallaxState` 不向外暴露任何旋转角。既有 `rotationY = tiltY`（`:198`）、`rotationX = tiltX`（`:199`）仅由按压/滚动驱动（`:90-105`），与陀螺仪输入无关。
- **卡片始终正面朝用户**：视差路径未对 graphicsLayer 施加 rotationX/rotationY；无绕轴翻转写入。
- **倾斜反方向加深阴影**：`ShelfParallax.kt:186` `shadowOffsetX = -roll * shadowShiftPx`；`:189` `shadowOffsetY = -pitch * shadowShiftPx`；半径与透明度随 |roll| 加深（`:194`、`:200-201`）。
- **四元数→倾角数学复核**：`quaternionToTilt` `ShelfParallax.kt:78-94`。
  - 分量长度检查 `:79` `q.size < 4` 返回 null；有限性检查 `:82` `!it.isFinite()` 返回 null；近零模长 `:84` `norm < 1e-6f` 返回 null。
  - 先归一化再取角：`:83` 求模、`:85` `wn/xn/yn/zn` 单位化。
  - 公式 `:88` roll = `atan2(2(wx+yz), 1-2(x²+y²))`；`:89` pitch = `atan2(2(wy-zx), 1-2(y²+z²))`，与标准四元数→ Tait-Bryan 欧拉角分解一致。
  - 范围钳制 `:91-92` `.coerceIn(-1f, 1f)`；除半 π 弧度（`:67` `HALF_PI`）把 ±90° 映射到 ±1。
