## 表三 · 建议补的门禁（只给设计，不改 `data_scripts/`）

1. **多档完整性**：解析 `并发档位.md` 与口径冻结"档 N = 写 a + 查 b"，逐档抽出三元组；PASS＝三档齐全且与口令串一致；FAIL＝任一档配比缺失或台账无写/查分列。

3. **旧口径作废扫描**：维护被否决串表（三布尔含 APK、≤3 并发、竖排引擎、红日版）；排除流水留档/否定句/作废清单后仍命中即 FAIL，须带"已作废+日期+取代条文锚点"。
4. **机制条文接线核对**：遍历总纲/口径冻结中"门禁/脚本"指向，校验 `rule-gate.sh`、`watchdog.sh`、`spec-check.sh`、`data_scripts/*.py` 有对应判据；条文无脚本落点即 WARN。
