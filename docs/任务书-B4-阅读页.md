- **B2 坏文件（解析失败/编码损坏/章节体非文本）**：单章解析异常 → 该章落错误占位行（章节标题 + 损坏提示 + 重试/跳过动作），不阻断全书翻页；位置记录跳过坏章；异常记 warning，不崩出页。
- **B3 断网 / 离线**：在线书章节未缓存时打开 → 落离线兜底空态（已缓存章节可读，未缓存章提示网络不可用）；气泡字典/地名/人物 Provider 走本地缓存，全空走 Missing 兜底（允许查网络/加入生字本）；不转圈死等。
- **B4 大文件卡顿**：超长章节/密集批注章 → 分页按章切批渲染，首屏先出当前页，余页后台预载；测量缓存（sparse array）命中后重排 ×3；渲染超 16ms 帧时先降氛围粒子密度，不砍翻页与排版正确性；缓存只留前后各 3 章，其余释放。
- **B5 竖排测量缓存失效**：缓存失效（字号/字体/列宽变更、旋转、进程重建后）→ 按 `invalidateCache()` 口径重算当前章，重算期间显示旧页占位不白屏；缓存键带样式/字号/字体版本，版本不符自动失效重建。
- **B6 旋转 / 配置变更 / 进程重建**：当前章、页内位置、选区、气泡态、Sheet 待决状态由 `rememberSaveable` + `ReadBook` 位置记录恢复；恢复后不落错章、不回首页；离场闸两段式状态不卡在离场段。
- **B7 reduce-motion（减少动画）**：掀角/墨爆粒子/辉光/转场走 `MotionSpec` 瞬时档，翻页直落终态；不砍阅读可达性与排版正确性。
- **B8 低端机 / 帧率掉线**：双引擎并存超 100MB 按三档（≤100 过 / 100–120 待优化挂账 / >120 打回），不靠减粒子数绕内存门禁；地图前台阅读绘制抑制，低端机不并发抢 GPU；性能掉线先查预载/缓存/绘制回调，不归因机器不行（B13）。
- **B9 暗色 / 纯黑主题**：新壳色值回 token 单源，暗色档纸白/墨色/朱砂/暖金/石青按 token 映射翻转；注音小字与进度线在暗色下保持可读对比；无 token 映射的装饰色不自造裸值；墨水屏静态开关（关动画/粒子/3D/黑白灰配色）位随设置批次落位（切片-05 缺项行）。
- **B10 最强反例自否**：假设「直接把旧 `ReadBookActivity` 的菜单/对话框原样搬进 Compose 最快接线」——否证点：旧壳 3777 行耦合 `ReadView.CallBack`、旧菜单编排与 `lib/prefs` 对话框，搬皮等于把双轨固化进新壳，引擎接线（设计件 C-1 文字面上屏）被界面债务压住；正确路径是先按路线 C 把引擎文字面与状态源接通，菜单/对话框逐件按 B1 组件重写。再假设「顺手把引擎 View 宿主改成接口解耦（路线 A）」——否证点：沙箱不能本地编译，跨文件签名改动一次红就是几十条编译错，CI 未连绿前做 A 分不清责任；A 延后独立成单。
