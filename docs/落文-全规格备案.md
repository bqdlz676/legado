### 2.6 凭据泄露风险与轮换指引

- **本文档含真实明文凭据**：GitHub PAT（`ghp_…`）与 keystore 双口令。使用约束：
  1. 只许存私有仓库或个人离线备份；**严禁**贴到公开仓库、公开文档、聊天群、截图、 issue / PR、博客或任何对外渠道。
  2. 飞书镜像同样按私有文档权限管理；分享前确认接收方范围。
  3. 凭据只用于本项目出包与推送，不复用到其它站点。
- **Token 泄露处置**：一旦 `ghp_` token 出现在公开场合或怀疑外泄，立即到 GitHub 后台 `Settings → Developer settings → Personal access tokens` revoke 该 token → 重新生成新 token → 更新 `~/.git-credentials`（`https://bqdlz676:<新token>@github.com`）→ 同步更新本文 2.1 节与飞书镜像；旧 token 作废后所有用它发起的会话立即失效。
- **Keystore 口令泄露处置**：若 `luowen.jks` 口令外泄，需重新生成 keystore 与密钥对；注意新密钥对指纹会变，旧版本已装设备无法覆盖安装，需先卸载或走应用内升级说明。keystore 文件本身应离线备份，丢失将无法再签出与旧包同签名的升级包。
- 轮换后必须回写两处：`app/build.gradle` 签名块（或 `RELEASE_STORE_FILE / RELEASE_STORE_PASSWORD / RELEASE_KEY_ALIAS / RELEASE_KEY_PASSWORD` 属性）与本文 2.3 节指纹 / 口令；保持仓库、本地、文档三处一致。

### 3.3 配色与视觉禁区（逐字口径）

- 四色系总原则：纸白、墨色、朱砂、暖金，全站只用这四个色系；暗处偏暖不偏冷，金是沉金不是亮金；**禁止纯黑纯白**（`docs/落文-模块契约索引.md` L51,62）。
- **禁止 Material Design 色值**；关 MaterialTheme，Compose 自绘；禁用 Material 默认 ripple / elevation / shared-axis 转场（`docs/落文-模块契约索引.md` L39-40,106）。
- **禁线性渐变（linear）**：一切过渡优先 spring（overshoot 回弹）；曲线命中切片-15 动效表（`docs/落文-模块契约索引.md` L80,106）。
- **禁菊花**：加载指示器 = 三个金点依次亮灭 600ms 循环（`docs/落文-模块契约索引.md` L56,79）。
- 其余美学禁区：禁 iOS 式大圆角、禁霓虹 / 镭射渐变、禁 emoji 当图标、禁系统默认 drop shadow / elevation（`docs/落文-模块契约索引.md` L106）。

### 3.4 贴皮定义与可复用边界（铁律 56，逐字口径）

**禁止**复用：旧 XML 布局、`*Binding`、旧 Adapter / ViewHolder、旧 Fragment 的界面编排；**禁止**把旧 XML 结构逐条翻译成 Compose（换皮同样算贴皮）。

**允许**复用底层能力：DB/DAO、网络抓取、规则解析、偏好存取、`model` 数据类——这些是基础设施不是界面。

**必须新写**：页面状态模型、VM 编排、交互、组件、动效。每包必须有「功能项 100% 对照表（旧功能→新落点行号）」；门禁含 `setContentView` / `*Binding` 归零、旧 Adapter 类删除清单、hex=0、Material 引用下降数（`docs/落文-规矩总纲.md` L89-94）。

- 性能红线：翻页 ≤16ms/帧、气泡冷 ≤300ms / 热 ≤80ms、字典 ≤15MB、启动→书架 ≤1.8s、内存 ≤180MB、字体子集 ≤200KB、地图 ≤2s、纪年换算 ≤8ms、球面 LOD 2-3 帧、球面 55fps 手机 / 120fps 桌面、首次加载 ≤800ms。
- 被剔除功能不回流：每日一首诗 / 一段文、古籍朗读、WebDAV 云同步三项明确不进计划、不实现。
- 推演引擎通用化：只吃 JSON + 高度图 + 规则，换仗只换数据不换代码；战役事件用条件触发器声明，不硬编码回合数。
- 数据分层按需加载：APK 只内置核心小数据；书、图层、战役、大词典全部按需下载 + 预缓存 + 断网兜底。
