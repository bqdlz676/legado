# 反思 · 导航三 Tab · D25

## 1. 做了什么
基线 `213bd6c`：底部导航由 4 项（书架/发现/我的/画板）收为 3 项（书架/发现/设置），第三槽换规格切片设置图形（两竖线+顶端圆点，非齿轮）；搜索从独立页改为书架页下拉浮层（输入即查、遮罩/下滑收起、空态占位）；导航图标 4→3，按图标规格以 1.5px 描边、圆角端点、暗铜/暖金重绘；新增 5 条 JVM 单测。改动集中在 `ui/main`、`lib/theme/view`、`res/menu`、`res/drawable` 与书架 Compose。

## 2. 踩过的坑 / 教训
- 旧 `realPositions` 是 4 元素数组且 `idMy` 重复占位，删槽位时必须同步改适配器三分支与 `PageChangeCallback`，漏一处就会在恢复 Fragment 时 `POSITION_NONE` 闪屏。
- 导航图标是 selector（`_e`/`_s` 双矢量），改图标要同时改 menu、`ThemeBottomNavigationVIew.defaultIcons`、selector 与矢量描边配色，只改 menu 会被皮肤还原逻辑覆盖；第一版误用填充齿轮，被附件规格打回重做成描边切片，教训是动手前先把图标规格附件读完，不要凭旧矢量改色。
- 工作区里已有大量他人未提交的删除文件，`git status` 不能当自己的改动；清单只列本单动过的路径。
