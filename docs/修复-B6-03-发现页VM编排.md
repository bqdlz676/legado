### 状态位机判口径

- `applyRegion`（DiscoverViewModel.kt:206-226）：`failure == null` → 按映射结果落 CONTENT / EMPTY，清 offline 与 errorMessage；`failure != null` → offline=true、errorMessage 取异常摘要，有旧内容置 ERROR 并保留旧 items，无旧内容置 OFFLINE。
- 初始五区均为 LOADING + 空 items（RegionState 默认值，:43-50）；单测 `initial snapshot has five loading empty regions`（DiscoverViewModelTest.kt:58）逐区断言。

### 不自存进度 / 掌握态证明

- VM 类成员反射断言：`DiscoverViewModel::class.members` 中不存在 `mastered` / `watchedStage` / `progress` 成员（DiscoverViewModelTest.kt:209-219）。
- `NotebookEntryCard` 仅暴露 `count` 一个属性（DiscoverModels.kt:205；测试 :216-218）；VM 不维护复习次数、掌握分组第二份状态。
