### 11.2 九种边界迂回（逐条有方案，不留空白态）

- B1 空分组 / 空记录：某分组无可见行（无服务、无记录、无规则入口）→ 整组隐藏；我的统计无阅读记录 → 入口摘要落空态引导；整页全空时落页级空态（金点 + 引导文案），不留纯白屏。
- B2 坏偏好值 / 坏备份文件：SP 类型不符（Boolean 键被写成 String 等）→ 桥内 catch 回落纯函数默认值（R16）；备份 zip 损坏 / 部分解析失败 → 不覆盖现有库，失败项回吐文案，不静默吞错；枚举/档位越界回落首位或默认档。
- B3 断网 / 离线：WebDAV 测试连接 / 同步 / 更新检查离线 → 显「无法连接，检查地址和密码」类失败文案或更新失败 toast，不显绿点/不显示已是最新；本地备份/恢复/局域网传输不依赖公网；离线态本地偏好可读可改。
- B4 大库 / 长列表卡顿：压缩库 VACUUM、备份导出走 IO 线程不卡主线程；设置/我的列表静态 LazyColumn 懒加载，首屏只算可视区行；超长标题/摘要单行截断；不在页面堆粒子 / 3D 渲染。
- B5 测量 / 令牌缓存失效：字体回退、字号令牌变更或重组后行高/尺寸重算；行宽随 `LocalConfiguration` 重组重算，不跨配置硬存像素尺寸；布局失败回退基座默认尺寸。
- B6 旋转 / 配置变更 / 进程重建：槽位选中态经 `rememberSaveable` 存活；当前分组、搜索词、测试结果在壳态/页面态保留；`sheetTarget` 持 lambda 不可序列化（O-14 残留），重建后回默认待决态，不卡死弹层；重建期间不闪旧 Fragment 帧。
- B7 reduce-motion：系统关闭动效 → 开关浸染、按压反馈、转场时长按 `reduceMotion` 令牌归零或最小；卡内浸染与弹层动效消费点归组件/卡片批次（O-12）；不砍设置项可达性。
- B8 低端机：毛玻璃/颗粒/倾斜渲染开销按设备档位降级；页面为静态列表，不引入高开销动效；首屏分组数封顶，懒加载续出；不掉帧不砍行信息层级。
- B9 暗色：仓内组件/卡片令牌当前浅色单源，暗色映射未落地；本面不内联暗色专属色值，暗色缺口登记 N5 待裁；兜底为现有令牌下可读对比，不出现黑底黑字；暗色主题随组件令牌批次统一落地。

### 11.3 数据源三链（缺源不靠假设）
