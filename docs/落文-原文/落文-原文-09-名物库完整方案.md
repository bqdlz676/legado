## 一、范围：十七类（不是六类，不是加三个 Provider）

## 二、通用架构（核心：加新类别只加数据表，不改 Provider/UI）

- 统一查询接口：`EntityProvider.query(name, type, anchor) -> BubbleContent`
- 所有类别走 ContextAnchor 消歧（同名建筑按地点+始建年代过滤）
- 所有类别走 BubbleView 统一渲染（撕边纸片+金边+spring）
- 核心表：
  - `artifact`（人造物，type=sword/horse/instrument/vessel/textile/vehicle/seal/jade/armor）
  - `architecture`（建筑，type=temple/daoist/tower/palace/pavilion/bridge/tomb/academy）
  - `astronomy`（天文星宿，type=star/constellation/planet/asterism/calendar_term）
  - `food`（饮食，type=wine/tea/dish/snack/ingredient）
  - `landscape`（山川风物，type=mountain/river/lake/sea/waterfall/cave/boundary；不放 artifact，artifact 是人造物）
  - 已有：`person`+`person_alias`、`place`+`place_name`、`plant`、`animal`、`medicine`

## 三、原有六 Provider 不变，新增三个 Provider

- 原有：Char / Allusion / Person / Place / Date / Word（字/典故/人名/地名/年号/词义）
- 新增：PlantProvider（草木 800 种）/ AnimalProvider（鸟兽 600 种）/ MedicineProvider（药名 1800 种）
- 其余类别（名剑/名马/名寺/名楼/名琴/名鼎/星宿/名酒/名锦）走通用 EntityProvider，不加新 Provider
- 边界：EntityProvider 不重构 D1/D2/D3：D1（字典）、D2（人物）、D3（地名）保持各自实现不变，EntityProvider 只对新增类别生效，D1/D2/D3 走原 Provider 路径不双轨；EntityProvider 内部调用 D1/D2/D3 接口复用，但代码结构不合并。

## 四、文风分析引擎（四项）+ 格律检测

文风四项（书入库时后台跑一次，存书详情表，不阻塞阅读）：
1. 虚词频率：古文 15 字（之乎者也矣焉哉而以此则于为所与）、现代文 12 字（的了吗呢吧过着了就也还），占全文百分比 + 排名前 5；古籍/现代文词表自动切换
2. 用典密度：3 万条 allusion.txt 首两字索引扫全文，每千字典故命中数（现代文自动关）
3. 平均句长：标点切句，字均数 + 句长分布四段（0-10/11-20/21-30/31+）
4. 格律分布：五言/七言/词牌/长短句/通篇骈偶段落占比 + 韵脚重复模式（古诗词开，现代文关）
5. 同类对比基准：预跑 100 部内置古籍六项指标，新书对号同类均值
6. 输出：书详情页「文风」入口 → 六项仪表盘 + 同类对比表；规则模板填空生成一句话总结，不调 AI

格律检测：
- 五言/七言识别：每行 5 或 7 字占比 >40% → 判诗
- 词牌识别：句长序列 vs 词牌库（浣溪沙/鹧鸪天/蝶恋花/满江红各 50+ 种）匹配 >60% → 标词牌
- 平仄检测：中古音平仄库（广韵/平水韵）查表 → 整句平仄序列 → 标拗句
- 韵脚检测：句末字韵母归韵 → 换韵标记
- 输出：正文右侧极淡标注（仄字下石青点/韵脚暖金点/拗句左淡朱砂），不影响阅读

## 五、五入口

1. 阅读页气泡（被动，主入口）：点任何名物字词 → 气泡
2. 发现页手卷「名物」标签：十七类竖排索引 → 类别条目首字竖排列表 → 半屏 Sheet
3. 搜索：输「赤兔」→ 匹配「赤兔·名马·吕布坐骑」→ 半屏 Sheet
4. 人物/地名 Sheet 底部「相关名物」：人物→持有物、地名→所在建筑、作品→提及名物
