## 一、地图页壳（同一个 Activity，两种底图）

`PlaceMapActivity` 统一壳，2D/3D/全球三种模式共用一套壳，切换不跳页面：
- 中国：2D Leaflet + 3D 沙盘，共用一套朝代图层
- 世界：2D 世界地图 + 3D 地球仪
- 右上角「🌐」切换中国↔世界，镜头飞到对应区域
- 双指捏合自然缩放（缩小→全球地球，放大→局部高精度）；右侧竖线标当前视距层级（大洲/区域/战场/全球）
- D17 是 S-20（沙盘与地球仪合并）的落地，吸收 S-06（3D沙盘）与 S-18（3D地球仪）需求来源，不再有独立 S-06/S-18 模块。

## 二、六入口

1. 阅读页地名气泡 → 底部「2D/3D/地球」三选一（中国地名进中国，世界地名进世界）
2. 发现页「地图」标签 → 默认中国模式，当前朝代图层
3. 发现页「世界」标签 → 默认世界模式，世界战役位置 + 金针
4. 发现页「马克思」卡片 → 世界地图 + 马克思行迹线，时间轴 1818-1883
5. 发现页「党史」卡片 → 中国地图 + 长征路线/根据地，时间轴 1921-2021
6. 发现页「战役」卡片 → 中国战役进中国沙盘，世界战役进地球仪

（另：人物 Sheet 底部「一生行迹」→ 该人物行迹金线；书架长按书「本书地理」→ 该书地名索引）

## 三、中国模式

- 底部滑条：18 朝代（春秋·战国·秦·西汉·东汉·三国·西晋·东晋·南北朝·隋·唐·五代·北宋·南宋·元·明·清），滑到哪个色块 morph 到哪个疆域
- 图层叠加开关（默认疆域+城池+河流开）：疆域/城池/河流/行军路线/等高线/卫星底图
- 右下角「📍」地名搜索：输「鄢」→ 候选（鄢·春秋郑邑/鄢·战国楚邑/鄢陵·今河南鄢陵）→ 地图飞到
- 右下角「今」按钮 → 回现代基线（纯国界+金针，无历史色块）

## 四、世界模式

- 底部滑条：5 时段（古典·中世纪·近代·二战·现代）
- 内容：世界战役 30 场（Wikidata）/ 预设路线 60 条（汉尼拔/亚历山大/蒙古西征/十字军）/ 12 套势力图层（罗马/波斯/蒙古/阿拉伯/奥斯曼/大英）/ 世界地名 500+（Pleiades+Wikidata）/ 马克思+恩格斯行迹线 / 全球河流（Natural Earth）/ 全球山脉（SRTM）/ 卫星纹理+云层+大气（NASA Blue Marble）

## 五、党史内容（中国地图上）

- 根据地变迁图层：1927-1949 逐年多边形（铜/朱砂色块贴地形，滑时间轴切年）
- 长征路线 17 段：金色贴地箭头 + 每段里程/天数/海拔
- **推演模式：国军追兵 vs 红军突围，引擎跑 A\* + 规则意图 + 兰彻斯特结算**（军事推演，非政治推演）
- 党史事件标记：1921-2021 每年关键地点朱砂方钉，点开半屏 Sheet
- 党史地图模式打开时，滑条自动切党史年代段（1921-2021）；切回朝代模式滑条回 18 朝代

## 六、专题联动

- 马克思专题「行迹」Tab → 世界地图，预载马 7 城 + 恩 5 城行迹线，时间轴 1818-1895，滑到 1848 巴黎交汇点高亮
- 党史专题「根据地」Tab → 中国地图预载根据地图层；「长征」Tab → 3D 沙盘预载 17 段 phase + 国军追兵；时间轴/人物 Tab 不在地图页
- 专题数据 vs 地图壳边界：本 Activity 只提供壳+图层/行迹线渲染；马克思行迹坐标数据由 D18 提供，党史根据地/长征多边形与 phase 数据由 D19 提供，本壳不内嵌专题数据。
