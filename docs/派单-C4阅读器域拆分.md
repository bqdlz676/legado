# C4 阅读器周边域拆分（总控规划稿）

> 目的：C4 域 131 个 kt 中仍有 36 个带旧式成语（DialogFragment / android.widget / R.layout / BottomSheetDialogFragment）。按文件亲和度切成 6 个互不重叠的包，逐包重写为 Compose 原生自绘，每包独立验收。
> 重写口径：**只保留 legado 排版引擎**（`page/provider/*`、`page/entities/*`、`page/api/*`、`page/delegate/*` 一行不动，那是引擎）；`vertical/*` 是落文自有竖排引擎，只冻结公开 API 签名、内部可维护；壳、菜单、对话框、设置面板全部 Compose 自绘。

## 派单纪律（每包通用）
- 文件域独占，不许碰别包文件；`page/provider/*`、`page/entities/*`、`page/api/*`、`page/delegate/*` 是 legado 排版引擎、一行不动；`vertical/*` 是落文自有竖排引擎，只冻结公开 API 签名（`layout/hitTest/invalidateCache`）、内部可维护，不当"禁止改"锁死。
- 删除旧 `R.layout.*` 引用后必须 grep 确认该 layout 零引用，才能删 xml。
- 每个对话框统一走 `ui/components/InkHalfSheet`（content 显式具名，防尾随 lambda 被 onLinkSelected 抢走）或 Compose `Dialog`，禁 BottomSheetDialogFragment。
- 每个包附 grep 回证（旧成语在该包内命中数必须为 0）+ 报告 + 未验证项声明。
- 禁 git 写操作；禁改 build.gradle；禁 @Ignore / assertTrue(true)。
