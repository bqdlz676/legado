## 2. 踩的坑 / 教训（下任避开）

- **纯 Python 逐像素 + 全体调色板配对爆炸**：首版 AA 判定对 562k 像素 × 25 端点做笛卡尔积，1 帧跑几分钟。改成「调色板色 ↔ 夜空底」单端点对、向量化 numpy 后 7 帧 10 秒。像素脚本先估 N×M×3 内存量级再写循环。
- **默认扫描别跨模块**：目录递归把书架 / 卡片帧全扫进来，暖纸底色被误判越界簇。默认只滤 `SkyEight`，`--all` 才放开；禁色判据先圈定自己的层。
- **低饱和暖灰不是主题色**：星点叠暗后的暖灰棕被色相分桶误报成 h1 簇。必须分「饱和主题色」与「neutral 残色」，后者只登记不判红。
- **锚色近邻 0 不等于锚色缺失**：alpha 叠暗后精确 hex 不落帧；报告里把这个缺口写明，不拿近邻计数当锚色在位证据。
