## 五、认知成本

- 两套帧清单不要混：`frames-baseline.json` 是提交入库的期望帧契约（静态、在册、被源码哈希冻结）；CI 产物 `frames.json` / `frames.md` 在 build 输出目录，不入库，是实测回填。
- 基线双层：本轮登记源码契约层；PNG 帧哈希层留待冻结通过轮。读基线文件时不得把源码条目读成「帧已冻结验收」。
- 帧名口径：包名点号转下划线 + 类名 + 方法名；改测试方法名必须同步改清单条目并重新冻结。
- 抽象取舍：两套新夹具各自私有布局 helper，未向 `ScreenshotFixtures.kt` 塞共享抽象；文件 96 / 136 行，均低于 600 行棘轮。接手人若要抽共享件，先确认复用面超过两套再动，避免过早抽象。
