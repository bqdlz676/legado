## 三、新发现缺陷 / 观察项

- N1（B 级，静态可证，疑似单测必红）：陈旧子串标记失配。`ShelfOverlaySearchTest.kt:176` 断言清单含 `"attach(null, null)"`，但 `InkShelfFragment.kt:94` 现为 `onAttachSearch = { key, scope -> searchViewModel.attach(key, scope) }`；`grep -rn "attach(null, null)" app/src/main/java/io/legado/app/ui/main/bookshelf/` 零命中。该兜底断言跑到此标记必 `assertTrue` 失败。成因：跨页检索请求接线把字面量调用改成透传 `key/scope` 后，兜底标记未同步更新。修复方向：标记改为断 `attach(` 调用存在，或改走 VM 签名 / 调用记录桩；本单只读未改。
