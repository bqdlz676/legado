## 7. 可复用裁决规则：新屏能否在 `:screenshot` 独立渲染

- R4 自绘 / 纯常量豁免：只取 `ComponentTokens` / `ComponentPalette` 纯数值常量、`Canvas` / `BasicText` / 自绘 `Modifier`，入参为展示模型与字面量回调 → 可独立渲染。

1. 优先把组件改成资源 / 宿主注入形参（文案、图标由调用方传入），夹具喂字面量；这是最保真的帧形态。
