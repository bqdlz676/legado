## 一、事实锚点

- 原生桥：`app/src/main/java/io/legado/app/help/sensor/GyroBridge.kt`
  - FIFO 上限 10 条四元数（`:31`、`:45`、`:150-153`）；`drainLatest()` 队首出队（`:132`）；`stop()` 注销清队（`:135-147`）。
  - 三级降级：`TYPE_ROTATION_VECTOR`（`:75`、`:81`）→ `TYPE_GAME_ROTATION_VECTOR`（`:76`、`:82`）→ 加速度 + 磁力融合矩阵（`:77-78`、`:83`、`:156-163`）；全无传感器 `start()` 返回 false（`:84-86`）。
  - 兜底分支 `degraded=true`，JS 强制权重 0.04（`:59`、`:34`）。
- 接线：`ui/main/PlaceMapActivity.kt`、`ui/main/BattleActivity.kt`
  - 各新建 `GyroHost` 内部类，`addJavascriptInterface(..., "GyroBridge")`；方法 `pull() / degraded() / available()`。
  - `onResume` 重注册、`onPause` 注销、`onDestroy` 停传感器并销毁 WebView。
- JS：`assets/map/gyro.js`（独立文件，未内联进 HTML）
  - 三模式 `off / follow / parallax`，中文「关闭 / 跟随 / 叠加」（`:43-45`）；默认权重 0.08，区间 0.04–0.20（`:21`、`:38-40`）；叠加权重 0.12（`:165`）。
  - 松手 600ms 回弹（`:155-159`）；进模式 / 回前台 800ms lerp 过渡（`:99-101`、`:136-148`、`:207-214`）；`orientationchange` 重置基准（`:200-204`）。
  - 三态图标（灰 / 暖金 / 暖金脉冲）、长按竖排菜单、单点 toggle、四金点上下滑调档（`:211-347`）。
- HTML 接入：`assets/map/three.html:48`、`assets/map/battle.html:81` 引脚本；合成钩子在 `renderer.render()` 之前（`three.html:479`、`battle.html:387-388`）。

## 二、实测修正（与规格 §九两处不符，以现实为准）

1. 仓内两个 Activity 此前无任何 JS 桥；「加在已有 InkSlate 桥里」前提不成立，已新建 `GyroHost`。
2. `three.html` animate 在 :465 / render 在 :474（非规格所写 :282）；钩子插在 render 前。
3. 仓内 three.min.js 的 `Quaternion` 无 `lerp` 方法；800ms 过渡用手写四分量 lerp + normalize 实现。

## 三、判据（验收逐条核对）

1. 原生：队列上限 10、逐帧取一条、stop 注销；三级降级顺序正确；兜底分支权重锁 0.04；全无传感器返回 false 且不报错。
2. 接线：两个 Activity 均注册桥；onCreate / onResume 启、onPause 停、onDestroy 释放；WebView 销毁后无 `evaluateJavascript` 实调用。
3. JS：三模式语义与规格 §四一致；跟随手指只缩放、叠加弱视差；回弹 600ms、过渡 800ms；方向翻转重置基准；权重 0.04–0.20 可调、降级强制 0.04；双指缩放与棋子 / 地名拾取仍走屏幕坐标，不被镜头偏移污染。
4. UI：三态颜色与脉冲、长按竖排三模式、单点 toggle、四金点滑杆；色系为暖金 / 墨色，无 Material 蓝紫。
5. 边界：抖动 / 精度差、快速前后台、销毁后回调、无磁力计、旋转 90°、平放奇异、拖到一半切后台，七种情形均有迂回实现，无空白态、无「暂不支持」。

## 四、边界

- 不改既有渲染管道与命中测试；不引入新 Gradle 依赖；单文件 ≤600 行（gyro.js 380 行、GyroBridge.kt 219 行）。
- 编译 / 单测 / Lint 面以 CI 为准；本单未本地编译、未跑 gradlew。
- 真机传感器精度、漂移、功耗与平放奇异表现需上机验收，无头环境无法标定。

## 五、已知遗留

- `battle.html` 手势为 touch 事件，gyro.js 跟随拖拽挂 pointer 事件；个别内核若不合成 pointer，需补 touch 监听。
- 模式 / 权重未持久化，重启回默认关闭 + 0.08。
- 跟随模式相机位置仍走既有球面轨道，姿态由陀螺仪覆盖；视点锁定纯换朝向未做。
