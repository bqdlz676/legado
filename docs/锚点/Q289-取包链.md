## 三、边界与取舍

- 沙箱无 aapt / apksigner：Manifest 只做 zip 结构检查；证书指纹、versionName、v2/v3 方案未判定；签名块 scheme id 的手工解析在本单未作为结论依据。
- 弱网截断：脚本无续传、无标称字节比对；本单手工 HTTP 206 续传补齐后复用脚本自带校验器复核。续传增强与字节比对属另单待裁项，不在本单范围。
- 反样本第二道 Package 闸（skipped 分支）未端到端实跑：被第一道 Verify cancelled 闸先行拦下；该分支由代码审查与 selftest E/F 夹具覆盖。
- `workflow_run` 事件漏发无对账兜底：Verify 绿而 Package 缺失时脚本 RC=1 人工发现，本仓无补齐 cron；列入待裁，不在本单改调度 / workflow。
