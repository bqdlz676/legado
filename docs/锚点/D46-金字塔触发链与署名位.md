# D46 金字塔触发链与署名位（星空天象层宿主交付）

## 范围

- A 金字塔宿主触发链：magLimit >6.5 触发 L1，>9.0 触发 L2；在途去重 + 失败冷却；任一时刻星表 = L0 ∪ 已加载层，回落不抛异常、不清空。
- B 真实进度上报（已解压行数 / 总行数，禁止假进度）+ 错误态可注入异常目录入口。
- C BY-SA 4.0 署名四要素宿主可见接线。
- D 悬停 120ms 回弹（可注入时间源，测试可推进时钟）。

## 参数表

- 触发阈值：L1 界 6.5（`SkyParams.MAG_BRIGHT_ENTITY`）；L2 界 9.0（handler 私有 `LEVEL2_TRIGGER_MAG`）。
- 悬停回弹：`HOVER_RESET_MS = 120L`。
- 失败冷却：`PYRAMID_RETRY_COOLDOWN_MS = 30_000L`。
- 署名字号：`SkyParams.SHEET_SOURCE_FONT_SP`（14sp，≥14sp）；颜色 `textSecondary` / `textTertiary`，非纯黑纯白。

## 可测判据

- 满混合触发 L1/L2 各一次；中混合只触 L1；失败冷却期内同层不重复触发，错误回调收到提示。
- 悬停 100ms 内不回落，121ms 超时归 -1。
- 坏片经门面回 Corrupt，内置 L0 星仍可查；进度为真实行数比值。
- 署名四要素（数据名 / 作者来源 / 许可名与链接 / 衍生表述）在宿主可见处挂载。
