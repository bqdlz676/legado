## 二、参数表

| 组件 | 关键参数 |
|---|---|
| Bubble | 四变体（字/词/人名/地名）共用容器；撕边纸片 + 金边（1px 金）+ spring 注入 |
| BottomSheet | 三段高度 30% / 60% / 90%；金杠拖拽；跟手下拉关闭；遮罩联动 |
| Timeline | 竖线 + 节点 + 政权对照行；纪年页与人物 Sheet 复用同一组件（只换数据） |
| InkButton | 禁 Material ripple；按下泛朱砂（背景 0→8% `TEXT_ACCENT`）；统一交互 |

## 三、判据（机械可判）

1. 四组件各自的参数常量可 grep（四变体枚举 4 项、三段高度 0.3/0.6/0.9、泛朱砂 0.08）；
2. 全包 0 处 Material ripple / MaterialTheme 引用（护栏单测 `DesignTokenGuardTest` 已在跑）；
3. 颜色全部取 `ComponentPalette`，0 个裸 8 位 hex；
4. Timeline 必须被"纪年页"与"人物 Sheet"两处引用同一实现（禁两套）；
5. 空数据/断网/缺年份三态各有兜底文案（不许空白）。
