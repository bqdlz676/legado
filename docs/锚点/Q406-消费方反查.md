## 二、三面判据（机械可判）

1. 删除面（DELETE，FAIL）：改动面相对 origin/main 删掉 enum entry、sealed 子类声明或伴生常量名字后，全仓 token 边界 grep 该名字；注释剥掉、字符串保留（字符串 handler 映射也算残留）；任一残留引用（import、when 分支、类型引用、字符串映射）即红，点名 文件:行。
2. 新增面（ADD，WARN 不硬红）：新增 sealed 子类或 enum entry 后，找归属父类型的 when 表达式；有 else 分支或已有对应新成员候选分支即记配对；无 else 且未覆盖新成员必须 WARN 点名 文件:行 与缺哪个成员，不许默不吭声。
3. 改名面（RENAME）：同文件内一个公开名字被删且同时新增新名字，按改名判；旧名残留为零 → 通过并输出配对记录；旧名有残留 → 红。

形态覆盖：多行 when、带 subject 的 when、`when (val x = …)`、sealed 嵌套子类 `object Foo : Bar.Baz`。

## 三、自测夹具（`--selftest` 八例，临时迷你仓验完自删）

- 夹具一：删除枚举 entry 后另一文件 when 分支仍引用 → 独立 FAIL。
- 夹具二：删除 sealed 子类后全仓零引用 → 独立 PASS，残留 0 记录。
- 夹具三：新增 sealed 子类、when 有 else → 放行，不点名。
- 夹具四：新增 sealed 子类、when 无 else 且无新成员分支 → WARN 点名 文件:行 + 缺成员名。
- 夹具五：改名零残留 → PASS + RENAME 配对记录。
- 夹具六：改名旧名有残留 → 独立 FAIL。
- 夹具七：嵌套子类 `Bar.Baz.Two` 无 else → WARN 点名归属父类型。
- 夹具八：`when (val x: Bar = get(a, b))` 带内层括号的 val-subject 形态可解析，无 else 未覆盖 → WARN 点名。
