## 三、机械可判据

1. N1 销毁摘牌：onDestroyView 与 onDestroy 各有一次 `syncShelfBridge()` 调用；两处生命周期状态均非 RESUMED，裁决走交还分支；release 不收 Context，解挂后可安全调用。
2. N2 可见性闸门：申领条件唯一写在 `syncShelfBridge()` 内，`RESUMED && !shelfHidden && 偏好开启` 三者同时成立才上牌；onHiddenChanged(false) 不再单独判偏好，必须过 RESUMED 二次判断。
3. 单点收敛：`acquireShelfBridge()` / `releaseShelfBridge()` 的调用点只出现在裁决方法内；生命周期与回调处不直接调原语，仓内 grep 无第二份申领 / 交还 if。
4. 幂等不误伤：`release("shelf")` 只移自己标识；未上牌重复交还 `remove` 返回 false，不触发 teardown；地图 / 沙盘持牌期间书架连续交还不拆他人监听。
5. Q441 功耗保留：hidden=true 时 `shelfHidden=true`，裁决 `visible=false` → 交还；切 Tab 仍停桥，未放宽。
6. 兜底安全：申领路径 `context` 为 null 直接 return，`activity` 为 null 方向基准回落 0；不抛 `IllegalStateException`，不静默上牌；回可见路径由 onResume / onHiddenChanged 补申领。
