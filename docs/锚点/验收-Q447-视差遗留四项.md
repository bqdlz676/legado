## 三、机械可判据（八条）

1. N5 引用计数：同宿主重复 `acquire` 不重复上牌；未上牌宿主 `release` 幂等；仅集合清空才 `teardown()`。四段交错时序见复核报告判据 1。
2. D1：关开关立即 `release`，平滑值经 `setEnabled(false)` 回中；开开关仅 `RESUMED && !shelfHidden` 才 `acquire`；不可见不抢桥，回可见由 onResume / onHiddenChanged 补申领。
3. D2：非 active 时偏移精确 0f、半径回 `baseRadiusPx`、色回 `baseShadowColor`；非活跃态 getter 不新建 `Color`、不重算 dp 换算。
4. D3：关闭态 500ms 一醒（2Hz），不 `drainLatest`、不做倾角换算与平滑、无数组分配；传感器侧最后持牌者 `teardown()` 注销监听。
5. 既有数值零回退：6dp / 4dp / 0.06 / 400ms / 半径 12+|roll|×6 / 透明度 0.3+|roll|×0.15 逐项在位。
6. API 语义：`drainLatest` / `level` / `degraded` / `setDisplayRotation` 签名语义不变；JS 三方法 `pull` / `available` / `degraded` 未改名。
7. 三宿主同一时机同一方法（onResume 申领 / onPause 摘牌；地图沙盘另加 onDestroy 摘牌）；仓内无裸 `GyroBridge.start(` / `GyroBridge.stop()` 调用点。
8. 报告一致性：写码方自报行号抽样逐字回源，命中率见复核报告判据 8。
