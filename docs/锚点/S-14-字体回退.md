## 三、判据（机械可判：可 grep / 可跑单测）

1. `grep -n` 命中 `ui/font/contract/` 五角色常量（族名 / 策略 / 子集上限），五枚回退目标可枚举；契约层 7 断言单测全绿（索引:283）。
2. 构造子集外生僻字 / 异体字文本用例：断言无 `.notdef` 字形 / 豆腐块、回退命中系统字体族、段落行数与基线不塌（补条款:107）。
3. 逐个摘除 / 损坏五枚子集文件：首屏均以系统字体可见、无 FOIT 白屏等待；子集回补后字形可替换且文字位置不跳；失败日志区分缺失 / 损坏 / 校验失败 / 读取被拒 / 超时（补条款:125）。
4. 回退链常量单点定义可 grep 回源；回退字沿用当前字号与基线，不单字缩放、不换颜色（补条款:102）；注音 10sp、正文 18sp（S-09 口径）回退时不缩小。

## 四、兜底边界

- 子集缺失 / 损坏 / sha 校验失败 / 读取被拒 / 加载超时（推定 800ms）：按 swap 口径先用系统字体排版，子集后台到位后再替换字形；标题 SemiBold 加载失败也落系统粗体，不允许 FOIT 白屏。
- 单枚子集失败隔离：其余四枚继续各自加载，不被失败项拖垮；回补后仅做字形替换，不动布局位置。
- 单字缺字逐级回落系统字体族，不渲染豆腐块，单字缺字不得拖垮整段排版。
- 回退链顺序、notdef 检测口径、800ms 超时、sha 校验、失败隔离、回补不 reflow 均为工程推定待拍板；切片-14 无对应条文处按 F-73 退回设计，禁止自创校验手段或阈值。
