## 三、九条验收判据（机械可判）

1. FIFO 上限 10、逐帧取一条、stop 清队注销；降级优先级 ROTATION_VECTOR → GAME_ROTATION_VECTOR → 加速度+磁力；全无传感器 start() 返回 false 不报错。
2. 降级分支 JS 权重锁 0.04 真锁住，非降级不被锁；无第二条绕过赋值路径。
3. 原生不按传感器事件推，仅上层拉取；WebView 销毁后无 evaluateJavascript 实调用；销毁顺序 stop → about:blank → destroy → 置空。
4. off 不动镜头；follow 权重 0.08、手指只缩放、松手回弹；parallax 权重 0.12 弱视差。
5. 800ms 过渡为分量 lerp + normalize（非 slerp），过渡期间不跳变。
6. 拾取/点选仍用屏幕坐标，镜头偏移不进拾取路径；缩放路径不读陀螺仪状态。
7. orientationchange 重置基准；remapCoordinateSystem 四向换轴；平放奇异帧丢弃 + 归一化除零保护；NaN 帧丢弃。
8. 两 HTML 都引 gyro.js（three.min.js 之后）且钩子在 render 之前；两 Activity 都注册桥且 onResume/onPause/onDestroy 齐全。
9. 三处疑点定裁：四金点/0.08 口径矛盾；视点锁定未做；battle.html pointer 与 touch 不匹配。
