## 一、规格逐字引文

- 效果：「不是转地球。书架卡片微微随手机倾斜而偏移——纸面浮雕感。」
- 效果：「手机左倾 → 所有卡片微微右移，卡片右边缘阴影加深，像光从左边打过来。手机前倾 → 卡片微微下沉。不是 3D 旋转，是 2D 位移 + 阴影动态偏移——卡片始终正面朝你，但它在纸面上浮起来的高度感随倾斜变化。」
- 实现：「同一个 GyroBridge，但只取 pitch（前后倾）和 roll（左右倾），映射到卡片位移和阴影偏移。」
- 实现数值：「maxShift = 6f（卡片最大位移 dp），maxShadowShift = 4f（阴影最大偏移 dp）；apply(cardView, pitch, roll)：roll -1←左倾→+1 右倾，pitch -1←前倾→+1 后倾；dx = roll*maxShift，dy = pitch*maxShift，shadowDx = roll*maxShadowShift，shadowDy = pitch*maxShadowShift；translationX=dx，translationY=dy；阴影偏移：倾斜反方向加深，radius 12f + abs(roll)*6f，偏移 -shadowDx/-shadowDy，颜色 Color.argb((0.3f + abs(roll)*0.15f).toInt(), 212, 165, 74)。」
- 交互：「陀螺仪数据经过 0.06 slerp 平滑（比沙盘更惰性——卡片不能抖）；书架页 onResume 注册、onPause 注销；书架页手指滑动时暂停视差效果、松手 400ms 恢复——防止手指滑动和陀螺仪同时作用产生抖动；书架页不可见（切到其他 Tab）→ 注销。」
- UI：「书架页右上角同一个小「📱」图标，三种状态：灰色=关闭（卡片静止）；暖金=开启（卡片随倾斜微微浮动）；不提供「跟随」模式——书架只有开/关，没有叠加。默认开。」

## 三、验收判据与结论（八条）

1. 数值逐项对齐（6dp/4dp/0.06/400ms/12+|roll|×6/212,165,74/0.3+|roll|×0.15）—— **PASS**，落点见 §二。
2. 语义正确：2D 位移非 3D 旋转、卡片正面朝用户、阴影反方向；四元数归一化 + 钳位数学正确 —— **PASS（静态层）**；符号方向真机未核对（N1）。
3. 性能：单状态单协程共享平滑值，无逐卡平滑器；remember/derivedStateOf/状态提升到位 —— **PASS**；观察项 O1（getter 每帧重算/值类构造）、O2（关闭态轮询空转，D3）。
4. 生命周期：onResume/onPause/onHiddenChanged 注册注销齐全；回前台续跟不跳变；关闭开关不主动停桥为现状事实（D1）。
5. 无传感器：按钮置灰不可点、卡片静止、runCatching 与 null 兜底链存在 —— **PASS**；阴影残留边界见 D2。
6. 持久化：复用 PreferKey/AppConfig 既有口径，默认 true，未自造存储 —— **PASS**。
7. 与既有 rotationX 俯仰共存：同层叠加、属性不互覆、无双重位移 —— **PASS**。
8. 报告与实现一致性：核心行号命中；2 处自报行号失准（drainLatest 脱靶、先例 detectTapGestures 脱靶）—— **部分 PASS**，见复核报告判据 8 与 D4。
