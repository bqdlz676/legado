## 二、判据（逐条可断言）

1. 二分：净化保留集排序后 a = `ceil(n/2)`、b = `floor(n/2)`；守恒断言两批并集 == 净化全集、两两重叠为空，违例报错退出。
2. 小集合：条数 < 4 不再折半，全量进 `suspect-a.txt`，不产 b；片段切 `bisect-small` 单 job。
3. 空集：输入空或净化后空，退出码 1，不落清单、不落片段（空 job 假绿防护）。
4. 片段：`workflow_dispatch` + `matrix.side: [a, b]` + `timeout-minutes: 8` + 只跑本批 `--tests`；片段只写到 `--emit-workflow` 文件，不改 `verify.yml`。
5. 收敛实算：161 条 `ceil(log2 161)=8` 轮、最坏 `8×8=64` 分钟，阶梯 `161→81→41→21→11→6→3→2→1`；149 条净化后同为 8 轮 / 64 分钟；小集合规则下 7 轮内出线索。
6. 本轮实算：`/tmp/cl2/shard-2.txt` 161 → 保留 149（category 9、non-class-decl 3、missing-source 0），a=75、b=74，并集 149、重叠 0。
7. 两批都挂：二分失效，禁止继续折半；换维度——`maxParallelForks=1` 串行、按包前缀切、绕开嫌疑包保 CI 绿。
8. 概率性挂死：同集连跑两次结果不一致记 flaky 不记 innocent；按命中率（挂死次数/N）保留嫌疑；静态扫描 `Thread.sleep` / 无超时 await/get/join/take / `Object.wait` / 正则回溯 / 无限递归 / 裸起线程 / 无超时网络直连。
9. 边界：不新增门禁；不改 `app/src/**`、既有 `check-*.py`、`app/build.gradle`、`verify.yml`；无 git 写；沙箱无 JDK，不跑 gradle / kotlinc。

## 三、边界与取舍

- 片段假设清单以 artifact `bisect-suspects` 上传；贴进独立 workflow 时需先上传清单 artifact 或提交固定路径（报告 §八-4，待裁）。
- 8 分钟熔断为取证速度取值；对需特定时序触发的慢挂可能过短，两轮未复现应拉长时长或串行多轮，不削减嫌疑类。
- category 类排除口径与分片 job 一致：它们由 rhino-eval-tests / slow-bench-tests 独立 job 执行，不在分片挂死嫌疑面内。
