# 锚点卡：拼合质量四判据

前置设计卡。对应正文 `docs/落文-拼合质量四判据.md`。

## 这份文档干什么

给"单项验收全过、拼合起来是空的/断的/双轨的"这类缺陷定判据，作为待并入总纲 F9 的机制草案。

## 五条判据

可达性：新符号必须从入口可达，不在可达集的记孤儿。
被使用性：新增链路必须有非测试调用方，且该调用方本身可达。
双轨消解：新旧并存必须有退场单、判据与退场 sha，旧符号不得新增引用。
缺口可见性：契约分支的 return null 必须有可见态或登记为静默缺口。
锚点可回源：文档里的 文件:行 必须能被脚本回源命中，漂移登记为待裁。

## 证据分级

一级静态走查只作辅助；二级脚本机检作门禁结论；三级 CI 编译是契约同步硬证据；四级运行时可断言是拼合质量硬证据。

## 边界

本文不并入总纲，等在飞验收单收口后再 sync，避免在飞验收件的回执指纹失效。
