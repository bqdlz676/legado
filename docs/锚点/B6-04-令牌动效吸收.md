## 三、参数与契约对齐表

- 档位：`DISCOVER_REVEAL_MOTION = "PANEL"` → `MotionSpec.PANEL`；弹簧 0.80 / 360（REVEAL 单源）；时长 350ms（DURATION_PAGE）；缓动 `ComponentTokens.cardEnterEasing`。
- stagger 延迟：正常档窗口均分，`delay = index.coerceIn(0, count-1) * window / count`；reduce-motion 恒 0；count ≤ 1 恒 0。
- reduce-motion：时长 0ms；弹簧瞬时档 1000f / 1.0f / label `instant`（契约口径，本层不另造）。
- 未知档：空白 / null → PANEL；非空未知串 → 契约 BY_NAME 回退 PRESS（120ms），不抛异常。
- 不持有的东西：色值、dp 尺寸、刚度 / 阻尼字面量、cubic-bezier 四参数、旧侧 45ms 步长与 8 条封顶。
