## 三、机械可判据

1. N5：任一宿主 `release` 后，只要 `holders` 非空，监听不注销、FIFO 不清空；仅集合清空才走 `teardown()`。静态推演序列：地图持牌中书架交还 → H={map} 保留监听；双持牌后书架先还 → H={map} 保留；地图再还 → H=∅ 注销。
2. D1：关开关回调立即 `release`；开开关仅在 `RESUMED && !shelfHidden` 时 `acquire`；不可见不申领，回可见由 onResume / onHiddenChanged 补申领。
3. D2：`active = enabled && available && !touchPaused`；非活跃态四个阴影 getter 偏移精确 0、半径回基础值、透明度回基础值，`shadowColor` 返回缓存实例不新建 `Color`。
4. D3：开启态 16ms 轮询不变；关闭态 500ms 一轮，不 `drainLatest`、不做倾角换算与平滑、无数组分配。
5. 接口面：`drainLatest()` / `level` / `degraded` / `setDisplayRotation` 签名语义不变；JS 接口 `pull` / `degraded` / `available` 不动；无新依赖。
