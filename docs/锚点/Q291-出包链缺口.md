## 三、判据（机械可判）

1. 下载：`expected`（元数据 `size_in_bytes`）存在时，落盘字节必须相等；不等即 `SIZE_MISMATCH` 退出，禁止进入 `validate_zip`；404 不进续传循环。
2. 签名三态：v1 三件齐 → `v1`；v1 缺但 Block 魔数 + v2/v3/v3.1 ID 命中 → `v2/v3-only` WARN；两者皆无 → `none` 判红。探测只判存在性，NOTE 行必须写明未验签。
3. 对账：同 `head_sha` + `event=workflow_run` 才配对；非 completed 单列 `IN_PROGRESS` 不落 MISSING；`MISSING > 0` RC=1。
4. selftest 必须全绿：fetch-apk 7/7、trigger 7/7；夹具目录 `/tmp` 自删，无残留。
5. 二阶回查：无其它脚本引用旧签名取值；`.github/**`、`app/src/**`、其它 `check-*.py` 零改动。
