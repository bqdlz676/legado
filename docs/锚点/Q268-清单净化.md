## 三、结论锚点

- C1 清单净化前置到分片之前，四片按真实可执行类均分；`--tests` 模式每片 161 → 150/150/149/149。
- C2 manifest 双轨：`classes` = 分片类 + 分类类（aggregate 归属核对用）；`shard_classes` / `category_classes` / `dropped` 为附加字段，旧字段语义保留。
- C3 分类类执行位置不变：rhino-eval-tests / slow-bench-tests 按 `includeCategories` 选取，分片 `-PexcludeRhino -PexcludeSlowBench` 不变；互斥并集口径不变。
- C4 aggregate 基线断言 `total >= 3185` 针对 XML 用例条数；19 条伪条目本不产 XML，27 条分类类仍在独立 job 出 XML，总条数不受影响。
- C5 误杀防护：companion object `@Test`、全限定 `@org.junit.Test`、基类继承、顶层 facade `@Test` 四条通路均有判定与夹具；当前仓内仅普通 class + 短名 `@Test` 形态。
