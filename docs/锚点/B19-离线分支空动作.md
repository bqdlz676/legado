## 二、判据（逐条可断言）
1. 两处离线分支都传入真实动作回调，且回调指向各自的重试/刷新入口（不是空 lambda）。
2. 点击重试后确实发起请求：可从回调链路上溯到发起函数（给文件:行）。
3. 若某处调用点确实没有可接的重试回调，则不得显示可点的重试按钮——按钮应回落到禁用或改为纯提示文案，禁止「可点但无动作」。
4. 容器本体仍保持 OFFLINE 禁点，本次修复不得把容器重新放开。
5. 补用例：断网 → 点重试 → 请求发出（单测层面可断言回调被调用一次，不依赖真实网络）。

## 三、边界
- 无重试回调的调用点（若存在）：按判据 3 降级，不许抛异常、不许静默。
- 双击重试：允许重复发起，但每次点击都应有一次回调（不在本单去重）。
- 本次不碰 B18 范围（压淡双源、书架裸 clickable、组件契约语义）。
