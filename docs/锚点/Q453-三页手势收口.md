## 二、验收判据（逐条核对）

1. N2 同构：battle.html 与 three.html 的 `orbitStart` 均在写锁 / 写基准前加已激活早退；任一通路 start 时另一通路在途，第二通路早退，锁归属与 `last` / `tapX` 基准不被覆盖；无头桩两向顺序（touch 先 / pointer 后）锁均不翻转。
2. N1 落点抑制：双指按下→轻移→抬起序列走完，`dropPoint` 不触发；捏合期间 `dist` 缩放照常生效；标志不跨手势残留，全新单指轻点落点恢复正常；pointer 通路与 `touchcancel` 落点行为不变。
3. N4 死变量：`down` 标识符在 battle.html 零残留；不留占位注释；`last` 承接上一坐标职责。
4. 不回退：拖拽量级 0.030 档未翻倍；800ms 过渡结构在位；死字段扫描零命中；权重、回弹、钳制区间、follow 模式短路均原样。
5. 改动面：仅 `app/src/main/assets/map/battle.html`、`app/src/main/assets/map/three.html`；零 Kotlin、零资源清单；`gyro.js` 本轮零 diff。
