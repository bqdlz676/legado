## 三、判据（机械可判）

1. 所有进图路径（六主 + 二附 + 专题联动）只启 `PlaceMapActivity` 一个壳；2D/3D/全球（地球）模式在同一 Activity 内切换，切换不跳页面、不退首页（10:8，索引:201）。
2. 三模式名称照原文登记；气泡三选一口径「2D/3D/地球」与壳层口径「2D/3D/全球」的用词差异见兜底冲突条，禁自造第四模式名。
3. 壳内只做壳 + 图层/行迹线渲染，不内嵌 D18/D19 专题数据（10:56）；图层开关六项齐全，默认开疆域/城池/河流三项（10:29）。
4. 旧 U10/U11/U13（S-06/S-07/S-18/S-20）归档后，3D 能力只从此壳出，禁另立独立地图模块（索引:195–197/219）。
