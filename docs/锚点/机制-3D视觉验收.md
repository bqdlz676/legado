## 三、验收判据（逐条销项，任一不满足即打回）

1. 十步工作流落点齐全：任务书视觉方向、形体推理、表征归属、构造路线、三距离帧、home 首视图、行为归属、真实产物检查、按证据精修、诚实汇报，逐项在报告有小节或明确未验证声明（机制正文第二节）。
2. 条件性判据按三段套用：形与身份、材质与光、构图与传达；不适用条目不写豁免文档；禁止把提示当评分表（机制正文第三节）。
3. 帧存覆盖：每页总览 / 近景 / 交互或动作态 / 边界或极端视角齐备；夜景档未实现的页登记 DEFER，不硬凑（机制正文第四节、9.1）。
4. 单帧六项：高光未裁剪成块、阴影未压死、填充未过度发灰、边界可读、材质身份成立、特效承认成本（机制正文 4.2）。
5. 参数组口径：黄昏 / 阴天 / 夜景三组整块引用；换风格整组换，不许单片改数；外部 hex 落地回挂本仓暖金 token，不新造裸 HEX（机制正文第五节）。
6. 运行时契约逐条核：需求驱动渲染带 invalidate、`views[0]` 为 home、补间 0.9s、阻尼开 / 平移关、用户输入让位跟随；每条按机制正文第六节的症状反查。
7. 门禁边界：自动门禁只判帧存在与动作发生；美术判断由验收代理逐帧人工核，不进自动打分（机制正文 9.2）。
8. 来源留痕：引用外部数值 / 片段处标注仓库、commit `d077e0e68915c25be8e71d74684d3144fd1c2aca`、MIT、原文链接（机制正文第八节）。

## 四、边界与不适用

- 2D Leaflet 二维图、阅读页 / 卡片观感不属本卡范围，归 `docs/工序-观感打磨.md`。
- 纯 JVM 模型层正确性归既有单测与 U13 静态验收线；本卡只管画面与行为层。
- 外部 kit 档位不是质量天花板，外部西幻方向不是本仓方向；外部数值仅为起点，须按绢帛 / 墨 / 暖金物料语言整组调整。
- 本仓 CI 无 Blender；捕获路线不引入 Blender。Paparazzi 纯 JVM 现栈出不了 WebView / WebGL 帧，路线未接通前 3D 帧条目登记 DEFER，不伪造帧。
- 本卡不登记外部仓内部路径为仓内锚点；外部路径仅在机制正文第八节来源节以链接形式引用。
