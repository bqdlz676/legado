## 三、可测判据（P1…P10 + FAIL 条件）

- P1 设置页分组以云灰细线分隔，不套 Material 卡片、不给设置行套卡片框；FAIL：出现 CardView/elevation 卡片框、行内自造阴影圆角。
- P2 设置行 48dp、标题竖排 14sp 墨色、当前值 12sp 石青、分组间隔 16dp；FAIL：尺寸/字号/色值与锚点不符或内联 hex。
- P3 开关行右侧 ToggleButton 暖金 on / 云灰 off 替代箭头；导航行右侧 chevron；FAIL：开关与箭头并存、Material Switch 直用。
- P4 设置内搜索大小写不敏感子串匹配；空 query 零过滤；无命中落兜底空态；FAIL：纯空格出结果、整页空白态、另造一套匹配规则。
- P5 危险动作（清缓存 / 清 WebView 数据 / 压缩库）点击先弹确认层，确认后才执行；FAIL：直调 VM 动作、确认取消后仍有副作用。
- P6 「音效反馈」行读 D27 三态当前值，与 `InkSoundPool` 同源单源；FAIL：设置页自存第二份开关状态。
- P7 云同步分组含 WebDAV 地址 / 账号 / 密码三输入框 + 测试连接反馈（绿点 / 失败文案）；FAIL：缺输入框、失败无文案。
- P8 阅读字体三选项带《左传》竖排预览，选中全 App 正文切换、注音小字维持无衬线；FAIL：预览缺失、注音随正文字体切换。
- P9 偏好坏值（类型不符 / 未知键 / 档位越界）回落默认值不崩；FAIL：类型转换异常上抛、落空白页。
- P10 旧 Preference 页在新设置面接线验收通过后才三口径扫描删除（先接后删）；FAIL：未接新面先删旧页留空窗。
- P11 数值档位走数字步进盘（min–max 钳制 + 恢复默认）；设置域不自造连续 Slider / SeekBar；FAIL：配置域出现 `Slider|SeekBar`、档位越界不钳制。
