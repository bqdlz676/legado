# 锚点卡 · B23 名物库超时态缺失

> 用途：D16 契约层判低项收口依据。出自独立验收 `docs/验收-D16-名物库契约层.md`（全包 grep 超时零命中）。

## 一、事实锚点
- `help/artifact/` 全包：无超时枚举、无超时参数、无可断言路径。
- 规格要求「四边界」（离线/空数据/失败/超时必须可断言且有迂回方案）。
- `policy/ArtifactLoadStrategy.kt`：加载策略的既有形态（读现状后判定超时挂在哪一层）。

## 二、判据
1. 超时态在契约层有明确表达（枚举项或显式状态对象），不是靠调用方各自超时。
2. 超时后必须走兜底数据（缓存/降级），不返回 null、不抛异常到 UI。
3. 可断言：纯 JVM 单测能构造「超时」并断言兜底结果。
4. 超时阈值集中一处配置，不得散落第二份常量。

## 三、边界
- 只动 `help/artifact/`；不接七槽、不动 D1/D2/D3、不动 UI。
- 不引入网络依赖到契约层（保持零 android 依赖）。

## 四、验收
独立验收代理对照四条；CI 唯一编译手段。
