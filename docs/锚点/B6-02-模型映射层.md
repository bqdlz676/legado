## 三、参数与契约对齐表

- BattleSource → BattleCardData：title ← title（必填，空白过滤）；subtitle ← era；description ← context；watchedStage 恒 0；totalStage 三态：phases 非空取 phases.size → rounds>0 取 rounds → 双空取 0。
- ClassicSource → ClassicBook：title ← title（必填）；dynasty ← dynasty（缺源空串，竖排列不渲染）；wordCount ← wordCount（可空归一空串）。
- TopicSource → TopicCardData：title ← title（必填）；preview ← preview（可空归一空串）；allusionCount ← allusionCount（负值兜底 0）。
- HeroSource → HeroCardDraft（页面层草稿，无卡片族数据类）：kind ← HeroKind；title 必填；subtitle / yearStart / yearEnd 可空归一空串，不补示例年份。
- NotebookEntrySource → NotebookEntryCard：count ← 条目列表 size；只认 token / bookName / chapterTitle / timestamp 四字段。

## 四、可测判据（P1~P7 + FAIL 条件）

- P1 映射层落在 app/src/main/java/io/legado/app/ui/main/discover/，不进 ui/card/ 包；ui/card/** 双通道 diff 与 status 空集。FAIL：映射类型写进卡片族包，或冻结面出现路径行。
- P2 四类转换成功路径各有单测谓词：战役字段搬运 + 分母三态；典籍三字段空兜底；专题预览与计数兜底；Hero kind 与五参。FAIL：任一转换无实际谓词断言，或断言仅「不抛异常」。
- P3 坏条目经 runCatching 过滤并计入 MapOutcome.dropped，单条失败不中断整区。FAIL：坏条目向上抛出；dropped 计数与实际过滤数不符。
- P4 同名旧 ClassicBook 不跨包引用：DiscoverModels.kt 仅 import io.legado.app.ui.card 包；解析类型包名断言为 io.legado.app.ui.card；源码无旧 explore 包 dotted 路径。FAIL：出现 ui.main.explore import 或旧模型类型引用。
- P5 NotebookEntrySource 仅四字段；源码不含 mastered / reviewCount 预判字段。FAIL：映射层私加掌握态或复习计数字段。
- P6 战役分母三态穷举（phases 非空 / phases 空 rounds>0 / 双空）；watchedStage 恒 0，不画 3/10 示例。FAIL：watchedStage 取假进度；分母除零或出现 phases 优先序倒置。
- P7 单测纯 JVM，不引 Android 类、不拉起 Compose 运行时；测试函数名无 JVM 非法字符。FAIL：测试 import android.* / androidx.compose.runtime 运行时，或反引号名含 . : [ ] / ; < >。
