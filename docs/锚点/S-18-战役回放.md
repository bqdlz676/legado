## 三、判据（机械可判）

1. 出生五段时序（0-400 / 400-800 / 800-1000 / 1000-1200 / 1200ms）可被单测断言；画面全程无转圈、无进度条、无「请等待」。
2. 棋子/箭头/交战参数为单点常量：呼吸 1200ms、选中 400ms、溃散 800ms、遭遇光环 300ms、冲击环 120dp、设伏 0.3 opacity、光轨 240°/6s、圆点浮高 2dp，禁内联另写。
3. 回放层只经 `ReplayGround` 注入 `TerrainElevation`，禁止二次解码 DEM；势力三档透明度与沙盘同值同源。
4. 观感对照绢帛军图三色 + 2px 噪点；顶栏与控制栏 3 秒无操作自动隐退，信息卡 3 秒后自动消失（切片-06:155），不遮挡地形。

## 四、兜底边界

- 无战役数据/无网：本地缓存 `campaign.json` 照放；远端拉取失败走缓存与空状态三变体（离线=缓存瓦片+toast），不空白、不崩；缺实体时降级小字标志（契约索引:196）。
- 低端机：粒子走 GPU 实例化与合批、动画帧采样降密、shader 降精度——属算法/精度降档，不减少棋子数量、不砍阶段标签与交战动画。
- 高程缺失：复用沙盘 Flat 回落口径，贴地降级为平面贴合，箭头仍沿路径与阶段推进，回放闭环不断。
