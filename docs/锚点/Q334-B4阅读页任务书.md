## 三、可测判据（P1…P14 + FAIL 条件）

- P1 横排引擎四包（provider/entities/api/delegate）签名零改动；FAIL：四包内出现签名变更、新对外类型或被新壳反向改调用约定。
- P2 `VerticalLayoutEngine.layout/hitTest/invalidateCache` 三公开 API 签名冻结；FAIL：三 API 形参/返回值被改；内部实现改动须有单测回证。
- P3 新壳状态源唯一为 `ReadBook`；FAIL：壳内自存第二份当前章纯文本 / 进度 / 样式状态。
- P4 接线走 Compose 枚举目的地 + `rememberSaveable` + `AnimatedContent` 既有范式；FAIL：引入 navigation-compose、新建路由表或第二套页面状态持有。
- P5 气泡统一入口 `BubbleResolver.resolve`；Action 五子类冻结；FAIL：Provider 绕开 resolver 直接出气泡、Action 增删子类。
- P6 气泡关闭不留残余状态；详情 Sheet 关闭后阅读位置 / 滚动位置 / 下划线一字不差；FAIL：关闭后位置漂移、下划线状态残留、气泡态泄漏到翻页后。
- P7 气泡冷 ≤300ms / 热 ≤80ms 有 bench 数据；FAIL：无 bench 采集点、阈值无报告数字。
- P8 竖排参数 18sp / 行距 1.8 / 列距 2.5 / 列宽 0.82 落 token 单源；FAIL：字号行距列距内联裸值、注音小字随正文字体切换。
- P9 翻页方向随排版方向：竖排掀角、横排滑动；FAIL：方向与书类型绑定、横竖共用同一翻页手势。
- P10 双列对照两列独立滚动；FAIL：两列联动滚动、对照列正文用墨色。
- P11 章节切换 0 白屏、翻页 16ms/帧、阅读缓存峰值 ≤60MB 有 bench；FAIL：章节切换显白屏帧、缓存章数超前后各 3 章。
- P12 地图前台期间阅读 `onDraw` 空返回；切回成对恢复、首帧不留白；FAIL：地图占屏时阅读仍抢 GL/Canvas、切回黑屏花屏。
- P13 批注链路接 `NotebookStore` / `vocab_log`；画板批注带出章节名 + 正文纯文本；FAIL：批注只存坐标不带章节正文、回链断章。
- P14 朗读底层 service 保留；朗读控制条 UI 随阅读页 Compose 重写；FAIL：service 编排被搬进 UI 壳、控制条复用旧 SeekBar/弹窗贴皮。

## 四、边界

- 保留引擎：`page/provider/*`、`page/entities/*`（含 `column/`）、`page/api/*`、`page/delegate/*` 一行不动；`vertical/*` 只冻结公开 API，内部可维护；`paragraph/*` 分页输入侧模型保留。
- 引擎根 View 宿主（`page/` 根 13 文件）逐文件判定：产出分页结果 / 文字度量 / 翻页决策的算法件保留；氛围装饰 / 模板 / legacy PDF 形态剥离重写；`InkView.kt`、`InkMoodView.kt` 归属开工前逐行 sweep 定界。
- `help/bubble/**` Provider 与 resolver 契约保留；`service/BaseReadAloudService`、`TTSReadAloudService`、`HttpReadAloudService`、`model/ReadAloud` 保留，本页只接控制面。
- 旧 `ReadBookActivity` 与旧菜单 / 对话框在新壳接线验收通过后按 A3 先接后删；本单不提前物理删旧。
- 本卡未覆盖的字段级细节（掀角曲率、粒子数量、噪点 alpha 档位）见任务书 §八反例与 §十一未验证项，按 C3 兜底并回填出处。
