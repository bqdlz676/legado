## 三、机械可判据

1. 单点化：五组触发点（onResume / onPause / onHiddenChanged 双向 / 开关回调 / onDestroyView+onDestroy）六处调用全部进入 `syncShelfBridge()`；`acquireShelfBridge()` / `releaseShelfBridge()` 原语只在裁决方法内被调；全文件无第二份 `shelfHidden` 读取或偏好申领闸门。
2. 幂等不误伤：`release("shelf")` 只移自己标识；未上牌重复交还 `remove` 返回 false，`&&` 短路不触发 `teardown()`；地图 / 沙盘持牌期间书架连续交还不拆他人监听。
3. 销毁安全：销毁两处走不收 Context 的 release；申领路径 `context ?: return`、`activity?.windowManager… ?: 0` 可空兜底；`requireContext()` 仅存于 onCreateView 视图创建路径，`requireActivity()` 代码零命中。
4. 功耗未退化：hidden=true 回填 `shelfHidden=true` 后裁决 `visible=false` → 交还；开关关掉偏好置 false 后立即交还，不等下一次生命周期回调；Q441 切 Tab 停桥口径未放宽。
5. 静态可编译：新方法签名、可空链取值类型、偏好 Boolean 类型、既有 import 贯通静态推理；kotlin-syntax-lint PASS；真类型推断与编译以云端 CI 为准。
6. 报告一致性：写码方自报行号逐字回源命中率 20/20；「自查反例」节八条均为反事实推演 + 现行缓解，非自夸。
