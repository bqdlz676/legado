## 三、可测判据（P1…P14 + FAIL 条件）

- P1 发现页只挂在 `ShellTab.EXPLORE` 槽位，走 Compose 枚举目的地 + `rememberSaveable` + `AnimatedContent` 既有范式；FAIL：引入 navigation-compose、新建 NavHost/NavController 或第二套页面状态持有。
- P2 三种卡片 + 马恩党史卡全部消费 `CardBase`（`state` / `modifier` / `content` 三槽）；FAIL：发现页另造卡片边框、阴影、圆角、骨架屏或私有色值 token。
- P3 战役横卡字段映射 `BattleCardData`（title/subtitle/description/watchedStage/totalStage）；FAIL：卡内自造第二套模型、进度分母 ≤0 时除零。
- P4 典籍竖卡字段映射 `ClassicBook`（title/dynasty/wordCount）；FAIL：缺字段时渲染空白占位框或用假数据填充。
- P5 专题横条卡字段映射 `TopicCardData`（title/preview/allusionCount）；FAIL：金点数量 ≤0 仍渲染一排金点、分组无目录时硬画空条目。
- P6 五态齐：Loading 走基座骨架灰块 + 暖金斜光带；Disabled 不响应手势；Empty 走 `EmptyStateCard`；Offline 走缓存 + 提示；FAIL：任一态在发现页缺兜底或自绘一套骨架。
- P7 数据源只取在册资产：战役取 `campaigns.js`；典籍取 `books` 表；专题取 `allusion.txt`；FAIL：写死 mock 列表顶替真实数据源、来源不可考。
- P8 缺源字段（战役进度、典籍朝代与精选目录、专题分组目录、马恩党史条目、生字本 mastered 标记）在任务书登记为待供批次；FAIL：本单自造假数据填槽、或把缺源伪装成已接线。
- P9 旧 explore 侧先接后删：`exploreInfoMapList` LruCache 被 `BookSourceExtensions` 依赖，迁移到 `help/source/` 后才允许删旧 Adapter；FAIL：直接删 Adapter 导致书源发现项缓存编译断裂。
- P10 卡片尺寸 / 边框 / 字号逐条命中切片-25:65、切片-25:66 清单；FAIL：战役卡非 0.85×96dp、典籍卡非 0.28×160dp、专题卡非 72dp、默认卡自带边框。
- P11 动效走既有令牌：snap fling、stagger 编排、前倾弹簧参数取 `CardTokens` / `ComponentTokens`；FAIL：发现页内联裸弹簧参数、裸曲线时长。
- P12 断网 / 空目录 / 坏条目 / 长列表 / 旋转重建 / reduce-motion / 低端机 / 暗色九种边界逐条有兜底实现；FAIL：任一边界落空白态、崩溃或降级砍功能。
