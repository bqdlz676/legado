## 可测判据（施工图 §1.4 六条）

1. 地球域全就位：9 EARTH `READY_REMOTE` → `degradation(EARTH) == FULL_TEXTURES`、`degradation(SKY) == PROCEDURAL_ONLY`。
2. 星空缺档不污染地球域：仅 EARTH 缓存 → 地球 `FULL_TEXTURES`、星空 `PROCEDURAL_ONLY`。
3. 两域各自混合档互换缓存后仍按本域计数，各 `CACHED_MIX`。
4. 域标注完备：每个 `TextureKind.domain ∈ FallbackDomain.entries`，三 SKY 项标 SKY。
5. 空域空集口径：`levelFor(emptyList()) == PROCEDURAL_ONLY`；单真实 → `FULL_TEXTURES`；真实 + 兜底 → `CACHED_MIX`。
6. 快照分域回填：`markAssetCached(DAY_SATELLITE, null)` 后 `snapshot.degradation == CACHED_MIX`（地球域）、`snapshot.skyDegradation == PROCEDURAL_ONLY`（星空域）、`fallbackResolutions.size == 12` 不变。
