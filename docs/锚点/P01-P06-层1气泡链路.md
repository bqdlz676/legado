## 三、判据（机械可判）

1. 每对必须有 `file:line` 锚点 + grep 命令与输出原文，无锚点判「无法判定」。
2. 状态只用矩阵四词：已验-PASS / 已验-有缺陷 / 待验 / 未落地；回写矩阵时三列（代理/状态/锚点）同步。
3. 空值兜底：无命中不得返回 null 或抛异常，须返回结构完整对象；违反即「有缺陷」。
4. 时序：注册点必须唯一（grep 计数 = 1），双写即「有缺陷」。
5. 不许把静态契约结论冒充运行验证；编译/单测一律标「未实测，等 CI」。
