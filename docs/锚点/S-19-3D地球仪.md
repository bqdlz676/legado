## 二、可数值化参数（契约层 `ui/map/globe/contract/GlobeParams.kt`）
- 地轴倾角 23.5°（`:49`）
- 惯性衰减 800ms 到 0（`:61`）
- 经线/纬线网格 128×128（`:7`/`:66`）
- 暗半球亮度 0.15（`:40`）
- 晨昏线渐变带宽 5°（`:41`）
- 星空球半径 900 世界单位（`:46`）
- 自转周期 / 球面半径 dp / 标记点直径 / 脉冲周期：**规格未给数值，标 `[待拍板]`**

## 三、判据（验收逐条打勾，任一不满足即打回）
1. 地轴倾角必须是 23.5° 且光照基于倾斜后的法线，不许"直立自转"。
2. 惯性必须是 0.8s 衰减到 0，手感不能瞬间停。
3. 晨昏线必须是 5° 渐变带 + 日出侧橙光，禁止硬切边。
4. 星空必须固定、地球自转，星空球半径 900，背景不许死黑。
5. 经度 0 的坐标约定：契约层与 `geo/Geo.kt` 已统一为 `+z`（东经绕 +Y 右手系，赤道东经 90° 落 `+x`，北极 +Y）；两层口径不许各写各的，任一层改口径必须两层同步改，投影层不再做轴映射。
