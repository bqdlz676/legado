## 三、可测判据

- P1 底栏 tint 选中取 `brandGold`、未选中取 `brandCopper`，壳包零内联 hex、零 `textSecondary` 作 tint。
- P2 宿主同步回路首 composition 不覆盖恢复态；`LaunchedEffect` 键为请求代次，且经策略门判断；冷启默认槽仍由 `initialTab` 兜底。

- P4 三槽顺序书架 → 发现 → 设置不动；坏偏好 / 非法槽回落书架不崩；reduce-motion 与低端机降级路径不改。
