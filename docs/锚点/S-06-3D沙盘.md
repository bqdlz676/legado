**兜底边界**
- 数据缺失/消歧失败：多源交叉验证后仍无命中 → 进候选列表与今址参考层，不留空点、不崩；推定坐标只渲染色块不画点，不伪造实测精度。
- 无网：本地打包的本体/多边形/河流/古迹 JSON 照读；远端失败走缓存，缺项以占位层兜住，不空白。
