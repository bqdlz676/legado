## 二、验收判据（七条逐条）

1. start 守卫同构：三处 start 在已有一路拖拽时早退，不写来源锁、不重置坐标基准；无头桩复跑 touch 先 / pointer 后、pointer 先 / touch 后两向顺序，锁归属与基准均不被第二通路覆盖。
2. 捏合抬手不落点：双指按下→轻移→抬起完整序列走完，`dropPoint` 不触发；`wasPinch` 在复位前快照，快照点正确。
3. 标志复位：抬尽、全新单指、`touchcancel` 三处复位 `pinchActive`，无跨手势残留（含标志位与来源锁计数）。
4. 死变量零残留：`var down` / `down =` / `last = down` 标识符级 grep 零命中；删除后 `last` 仍正确承接坐标。
5. Q446 成果零回退：单次拖拽量级 ≈0.030 不翻倍；四向 800ms 过渡在位；死字段 `gyro.active` / `drag.q` 零残留；weights 0.08 / 0.12 / 降级锁 0.04 不变。
6. 缩放不被拖拽吞掉：three 捏合缩放仍生效，记录 `dist` 指距变化数字；钳制区间在位。
7. 报告一致性：抽 ≥6 处写码方自报行号逐字回源，命中率给数字；无死文件、无越界。
