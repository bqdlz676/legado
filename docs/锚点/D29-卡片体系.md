## 二、参数表

通用 Token（唯一来源 `CardTokens.kt`）：底色纸白 `#F7F1E6`；三档阴影 默认 `0 0 12px rgba(212,165,74,0.3)` / 悬浮 `0 0 20px rgba(212,165,74,0.45)`（轻抬 2dp）/ 点击 `0 0 8px rgba(194,59,46,0.3)`；圆角 16dp；卡间距 12dp；默认无边框（仅战役横卡暖金 1px、马克思暖金 1px、党史朱砂 `#C23B2E` 1px）；纸白纯色 + 2px noise 颗粒，不透明度 0.03。

12 类尺寸速览（行号给验收逐条回核）：

1. 书籍卡（:19-20）：宽屏宽×0.28、高屏高×0.42；悬浮前倾 5°、点击 8°
2. 战役精选横卡（:24）：宽屏宽×0.85、高 96dp；毛玻璃 backdrop-blur 8px + 纸白 80%；scroll-snap 居中
3. 典籍竖卡（:27）：宽屏宽×0.28、高 160dp；悬浮前倾 3°；栅格 3 列间距 8dp
4. 专题横条卡（:30）：满宽（左右各 12dp）、高 72dp；毛玻璃 + 纸白 70%
5. 马克思/党史卡（:33）：标题 18sp 暖金 Bold；马暖金 1px 边框，党史朱砂 1px
6. 搜索结果卡（:36）：高 56dp；匹配朱砂高亮；在线源追加本地之后 + 暖金「在线」标签
7. 名物索引卡（:39）：高 72dp
8. 名物条目卡（:42）：高自适应 60-80dp；点击半屏 Sheet 展开
9. 人物关系卡（:45）：宽屏宽×0.45；双击弹出 200ms 淡入；点外部消失
10. 分享卡（:48）：四背景（纸白/暗色/护眼/宣纸纹理）+ 暖金渐变 opacity 0.05；导出 PNG 到 `/sdcard/Download/落文卡片/`，文件名 `书名_日期.png`
11. 空状态卡（:51-53）：三变体 `empty` / `notFound` / `offline`
12. 设置行卡（:56）：每行 48dp；分组间隔 16dp；无卡片框，云灰细线分隔；开关行 ToggleButton（暖金 on / 云灰 off）
