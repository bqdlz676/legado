## 二、判据（可机判部分）

1. 逐行断言全量禁抽样：每行 `magVt ≤ 6.5`（含等于）；解析失败 / NaN 非有限 / 重复主键 / 坐标越界分类计数；违规逐行打印 `stars.csv:行号` 与实测值，不只报总数。
2. 可回源摘要：源表行数、逐行通过数、异常分类计数、内层 L0 累积数（= 源表行数 8920）；CI 静态闸可见。
3. `--selftest`：坏样本（mag=7.0、NaN、重复主键）必须 exit 1，好样本 exit 0，贴原始输出。
4. 三时刻 alt/az 手算对拍：可手算输入（格林尼治 0°、赤道上中天），期望 alt/az 闭式算式入注释，投影输出反演值与期望差 ≤1°。
5. 观测点注入链路：`injectedUtcMillis → effectiveUtc → LST → 帧快照 → StarProjector` 在 JVM 走通；帧内 LST 与纯函数直算一致，帧内观测点/LST 投影与直算投影逐位一致。
