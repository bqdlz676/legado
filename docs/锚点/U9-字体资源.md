## 三、判据（机械可判：可 grep / 可跑单测）

1. `ls app/src/main/assets/fonts/` 五枚打包文件齐全；`grep -n "luowen-font-manifest/v1\|GENERATED"` 命中 `manifest.json`；五角色 role 名与登记册:109 五枚分工逐条对上。
2. 逐枚 `bytes ≤ budgetBytes`：正文 / 标题 204800B、数字 20480B；超体积红线的内置资产被加载器拒绝并回落系统字体（manifest `budgetNote`）。
3. `coverage.json` 逐字 cmap 覆盖 `mandatoryText`；五角色 `fallback` 字段可枚举；子集未覆盖字回落系统 serif / sans / mono，不崩、不出空白态。
4. `LICENSE-OFL.txt` 登记 OFL-1.1 来源与版本；`grep` 资产目录无禁源（Wikipedia / OSM / CC-CEDICT）派生字体文件。

## 四、兜底边界

- 子集文件缺失 / 损坏：加载器回落对应系统字体族（serif / sans / sans-tabular / mono），首屏可见文字，不崩、不白屏。
- cmap 覆盖不足：生僻字 / 异体字回落系统全量 CJK 字体；扩字走 `subset_generate.py --top-n` 重裁，体积超红线脚本直接报错拒绝打包。
- 无 coverage 记录或验收纪要：以 manifest `roles[].fallback` 为核对基准；切片与 manifest 均无出处的新增字体 / 角色，按 F-73 退回设计，禁止自行添入资产目录。
- 「正文常用 2500 字」为 web woff2 口径；Android 内嵌 OTF 在 200KB 红线内裁不下 2500 个 CJK 字形时，按体积红线取核心高频字表，不为凑字数突破 200KB 上限。
