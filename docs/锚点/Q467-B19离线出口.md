## 二、判定口径（不许放宽）

1. 判「接上了」：该浮层离线态有可点的下一步，且下一步真能做到事（重载列表 / 重试导入 / 刷新统计 / 重新校验 / 打开本地缓存等）；传空 lambda 糊过去算缺陷，不算接上。
2. 判「HintOnly 合理」：浮层内容是本地表单 / 本地菜单 / 已载本地数据 / 本地解析器产物，离线不产生新的可做事项；远程流的失败重试必须已在屏体直挂控件（直挂 `InkEmptyState` / `ErrorBanner` 等）接到真实发起函数。须写明为什么没有迂回路径。
3. 不许为消掉 HintOnly 编造无意义动作；不许把行级触发的菜单动作伪装成 Sheet 级离线重试。
4. 组件对外签名冻结：`InkBottomSheet.kt` / `InkHalfSheet.kt` / `InkEmptyState.kt` 的形参不动；只在宿主侧接。

## 三、可测判据（grep 回证，逐条可断言）

1. `grep -rn "InkBottomSheet(\|InkHalfSheet(" app/src/main --include=*.kt` 全量枚举；宿主调用点总数、各自是否传 `onRetry`、是否空 lambda，逐条列文件:行。
2. 逐块解析调用点参数：是否传 `state = ComponentVisualState.*`；是否出现 `onRetry = {}` / `onRetry = null`。
3. 每站给因果：文件:行 + 该宿主离线态能做什么 + 结论（Wired 应接 / HintOnly 合理 / 域外遗留）。
4. 回证前后计数：调用点总数、传 null 数（显式 null / 省略落默认 null 分列）、真动作数、空 lambda 数，前/后对照。
5. `python3 data_scripts/kotlin-syntax-lint.py <改动文件>` PASS；禁跑 gradle / kotlinc，编译与单测归云端 CI。
