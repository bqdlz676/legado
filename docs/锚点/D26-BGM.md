## 三、判据（机械可判）

1. 六路径可达：回合 0 / 行军 / 交战 / 战后胜 / 战后败 / 收尾各触发对应轨，无「同一首循环到底」（:76）。
2. ducking 可测：音效帧 BGM 音量 ≤0.3；降压时间窗 ≤500ms，恢复 ≤800ms（:77）。
3. 通道隔离：BGM 模块 `grep -rn "MediaSession\|ExoPlayer\|Player"` 0 命中复用；仅走 SoundPool/AAudio（:53/:80）。
4. 优先级与资产：用户音乐在播判定函数 + 用例存在；五段总时长 <60s 且每段来源可溯（:78/:79）。
