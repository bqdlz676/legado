## 二、参数表

| 项 | 值 |
|---|---|
| 拖拽指示器 | 4dp 高，金色 `BRAND_GOLD` |
| 阅读页下沉 | 8dp |
| 遮罩暗化 | 40%，茶色毛玻璃（`BG_OVERLAY` 派生） |
| Sheet 背景 | 纸白 `BG_PAGE` |
| 分隔线 | 云灰 1dp（`TEXT_TERTIARY` 派生） |
| 内容段 | 五段（原文字词 Sheet 是四段） |

## 三、判据（机械可判）

1. 关闭 Sheet 后阅读位置/滚动位置/下划线状态不变——必须写成可跑断言（不是"看起来没变"）；
2. 下沉 8dp、暗化 0.4、横杠 4dp 三项可 grep 断言；
3. 颜色只引用 `ComponentPalette`，不许内联 hex；
4. 空数据（无同场人物 / 无时间轴 / 无同名他人）每段都要有兜底文案，不许空白段。
