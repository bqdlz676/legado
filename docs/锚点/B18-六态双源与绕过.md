# 锚点卡 · B18 六态双源与绕过

> 用途：B18 写码单开工依据。缺陷条目见 `docs/问题清单.md` B18 行；成因见 `docs/验收-Q53-空态压淡.md` §6.1–6.6。

## 一、事实锚点（逐字，含文件:行）
- 压淡双源：`ui/card/CardTokens.kt:109` `disabledAlpha=0.30f` 与 `ui/components/ComponentPalette.kt:77` `DISABLED_OPACITY: Float = 0.30f` 各写一份。
- 自持状态：`ui/card/EmptyStateCard.kt:50` 起自持 `CardState`，无 Empty/Offline 档，Offline 仅文字压 0.35。
- 书架独立状态机：`ShelfState` 不读 `contentAlpha/eventsAllowed`；裸点击点 `ui/main/bookshelf/BookshelfScreen.kt:476/574/628-636`、`ui/file/…/HandleFileSheet.kt:56`。
- 契约零消费：`ui/components/contract/ComponentSystemContract.kt:65` `componentStateOf` 渲染零消费。
- 契约语义现状（不得改动）：`ComponentSystemContract.kt:39-50` 六态枚举，DISABLED=0.30f/eventsAllowed=false、LOADING=1f/false、EMPTY=1f/true、OFFLINE=1f/false。

## 二、判据
1. 压淡单源：`0.30f` 字面量全仓只允许一处（`ComponentPalette.DISABLED_OPACITY`），`CardTokens.disabledAlpha` 改引用或删除，且全仓 grep 回证唯一。
2. 点击一律过闸：书架三处与文件 Sheet 一处改为走 `InkInteractionState`（或其派生的 `eventsAllowed`）判定，禁裸 `clickable`/`detectTapGestures`；每处给改前后行号。
3. `componentStateOf` 处置二选一：要么接真实渲染消费（至少一处调用点，给出证明），要么删除该函数并在注释写明「三布尔快照不足以表达六态」；不许留零消费的假契约。
4. 卡片自持状态收敛：`EmptyStateCard` 的 `CardState` 要么映射到统一六态（含 Empty/Offline 档），要么证明它只是视觉变体、不参与事件许可判定；不许出现第二套「能不能点」。
5. Offline 文字压 0.35 的去留：与契约 OFFLINE=1f 冲突则必须裁决其一并写明口径，禁止两套并存。
6. 不改契约枚举语义（`ComponentSystemContract.kt:39-50` 保持），只改消费侧。
7. 可断言：每条判据至少一条纯 JVM 断言（状态解析 / 单源常量 / 闸门布尔）。

## 三、边界
- 只动：`ui/card/CardTokens.kt`、`ui/card/EmptyStateCard.kt`、`ui/components/ComponentPalette.kt` 的引用侧、`ui/components/contract/ComponentSystemContract.kt`（仅 `componentStateOf` 去留）、`ui/components/InkInteractionState.kt`（若需新增判定入口）、`ui/main/bookshelf/BookshelfScreen.kt`、`ui/file/**/HandleFileSheet.kt` 与其测试。
- 不碰：reader 域（B20/B21 已落）、`InkEmptyState/InkButton/InkBottomSheet/InkHalfSheet`（B17/B19 已落）、地图、名物库。
- 视觉不变优先：本单是「收敛单一来源 + 补闸」，不是重新设计卡片外观；压淡数值维持 0.30 不变，只去掉第二份写法。
- 若某处裸点击补闸后会「看起来能点但点不动」，必须同时给出禁用视觉（压淡或光标），不许静默失效。
