## 四、放行类别（误报防制，均有独立夹具断言）

- SKIP:NONHAN：非汉字符号（`※` U+203B、ASCII、标点、数字），不可能进汉字种子索引。
- SKIP:ECHO：字面量同时是同用例被测函数入参，断言透传一致性。
- SKIP:SELF：两边都是被测函数输出派生表达式，无字面量参与。
- SKIP:STRUCT：非空 / 非崩 / 不空白 / 列表空结构完整性断言。
- SKIP:INVARIANT：纯函数不变量（上下界、长度区间、夹取范围）。
