## 二、参数表

合并口径（单一权威）：几何 `PlaneGeometry(SIZE,SIZE)` → `SphereGeometry(100,128,128)`（:118）；坐标 `lonU/latV` → 球面坐标，全场景一套坐标禁两套并存（:118）；入口＝同一球、缩放区别，非两个页面，不做新文件/不建新页面（:3/:104）；推演数据同一份 `campaign.json`，引擎自动判模式（:84）；引擎分流：沙盘区域 A* + 规则意图 + 兰彻斯特，球面/海上大圆弧线 + 遭遇结算（无地形分析）（:82-83）。

LOD 三档（:25-27）：> 球半径×3 → 128×128、2K；×1–3 → 256×256、当前大洲 4K 其余低精；×0.1–1 → 局部 512×512–1024×1024，高度图切当前区域。

交互（:91-96）：单指拖动＝旋转/平移（沿球面）；双指捏合＝缩放（全球↔区域↔战场多级 LOD）；双击＝飞到点击位置；右下按钮＝自动旋转 0.2°/s，惯性慢转 0.8s 停稳；点光针/标签＝弹出悬浮竹简信息卡；点城池光柱＝金色虚线旋转圆环 + 半屏 Sheet 详情。

性能红线（:109-116）：LOD0 128×128、2K、≤10 draw call；LOD3 512×512、8K、≤18 draw call；帧率 55fps（手机）；首载 2K 纹理缓存本地 ≤800ms；LOD 切换 GPU morph 2-3 帧。

既有代码对接（:99-103）：`three.html` 保留做全球球面 + LOD；`china_height.js` 保留为区域高精度源；`cities.js` + `world_places.js` 合并到 atlas 纹理标签；`powers_poly.js` 多边形采样球面顶点；`engine.js` 加球面模式（大圆弧替代 A*）。

## 三、判据（机械可判）

1. 单一权威几何/坐标：全场景只存在一套球面模型与球面坐标（`SphereGeometry(100,128,128)`，`lonU/latV` 已映射球面）；沙盘与地球仪共用同一球，禁两套坐标、两套渲染并存（:3/:118）；
2. 入口单一：不建新页面/新文件，同一宿主承载全球球面 + LOD 切换；双指捏合在全球↔区域↔战场间多级过渡（:92/:104）；
3. 状态保持：同一份 `campaign.json`，切 LOD / 切区域不重置推演状态，引擎自动判沙盘或球面模式（:84）；
4. LOD 切换 GPU morph，2-3 帧内平滑完成、不掉帧（:28/:116）。

## 四、兜底边界

- 渲染栈时代口径：裁决十三取 JVM 软渲染门面；切片内 Three.js shader / `three.html` / `.js` 文件名仅作视觉目标与模块来源参照，Android 落地为原生门面，不引入 WebGL/Three.js 运行时。
- 桌面 120fps / 1.5GB 显存档（裁决十四）标"暂不适用：本包无桌面目标"，移动红线 55fps 生效，条文保留不删。
- 数据缺源兜底：高程/卫星/云层/夜景等纹理预缓存本地；离线回落 `china_height` 区域高精度源；纹理缺失时软渲染按既有近似实现，禁空白崩溃。
- 球面/海上无地形分析，走大圆弧 + 遭遇结算；沙盘区域 A* 引擎路径不改写。
