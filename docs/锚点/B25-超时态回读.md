# 锚点卡 · B25 名物库超时态回读

> 用途：B25 写码单开工依据。出自独立验收 `docs/验收-名物库判低两项.md` 的 B23 判据 1。

## 一、事实锚点
- `ArtifactFallback.kt:47-57`：`notFound(...)` 收 `state` 形参但函数体未读取。
- `FallbackState.TIMEOUT` 仅透传，无分支消费；`CacheStatus.TIMEOUT` 生产零消费。
- 结果：调用方拿到兜底气泡也无法区分「超时」与「查无此项」。

## 二、判据
1. 二选一落地：要么兜底气泡承载状态标记（在允许扩展的位置），要么返回结构显式带状态字段；不许两边都加。
2. 消费侧真实可读：至少一个生产代码路径能读到该标记并据此改变行为（如提示文案「加载超时，展示缓存」vs「查无此项」）。
3. 五态口径一致：TIMEOUT 与 NOT_FOUND/OFFLINE/EMPTY/FAILURE 的回读方式同构，不许只为超时开特例。
4. 可断言：纯 JVM 单测能区分「超时兜底」与「查无兜底」两条返回。
5. 保持零 android 依赖与阈值单源，不新增第二份常量。

## 三、边界
- 只动 `help/artifact/**`；不接七槽、不动 D1/D2/D3、不动 UI。
- 不改变 B23 已确立的 TIMEOUT 枚举语义。

## 四、验收
独立验收代理逐条对照；CI 唯一编译手段。
