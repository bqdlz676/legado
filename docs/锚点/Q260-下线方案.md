## 二、结论锚点

- C1 三页运行期活引用均为 0：main 侧无 `::class` / `Intent` / 反射 / 深链拉起；可达性风险只在孤儿宿主 `MyFragment`（about 路由）与测试源集。
- C2 AboutActivity 不可直接删：新壳 AboutInkActivity 功能不等价，11 项缺口（Beta 更新、贡献者、更新日志、崩溃日志、日志包、堆转储、隐私、协议、免责、邮件、公众号、分享口令）需先迁移或裁撤留痕。
- C3 BookshelfManageActivity 不可直接删：新书架单组平铺无多选 / 分组 / 批量换源 / 封面修复链路；`GroupManageDialog` 数据层存活但入口链断。
- C4 RemoteBookActivity 成组下线前提是产品确认远程浏览导入功能存废；UI 包 8 文件 + 菜单可下，WebDAV 数据层与服务器配置表保留。
- C5 施工顺序：切路由 / 清 import → 测试指向改写 → 摘 manifest → 删类与伴生 → 清资源；每步独立验收锚点 + 回滚点，见报告第五节。
- C6 最大反例风险是功能静默丢失（不崩溃、无 Crashlytics 信号）；缺口未销号前不得进入摘 manifest 及以后步骤。
