## 六、自查反例与边界

- 反例一：只改外观不改闸门。若压淡接上 `contentAlpha` 但箭头 `enabled` 仍只读模型边界，DISABLED 下箭头看起来淡了却仍能点。反证链：`Timeline.kt:88` 闸函数先取 `state.eventsAllowed`，`Timeline.kt:214` / `:227` 与运算后才进 `TimelineArrow` 的 `rememberInkGesture`；静态测试 `:71` / `:75` / `:79` 三条谓词锁死该链路，改坏即红。
- 反例二：离线套用禁用压淡。契约 OFFLINE `contentAlpha=1f`（`contract/ComponentSystemContract.kt:49`），不得套 DISABLED 的 0.30；本单 Body 压淡整读 `state.contentAlpha`，OFFLINE 不压淡，与 `ComponentSystemContractTest.kt:81-82` 既有口径一致。
- 反例三：空数据被当成禁用。契约 EMPTY `eventsAllowed=true`、`contentAlpha=1f`；空态分支走 `InkEmptyState`，重试按钮按 B17 独立入口分闸，本单未改该口径。
- 边界一：`model` 为空。`effectiveEmpty` 在 `Timeline.kt:102` 兜住空列表进 `InkEmptyState`；Body 内 `model.current() ?: return`（`Timeline.kt:129`）二次防空，索引越界时不崩、不画越界节点。
- 边界二：单向可用。首节点 `canGoBack=false`、末节点 `canGoForward=false`，另一支箭头按与运算置不可点；`TimelineModel.goBack()` / `goForward()` 在边界原地返回（`Timeline.kt:56-58`），不抛异常。
- 边界三：低端机 reduce-motion。整行压淡走静态 `alpha` modifier（`Timeline.kt:132`），不挂动画时长弹簧；reduce-motion 只归零动画区间，不回退静态透明度，压淡仍然成立。
- 边界四：显式 state 与既有布尔冲突。`effectiveLoading` / `effectiveOffline` / `effectiveEmpty` 取并集（`Timeline.kt:100-102`），与上一单 Button 并集口径同构；宿主传 `state=DISABLED` 时无论布尔如何，箭头闸都按契约关闭。

## 七、认知成本

- 收口后状态口径一句话：档位与规则只在契约枚举；快照是输入记录，经 `resolve()` 归并到枚举；组件消费只读枚举字段。接手者不再需要在快照布尔与枚举字段之间判断哪份是准的。
- 新增概念一个：`timelineArrowAllowed` 纯函数，位置在 `Timeline.kt:87`，职责单一（契约许可叠加模型边界），可在普通 JVM 单测中断言，不依赖 Compose。
- 残留认知债务：`ComponentVisualState` 一名两源（contract 定义 + `ComponentState.kt:23` 别名）与 compat 身份扩展仍滞留排除域，回收前接手者需知道别名只是同义名；回收后可消除这一层跳转。
- 快照 `accentOverlayAlpha` 命名仍带 Alpha 字样，但它是悬停 / 按压泛色覆盖，不是整行压淡系数；整行压淡一律看枚举 `contentAlpha`，两者不要混读。
