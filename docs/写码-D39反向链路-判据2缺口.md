## 5. 二阶三阶影响

- **一阶**：地球点按经纬度 → 州域名 → 进天外视角；观测点随选点写回；星空 LST 可由测试 / 回放注入固定时刻；三时刻地平换算有契约断言兜底。
- **二阶**：
  - 耦合方向受控：`RegionHitResolver` 只收经纬度标量、只出州域名字符串，不引用星空渲染类型；`FieldAllocationLayer` 只认 code / region 字符串，不持有地球几何，地球命中逻辑不反向侵入 astro 层（施工图 4.2）。
  - `setObserver` 被选点路径接通，与定位权限分支共享同一观测点事实源；注入时刻与墙钟时刻共用 `effectiveUtc` 单路径，不出现第二套 LST 计算。
  - 分野词表两份消费（正向 `regionForAsterism`、反向 `regionForCodes/asterismCodesForRegion`）同出 `entries` 单一事实源，未建第二张映射表。
- **三阶**：
  - 后续锚点表升级为真实州界多边形时，命中算法从最近邻换成多边形包含，`resolve(lat, lng): String?` 签名不变，调用方无感。
  - 若未来回放时间轴接 `setObservationTime`，历史 / 未来时刻星空与地球回合可同一时钟驱动；当前 `scene.update` 太阳方位仍跟帧 `utcMillis`（见 §8 未验证项）。
  - 维护成本：新增概念仅 `RegionHitResolver` 一个；未引入新 Provider / 新模块。

## 6. 反例边界（穷举）

1. **锚点半径外 / 对跖点 / 海洋**：`resolve` 返回 null，地球 tap 不产生任何星空写回，不凭空造最近州域（施工图 2.3 边界 3）。
2. **分野表残缺 / 锚点表为空**：resolver 空表恒 null；layer 空表 `focusRegion` 返空列表；整条反向链静默不动作，不抛异常、不崩。
3. **州域命中但分野表无条目**：`focusRegion` 返空列表；`selectedRegion` 不被写入（不清空旧值）；门面不转向，避免空脉冲环落屏心。
4. **同名 / 多宿同域消歧**：一州多宿 codes 全量返回；高亮取 `codes.firstOrNull()`（renderer 桥接侧）；成员凸包 `memberIdsForRegion` flatMap 并集；异说不参与反查，不合并仲裁。
5. **重复点按同一州域**：`focusRegion` 重起脉冲时刻；`enterSky` 同态早退；弹簧打断续接沿用既有 `poseValue/poseVel` 口径，不叠加第二路过场。
6. **非有限输入**（NaN / ±Inf）：resolver 直接回落 null，不进夹角计算。
7. **反例自检（假设本方案错了）**：最强反例是「州域命中本应走地球渲染层区域拾取，而不是纯 JVM 最近邻」。当前仓内无州界多边形数据（§十一.4 tier3 示意），地球渲染层也无区域命中入口；一期锚点最近邻是数据现实下的迂回方案，接口预留升级位。若验收要求真实多边形命中，须另立数据缺陷，本单不凑。
