1. **S-12 通路口径冲突**：`切片-12-画板InkSlate.md:9` 8.3 明文「WebView 预热…Excalidraw 主库异步 import…removeView 而非 destroy」；`docs/落文-模块契约索引.md:172`（U7）记「WebView/Excalidraw 与 `assets/www` 整包已删；新增原生位图渲染 `InkSlateBitmap`」。两侧并存，不自择；规格侧须先修订 8.3/8.4 再验收。
2. **S-13 形态冲突**：`切片-13:7`「居中一个输入框」为独立搜索页口径；`docs/问题清单.md:139`（D25）定「搜索做书架页下拉浮层，禁独立搜索 Activity 入口」，索引 `:173` 同 D25。UI 元素对片、入口形态以 D25 为准。
3. **S-10 待拍板冲突**：`切片-10:22` 含「3D 前倾旋转 5°」「15-20 粒极淡金色微粒」；`docs/问题清单.md:263`（T3）将「书架卡片 3D 前倾、右下角金色微粒氛围层」列为未拍板（四份台账 0 命中）。两侧并存，派单前需拍板。
4. **S-08 时代口径缺口**：`切片-08:37-41`「WebView 复用（画板/地图/沙盘三家共享一池）…预热 3 个 WebView 入池」与现状不符（U7 已原生位图、`assets/www` 已删，索引 `:172`）；`:65-69`「七、iOS 独有」（Metal/os_unfair_lock/Core Text）对 Android 仓不适用，派单时剔除。
5. **S-07 归属冲突**：`docs/落文-模块契约索引.md:176`（U11）记「已归档 D17，不再独立派单」；`docs/规格登记册.md:19` S-07 仍 `[待立项]`；`docs/问题清单.md:131`（D17）吸收范围仅列「S-06/S-18/S-20」，未含 S-07。归属需拍板：随 D17 壳吸收，或保留 D9 独立收口。
