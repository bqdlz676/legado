## 七、二阶 / 三阶影响推演

1. 组件签名未动；35 站维持默认 null，裁决恒 HintOnly。视觉相对上一棒：旧版离线分支是可点空动作按钮，B19 接缝已收口为不渲染按钮，本单维持该口径，不回退。
2. 将来某宿主接入 Wired：必须从 VM / Actions 传真实发起函数；禁止在 `resolveSheetOfflineAction` 内对 null 回调兜底包装 `{}`，否则判据 3 回落口径被架空（沿用 `docs/修复-B19-离线分支空动作.md` §7.5 第三阶注记）。
