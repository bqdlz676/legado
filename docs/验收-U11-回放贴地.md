## 三、注入链路说明

```
ReplayScreenHost(elevation?, director?)
  ├─ 外部显式 elevation            → 直接采用
  ├─ 外部显式 director             → 沿用 director.elevation，不再解码
  └─ 缺省                          → remember(context) { DemTerrainLoader.load(context) }
                                          │ （sandbox 公开 API；解码失败回落 TerrainElevation.Flat，日志只打一次）
                                          ▼
                          ReplayDirector(campaign, clock, elevation)
                                          │
              ┌───────────────────────────┼───────────────────────────┐
              ▼                           ▼                           ▼
     visuals() → PieceVisual      arrows() → BattleArrow       detectClashes()
     .groundHeight                .ground: List<GroundPoint>   ClashEffect/EncounterRing
     棋子基座贴地                  箭身节点逐点贴地              .groundHeight 落点贴地
                                          │
                                          ▼
                            sectorSurface() → ReplayFrontSector.sampleSurface()
                            势力 / 战线多边形顶点逐点贴地
```

- 回放域只持有 `io.legado.app.ui.map.sandbox.TerrainElevation` 接口引用与 `DemTerrainElevation.degraded` 公开属性；不持有栅格、不接触 `Bitmap` / 资产路径。
- 注入实例与沙盘同源：`DemTerrainLoader` 是 sandbox 侧既有 Android 薄适配，回放壳层只调用其 `load(context)`，不存在第二套解码口径。
- 降级可见：`ReplayDirector.terrainDegraded`（Flat 或 `DemTerrainElevation.degraded`）为 true 时，壳层右上角显示 token 色小字「平面地形」；时钟推进 / 事件派发 / 交战检测不受影响。

## 四、世界单位换算依据

- DEM 核心口径（`DemTerrainElevation`，U10 已定）：灰度 0..255 → 米制 `gray/255 × 7000m` → 世界单位 `meters × 0.009`（7000m ↔ 63 单位）。
- **回放不设第二套夸张系数**：`ReplayGround.heightAt` 只做有限值 / 负值兜底，高度值原样透传；单测 `高程沿用沙盘 0_009 换算回放不二次缩放` 断言 255 灰度 → 63.0 单位，与沙盘 `VERTICAL_EXAGGERATION` 乘积一致。
- 回放自身世界尺度现状：壳层仍是 2D Compose Canvas，尚无经纬度 → 世界平面投影；回放既有竖向常数（`RING_LIFT_UNITS=3.0`、`TOP_LIGHT_UNITS=8.0`）与沙盘光柱（12 / 6 单位）、雾气（260 单位）同处一套世界单位语义空间，故高程 1:1 对接即可。
- 遗留前提：后续 3D 渲染 pass 若为回放引入独立投影 / 缩放尺度，需在该 pass 复核高程换算，避免与沙盘 0.009 口径脱节（见第七节交接）。

## 八、跨模块问题与交接

### 1. 同一解码实例 / 单份栅格内存（建议 sandbox 侧收口，需总控批准）

- 现状：`DemTerrainLoader.load(context)` 每次调用都重新解码 PNG；沙盘屏与回放屏若先后挂载，会各持一份栅格内存。回放域遵守红线未在 sandbox 侧改代码。
- 建议（sandbox 公开接口 / 实现层调整，交总控排期）：在 `DemTerrainLoader` 内加 `@Volatile` 缓存实例（首次解码后复用，失败 Flat 同样缓存），或抽一个中立地形持有物；沙盘与回放注入同一缓存实例，彻底避免两份栅格 / 两套采样口径。
- 回放侧已留好对接位：`ReplayScreenHost` 优先采用外部注入的 `elevation`，共享持有物就位后直接传入即可，回放域无需再改解码逻辑。

### 3. 回放投影尺度复核点

- 回放当前无独立世界投影；高程按沙盘 0.009 口径 1:1 透传。后续 3D pass 若引入回放专属投影 / 垂直缩放，需在该处复核高程换算，并与沙盘 / globe / crossing 的 7000m 口径对齐（globe 用 `meters/7000 × 2.0` 球面位移，与沙盘 0.009 不可互换，见 U10 报告第七节）。
