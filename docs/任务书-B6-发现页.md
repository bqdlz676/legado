## 八、二阶三阶影响（改坏推演）

- 二阶：发现页分区编排若直接复用旧 `InkExploreGrid` 的私有尺寸常量（262dp / 112dp），会与卡片族规格 0.85×96dp / 0.28×160dp 双口径并存，后续 token 收口时典籍 / 战役两卡尺寸再漂移一次；处置：分区只给修饰符与间距，尺寸归属卡片自身。
- 二阶：战役进度字段若在页面层造本地计数，会与将来战役回放进度落库形成第二份进度状态，回显不一致；处置：进度只从回放进度源读取，缺源显示 0/0，不自存进度。
- 三阶：专题分组目录未落地前，若先按 `allusion.txt` 词首字或朝代临时分组，将来正式 catalog 落地时分组口径要整体回炉；处置：无 catalog 时整区空态，不做临时分组猜测。
- 三阶：旧 Adapter 的 LruCache 若随 Adapter 一起删，书源发现项置顶 / 登录态缓存断裂，影响书源域功能；处置：缓存先迁 `help/source/`，书源域回归通过后再删旧。
- 跨模块：发现页点击回调（进战役回放 / 典籍阅读 / 典故列表 / 生字本）的目标页多数在后续批次；本单回调参数类型先与目标批次契约对齐，避免回调签名二次返工。
- 长期维护：discover 包内若再建私有 token / 私有模型别名，B1 收口时会成为第二个 explore 半成品；处置：模型映射只做转换，色值尺寸全部引令牌包。

### 9.2 九种边界迂回（逐条有方案，不许空白态）

- B1 空分区：某一类卡片数据源返回空列表（无战役 / 无典籍 / 无专题 / 无马恩条目）。迂回：该分区整区渲染 `EmptyStateCard` 对应 `EmptyKind`，分区标题保留或隐藏按实现单定；整页四类全空时落页级空态（金点 + 引导文案 + 去书架看看按钮），不留纯白屏。
- B2 坏条目：单条数据字段缺失 / 类型坏值 / 解析抛异常。迂回：映射层逐条 `runCatching` 过滤坏条目并计数上报；坏条目不拖垮整区；标题 / 朝代 / 字数任一为空，对应竖排列不渲染，不补占位框。
- B3 断网：在线书源 / 网络资料不可达。迂回：先取本地缓存（已下载典籍、本地缓存的战役 / 专题元数据）；缓存为空走 Offline 态 `EmptyKind.Offline` + 提示文案；在线重试由宿主数据层调度，页面不裸抛网络异常。
- B4 大目录卡顿：典故 30140 行、典籍长列表滚动。迂回：专题分组只渲染当前分组条目；列表走懒加载，首屏只算可视区卡片；分组计数在后台协程算，不卡主线程；超长文案单行截断。
- B5 测量 / 布局缓存失效：字体回退、字号令牌变更或重组后卡片尺寸重算。迂回：卡片宽高随 `LocalConfiguration` 重组重算（典籍卡宽屏宽×0.28 同理）；不跨配置硬存像素尺寸；布局失败回退基座默认尺寸。
- B6 旋转 / 配置变更重建：横竖屏切换、分屏、字体大小调整。迂回：槽位选中态经 `rememberSaveable` 存活；分区滚动位置由列表状态持有；卡片尺寸随新配置重算；重建期间不闪旧 mock 帧。
- B7 reduce-motion：系统关闭动效。迂回：stagger 逐行浮入、前倾 3°、snap 吸附弹簧时长按 `reduceMotion` 令牌归零或减到最小；转场只留淡入淡出；不依赖动效传递信息。
- B8 低端机：毛玻璃模糊 / 颗粒 / 倾斜渲染开销高。迂回：模糊与颗粒按设备档位降级（参考组件既有降级判断）；parallax 前倾在低端机回正；首屏分区数封顶，懒加载续出；不掉帧不砍卡片信息层级。
- B9 暗色：仓内卡片 / 组件令牌当前为浅色单源，暗色映射未落地。迂回：本单不内联暗色专属色值；暗色缺口登记待裁（见 §十一 N5）；兜底为现有令牌下可读对比，不出现黑底黑字；暗色主题随组件令牌批次统一落地。
