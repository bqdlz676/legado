# 规格候选-T6-A · 章节氛围剪影（分层轮廓位图 + 双视差粒子）

> 流水线：F-73 三段流水线第①段设计候选。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；既有 `InkMoodView` 关键词四分类与硬编码色仅作参考、不复用（B7）。
> 硬指标归属（用户口径，非切片引文）：T6=A 档两项之二——章节氛围剪影/粒子：阅读页进入某章节时呈现该章氛围层；点名两例：城濮战场轮廓、郑伯克段母子对峙轮廓。
> 规格锚点（逐字）：`切片-09:7`「章节氛围层：读《城濮之战》→ 远处极淡水墨战场轮廓粒子，不是图是粒子勾勒」；`切片-03:101`「水墨轮廓粒子（《城濮》→ 战场剪影）」；`切片-03:322` 行：「水墨氛围粒子」上限 40、不高于 #000 8%、60fps「否则降级到静态」；`切片-03:330` 滚动 3 秒「秒后自动暂停」。

## 1. 作用域与触发条件

- **屏幕**：阅读页竖排正文层之下、宣纸底之上；不进入正文 0.82 列宽区（`切片-09:7` 列宽口径）。
- **时机**：切章回调到达后 → 旧层 200ms 淡出、新层 250ms 淡入；翻页不重置氛围层；离开阅读页释放位图。
- **生命周期**：章节挂载 → 前后章位图预载（对齐 `切片-08`「预载前后各一章的排版缓存」，章节切换 0 白屏）；切章后旧章位图降级为仅留当前章 + 邻章。

## 2. 视觉描述（形态 / 层次 / 动效曲线 / 时长）

- 三层横向轮廓压在页面上下留白：远景山脊（石青淡墨）、中景叙事轮廓（墨色剪影）、近景一缕暖金尘烟；粒子沿轮廓边缘缓慢游走。
- 双视差：前景轮廓随翻页位移系数 0.06，远景 0.03，制造绢帛上前后两层纸的纵深感。
- 点名两例：**城濮**——旷野山脊 + 车阵 / 战旗中景轮廓 + 两侧狼烟；**克段**——高台之上母子双人对位轮廓，二人相隔一线、中间大面积留白。
- 动效：淡入 250ms `cubic-bezier(0.34,1.56,0.64,1)`（`切片-15` 气泡弹入曲线），退场 200ms `cubic-bezier(0.4,0,0.6,1)`；粒子呼吸明暗，不做快速飞窜。

## 3. 逐部件参数

| 部件 | 尺寸 / 归一化位置 | 透明度 | 色值（回挂 token） |
|---|---|---|---|
| 远景山脊 | 高度 ≤ 屏高 18%；贴页面上 / 下留白带 | 0.22 | `CardTokens.stoneBlue`（`0xFF3A6B66`） |
| 中景叙事轮廓 | 高度 ≤ 屏高 12%；城濮 = 车阵战旗，克段 = 双人对位 | 0.30 | `CardTokens.ink`（`0xFF1A1410`） |
| 暖金尘烟 / 狼烟 | 高度 ≤ 屏高 6%；沿轮廓边缘竖向游走 | 0.18 | `CardTokens.warmGold`（`0xFFD4A54A`） |
| 雾带 | 横亘轮廓与正文之间，高 4dp | 0.12 | `CardTokens.cloudGray`（`0xFF9B9687`） |
| 纸面噪点 | 复用 `paper_noise_tile.png` 64×64，进程级缓存既有链路 | `CardTokens.noiseAlpha` 0.03f，种子 `noiseSeed` | `CardTokens.ink` 撒点 |
| 正文保护区 | 中央列宽 0.82 区域内氛围像素 ≤1% | — | 不叠色 |

- 粒子：总数 ≤40（`切片-03:322` 上限），单粒半径 1.4–3.8dp，固定种子布局，跨帧不闪烁。

## 4. 与太阳 / 章节数据的绑定方式

- **数据源**：章节标识 `TextChapter.title`（现状查证 #7）→ 内置章节轮廓映射表（先落 `chengpu` / `duan` 两例 key，其余按关键词回退）。
- **匹配规则**：标题含城濮 / 战 / 军 / 伐 / 兵 → 战场层；含克段 / 鄢 / 母 / 隧 / 姜氏 → 对峙层；均不中 → 通用远山层。
- **缺数据兜底**：无映射资产 → 通用远山位图；标题为空 → 不挂氛围层，但纸底 + 噪点 + 左上暖光保留，不留空白态；同名章消歧失败 → 按书名 + 标题双键查表，仍失败走通用层。

## 5. 性能预算（明确上限）

- 每帧 draw：三层位图 ≤3 次 + 粒子 ≤40 个圆点 draw；不每帧解码位图。
- 内存：单张分层位图 ≤256×128，≤128KB/章；同时驻留 ≤2 章（当前 + 邻章）；位图缓存随页面离开释放。
- 粒子数组定长 40，复用对象，零每帧分配；Path / 位图在切章时一次性硬化缓存（对齐 `切片-08`「笔画完成时一次性硬化成」Path 缓存口径）。
- 帧预算：氛围层单帧 ≤2ms；阅读页保持 60fps（`切片-03:322`）。

## 6. 降级与兜底（四种边界，不允许空白态）

- **无网络**：分层位图随包 / 离线缓存，不依赖在线插图；断网不影响氛围层。
- **无章节数据**：标题缺失或映射失败 → 通用远山层；仍不可用 → 仅纸底 + 噪点 + 暖光，正文排版不受影响。
- **低端机**（线程数 <4 或 Android ≤8）：粒子减半至 20，关闭双视差，只留中景位图；雾带关闭。
- **帧率掉线**：连续 3 帧 <50fps → 粒子停摆、位图冻结静态（对齐 `切片-03:322`「否则降级到静态」）；用户 idle 3 秒无滚动 → 粒子动画暂停，滚动恢复（`切片-03:330`）。

## 7. 可测断言（机械核验）

- C-1 切到「城濮之战」章节后 12 帧内，氛围层可见像素占比 ≥3% 且 ≤12%，且不侵入正文 0.82 列宽区。
- C-2 中景轮廓与目标分层位图 mask 的 IoU ≥0.75。
- C-3 克段章双人轮廓中心水平间距 ∈ 屏宽 30%–50%，中间留白带无墨色填充。
- C-4 淡入 250ms 内中景 alpha 0 → 0.30；退场 200ms 内归零。
- C-5 idle 3 秒后粒子帧推进停止；触摸滚动后 1s 内恢复。

## 9. 可测判据（P1…P10，含 FAIL 条件）

- P1 轮廓命中：城濮章中景为车阵 / 战旗 mask，IoU ≥0.75；FAIL = 落到通用远山或轮廓错位。
- P2 对峙间距：克段章双人中心距 30%–50% 屏宽；FAIL = 二人重叠或间距 >55%。
- P3 正文保护区：0.82 列宽内氛围像素 ≤1%；FAIL = 轮廓压到正文。
- P4 像素占比：层可见像素 3%–12%；FAIL = 占比 <3%（看不见）或 >12%（抢正文）。
- P5 粒子上限：≤40 粒；FAIL = 超 40 或每帧新建粒子对象。
- P6 内存驻留：位图 ≤2 张、单张 ≤128KB；FAIL = 驻留 3 张或解码缓存泄漏。
- P7 切章编排：旧层 200ms 淡出、新层 250ms 淡入；FAIL = 硬切或叠影超时。
- P8 idle 暂停：3 秒无滚动粒子停摆；FAIL = 静置仍持续重绘白烧 GPU。
- P9 掉线降级：连续 3 帧 <50fps 冻结静态；FAIL = 掉线后仍逐帧跑粒子。
- P10 token 合规：无色板外 HEX；FAIL = 出现未声明 lerp 的新十六进制。

## 10. 自我论证：为什么它最符合全 App

- 位图分层让城濮车阵、克段对峙这类具名叙事轮廓可被机械核验（mask IoU、双人间距），直接满足剪影进验收的硬指标；视差与雾带把层次做在留白区，不干扰竖排正文。
- 资产走预载 + 定长粒子，帧预算与内存上限明确，契合阅读页 60fps 与 A8 内存三档口径。

## 11. 它最可能被否掉的地方（自证反例）

- 反例一：每章一张分层位图的制作成本高，首批只能覆盖两例 + 通用层；长尾章节全部落通用远山，辨识度落差需验收代理评估是否可接受。
- 反例二：位图 mask IoU 对裁剪 / 缩放敏感，不同屏宽下轮廓可能被裁；需补多分辨率用例。
- 反例三：双视差在翻页动画期间可能与掀角 400ms 动效争抢位移预算；若翻页卡顿，视差系数需进一步下调。
