## 二、改法依据

### BundlePayloadContractTest

- 原测试意图分两层：① 迁移过的 RecyclerView payload 必须直接用平台 `android.os.Bundle`，不得回退 `androidx.core.os.bundleOf`；② 清单内关键文件真实存在且可读。
- 旧书架双路适配器随单路改造拆除后，书架侧已没有 RecyclerView adapter，不存在可纳入 payload 契约的书架条目；但任务要求把书架单路新实现的关键入口文件补进契约，而非单纯删条目。
- 因此保持原 payload 测试（11 个存活条目 + 平台 Bundle 断言）不动，另立一个入口文件测试：
  - 正向：5 个新单路 / 画板自绘关键文件必须存在且 `readText()` 可读；
  - 平台口径收口：同样禁止 `androidx.core.os.bundleOf` 导入与 `bundleOf(` 调用；
  - Compose 画面层本身不携带 arguments payload，故不强制出现 `Bundle(`，避免把画面层误塞进 adapter payload 契约。
- 新增 5 个入口文件（相对 `sourceRoot()`，与原清单同口径）：
  - `io/legado/app/ui/main/bookshelf/BookshelfScreen.kt`
  - `io/legado/app/ui/main/bookshelf/InkShelfFragment.kt`
  - `io/legado/app/ui/components/inkslate/InkSlateCanvas.kt`
  - `io/legado/app/ui/components/inkslate/InkSlateBitmap.kt`
  - `io/legado/app/ui/main/PaintActivity.kt`
