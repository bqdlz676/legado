## 三 判据 1 · 连续缩放静态证据

### 3.1 覆盖口径

- 缩放档（14 档）：`9.00 / 10.00 / 10.18 / 10.36 / 10.55 / 10.73 / 10.91 / 11.09 / 11.27 / 11.45 / 11.64 / 11.82 / 12.00 / 12.50`。
  区间 10.00R→12.00R 全覆盖，两端外侧各一档（9.00、12.50）用于钳平平台段对照。
- 缩放 → blend 公式逐字对照生产 `GlobeController.blendFromZoom`（`GlobeController.kt:93-98`）：
  ≤10R 为 blend=0；10R→12R 线性升到 1；12R 以上钳在 blend=1。测试侧只复刻同一条公式，不另写档位表。
- 既有契约层 JVM 测试 `SkyZoomContinuityTest.kt:44-85` 已锁：magLimit 随 blend 单调 6.5→11.5、
  端点精确与无跳变断言；本单像素差分是在该数值证据之外补的帧级静态证据。

### 3.2 差分方法

- 脚本：`screenshot/src/test/python/zoom_frame_diff.py`；亮度按 Rec.601 加权逐像素取绝对差，
  输出均值 / p50 / p95 / p99 与变化像素占比（>2 灰度级计为真变化，压掉编码底噪）。
- 尖峰判定：相邻对差异均值 > 3 × 全部相邻对差异均值中位数，记为疑似档位突变尖峰。
- 命令（CI 帧下拉到本地后）：

```
python3 screenshot/src/test/python/zoom_frame_diff.py \
  screenshot/build/outputs/zoom-sequence/frames screenshot/build/outputs/zoom-sequence
```

### 3.4 本项证据边界（反例自检）

- **环境限制（未做到的部分）**：screenshot 测试环境未挂载 `:app` assets，星表门面回落到占位目录
  （帧面「星表未载，当前为示意星空」横幅可见），占位散点与 blend / magLimit 无关，因此本批
  相邻帧差分值接近零底噪。本批差分只能证明「环境内未出现可见档边尖峰」，**不能**证明
  「星点密度随缩放连续增减」——那条通路在本环境不可见。
- 连续裁剪的生产路径：`SkyCanvasRenderer.kt:131` `if (mag > magLimit) continue`，逐星连续裁剪，
  无整层突现；该路径的真机观感仍须录屏复核。
- **真机还差什么**：差真机 GPU 上的星点密度渐变观感与捏合触控采样。
- **设备到手 3 步复测**：
  1. 真机录屏捏合 9R→13R 全程，逐帧回放核对星点只平滑增减、无整层淡入 / 突增；
  2. 同一轨迹在 10R、11R、12R 暂停截帧，与本单 14 档序列帧对位比较密度曲线；
  3. 录屏帧间差分校验：区间内无尖峰超过相邻中位数 3 倍（同本单脚本口径）。

## 四 判据 5 · 断网清缓存四态兜底

### 4.1 四态覆盖与断言（`PyramidOfflineFallbackTest.kt`）

| 态 | 构造方式 | 期望返回 | 兜底断言 | 改坏会红推演 |
| --- | --- | --- | --- | --- |
| 1 缓存目录不存在 | 传入未创建目录路径 | `Missing` | 内置 8920 颗可查、非占位、金字塔增量 0 | 缺目录若抛 NPE 用例直接炸；误判 `Loaded` 则 `assertEquals(Missing)` 变红；兜底清掉 L0 则守恒断言变红 |
| 2 gz 片缺失但内置层在 | 空缓存目录 | `Missing` | 同上，首颗锚点可反查、赤经 / 星等在界内 | 空目录若直接拼路径读片抛 IO；缺片误判 `Corrupt` / `Loaded` 则断言变红 |
| 3a gz 片截断损坏 | 合法 gz 截到六成字节，旁证按截断字节算 | `Corrupt` | 内置层不动，`pyramidSize=0` | 解压异常未收敛会向上抛；截断片若被合并，返回值非 `Corrupt` 且 `pyramidSize` 非 0，两行断言变红 |
| 3b 旁证校验和不符 | 合法 gz + 错误 sha256 旁证 | `Corrupt` | 同上 | 合并前若不校验旁证，坏片进入解析，返回值非 `Corrupt` 变红 |
| 4 缓存目录不可写 | 目录去写权限 + 坏片 | `Corrupt` 或 `Missing` | 不抛异常，内置层仍 8920 颗 | 隔离改名若未包异常，不可写目录抛 Security / IO 异常；返回 `Loaded` 变红 |
| 附 空缓存句柄 | `cacheDir=null` | `Missing` | 内置层不动 | 未判空直接拼路径抛 NPE；误判 `Loaded` 变红 |

## 九 反例边界（差分阈值怎么选）

- **放过跳变的风险**：若阈值过松（如 5× 中位数），档边整段差值被均摊后可能漏判；本单取
  3× 中位数（任务书给定口径），且同时看 p99 与变化占比，避免单靠均值被大面积微差稀释。
- **误报压缩噪声的风险**：PNG 编码底噪在平滑夜空大面积出现 1–2 灰度级微动，故变化像素阈值
  取 >2 灰度级；均值口径对大面积微差敏感，p99 口径抓局部尖峰，两者并列。
- **占位态退化边界**：本批帧在占位星表下差分趋近底噪，此时「无尖峰」不构成「连续」的强证据；
  强证据待带表环境 / 真机。反例找不到不等于没有：本单已在 §3.4 写明未闭环部分。
- **时钟边界**：layoutlib 计时受 CI 调度与 GC 影响，单轮 max 可能毛刺；故 15 断言用 P99，
  14 报告中位数 + P95 而非裸 max。
