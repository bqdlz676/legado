## 落文 Windows 端 · 3D 沙盘旗舰画质
桌面独显不压着用。
---
### 一、地形精度
| 参数 | 手机版 | Windows 旗舰版 |
|---|---|---|
| 网格段数 | 128×128 | **1024×1024**（1,050,625 顶点） |
| 高度图 | 512×512 灰度 PNG | **2048×2048 16bit PNG**（SRTM 30m 原始精度不压缩） |
| 地域覆盖 | 单区域 120km | **同屏 500km** 范围，全国一张大图 |
| 顶点色 | 3 阶分带（青灰/赭石/米褐） | **连续渐变**——高程 1m 一个颜色过渡，山脚到山顶丝滑变色 |
---
### 二、材质系统（从 Google Earth 学）
不只是顶点色。6 层材质叠加：
| 层 | 来源 | 效果 |
|---|---|---|
| 1. 卫星底图 | Mapbox/OpenStreetMap 2560×2560 纹理 | 耕田是黄色、森林是深绿、城市是灰色 |
| 2. 法线贴图 | 从高度图自动生成 normal map | 山脊的每一个褶皱都有光照细节 |
| 3. 粗糙度贴图 | 坡度→粗糙度映射（陡 = 粗糙、缓 = 光滑） | 岩石面哑光、平原微反光 |
| 4. 雪线 | 海拔 > 3500m → 自动叠加白色 + 微反光 | 贡嘎山/四姑娘山终年积雪 |
| 5. 河流 | 管状水体 → **平面反射水体**（`THREE.Water` shader） | 河面反射天空和山影，不是金色是真实水 |
| 6. 云影 | 一个半透明云层 Plane 浮在 200 单位高空，慢移 | 云投下的影子在地形上滑过 |
---
### 三、光照（PBR）
| 光源 | 手机版 | Windows 旗舰版 |
|---|---|---|
| 太阳光 | `DirectionalLight` 单光源 | **`DirectionalLight` + 环境贴图**（HDR 天空球） |
| 阴影 | 无 | **Shadow Map 2048×2048**，山脊在对面山坡投下阴影 |
| 环境光遮蔽 | 无 | **SSAO**（屏幕空间环境光遮蔽），峡谷/裂缝自动变暗 |
| 大气散射 | `scene.fog` 混合雾 | **Rayleigh + Mie 散射 shader**——远山偏蓝、近景偏暖 |
| 辉光 | 无 | **Bloom 后处理**——都城光柱和渡口发光有真正的 bloom 溢出 |
---
### 四、古城池 3D 模型
手机上是光柱 + 标签。旗舰版用真实 3D 模型：
| 级别 | 模型 | 细节 |
|---|---|---|
| 都城 | 简模城墙（方形围合 + 四面城门 + 角楼） | 墙高 6 单位，暖金瓦顶，城内有极淡暖光透出 |
| 郡邑 | 简模寨墙（方形低围 + 两面门） | 墙高 3 单位，铜色木顶 |
| 关隘 | 两座敌楼夹峡谷，中间一道关门 | 墨灰石质，门前插一杆旗 |
所有城池用 **InstancedMesh**——30 座城 = 1 次 draw call。LOD 三级：近距离 3D 模型、中距离简模、远距离光柱。
---
### 五、军队棋子升级
| 手机版 | Windows 旗舰版 |
|---|---|
| 三角棱锥（4 面） | **二十面体 + 细分**（72 面），常规部队圆润、精锐部队尖锐 |
| 纯色自发光 | **金属 PBR 材质**（暖金 = 金材质 + 粗糙度 0.25，敌灰青 = 铁材质 + 粗糙度 0.5） |
| 棋子静态 | **微动效**——棋子在地表上方 1 单位处极缓慢上下浮动（±0.3 单位，正弦周期 3s），站立状态不是死的 |
| 无阴影 | **每颗棋子在下面地形上投真实阴影**（深度图采样） |
---
### 六、粒子系统
| 手机版 | Windows 旗舰版 |
|---|---|
| 140 粒（墨+金） | **2000 粒**，GPU 计算，不占 CPU |
| 粒子形态：圆点 | 圆点 + 细长飞白丝 + 小三角碎屑三种形态混合 |
| 金粉简单淡出 | **金粉在空中旋转 + 受风飘移**（sin 噪声位移） |
| 渡口闪光三下 | **渡口上方有持续的金色光柱粒子上升**（每柱 40 粒，柱高 15 单位） |
---
### 七、后处理（Post-Processing）
| 效果 | 参数 |
|---|---|
| **Bloom**（辉光） | 阈值 0.7，都城光柱、渡口、金粉自动泛光溢出 |
| **SSAO**（环境光遮蔽） | 峡谷、城墙根、棋子底部自动变暗 |
| **DOF**（景深） | 镜头推近时背景自然虚化（剧场模式交战聚焦用） |
| **Vignette** | 全屏暗角，剧场模式加深 |
| **Color Grading** | LUT 查找表，绢帛军图色调全天候统一 |
---
### 八、帧率与显存
| 参数 | 值 |
|---|---|
| 目标帧率 | **120fps**（高刷屏） / 60fps（普通屏） |
| 显存占用 | ≤ 1.5GB（1024×1024 网格 + 6 层 2048 纹理 + shadow map） |
| 最低显卡 | GTX 1050 Ti 4GB（中画质 60fps） |
| 推荐显卡 | RTX 2060 6GB（旗舰画质 120fps） |

### 九、画质档位
| 档位 | 网格 | 纹理 | 阴影 | 后处理 | 目标 |
|---|---|---|---|---|---|
| 低 | 256×256 | 单层顶点色 | 关 | 关 | 集显笔记本 60fps |
| 中 | 512×512 | 卫星底图 + 法线 | 1024 shadow | Bloom | GTX 1050 Ti |
| 高 | 1024×1024 | 6 层全开 | 2048 shadow | 全开 | RTX 2060 |
| 旗舰 | 1024×1024 | 6 层 + 水面反射 | 2048 shadow | 全开 + DOF | RTX 3060+ |
