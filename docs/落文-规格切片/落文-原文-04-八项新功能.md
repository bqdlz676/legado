## 1. 生字本
### 数据模型
```sql
CREATE TABLE vocab_log (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    char      TEXT NOT NULL,         -- 单字或词
    type      TEXT DEFAULT 'char',   -- 'char' | 'word' | 'allusion'
    book_id   TEXT,
    chapter   TEXT,
    context   TEXT,                  -- 原文句子（含该字）
    clicked_at INTEGER,              -- 首次点击时间戳
    review_count INTEGER DEFAULT 0,
    last_reviewed INTEGER,
    mastered  INTEGER DEFAULT 0     -- 0=需复习 1=已掌握
);
```
### 写入逻辑
气泡弹开 → 同时 `INSERT OR IGNORE` 写入 `vocab_log`。同一个字在同一本书同一章里不重复计。同一个字在不同书/不同章里各算一条（出处不同，语境不同）。
### 复习提醒
- WorkManager `PeriodicWorkRequest`，每 6 小时轮询一次
- 查询 `last_reviewed < now - 7天 AND mastered = 0 AND review_count < 5` → 如果有 ≥ 3 条 → 推通知"《左传·隐公元年》里有 3 个字需要复习"
- 点击通知 → 直接进复习列表
### UI
发现页多一个入口卡片：「生字本 · N 字待复习」。点进去 → 竖排字列表。每行：字（墨色 18sp）+ 拼音（石青 10sp）+ 原文出处句子（云灰 12sp，该字用朱砂高亮）。点一行 → 半屏 Sheet 显示完整字义 + 说文 + 用例。底部两个按钮：「已掌握」（加 mastered=1）、「再看一次」。
### 复习列表排序
按遗忘曲线加权 = `距今天数 × (5 - review_count)`，越久没复习排越前。复习一次 `review_count++`，5 次后自动 `mastered=1`。

## 2. 古籍对照阅读
### 数据模型
```json
// assets/parallel_texts.json
{
  "左传": {
    "隐公元年": {
      "mappings": [
        {
          "src_range": [0, 450],         // 原文段落字符偏移
          "targets": [
            {
              "book": "史记",
              "chapter": "郑世家",
              "section": "叔段之乱",
              "text": "武公十年，娶申侯女为夫人，曰武姜。生太子寤生……",
              "diff_flags": [             // 异文位置
                { "pos": 0, "note": "《左传》作'庄公寤生，惊姜氏'" }
              ]
            }
          ]
        }
      ]
    }
  }
}
```
### 生成方式
- ctext.org 已有《左传》《史记》等书的数字化全文 + 段落对齐
- 写一个 Python 脚本：对同一历史事件，用时间关键词（"元年""克段""伐郑"）自动对齐段落 → 人工校准 5%
- 异文检测：两段文本 diff（最长公共子序列），不一致的句子标记 `diff_flags`
### UI
阅读页右上角一个双书叠图标：
- 灰色 = 当前章没有对照数据
- 亮暖金 = 有对照数据，可点
点一下 → 阅读页从单列裂成左右双列竖排。左列是原书（墨色正文），右列是对照书（石青色正文）。两列独立滚动——左列翻左、右列翻右，各翻各的。
异文处：右列那片文字用朱砂 `#C23B2E` 底色 8% 透明度高亮。手指长按高亮处 → 浮出小字气泡："《左传》此处作'庄公寤生，惊姜氏，故名曰寤生，遂恶之'"
顶部加一个对照书选择器（横向滚动条），显示当前章所有可对照的书名——点《史记》《国语》《春秋公羊传》《谷梁传》随时切右列内容。

## 3. 人物足迹地图
### 数据模型
```sql
CREATE TABLE person_route (
    id         INTEGER PRIMARY KEY,
    person_id  TEXT REFERENCES person(id),
    place_name TEXT,
    place_id   TEXT,              -- 关联 place 实体表
    lat        REAL,
    lng        REAL,
    year       INTEGER,           -- 公元年，负数=公元前
    event      TEXT,              -- "出生","任左徒","流放汉北","自沉汨罗"
    source     TEXT                -- 出处
);
```
### 生成方式
- CBDB `person.txt` 已有官职任免记录 → 自动抽职位对应的治所位置 → 写入 person_route
- 《中国历史人名大辞典》→ 生平行迹文本 → NER 抽地名 + 正则抽年份 → 批量灌
- 24 史列传文本 → NER 抽地名 + 关联时间 → 自动生成
人工智能标 80%，人工瞄一眼校准重要人物的 20%。
### UI
人物 Sheet 第四栏「档案」下方加一行「一生行迹」（有数据时亮暖金，无数据时灰色）。
点 → 全屏地图。地图上是该人物的金色行迹线——从出生地连到卒地，中间每个重要地点一个暖金圆点。圆点旁边竖排小字：年份 + 事件（如"前340 · 任左徒"）。底部一条横向时间轴，左端出生年、右端卒年，手指在轴上滑动 → 金线上高亮对应年份段，该段的行迹变朱砂色。
右上角一个「全部地名」按钮 → 点一下列出该人物所有到过的地方，竖排列表，点一个飞到该位置。
首批覆盖：200 人 L1 核心库（《左传》《史记》《三国志》《通鉴》高频人物）全做。

## 4. 古籍朋友圈（谱系长卷）
### 数据模型
```sql
CREATE TABLE person_relation (
    from_person_id TEXT REFERENCES person(id),
    to_person_id   TEXT REFERENCES person(id),
    relation_type  TEXT,           -- teacher_of / student_of / father_of / son_of / colleague / friend / enemy / killed_by
    source         TEXT,
    PRIMARY KEY (from_person_id, to_person_id, relation_type)
);
```
### 生成方式
- CBDB 社会关系表（已有，8.9 万条里含亲属/师徒/仕宦/社交）
- 《左传》PersonRelation——从 `RelationExtractor` 的段内共现数据 + 同章出场关系 → 自动灌 kinship/colleague/enemy
- 24 史列传——"XX，XX之子也""师从XX""XX举XX"这类模式 → 正则自动抽
### UI
人物 Sheet 底部加「关系网络」入口。
点 → 全屏横向长卷（`HorizontalScrollView` 内嵌自绘 Canvas）。中心是当前人物（大节点——暖金圆环包围、圆环呼吸光芒）。从中心往外三层：
- **第一层**（紧邻）：直系亲属（父子/兄弟）+ 直接师承（师傅/弟子）。铜色连线 + 铜色小圆点
- **第二层**：同僚/交游/举荐。暖金色连线
- **第三层**（最外层）：敌对/杀害/政治对手。朱砂色虚线连线
每个节点上竖排标注：姓名 + 关系标签（10sp 石青色）。点任意节点 → 镜头平移到该节点成为新的中心，整张长卷重新以它为中心布局。
右上角固定一个方向罗盘（缩小版全景缩略图），手指在罗盘上拖动可以快速跳转长卷位置。
长卷不画力导向图。用固定环形分层布局——中心人物固定在画面中央，一层节点均匀分布在半径 80dp 的圆环上，二层半径 180dp，三层半径 300dp。手指横划才平移。

## 5. 每天一首诗/一段文
### 数据
```json
// assets/daily_quotes.json
[
  { "day": "01-01", "text": "元亨利贞", "source": "《周易·乾卦》", "author": "" },
  { "day": "01-02", "text": "关关雎鸠，在河之洲", "source": "《诗经·周南》", "author": "" }
]
```
365 条，人工从内置 100 部古籍里摘。不苛求每天对应节气（后面可以），先凑满 365 条。
### 逻辑
WorkManager `PeriodicWorkRequest` 每天早上 8:00 触发：
1. 读今天的 `day` → 查 `daily_quotes` → 取 text
2. 构建竖排通知（`NotificationCompat.Builder` + 自定义 `RemoteViews` 竖排文字布局）
3. 通知栏只显示文字，无来源、无作者、无按钮
4. 点击通知 → `PendingIntent` → 打开落文 → 半屏 Sheet 显示全文 + 出处 + 作者 + 一个「收藏」按钮
### UI
半屏 Sheet 里：顶部竖排诗句（22sp 墨色，居中），下方横排来源（石青色 12sp），再下方一行"收藏"按钮（暖金边框，点一下变实心金）。最底部小字「明日 8:00 再见」。
右上角历史按钮 → 日历视图（竖向滚动），显示过去每一天的句子，点一天出那天的那句。

## 6. 字源演变
### 数据模型
```sql
CREATE TABLE char_etymology (
    char          TEXT PRIMARY KEY,
    oracle        TEXT,         -- 甲骨文 SVG path
    bronze        TEXT,         -- 金文 SVG
    seal          TEXT,         -- 小篆 SVG
    clerical      TEXT,         -- 隶书 SVG
    regular       TEXT          -- 楷书 SVG
);
```
每个字形存为 SVG path 字符串（`<path d="M..." />`），不是图片——一张图片 0。一个字的 5 个字形加起来约 4KB，2 万汉字 = 80MB。只覆盖常用 6000 字（24MB），其余冷僻字按需下载。
### 来源
- **Chinese Etymology（字源网，Richard Sears）**——公版免费。几万汉字从甲骨文到楷书的全部字形，每字形 SVG 或高清 PNG。直接爬他们的开放 API
- **小篆/隶书**——《说文解字》收录的字形，从 ctext 的《说文》数字化版里自动截字形图
- 楷书 → 就是现在用的 Noto Serif SC，不需要单独存
### UI
字详情 Sheet 底部加一栏「字源」。点 → 全屏 Canvas 竖排显示五个字形从上到下：
```
甲  (甲骨文，底部标注"甲骨文·商")
金  (金文，标注"金文·西周")
篆  (小篆，标注"小篆·《说文》")
隶  (隶书，标注"隶书·汉")
楷  (楷书，标注"楷书")
```
进入时自动播放：甲骨文出现 → 停顿 600ms → 金文淡入并变形成一个过渡态 → 停顿 → 小篆淡入 → 隶书 → 楷书。不是硬切，是用 `PathMorph` 做形状过渡（两个 SVG path 之间插值）。每个形变段 400ms。
手指上下滑可以慢看、跳过变形的某个阶段。右下角一个「播放」按钮可以重播。

## 7. 异体字/避讳字标注
### 数据模型
```sql
CREATE TABLE variant_char (
    variant   TEXT NOT NULL,    -- 异体字字形
    standard  TEXT NOT NULL,    -- 标准字形
    reason    TEXT,             -- '避讳·唐太宗李世民' / '异体' / '俗字' / '简化'
    PRIMARY KEY (variant, standard)
);
```
### 生成方式
- Unihan 数据库 → `kTraditionalVariant` + `kSimplifiedVariant` + `kSemanticVariant` 三个字段直接导
- 避讳字表——手写一份 JSON，含历代帝王名讳（李世民→"民"缺笔、"世"缺笔；康熙→"玄"缺笔）、圣人讳（孔子→"丘"缺笔）、家讳（手写不完，只收最常见的）
约 2 万条异体 + 200 条避讳规则。
### 排版层改动
阅读页排版时（分页阶段），逐字扫描正文：
- 查 `variant_char` 表 → 命中 → 在该字右上方标注正字
- 标注格式：石青色 `#3C5C6E`、6sp、半透明 0.6、float 在该字右上方 4dp
标注不是覆盖在原字上，是偏右上的极小字——不影响阅读，像眉批一样的存在感。
### 交互
点异体字 → 气泡多一行："避唐太宗讳"（石青色 10sp）+ 气泡正文仍是正常释义。点气泡 → 半屏 Sheet 正常字详情，底部多一栏「字形说明」：这段话在清代刻本中是 XXX 字形，避 YYY 讳。

## 8. 注释/批注播放
### 数据
需要一份「章句级别」的注释数据。从 ctext.org 直接拖：
- 《左传》杜预注 / 孔颖达疏 → 全公版，ctext 已有段落对齐数据
- 《史记》三家注（裴骃集解/司马贞索隐/张守节正义）→ 全公版
- 《论语》何晏集解/朱熹集注 → 全公版
- 《诗经》毛传/郑笺/孔颖达疏 → 全公版
格式：
```json
// assets/annotations/左传.json
{
  "隐公元年": [
    { "range": [0, 120], "text": "杜预注：惠公，鲁惠公。元妃，嫡夫人也。孟子，惠公之元妃也。" },
    { "range": [120, 280], "text": "杜预注：言寤生而惊姜氏，故名曰寤生，遂恶之。" }
  ]
}
```
### 排版层改动
分页完成后，把每段的字符偏移映射到页号 + 行号。翻页时查「当前屏幕第一行的字符偏移」落在哪条注释的 `range` 里 → 底部注释条显示对应注释。
### UI
阅读页右上角一个「注」图标：
- 灰色 = 当前章没有注释
- 亮石青 = 有注释，点一下开启
开启后 → 底部浮现一条横向注释条（毛玻璃底 40dp 高，纸白半透明 + 金线上边）。条内横排小字："杜预注：惠公，鲁惠公。元妃，嫡夫人也。孟子，惠公之元妃也。"（12sp 墨色）。
手指往下滑正文 → 当前屏幕第一行的字符偏移变了 → 底部注释条淡出 200ms → 查新偏移对应的注释 → 淡入新注释 200ms。
关闭注释 → 点「注」图标再次 → 底部条下滑消失。整页回复正常阅读。
注释来源选择器：长按「注」图标 → 弹出小面板列出所有可用注本（杜预注/孔颖达疏/杨伯峻注 等）。勾选一个或多个——底部注释条自动拼接多本注释，按注本名分隔。
