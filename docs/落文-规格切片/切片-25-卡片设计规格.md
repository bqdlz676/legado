## 通用卡片 Token
| 属性 | 值 |
|---|---|
| 底色 | 纸白 `#F7F1E6` |
| 阴影（默认） | `0 0 12px rgba(212,165,74,0.3)` 暖金微光 |
| 阴影（悬浮） | `0 0 20px rgba(212,165,74,0.45)` 暖金加深 + 卡片轻抬 2dp |
| 阴影（点击） | `0 0 8px rgba(194,59,46,0.3)` 朱砂暗影 |
| 圆角 | 16dp |
| 边框 | 无。卡片靠阴影拉开层次，不靠边线 |
| 材质 | 纸白纯色底 + 2px noise texture 宣纸颗粒，不透明度 0.03 |
| 间距 | 卡片之间 12dp |

## 一、书架页 · 书籍卡片
- 书名竖排 22sp 墨色 Bold；作者竖排 11sp 石青；字数竖排 10sp 云灰；云灰细线 1px 分隔；右侧朱砂进度竖线 2dp（已读朱砂/未读云灰）；右下角落文金点 6dp。
- 宽=屏宽×0.28，高=屏高×0.42；悬浮 `cameraDistance` 前倾 5°，点击加深到 8°；右滑删除＝碎成 8-12 粒碎墨散开 200ms；长按菜单＝置顶/导出批注/删除（竖排三行）。

## 二、发现页 · 战役精选横卡
- 标题横排 16sp 墨色 Bold + 右箭头；云灰细线；副标题 12sp 石青；一句话描述 11sp 云灰；进度条 3/10 阶段已看。
- 宽=屏宽×0.85，高 96dp；**边框暖金 `#D4A54A` 1px**；底色毛玻璃（backdrop-blur 8px + 纸白 80%）；横向 `scroll-snap` 吸附居中；骨架屏＝同尺寸灰块 + 暖金斜光带 1.5s 扫过。

## 三、发现页 · 典籍竖卡
- 书名竖排 16sp 墨色 Bold；朝代竖排 10sp 石青；字数竖排 8sp 云灰；右下金点 4dp；宽=屏宽×0.28，高 160dp；悬浮前倾 3°；栅格 3 列间距 8dp。

## 四、发现页 · 专题横条卡
- 标题竖排 14sp 墨色 Bold + 右箭头；预览 10sp 石青；金点横排表示典故数量（如 28 颗）；满宽（左右各 12dp 边距），高 72dp；毛玻璃 + 纸白 70%；点击进典故列表页。

## 五、发现页 · 马克思/党史卡片
- 竖排标题 18sp 暖金 Bold；副标题 12sp 石青；时间线示意（如 1818 ——— 1883）；边框暖金 1px；底色毛玻璃 + 深墨 15% 透底；党史卡同尺寸，边框换朱砂 `#C23B2E`。

## 六、搜索结果卡
- 书名 14sp 墨色 + 作者·年份 10sp 石青；字数·进度 10sp 云灰；来源标签 8sp 石青；高 56dp；匹配文字朱砂高亮；在线源结果追加在本地之后 + 暖金小标签「在线」。

## 七、名物索引卡片（类别入口）
- 类别名竖排 16sp 墨色 Bold + 右箭头；条目数 12sp 石青；云灰细线；代表条目预览 10sp 云灰横排（如 干将 · 莫邪 · 赤霄 · 湛卢 …）；高 72dp；点击进类别列表。

## 八、名物条目卡片（详情列表行）
- 名称 14sp 墨色 Bold；年代·国别·类别 10sp 石青；一句话描述 11sp 云灰；出处 9sp 石青斜体；高自适应 60-80dp；点击半屏 Sheet 展开完整描述。

## 九、人物关系卡（力导向图节点弹出）
- 本名 14sp 墨色 Bold；国别·封号 10sp 石青；关系 10sp 云灰；相关引文一句 9sp 石青斜体；「进人物详情 →」10sp 暖金；宽=屏宽×0.45；节点双击弹出 200ms 淡入；点卡片外部消失。

## 十、分享卡片（书摘生成图片）
- 选中文段竖排或横排 18sp 墨色（用户可切方向）；出处 10sp 石青横排；右下落文金点 8dp；背景四套可选（纸白/暗色/护眼/宣纸纹理）+ 极淡暖金渐变 opacity 0.05；导出 PNG 到 `/sdcard/Download/落文卡片/`；文件名 `书名_日期.png`。

## 十一、空状态卡（三变体）
- `empty`：金点 32dp 居中 + 「还没有书」竖排 18sp 墨色 + 12sp 云灰引导 + 暖金按钮「去发现页看看」圆角 20。
- `notFound`：金点淡暖金 + 三行随机推荐书名。
- `offline`：极淡朱砂断环 + 「本地已有 xx 本书可离线阅读」。

## 十二、设置行卡片
- 每行 48dp：标题竖排 14sp 墨色 + 当前值 12sp 石青 + 箭头；分组间隔 16dp，**无卡片框**只靠云灰细线分隔；开关行右侧 ToggleButton（暖金 on / 云灰 off）替代箭头。

**卡片总类：12 类。全部走 `CardBase` 基类——阴影 / 圆角 / 悬浮态 / 点击态 / 骨架屏五态覆盖。**

## 验收判据（可度量）
1. 12 类卡片各有 Compose 组件，且**全部继承/复用 `CardBase`**（`grep -c "CardBase"` ≥12，无各自复制阴影代码）；
2. Token 唯一来源：`CardTokens.kt` 里纸白/三档阴影/圆角 16/间距 12/颗粒 0.03 各一处定义，组件内 `grep "0x"` 硬编码色值 ≤2（例外：该卡类原文指定边框色/朱砂进度线/金点）；
3. 边框合规：默认卡 0 边框；战役横卡暖金 1px、马克思暖金 1px、党史朱砂 1px 命中；
4. 尺寸合规：书架卡 0.28×0.42、战役卡 0.85×96dp、典籍卡 0.28×160dp、专题 72dp、搜索卡 56dp、名物索引 72dp、名物条目 60-80dp、关系卡 0.45、设置行 48dp（逐条给行号）；
5. 五态：默认/悬浮/点击/骨架屏/圆角 在 `CardBase` 内各有实现；骨架屏斜光带 1.5s 且无 `delay` 硬切；
6. 三变体空态可触发且文案正确；
7. 分享卡四背景可选 + 导出路径与文件名规则正确（给函数与行号）；
8. 颗粒 noise 走 1 张 ≤64KB 平铺 png（不逐卡生成），滚动时无新 Bitmap 创建（grep 证明）；
9. 设置行卡「音效反馈」行读出 D27 三态当前值（与 `InkSoundPool` 开关同源，非各写一份）。
