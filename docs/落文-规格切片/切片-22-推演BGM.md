## 推演 BGM · 战时配乐

推演剧场模式自动配。不同阶段不同音乐，不循环一首到底。

---

### 阶段配乐

| 推演阶段 | 配乐 | 乐器 | 时长 |
|---|---|---|---|
| 部署（回合 0，双方布阵） | 低沉鼓点 + 极淡的号角长音 | 太鼓 · 古筝单音 | 开场 15s |
| 行军（箭头移动中） | 逐渐加快的弦乐 + 马蹄节奏 | 琵琶轮指 · 二胡急促短弓 | 随回合持续 |
| 交战（遭遇触发） | 骤然炸开的鼓面重击 + 弦乐骤停 0.5s → 急板重新进入 | 大鼓 · 镲 · 琵琶扫弦 | 交战场面 3-5s |
| 战后（一方溃退/胜利） | 胜方：低音鼓渐慢渐弱 + 一声悠远箫音。败方：弦乐骤停 → 寂静 2s → 单音琵琶低沉吟 | 箫 · 琵琶 · 大提琴拨弦 | 收尾 8s |
| 剧场收尾（最后一回合结束，镜头拉远定格） | 鼓声彻底静，只留一声极长的箫音渐弱到无。定格画面出现时音乐全静 | 箫 · 空 | 收束 6s |

---

### 不打断原则

**配乐永远低于音效**。交战的朱砂冲击环炸开时的那一声"砰"——配乐在那个瞬间自动降音量到 30%，音效过后恢复。

**用户自己的音乐优先**。如果用户在落文音乐播放器里已经开着歌（比如青鸾 z4 在放古琴曲），推演不打断它。BGM 只在用户没有听任何音乐时才启动。优先级：用户音乐 > 推演 BGM > 无音乐。

---

### 音源

**内置公版古乐片段**（不需要完整曲目，只需要 5 段配乐片段，总时长 < 60s）：

| 片段 | 用途 | 来源 |
|---|---|---|
| 鼓点低音节 | 部署/行军基底 | 自编 MIDI → 太鼓音色采样合成 |
| 琵琶扫弦急奏 | 交战爆发 | 自编 MIDI → 琵琶采样合成 |
| 箫声悠远 | 战后/收尾 | 自编 MIDI → 箫采样合成 |
| 二胡急促短弓 | 行军加速 | 自编 MIDI → 二胡采样合成 |
| 大提琴拨弦 | 败方收束 | 自编 MIDI → 弦乐采样合成 |

**采样音源（全公版/CC0）**：VSCO Community 管弦乐采样、FreePats 中国民乐采样、MuseScore 公版 MIDI 导出。

**不用完整古人录音**——那有版权问题。自编 MIDI + 公版采样合成，版权全是自己的。

### 实现

跟落文音乐播放器不是一个通道。推演 BGM 用 `SoundPool` 或 `AAudio` 直出，不和 ExoPlayer 的音乐播放混。原因：`SoundPool` 可以同时播多个片段 + 实时调音量（交战爆音时鼓点立刻压低声），ExoPlayer 是单轨不适合实时响应。

```
SimEngine.tick() → turnResult
    ↓
AnimationController.animate(turnResult)
    ↓
BgmController.checkPhase(turnResult)  →  检测阶段变化 → SoundPool 切音轨
    ├── 遭遇触发 → play(CLASH_SFX, priority=HIGH) + 鼓点音量降到 0.3
    ├── 一方溃退 → crossfade(DRUM, 0, 800ms) + play(SOLO_XIAO)
    └── 剧场结束 → stopAll() + play(ENDING_XIAO)
```

---

### 设置

地图页右上角一个喇叭小图标。三种状态：🔊 BGM 开（默认）/ 🔈 BGM 低音量 / 🔇 BGM 关。用户点一下切状态。不是设置页里藏的——是在沙盘页上直接调的。这是新要求。

## 验收判据（可度量，供写包自测）

1. 五阶段各能触发（含回合0/行军/交战/战后胜/战后败/收尾六条路径），阶段切换无"同一首循环到底"；
2. ducking：音效帧 BGM 音量 ≤0.3，音效结束恢复到原设定（0.3 倍时间窗 ≤500ms，恢复 ≤800ms）；
3. 用户音乐在播时不启动 BGM（给判定函数与用例）；用户音乐停止后 BGM 可接管；
4. 五段资产总时长 <60s，且每段来源可溯（文件名/来源表落档，禁无源资产）；
5. 通道隔离：BGM 不进 ExoPlayer 队列（grep 证明无复用 MediaSession/Player）；
6. 三态开关在沙盘页右上角，点一下切，状态持久化（重启保留）；三态都有 contentDescription；
7. 空态兜底：资产缺失/解码失败 → 静默降级为"无 BGM 但有音效"，并在喇叭图标上给弱提示，不崩不白屏。
