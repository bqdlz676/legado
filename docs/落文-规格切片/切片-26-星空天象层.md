## 〇、裁决与口径（规格 §〇 逐字）

用户已拍板（不可改）：

1. 深度 11.5 等推荐档，星表走 Tycho-2。（规格:24）
2. 星官 + 星座两套都要、可切、默认星官。（规格:25）
3. 缩放线性连续、不设档数；既有档数制一并改造。（规格:26）
4. 双视角：天外观 + 地上观，可切换。（规格:27）
5. 精致视觉（美学总纲六要素全适用）。（规格:28）

技术口径（本文件相对旧稿的修正，必须按此实现）：

9. 天球不是世界里的固定球，是**跟随相机的 2D 投影背景**。理由：固定球在相机推到 9R 时会站到球外，看到球壳外表面，模型本身不成立。（规格:38）
10. 连续缩放 = 相机 10R + `skyBlend` 连续标量；**不做连续细分 icosphere**。理由：`LodSelector.kt:13-25` 已有 morph 底座，扩展为连续权重成本低；重造连续细分网格要重写 mesh 生成器，成本高一个量级。（规格:39）
11. 视觉连续 ≠ 几何连续：本规格做到"任意缩放位置有唯一混合比例"，几何仍是三档常驻。这句必须写进验收报告，不许冒充几何连续。（规格:40）

## 三、色值表

### 3.1 UI 叠加层逐条（规格 §六 第 4~11 条，禁写 hex；:181-188）

4. 夜空底 = `textPrimary` 压暗 40% → `GlobeTokens.skyNightBase`，结果由函数算，不写死。理由：墨色偏暖（R26>G20>B16），压暗仍暖墨，天然"暗处偏暖、禁纯黑"。（规格:181）
5. 地平暖辉 = `brandCopper` 0.10 → `skyHorizonGlow`。（规格:182）
6. 星官线 = `brandGold` 0.55；星座线 = `textTertiary` 0.45。理由：星座是辅助参考层，云灰正是"辅助"语义，且不抢金。**不借石青**——石青已登记为"Toast 提示 + 沙盘敌方势力"，第三用途会语义污染。（规格:183）
7. 星官名标签：字 `brandGold`、底 `bgOverlay` 0.45、边 1px `brandCopper`。理由：不用朱砂边框——朱砂语义是失败/删除/强调，常驻星名会误读。（规格:184）
8. 选中星/分野填充 = `colorGlow`；分野边 = `brandGold` 虚线。（规格:185）
9. 网格 = `textTertiary` 0.12；黄道 = `brandGold` 0.30；天赤道 = `stoneBlue` 0.30（"基准线专用"，须在切片-26 声明用途）。（规格:186）
10. 禁用 = `textTertiary` 0.30（`DISABLED_OPACITY`）。（规格:187）
11. Sheet 全走 `bgSurface`/`textPrimary`/`textSecondary`/`textTertiary`/`colorDivider`。（规格:188）

### 3.2 内容色 `SkySpecColor` 四锚（规格 §六 第 12 条，:192）

星色四锚（B-V 连续插值）：早型 `#D8E4F0`（低饱和月白）→ 中间 `#FFFDF6` → 晚型 `#FFEED8` → 极晚 `#FFB37A`。（规格:192）

- 第 13 条：为什么"去蓝化"不是完全去蓝：早型星确实偏蓝，但纯蓝白在暖绢底上会"跳"；降饱和后只作点缀（全天约 5%、集中在最亮几颗），整体仍"暖夜微芒"。（规格:193）
- 第 14 条：无 B-V 的星按星等映射"纸白→暖白"，不猜色温。（规格:194）

### 3.3 银河 / 尘粒 / 流星（规格 §六 第 15 条，:195）

银河：暖白核心 `#FFFDF6` 0.10 + `brandGold` 0.06；冷蓝外围取消，改暖灰 `textTertiary` 0.04。尘粒 `textTertiary` 0.15。流星 `#FFFDF6` 头部。（规格:195）

派生三出口（规格:197）：`skyNightBase`（darken TEXT_PRIMARY 0.40）、`skyHorizonGlow`（BRAND_COPPER 0.10）、`skyStarWarm`（星色暖端，仅供图例/Sheet 小圆点，星点本体走 `SkySpecColor`）。

### 3.4 硬禁（规格 §六 第 16、17 条，:201-202）

16. 禁 `#000000`、禁 `#FFFFFF`、禁 Material 默认色、禁第 14 基础色。（规格:201）
17. 判据：`grep -rn "#[0-9A-Fa-f]{6}" ui/map/globe/` 只允许命中 `SkySpecColor.kt` 与 `GlobeSpecSurface` 既有表；其余命中即 FAIL。（规格:202）

## 九、数据源、许可与 schema（规格 §四，备查）

许可（两条并存，照实登记）：

1. CDS VizieR I/259，`https://cdsarc.cds.unistra.fr/viz-bin/cat/I/259`；2,539,913 行；Høg/Fabricius/Makarov et al.；bibcode 2000A&A...355L..27H；标 CC-BY-NC-3.0 IGO。（规格:118）
2. NASA Open Data Portal 镜像页标 usa.gov/government-works。（规格:119）
3. 取 CDS 分发副本；NC 边界如实记录；**派生素材不进 APK、不进 CI artifact、不进仓库**，做首启可选下载 + 许可确认页。理由：NC 数据随构建产物分发会把"非商用"粘到 APK 上。（规格:120）

字段细分（禁混）：

4. 位置/自行/BT-VT 星等/HD/HIP/Bayer/Flamsteed：全部 Tycho-2 一源到底。（规格:124）
5. 距离：只对"星官成员星 + 最亮 150 颗"注 Hipparcos 视差（标 ESA 1997）；其余显示"未收录"，不编。（规格:125）
6. 光谱/B-V：只对精选子集查证；其余不着色温，按星等映射暖白段。（规格:126）
7. 星名：古名取公版古籍（《史记·天官书》《晋书·天文志》《步天歌》）逐条带出处；IAU 约 450 名取 WGSN；西名中文译名自拟，不抄有版权星表。（规格:127）
8. 星座边界为 IAU 事实（Davenhall & Leggett 1989，VizieR 条款非商用可标用）；连线自绘，署名"参考 IAU/Sky & Telescope"。（规格:128）
9. 分野表取公版原文，出处逐条标（《史记·天官书》卷二十七）。（规格:129）

schema 四族（禁自造字段）：

10. `star`：id、tychoId、raDeg/decDeg（J2000 Double 必填）、magVt、bayer、flamsteed、hip、hd、colorBv、spectralType、distanceLy、constellation（88 之一必填）。后三者可空是有意设计——空字段不渲染对应行。（规格:133）
11. `star_name`：starId、name、lang（zh-xingguan / zh-modern / en-iau）、source、isPrimary。（规格:134）
12. `asterism`（星官与星座**分表**，理由：成员判定与样式完全不同，合并会造"一套数据两个语义"）、`asterism_member`（memberIndex 如"井宿一"、linkToNext）、`constellation_line`（fromStarId、toStarId、constellationId、style）。（规格:135）
13. `field_allocation`：asterismId、regionName（雍州）、stateName（秦，可空）、source、isVariant（异说 true + "一作"来源）。（规格:136）

体积：star+star_name <1.5MB；其余 <150KB；金字塔按需 <60MB 可删可重建。（规格:138）
