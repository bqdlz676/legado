## 1. 阅读进度云同步

Legado 已有 WebDAV 同步功能——`WebDavService.kt`，直接保留。落文这边加一个同步入口就行。

**设置页入口**：「云同步」一行，点进去——WebDAV 地址 + 用户名 + 密码三个输入框。"测试连接"按钮 → 连上显示绿点。连不上显示"无法连接，检查地址和密码"。

**同步内容**：
- 阅读进度（bookId + chapterId + 字符偏移）
- 生字本（vocab_log 表全量 JSON）
- 画板批注（InkPage 表全量 JSON）
- 书签/高亮

**同步时机**：
- 读完一章自动推一次
- App 切后台推一次
- 手动下拉书架页触发

**冲突**：最后修改时间戳，晚的覆盖早的。不搞 diff 合并，太复杂不值得。

**坚果云免费**：每月 1GB 流量，够用了。设置页里直接加一个「推荐：坚果云 WebDAV」链接，点进去是坚果云注册页。

## 2. 导出批注集

**触发**：书架上长按一本书 → 弹出菜单里多一行「导出批注集」。或读完最后一章自动弹 toast 问要不要导。

**导出内容（自动收集，不用手动）**：
- 这本书里你点过的所有字和释义（去重，按首次出现排）
- 这本书里你点过的典故
- 这本书里你点过的人物（每人一行身份）
- 这本书你在画板上的所有批注 PNG（每页一张缩略图 + 原文句子）
- 这本书你手动加的书签段落

**输出格式**：竖排 PDF。
- A4 竖版，纸白底色
- 封面：书名（竖排大号墨色）+ 阅读起止日期 + "落文 · 阅读笔记"
- 分四章：字词 | 典故 | 人物 | 批注
- 每章首页一个竖排章标题
- 正文竖排，字义横排小字注在右侧

**技术**：Android 原生 `PdfDocument` API 直接画 Canvas → 导出到 `/sdcard/Download/落文笔记_左传_20260122.pdf`。不依赖第三方库。

## 3. 阅读统计年报

**数据来源**：`vocab_log` + 阅读进度缓存 + 气泡点击日志。

**统计指标**：
- 年度阅读 x 本书、累计 xx 小时
- 最常读的时段（晚上 10 点 → "夜读型读者"）
- 最常查的字 top 10（朱砂色大号榜单）
- 最关心的历史人物 top 5
- 读得最慢的一本书（平均每章停留时间最长）
- 批注最多的章节
- 总阅读字数 / 总点击气泡数

**UI**：全屏竖排长卷，往下滑。每一屏一个数据，大号数字 + 一句话点评（口语化，像朋友聊天："这一年，《左传》陪你度过了 47 个夜晚。隐公元年是你读得最慢的一章——郑伯克段，你反复看了三遍。"）

**推送**：每年 12 月 31 日晚 8 点推通知"落文年度书单已生成"。点进去就是这份年报。可分享截图。

## 4. 桌面小组件

**三个组件尺寸**：

| 尺寸 | 内容 |
|---|---|
| 2×1（小方块） | 今日诗句竖排，墨色，纸白底。不显示来源 |
| 4×1（横条） | 正在读的书名竖排 2 行 + 朱砂进度竖线 + 当前章名 |
| 4×3（大方块） | 同上 + 最近点过的 5 个生字竖排列表 |

**技术**：AppWidgetProvider + RemoteViews。刷新频率：每天 8 点刷新诗句组件，阅读进度每次翻页刷新。Android 12+ 支持动态着色（Material You），但落文用固定配色——不跟系统主题。

**点击行为**：点诗句组件 → 打开落文 → 该诗的完整内容。点进度组件 → 打开落文 → 直接进那本书的阅读页。

## 5. 字体切换

**三款开源中文字体（全免费商用）**：

| 字体 | 用途 | 文件大小 | 来源 |
|---|---|---|---|
| Noto Serif SC | 标准古籍（默认） | ~16MB | Google Fonts |
| 霞鹜文楷 | 手抄本风格 | ~8MB | GitHub: lxgw/LxgwWenKai |
| 志安瘦金体 | 宋徽宗瘦金体模拟 | ~5MB | GitHub 开源瘦金体 |

**设置页入口**：「阅读字体」→ 三个选项，点一个立刻预览一段《左传》竖排文字。选中后全 App 正文切换字体。注音小字维持无衬线不变。

**加载**：Noto Serif SC 已内置。霞鹜文楷和瘦金体首次选择时下载（各 5-8MB），下载完缓存在本地。不需要在 APK 里自带三种字体——APK 太大了。

## 6. 古籍朗读

**引擎**：Android 系统 TTS（TextToSpeech） + 自定义断句层。不用自己训练模型。

**断句层（核心）**：
```
原文："郑伯克段于鄢"
没有断句 → TTS 直读："郑伯克段于鄢"（一口气，听不出意思）

落文断句：
1. 查典故词表 → 没命中
2. 查人名表 → "郑伯"命中 → 在"郑伯"后加 200ms 停顿
3. 查地名表 → "鄢"命中 → 在"于鄢"前加 150ms 停顿
4. 查虚词表 → "于"是介词 → 加 100ms 停顿
5. 最终："郑伯 ⏸ 克 ⏸ 段 ⏸ 于鄢"
```

**断句规则优先级**：
1. 典故词 → 词前后各加 200ms 停顿（第一优先级，不能把"四面楚歌"读成"四面/楚歌"）
2. 人名 → 人名后加 200ms
3. 地名 → 地名前后各加 150ms
4. 虚词（于/之/而/以/则/者/也/乎/哉/焉/矣）→ 虚词前加 100ms
5. 标点 → 句号/问号/感叹号 400ms，逗号 200ms

**TTS 引擎选择**：
- Android 自带 Pico TTS → 中文语音一般，能听
- 推荐用户装 **Google 文字转语音**（Play Store 免费）→ 中文语音自然很多
- 设置页加一行「推荐安装 Google TTS 引擎以获得更好的朗读体验」+ 跳转 Google Play 链接

**UI**：阅读页右上角一个喇叭图标。点一下开始朗读，再点停止。朗读时当前句子用朱砂色底高亮。底部浮出极简控制条：「⏸ 暂停」「← 上一句」「→ 下一句」「1.0× 速度」。3 秒后控制条自动半透明化。
