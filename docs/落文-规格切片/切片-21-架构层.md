### 0. 双引擎与共享边界

- 双引擎 = 阅读排版引擎（竖排/横排分页）与地图引擎（2D Leaflet / 3D 沙盘 / 3D 地球，同一 `PlaceMapActivity` 壳）。
- 共享对象仅限 Data 层 Store（只读数据 + 缓存）；渲染层、页面状态、手势状态不共享。
- 复用边界（F-10）：EntityProvider 不重构 D1 字典 / D2 人物 / D3 地名，只对新增类别生效；本切片不改动该边界。

### 3. 边界与兜底（按规格「不允许空白态/崩溃」推演）

- **空数据**：Store 未加载完成时，地图/阅读侧先显示占位空态，不抛空指针；共享实例懒加载，首次访问线程安全。
- **断网/离线**：按需下载资源未缓存时，对应大资源功能走兜底空态并提示离线可用范围；核心阅读与已缓存地名/年代可用。
- **低端机/帧率掉线**：地图前台抑制阅读绘制后，低端机双引擎并存仍超 100MB 时按三档走「待优化/打回」，不靠减粒子数绕过内存门禁；GPU 竞争不得以降画质替代抑制逻辑。
- **后台返回**：应用切后台再回前台，Store 单例不重建；GPU 回调按生命周期重新配对，不重复订阅。
- **体积超限**：超标明细未出齐不得出包；豁免项必须能逐条指认为按需下载，不得把大资源塞进内置目录规避 25MB。

### 4. DoD 对照（回写 D24）

1. Data 层共享：`PlaceStore`/`ChronologyStore` 单例共享，双引擎同引用、无双份缓存。
2. GPU 不竞争：地图前台阅读 `onDraw` 空返回，切回成对恢复。
3. 内置 ≤25MB 硬上限：CI 体积拆解 + 超标明细义务；按需下载豁免可枚举。
4. 内存 ≤100MB 三档：≤100 过 / 100–120 待优化 / >120 打回；峰值采集进 bench，旧 180MB 红线清零。

> 验收级别：L1（接线：共享实例/onDraw 空返回符号存在且被调用）起，L2（CI bench 数字达标）门禁；L4 真机不强制。
