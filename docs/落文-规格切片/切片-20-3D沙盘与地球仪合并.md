### LOD 系统
球面段数根据相机到球面中心的距离自动切：
- 距离 > 球半径 × 3 → 128×128，2K 纹理
- 距离 球半径 × 1–3 → 256×256，当前大洲 4K，其余低精
- 距离 球半径 × 0.1–1 → 局部高精度 512×512–1024×1024，高度图切到当前区域
LOD 切换时在 GPU 上做 morph（顶点从低精位置平滑过渡到高精），2-3 帧内完成，不掉帧。

### 渲染管线
顶点着色器：
1. 高度图采样 → 位移沿球面法线方向
2. 覆盖图采样 → 7 种覆盖类型 → 改顶点色
3. 森林覆盖区额外加 fbm 微凸起（振幅 ×1.5）
4. 雪线：海拔 > 3500m → 颜色覆盖白色半透明
片元着色器：
1. 卫星纹理采样
2. 法线贴图（从高度图实时生成）
3. 太阳光方向 × 法线 → Phong 漫反射 + specular
4. 海洋格（覆盖图 = 水域）→ 蓝底 + 基于太阳方向的镜面高光
5. 极地冰盖（纬度 > 66.5° 且覆盖图 = 冰）→ 冷白微蓝 + specular 0.15
6. 暗半球（背向太阳）→ 亮度 × 0.15 + 偏蓝 + 叠加夜景纹理
大气层：
- 半径 100.5 半透明壳，菲涅尔 shader（边缘淡蓝白光，正面透明）
- 半径 104 极淡蓝光晕，透明度 0.08
- 近地面高度 0–15 单位内 Rayleigh 散射简化（远距偏蓝微灰）
云层：
- 半径 101 半透明壳，独立旋转速度 = 地球自转 × 0.9
- 片元透明度 = 云纹理 alpha × 0.3
- 云层投阴影到地面：地面片元采样云纹理，alpha > 0.5 → 亮度 × 0.95
太阳：
- 金色圆盘辉光光源，直径 8 单位，永远跟地球保持 400 单位距离
- 太阳位置根据 UTC 时间计算（手机上几点、光照到对应位置）
- 太阳方向叠加柔和暖金散射到近侧大气层
晨昏线：
- 日照和暗的交界设 5° 宽渐变带，不是硬切
- 东侧（日出）暖橙渐变，西侧（日落）蓝紫渐变。太阳方向依据 UTC 时间
海洋：
- 底深蓝 `#1B3A5C` → 镜面高光（太阳反光）→ 浅海/海岸 turquoise `#3A7A8A`（离陆地 3 像素内变色）
- 高度图上海拔 ≤ 0 的区域自动填充海洋色 → 不用手动切水域
势力多边形：
- 贴在球面上。每个顶点投影到球面（沿球心到顶点的方向射线）
- 己方势力暖金半透明（opacity 0.12），敌方灰青（0.10），盟友铜色（0.08）
- 势力交界处自动叠加渐变（shader，2fps 流动）
城池光柱：
- 中国区域用现有光柱（三级渲染：都城 12 单位金柱 + 郡邑 6 单位铜柱 + 关隘脉冲金点）
- 世界地名用金色光针（从球面沿法线穿出 4 单位 + 顶圆点）
- 所有标签合并到一张 atlas 纹理
地名标签：
- Billboard Sprite，朝向相机，固定在球面位置
- 标签密度分级：都城任何缩放级别可见，一般地名放大后才浮出
- 远距时标签淡出避免堆叠
河流：
- Natural Earth 河流路径坐标 → 球面上的 CatmullRom 弧 → TubeGeometry
- 液态金线 shader（慢流反光，2fps）
行军路线：
- 沙盘区域用 A* 寻路 + 贴地金色锋芒
- 球面/海洋用 Great Circle Arc（大圆最短路径弧线，凸起球面 1.5 单位）
- 箭头锋芒 + 流动金粒子（跟沙盘同材质）
- 颜色按阵营区分：己方暖金、敌方灰青、盟友铜
推演引擎：
- 沙盘区域走现有引擎（A* + 规则意图 + 兰彻斯特结算）
- 球面/海上走简化版：大圆弧线 + 遭遇结算（无地形分析）
- 同一份 campaign.json，引擎自动判断在哪个模式跑
时间轴 + 阶段切换：
- 跟沙盘一样：底部金线 + 篆章节点 + 剧场模式全屏播放（1.2s 自动推进、交战聚焦、暗角）

---
**一句话**：当前 `three.html` 的 `PlaneGeometry(SIZE, SIZE)` → `SphereGeometry(100, 128, 128)`。`lonU/latV` → 球面坐标。LOD 自动切精度。无边界。从长平滑到北极不中断。
