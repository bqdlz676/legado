## 五、兜底边界四条落地

- **空数据**：`ArtifactFallback.notFound` 产出结构完整 `BubbleContent`；source=`未命中`（`MISSING_SOURCE`），candidates / actions 空列表，phonetic=null，body / detail 为空串；不返回 null、不抛异常。
- **断网**：`CacheStatus.OFFLINE_CACHE_MISS` 标记断网且本地缓存未命中；`FallbackState.CACHE_MISS_OFFLINE` 供气泡层区分回退态；本层不自动联网，重试策略归接线层。
- **缺年份**：`FallbackState.YEAR_MISSING`；空实现对 anchor 中年份缺失不过滤、不猜年代；年代锚消歧链归后续单。
