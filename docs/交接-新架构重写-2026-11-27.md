## 7. 已知坑（踩过的，别再踩）

1. **`git commit -m` 含反引号会被 shell 展开**——用 `-F <(printf ...)` 或写文件。
2. **中文路径**：所有 git 调用要带 `-c core.quotepath=false`，否则路径变八进制转义串，匹配全空（55 门禁就栽在这）。
3. **`.git/index.lock`**：提交前 `pgrep -x git` 确认无进程，再删 0 字节锁；否则会把并发 git 操作打断。
4. **禁止目录级 `git add <dir>`**：历史上把未验收产物扫进提交导致 CI 编译真红，必须逐文件白名单。
5. **沙箱无 JDK / gradle / Android SDK / aapt / apksigner**：禁 `./gradlew`、禁 `kotlinc`；任何"编译通过"的声称都是假的，只能给静态证据。
6. **GitHub job 日志**：`curl -sL -H "Authorization: Bearer $TOK" .../actions/jobs/<id>/logs`，**不加 `--location-trusted`**（会 401）；在跑的 job 取日志 401 属正常。
7. **APK 下载弱网会截断**：必须 Range 续传 + 标称字节闸，否则会拿到半个包还当成功。
8. **并发写同一文件**：两个单同时改 `AndroidManifest.xml` 这类文件，只许精确单块编辑，禁整文件 Write 重写、禁 `sed -i`，匹配不上就停并报总控。
9. **门禁 55 的回退分支无 selftest 夹具**：`report_paths()` 的空集回退只靠全量实跑间接命中（Q-300 已点名，待裁补好/坏两例），改这段代码前先补夹具。
10. **androidTest 源集无 CI 编译覆盖**：`verify.yml` 只编 JVM 单测，75 文件 / 341 用例 / 15 条未解析 import 长期不在门禁视野内；改动 androidTest 不算"CI 绿"，必须单独声明未编译。
11. **跨日坑**：③当日流水与 ㉖ 接手链按本地日期找文件，过了零点会因"缺当日文件"变红——那不是内容缺陷，补当日流水即可。
12. **`docs/契约-设计token.json` 是唯一 token 源**：页面里写死 hex 会绕过机检（机检只认登记项），新增 token 必须登记并写出处行号。
