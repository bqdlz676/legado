# 拼合质量四判据

本文不是报告，是机制草案（落文），给"每个模块单独验收都过了，拼起来却是空的/断的/双轨的"这类缺陷定判据。
待在飞验收单收口后并入 `docs/落文-规矩总纲.md` 作为 F9 条，并由 `sync-ironrules.py --write` 机械照录到总控必读与总账。

## 为什么要单独定"拼合质量"

单项验收只看"这个件本身正确"：函数签名在、逻辑对、测试绿。
拼合验收只看"这个件真的接上了、真的被用、旧的真的退了、缺的真的看得见"。
本段实证四起，全部是单项 PASS、拼合不合格：

1. B4-08 契约路由缝零生产调用方。`BubbleContractResolver` 与新 `routeContract`/`canDispatchContract` 全仓只有测试引用，生产仍跑旧链（控制器→Resolver→旧 Provider→旧 BubbleContent）。单测 12 用例全绿，用户侧零变化。
2. B4-08 名物入口静默丢弃。`OpenArtifact` 在适配层 `ArtifactBubbleProvider.kt:96` 被丢弃，旧链 UI 既不渲染 chip 也不置灰，用户感知为"功能不存在"而非"暂不可用"。
3. B4-07 契约不同步导致的编译红。控制器新增两条只读缝，实现方漏 `override`，静态门禁全绿、编译红（`0c9fd30`）。这是典型拼合期才暴露的接口↔实现错位。
4. g66 `--changed` 空转。门禁本身"正确"，但改动面路径两侧无归一，dirty 树上直配 0 条，等于门禁没接上（`ad24db3` 修）。工具链也有拼合质量。

## 判据一：可达性（没有孤儿接线）

新符号必须能从应用入口一路走到。判法：从 `Activity`/`Fragment`/`Application` 等入口出发做反向可达，不在可达集里的新增公开成员/新链一律记为孤儿。
不得以"以后会接"放过；未接的必须在台账里带退场单与截止条件。
机械化落点：新增"新增公开 API 零生产调用方"门禁（g68），`--changed` 判新增、`--audit` 登记存量。

## 判据二：被使用性（存在不等于生效）

符号存在、测试绿，都不等于生产在用。判法：新增链路必须有非测试调用方，且该调用方本身在可达集内（避免"被另一个死代码调用"）。
这一条专治"写得漂亮的新链，只有单测认识它"。

## 判据三：双轨消解（旧的一定要退）

新旧并存必须有明确退场单、退场判据、退场 sha。允许并存期，不允许无限期并存。
判法：旧符号不得新增引用（`--changed` 判），并存期超过一个批次未退场的必须升级为待裁问题。
本段 B4-09/B4-10 就是退场单：`ContentTextView` 壳桩、`ReadView` 回调壳桩。

## 判据四：缺口的可见性（不许静默降级）

能力未接通时，界面必须给出可见表达（置灰、占位、提示），不得静默丢弃。
判法：每个 `return null` / `?: return` 的契约分支，要么有可见态，要么在报告里登记为"静默缺口"并带归属单。
`OpenArtifact` 那条属静默缺口，已入队名物详情 Sheet 接线单。

## 判据五（附）：文档锚点的可回源性

拼合也发生在文档与代码之间：报告里的 `文件:行` 会随提交漂移。g65 验收已实测锚点行号漂移（待裁）。
判法：锚点必须能被脚本回源命中；漂移登记为待裁，不许静默保留旧行号。

## 新发现问题

- 待裁（归属拼合验收模板）：B4 各面普遍只有一二级证据，四级运转时可断言缺失。
- 待裁（归属名物接线单）：`OpenArtifact` 旧链静默丢弃属静合缺口，当前无可见态。
- 待裁（归属 g66 后续迭代）：门禁自身的改动面路径归一缺陷已修，但输出路径格式变更需下游核对。

## 证据分级（提高"拼合证据"的等级）

一级：静态走查（读代码说链路成立）——只允许作为辅助。
二级：脚本机检（门禁 PASS）——允许作为门禁结论。
三级：编译（CI Verify）——契约同步的唯一硬证据。
四级：运行时可断言（单测真跑、Robolectric、instrumentation）——拼合质量的唯一硬证据。
当前 B4 各面普遍停在一级+二级，故验收结论统一写"有条件通过（编译面待 CI）"。
提升方向：每个面交付时补一条"入口→出口"的运行时可断言，缺哪一级要在报告里写明，不许含糊。

## 结论

结论：拼合质量按"可达性、被使用性、双轨消解、缺口可见性、锚点可回源"五条判，证据分级四级，缺级必须在报告写明。

## 自查反例
反例推演：若只按单项验收放行，B4-08 那种"测试全绿、生产零调用"的缝会被判 PASS，用户侧零变化却记作完成；若允许静默 `return null`，名物入口会变成"功能不存在"且无人登记；若锚点不强制回源，报告会长期保留已漂移的行号。

## 落地顺序

1. 先派 g67（语料断言诚实性），堵住本轮 CI 红那类"断言依赖数据"。
2. 再派 g68（新增公开 API 零生产调用方，audit 起步），堵住 B4-08 那类孤儿缝。
3. 双轨退场扫描（g69）与 B4-09 剥桩同批做，避免退场单写了没人核。
4. 四条判据稳定后并入总纲 F9，由 sync 机械照录。
