## 一、改了什么（问题三问）

### 1. 改了什么

- 把翻页命令解析、翻页闸状态机、掀角弹簧积分、降级手势桥接、分区纯函数、手势路由、候选循环七件归位到纯逻辑层：公开判定入口全部吃标量参数，状态机列全状态与非法迁移处置，非法输入回退安全态并留可观测计数，不抛异常、不出空白态。
- 旧 `ViewGestureBridge` 把触摸/点击/长按监听字段直接挂在类上；本单把判定核心抽成 `touchMove` / `tap` / `longPress` / `zoneOf` 四个纯入口，View 挂摘降为 internal 接线侧 `attach` / `detach`，类内不持 View 字段、不持 Activity / Context / Binding / PopupWindow。
- 弹簧构造期补参数校验夹紧；候选循环构造期冻结候选列表；闸口补放行/动画屏蔽/边界拒绝三类计数与清零入口。
- 单测补行为谓词：负连发计数、裁决计数累加与清零、非法弹簧参数夹紧、阻尼比上限、长积分进度夹界、坐标 NaN 兜底、候选列表外部突变隔离、桥接四向路由与动画屏蔽、退化尺寸回退。

### 2. 为什么这么改

- 定界 I-06（docs/任务书-B4-阅读页-引擎定界.md:314）要求纯 JVM 无 KeyEvent import，Android 绑定只取键码；I-07（:319）要求动画态/边界可翻态由宿主灌入，闸不持 Android 引用；I-08（:324）要求二阶质量-弹簧-阻尼积分且无 Android 动画类依赖；I-09（:329）要求路由仍走 GestureRouter/ZoneClassifier，attach/detach 在新壳接线时重接，触摸监听不消费事件；I-11（:340）密度换算在调用处、判定保持纯函数；I-12（:345）点中字优先于翻页口径在 onTap 内落定；I-15（:366）query 裸名/display 装饰双字段口径不改。
- R17（docs/任务书-B4-阅读页.md:61）口径：手势随排版方向、与书类型无关；本簇只给中性 EdgeDirection 枚举与分区结论，不读书类型、不把左右写死为某一书种。
- R21（docs/任务书-B4-阅读页.md:65）口径：翻页全程 16ms/帧；本簇不碰绘制，但弹簧积分保证不发散成 NaN/Inf 拖垮单帧，闸口保证动画中不另起翻页。

### 3. 怎么验的

- 四包、paragraph、vertical 三 API、build.gradle 跑 git diff 双通道回证空集（第五节贴真实输出）。
- 七件与单测跑 kotlin-syntax-lint、test-fun-names、compose-pitfalls、ext-imports，末行见第九节。
- 每个公开函数入参类型核对：除 ViewGestureBridge 的 internal 接线侧外，公开签名不出现 Android framework 类；引用符号同包或已 import。

## 四、二阶三阶影响推演

### 4.1 七件被 B4-07 文字面上屏里程碑接走后的依赖点

- PageTurnGate：只收宿主灌入的三个布尔（animating、canPrev、canNext），不直引四包任何类型；首末页标志与动画回调由宿主实现侧从既有引擎读取后灌入。
- ViewGestureBridge / ZoneClassifier / GestureRouter：命中检测经 ReaderShellHost 端口（I-04）调 probeChar；路由结果只回 EdgeDirection 与端口回调，不直引 page/provider、page/entities、page/api、page/delegate 内的类。
- InkPageCommand：产出方向枚举与朗读切换命令，命令消费在 B4-07 接线侧，本簇不回四包。
- PeelSpring：纯积分，无引擎、无渲染依赖；渲染侧取 value 进度绘制掀角。
- CandidateCycle：只读 help/bubble 的 BubbleCandidate，属只读引用不改集合内对象。

### 4.2 会不会反向倒逼四包改签名

- 结论：不会。本簇与四包之间隔着 ReaderShellHost 端口与宿主灌入布尔两层；四包既有 prev/next/命中/测量契约保持只读。
- 规避方式：若 B4-07 需要首末页或动画态新事实，由宿主实现侧在端口实现里读取四包后转换为布尔/命中结果灌入本簇；不在本簇向四包提新方法、不改既有三公开 API 形参与返回值。
- 二阶影响：闸口计数与弹簧夹紧计数是纯内存观测点，不落日志、不持上下文；B4-07 接线时可接诊断面板，不反向要求引擎埋点。
- 三阶影响：迁移到独立可渲染 module 时，唯一需剥离的边界是 ViewGestureBridge 的 internal attach/detach（android.view.View）；其余六件无 framework 依赖可直接平移。剥离口径记入 B4-21 交接：View 适配换成端口实现即可，判定核心不动。

### 4.3 风险与反例自查（先假设本方案错误）

- 反例一：若把边缘方向直接写死成 Prev=左、Next=右，竖排阅读时手势方向会与阅读顺序相反。处置：本件只给中性映射，排版方向对调留给壳装配期；ZoneClassifier KDoc 已注明该口径。
- 反例二：若动画中允许新翻页，两次掀角动画会打架。处置：PageTurnGate 动画态优先，GestureRouter 与 ViewGestureBridge 入口先查 isPageAnimating。
- 反例三：若候选列表被外部继续修改，循环下标会越界。处置：构造期 toList 冻结，单测有外部清空后 size 仍为 3 的谓词。
- 反例四：非法弹簧参数在欠阻尼边界积分出 NaN，下一帧绘制即炸。处置：构造夹紧 + 速度软夹 + 状态复位三层兜底，长积分夹界谓词在册。
