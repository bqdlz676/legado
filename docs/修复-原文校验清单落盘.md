## 3. manifest 字段结构与来源（以校验脚本读取代码为准，未猜字段名）

### 3.1 顶层字段

- `vol_files`：**必须**。字典，键为卷号字符串（`"01"`…`"09"`），值为该卷在 `docs/落文-原文/` 下的文件名。来源：构建脚本 `VOL_FILES` 常量（reorder_build.py 内），9 项映射逐字沿用。校验脚本在 `reorder_validate.py:67` `vols = manifest["vol_files"]` 读取，并用 `SRC_DIR/vols[vol]` 打开原文。
- `blocks`：**必须**。块数组，顺序为重排后的新序（与 `groups` 展开顺序一致）。
- `groups`：**必须**。分组数组，每项为 `[组名, [[卷号, 起始行], …]]`。校验脚本在 `reorder_validate.py:112` 解包为 `grouped`，按输出顺序从 `block_by_key` 取块拼期望正文。组名字符串在校验侧被 `_` 丢弃（仅位置参与），保留组名仅为与重排索引对照的出处信息。

### 3.2 块字段（blocks 每一项）

- `vol`：**必须**。来源卷号字符串，取自切块常量 `STARTS` 的卷键。校验脚本 `reorder_validate.py:77` 读取用于定位原文卷。
- `start`：**必须**。源起始行（1-based，含）。来源：构建脚本每卷 `STARTS` 清单（块界 = 标题行 / 中文序号标题行）。
- `end`：**必须**。源结束行（含）。来源：下一块 `start - 1`；末块到文件尾（`len(body)`）。由切块逻辑实测推导，非手填。
- `bytes`：**必须**。块字节数。实测方法：把该卷原始字节按 `b"\n"` 切行，取 `body[start-1:end]`，`b"\n".join(...) + b"\n"` 拼回，`len(raw_block)` 得字节数。校验脚本 `reorder_validate.py:87` `assert len(raw_block) == b["bytes"]` 逐块复核。
- `sha256`：**必须**。块内容 SHA-256（十六进制）。实测方法：对上面同一块字节 `hashlib.sha256(raw_block).hexdigest()`。校验脚本 `reorder_validate.py:86` `assert sha(raw_block) == b["sha256"]` 逐块复核。
- `chars`：**可缺省**（构建脚本写入，校验脚本不读取、不复核）。实测为 `len(raw_block.decode("utf-8"))`，供索引与报告计数对照。
- `title`：**可缺省**（构建脚本写入，校验脚本不读取）。块标题，仅用于索引与重排版注释标记，不进正文。
- `key`：**可缺省**（构建脚本写入，校验脚本不读取）。`[vol, start]` 冗余键，便于人工对照。

### 3.3 实测方式与复算证据

- 生成器复用 `reorder_build.py` 自身的 `VOL_FILES / STARTS / TITLES / GROUPS` 常量（`import reorder_build`，不调用其 `main()`，故不覆写 docs 下重排版 / 索引），对 9 卷原文逐块切片，现场计算 `bytes / chars / sha256`，写入 `data_scripts/manifest.json`。无占位、无估算。
- 覆盖性自检（生成器内 assert）：分组展开 115 个键，无重复；与切块集合完全相等，无未覆盖 / 多余块。
- 聚合独立复算（shell，不依赖 Python 生成器）：9 卷按序 `cat` 到临时文件，`wc -c / wc -m / wc -l` 与 `sha256sum`：
  - 字节数 231700，字符数 120954，行数 4433，sha256 `aa200aac1c373273cf5bdbae238133213b7c06081278cdde02614e90e4a986ef`，与校验脚本基准段一致。
- 单块抽查（03 卷 L1–27）：manifest 登记 `bytes=966 chars=484 sha256=b48915452537985e6e8fffff55632b194d2feb5799f6814a8bd6efa5de7c8c9f`；独立按行切片重算 `len / decode 长度 / sha256` 三项逐项相等（match: True）。
- manifest 计数（实测）：块总数 115；分组 12 个；分组键合计 115；按卷分布 01=49、02=40、03=6、04=8、05=1、06=8、07=1、08=1、09=1；块字节合计 231700，块字符合计 120954；相对原始顺序调序块 107。
