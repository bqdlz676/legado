## 一、三条判低逐条处置

### D1-① 路径层「起点 = 终点」早返回无专门用例 —— 已补断言

判低原文：路径级 `from == to` 早返回（`Pathfinder.kt:13` 的 `find`、`:94` 的 `flankRoute`）无专门用例；度量层重合断言已有，路径层没有。

处置：新增 `PathfinderBoundaryTest.kt`，两条用例分别锁住两条路径入口的早返回：

- `find` 入口：起终点同格时返回列表仅含起点格、长度 1、首尾格距代价 0.0（容差 1e-12）。
- `flankRoute` 入口：起终点同格时返回 `FlankRoute(listOf(from), degraded = false, reason = "起点即终点")`，长度 1、仅含起点、不置降级标志、理由文本锁定、首尾格距代价 0.0；即便传入敌军条目也不进入视野闸门或兜底链条。

度量层 `octile(a, a) = 0.0` 既有断言在 `GridMetricTest.kt`，本单不重复。

### D1-② 同代价多条最优路径的平局确定性 —— 已补断言；平局选择不锁定

判低原文：同代价平局出队顺序无任何测试断言锁定。

处置：新增 `PathfinderBoundaryTest.kt` 第三条用例，Fixture 为起点 `(5,10)` → 终点 `(7,10)`，正中 `(6,10)` 为非渡口水面；上绕 `(5,10)→(6,9)→(7,10)` 与下绕 `(5,10)→(6,11)→(7,10)` 各两步斜向，平地代价同为 `2 × 根号二 ≈ 2.828427`，是两条等价最优解；其余绕行均多步、代价更高，不构成第三解。

断言要点：

- 两次独立构造 `Pathfinder` 并裁决同一输入，结果列表逐格相等（确定性 / 稳定性锁定）。
- 路径非空，首格为出发格，末格为目标格，不踏中被堵水面格。
- 结构断言：中间格只可能是上绕格 `(6,9)` 或下绕格 `(6,11)` 之一。

为什么不断言「选哪条」：A* 开放队列 `PriorityQueue` 仅按 f 值比较，同 f 节点的出队先后在 JDK 契约中属任意；`cameFrom` 仅在严格更小时改写父节点，因此上绕 / 下绕归属取决于堆内布局与邻接展开顺序。选哪一条等价路径不影响最优性，规格只要求路径最优；本用例只锁稳定性，不把平局选择写死。

实现层事实与移交建议（本单未改实现）：

- 当前实现未给开放队列比较器加次级确定性键（如节点编码）。同一 JVM、同一插入序列下两次裁决可复现；跨 JVM / 堆实现若观察到平局抖动，应另单给比较器补次级键固定出队顺序。
- 开工时 `Pathfinder.kt` 已被在飞 B8R5 改动占用（目标格视野豁免），按硬约束本单未对该文件做任何追加；上述平局确定性修正不在本单落地，交调度层另单处理。

### D3 `IntentResolver` 无专门单测 —— 已补 12 条纯 JVM 用例

判低原文：`IntentResolver` 无专门单测；Double 化后设伏 5 / 制高点 3 / 夺隘 5 / 支援 1 各斜向分支的几何翻转仅静态推演。

边界数值复核（计算器）：

- 正交三格 / 四格 / 五格 / 六格：octile 分别为 3.0 / 4.0 / 5.0 / 6.0，恰为整数阈值或阈值加一。

- 斜向一对一对角邻接：`1.414214`，大于应战阈值 1。
