# 启动图标三候选 · 横向对比表（供独立选型代理判）

> 流水线位置：F-73 第①段产出。本表只做维度对照，**不做选型结论**；判优/判低由独立验收代理完成。三候选规格见 `docs/规格候选-启动图标-A-绢帛墨印.md`、`-B-暖金金星.md`、`-C-磨砂墨玉.md`。

## 选型代理可直接追问的点

1. 浅底（A/C）与深底（B）在目标用户常用壁纸深浅下的轮廓对比，需真机/多壁纸目检。
2. B 星与 `ic_bookmark.xml` 五角星的区分度，对照切片-24 书签参数（外接圆 r=10、8° 断口）逐项核。
3. C 的玻璃半透明在 Android 8.0 以下（不支持自适应图标全特性）的回退表现。
4. 三候选 monochrome 层在系统主题着色后的轮廓可辨性，需单独出单色预览复核。
