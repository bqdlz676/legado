## 一、规格五节逐条对账（落点文件:行）

### 1. 效果（纸面浮雕感，非转地球）

- 手机水平正对脸 → 卡片正面、暖金阴影均匀：此时 roll/pitch 平滑值为 0，位移 0、阴影回中。落点 `app/src/main/java/io/legado/app/ui/main/bookshelf/ShelfParallax.kt` 的位移/偏移归零 getter 段（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写阴影 getter）。
- 手机左倾 → 卡片微微右移、右缘阴影加深，像光从左边打来：dx = roll × maxShift，阴影反方向偏移并随 |roll| 加深半径与透明度。落点 `ShelfParallax.kt` 阴影派生段（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写）；卡片绘制 `app/src/main/java/io/legado/app/ui/main/bookshelf/ShelfBookCard.kt:160-173`、`204-205`。
- 手机前倾 → 卡片微微下沉：dy = pitch × maxShift，translationY 承接。落点 `ShelfParallax.kt` 的 translationY getter（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写）、`ShelfBookCard.kt:205`。
- 明确不做 3D 旋转：graphicsLayer 只写 translationX/translationY，未新增 rotationX/rotationY（既有按压俯仰角保留不动）。落点 `ShelfBookCard.kt:197-207`。

### 2. 实现（同一 GyroBridge，只取 pitch/roll）

- 复用 Q-439 桥 `GyroBridge`（`app/src/main/java/io/legado/app/help/sensor/GyroBridge.kt`），本层不重复造采集；只做「整桥队列 → 四元数归一化 → 平滑视差状态」。落点 `ShelfParallax.kt` 的轮询协程（`GyroBridge.drainLatest()`，以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞拆分 enabled/idle 轮询分支）。
- maxShift = 6dp：`ShelfParallax.kt:35` `MAX_SHIFT_DP = 6f`；maxShadowShift = 4dp：`:38` `MAX_SHADOW_SHIFT_DP = 4f`。
- apply 口径：dx = roll×maxShift、dy = pitch×maxShift、shadowDx = roll×maxShadowShift、shadowDy = pitch×maxShadowShift；translationX=dx、translationY=dy。落点 `ShelfParallax.kt` 的 apply 口径 getter 段（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写）。
- 阴影：偏移 -shadowDx/-shadowDy；radius 12f + abs(roll)×6f；颜色 RGB 212,165,74，透明度 0.3 + abs(roll)×0.15。落点 `ShelfParallax.kt:47-61`（常量）、阴影派生 px 与颜色 getter（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写）。
- roll -1←左倾→+1 右倾；pitch -1←前倾→+1 后倾：坐标口径写在 `ShelfParallax.kt:76` 与 `:94-95`；符号调谐点隔离在纯函数 `quaternionToTilt`（`:81-97`），真机若镜像只改该处两处取负号。

## 二、边界六种自兜（实现点，无「暂不支持」）

1. 无传感器设备：`GyroBridge.start` 返回 false / `level == 0`，状态 `available=false`；开关按钮置灰不可点，`active=false` 使位移与阴影全部回中，卡片静止；所有 start 包在 `runCatching` 内，不抛异常、不报错。落点 `ShelfParallax.kt:151-153`、`:176-177`；`InkShelfFragment.kt` 相关生命周期分支（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞）。
2. 传感器精度差 / 抖动：0.06 低权重一阶平滑吸收高频抖动；倾角钳位 [-1,1]；四元数缺分量、NaN/Inf、近零模长直接丢弃本帧。落点 `ShelfParallax.kt:81-104`。
3. 快速切前后台：onPause 注销清队列，onResume 幂等重注册（桥 `start` 内部先 stop 旧监听）；平滑值保留在状态内，回前台直接续跟，不跳变；极端视图重建则从 0 缓入。落点 `InkShelfFragment.kt` 生命周期段、`GyroBridge.kt` 申领幂等口径（均以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞改为 acquire/release 持牌引用计数）。
4. Tab 切换与滚动同时发生：hide 即注销传感器；轮询协程随 composition 离场取消；触摸暂停位（touchPaused）在重新进入时由状态默认 false 复位，不残留「卡死暂停」。落点 `ShelfParallax.kt:135`、`:166-173`。
5. 分屏 / 横竖屏切换：onResume 用当前 `windowManager.defaultDisplay.rotation` 重设桥方向映射；配置变更导致 Activity 重建时 Fragment 随建随注册；多窗模式变化走既有 `BaseFragment.onMultiWindowModeChanged` 口径，不在本层另立状态。落点 `InkShelfFragment.kt` 方向重映射分支、`GyroBridge.kt` 方向映射与矩阵/四元数转换段（均以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞）。
6. 大量卡片（>100）滚动：单状态单协程；卡片不持有独立平滑器；graphicsLayer 与 drawBehind 只读共享标量；滚动暂停由列表态统一驱动，不在每卡挂手势监听做暂停判定。落点 `ShelfParallax.kt` 状态类（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞）；`BookshelfScreen.kt:228-236`。

## 三、与规格示例不一致之处（Compose 替代 View 阴影，附依据行号）

1. 阴影实现方式：规格示例写的是 View 体系 `Color.argb(...)` + `setShadowLayer` 口径；书架是 Jetpack Compose，卡片拿不到 View，`setShadowLayer` 不可用。实干替代：`Modifier.drawBehind { drawRoundRect(...) }` 自绘暖金偏移阴影，与既有卡片三层微光溢出同一绘制通道。依据：既有卡片阴影本就不走 elevation / setShadowLayer，见 `ShelfBookCard.kt:153-189`（drawBehind 三层叠晕）；视差阴影挂在同一 `drawBehind` 内 `:156-173`。
2. 透明度类型：规格示例 `(0.3f + abs(roll)*0.15f).toInt()` 是 View `Color.argb` 的 0–255 int 口径写法；直接 `.toInt()` 会把 0.3 截成 0。Compose `Color(alpha=...)` 取 0–1 浮点，本实现按浮点透明度 0.3+|roll|×0.15 钳到 [0,1]，语义与规格一致、类型按 Compose 口径转换。依据：`ShelfParallax.kt` 阴影颜色 getter（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞重写）；仓内既有暖金微光同样按浮点 alpha 派生，见 `ShelfTokens.kt:44` `colorGlow`。
3. 位移挂接层：规格示例的 `translationX/translationY` 是 View 属性；Compose 对应 `graphicsLayer(translationX=..., translationY=...)`。既有卡片已用 graphicsLayer 做俯仰/缩放/透明度（`ShelfBookCard.kt:197-207`；另一处 `app/src/main/java/io/legado/app/ui/card/BookCard.kt:131-138`），视差值并入同一层，未新开 View 层。
4. 注册宿主：规格文字写「书架页 onResume/onPause」；实干落在宿主 `InkShelfFragment` 的 `onResume/onPause/onHiddenChanged`，与仓内沙盘页 `BattleActivity.kt` 的桥注册/交还口径一致（以现行行为准，核对时点 2026-11-27 19:13 CST；Q-447 在飞改为 acquire/release 持牌）；Compose 侧只负责取数与渲染，不重复持有传感器注册。
