## 四、反例与边界

- **双分支同名据点**：key 为 `lng,lat` 四位小数（与 VictoryChecker 同口径），同名不同坐标不会撞键；本战役顶层仅一个胜利点，多据点扩展属后续单。
- **空存档 / 空军队**：`buildPointHolders()` 对无 point / 半径内无可战军返回空表；重建循环自然空转，不抛（B7-4、B7-7 覆盖）。
- **并发存档**：存档为内存深拷贝（`corps.map { it.copy() }` + 两表 `toMap()`），当前引擎单线程推进；未加锁，多线程并发 save/restore 属未覆盖边界。
- **旧档缺字段**：归属按军位重建、计数基线 1；若旧档军位也已失据，表为空，判定层按「未被任何方持有」处理（VictoryChecker 空值守卫）。
