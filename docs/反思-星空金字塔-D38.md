## 二阶三阶影响

- 一阶（直接效果）：缓存就绪且校验通过时，局部放大可并入 L1/L2 暗星增量；缺文件/损坏/低内存三态都不抛异常、不清空 L0，内置亮星层照常显示。
- 二阶（相邻环节）：
  - 内存与 GC：金字塔增量走独立扁平原始类型数组，查询期不 new 实体列表（§十二.2 零分配口径）；`pyramidMemoryGuard` 在合并前按行均 48B 估算对照空闲内存，拒绝时不留半合并态。L2 十万级行并入后的常驻内存与帧扫描成本，待接线单在 `SkyBenchTest` 回归。
  - 查询扫描顺序：数据层只提供增量数组与访问器；`StarStore.queryRect/nearest` 由单层扫扩为 L0→L1→L2 顺序扫属接线单改动面，本单未动 `StarStore.kt`。
  - 冷启动 IO：缓存目录不在启动读取路径，首帧仍只读既有 `astro/stars.csv`，启动→书架 ≤1.8s 红线不受影响。
  - L0 锚点不变：拾取/星名/星官成员/分野联动仍回 L0 id；金字塔层不回写 L0、不覆盖 `idToIndex`，跨层重复 id 只计数留痕。
- 三阶（流程与演进）：
  - 契约只绑星等带 + 瘦表字段 + 缓存文件名，不绑 CSV 格式；将来换二进制打包/坐标量化/按天区分片，上层访问器口径不变。
  - 9.0 等界值目前为本类私有常量 `LEVEL1_UPPER_MAG`，与 manifest `level1UpperMag` 对齐；待契约单提为 `SkyParams` 单源常量后收拢（方案 §8 交接 3）。
  - 数据工程：坏片 `.corrupt-<epoch>` 隔离后可整目录删除重建；发布侧切片/校验和/行数留痕沿用构建器与校验器同一 schema。

## 反例边界（最强反对者清单）

1. 断网首启 / 缓存被系统清理：切片或旁证不存在 → `Missing`，保留 L0；暗星区由低层密度底图覆盖，不空白不崩（§七.4、§十三.2）。
2. 半截/损坏下载：sha256 旁证先于解析拦截，半截文件不产生部分合并；坏片改名隔离，不覆盖好片（用例「坏片隔离不毁好片」覆盖 L1 坏 + L2 好并存）。
3. 校验和旁证缺失：按方案 §4.3 缺文件口径归 `Missing`（未下载/不完整），不误报损坏态；若后续口径要求「有片无旁证即 Corrupt」，只改 `loadPyramid:155` 一处分流。
4. 低内存设备：`LowMemory` 拒绝当前层合并，不追加数组、不抛 OOM；降层序列（关流星→尘粒→magLimit 9→银河）沿用 §十三.4，属渲染/宿主域。
5. level 越界（0、负数、>PYRAMID_LEVELS）：直接 `Missing`，不拼路径、不触发 IO。
6. 并发连点 / 重复调用：`loadedLevels` 去重，第二次同层调用返回 `Loaded(level, 0)`，数组不重复追加。
7. 跨层同名 id：与 L0 或已加载层重复的 id 不计入 `added`、不进金字塔索引，计入 `dupId` 留痕。
8. 极简包裁剪到 L0 也缺失：本单不改既有 `fromAssets`/`placeholder` 占位链路，仍回落 `StarField` 种子 9173 程序化兜底。
9. 没找到反例的面：时区/恒星时与金字塔层无关（J2000 静态坐标，时间变换在投影层）；行星/彗星属二期，不进本切片。

## 认知成本

1. 两级金字塔是同一星表按星等切的增量层，不是三张地图：L0 ≤6.5 内置；L1 (6.5,9.0]；L2 (9.0,11.5]；`PYRAMID_LEVELS=2`。
2. 四态语义必须分清：`Missing`=没拿到（不报错、可稍后重试）；`Corrupt`=拿到但不可信（隔离 + 留痕）；`LowMemory`=当下装不下（不追加、不降数据可信度）；`Loaded`=已并入。
3. 缓存布局：`filesDir/astro/pyramid/level_{1,2}.csv` + 同名 `.sha256` + `bundle_manifest.json`；旁证先于解析；NC 许可边界见台账 S-01，派生素材不进 APK/CI artifact/git。
4. 新增概念仅一处：`PyramidResult` 密封接口；访问器命名沿用 L0 既有 `xxAt(i)` 口径，无第二层抽象。
5. 接手提醒：数据层与查询层已切开——本单只到「校验 + 并入扁平数组 + 访问器」；`StarStore` 扫描扩层、宿主触发去重、进度线/提示文案均在相邻接线单。
