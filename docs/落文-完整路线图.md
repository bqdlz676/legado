## 落文 · 完整路线图

---

### 第一阶段：品牌基础

**1. App 图标**
圆形纸白底 + 竖排"落文"墨字 + 暖金细线边框 + 左下 8° 缺口。无字通知栏版（墨滴剪影 + 金点）。

**2. Logo 标准字**
横排版（网页/文档用）、竖排版（书架/阅读页用）、金点辅助标识。

**3. 启动动画**
2.8s：墨滴坠落 → 炸裂 → 回聚成字 → 金粉爆 → 远山浮现 → 暖金线扫过 → 标语淡入 → 淡出进书架。

### 第二阶段：阅读内核

**4. 排版引擎**
保留 Legado 文本解析/分章/分页/翻页。竖排正文 18sp、行距 1.8x、列间距 2.5x、Noto Serif SC。

**5. 书架页**
竖排书名卡片 + 暖金微光阴影 + 朱砂进度竖线 + 卡片 3D 前倾 + 右滑碎墨删除。

**6. 阅读页**
宣纸底 + 左上暖光渐变 + 页边朱砂进度线 + 章节氛围粒子 + 翻页掀角。

**7. 气泡系统**
墨爆触发 → 撕边纸片浮现 → 金边流光。字/典故/人名/地名/年号五种变体。冷启动首触 ≤ 300ms。

**8. 半屏 Sheet**
纸白金框 + 金杠拖拽器 + 茶色毛玻璃遮罩 + 60% 高。人物/字词/纪年/地名四种详情共用同一 Sheet 容器。

### 第三阶段：智能内核

**9. ContextAnchor**
书/章/年代锚点统一读写。纪年点年号写入、字词扫朝代写入、地名/人物读锚点消歧。

**10. 字词典故**
四大词表预热 + 二进制化。字义 + 说文 + 用例。典故首两字索引。

**11. 纪年系统**
519 条年号 + 213 位王公。年号→公元、公元→干支、多政权对照时间轴、朔望换算。

**12. 人物系统**
200 人 L1 核心库 + CBDB 8.9 万兜底。双引擎别名匹配（全名正则 + 无姓称谓）。同名按年代消歧。半屏 Sheet 阅读优先展示（本段行为 → 同场人物 → 时间轴 → 档案）。

**13. 地名 GIS**
两表时空本体（place 实体 + place_name 时间快照）。同名异地按 ContextAnchor 年代过滤。点面分离。坐标可信度 Tier 1/2/3 分级。

### 第四阶段：地图与沙盘

**14. 2D 地图**
Leaflet + 六套朝代图层（春秋/战国/西汉/三国/唐/北宋）。点击地名 → 底部浮出「2D 地图 / 3D 沙盘」选项。

**15. 3D 沙盘基础**
真实 SRTM 高程替换 fbm。绢帛军图风格。墨卡托投影。城市标签 atlas 合并。

**16. 3D 沙盘氛围**
势力范围多边形贴地表 + 都城光柱粒子 + 河流液态金线 + 古城池三级渲染 + 关隘/渡口/遗址标记。

**17. 预设路线回放**
首批 8 条经典行军路线。金色贴地箭头 + 里程/日程标注 + 疆域图层叠加。

**18. 战役推演引擎**
JSON 数据驱动 + 15 条规则意图轮询 + A* 寻路 + 兰彻斯特结算 + 剧场模式。垓下/长平/四渡赤水验收。

**19. 多方混战**
外交表 + 棋子多色 + 三家分晋验收。

### 第五阶段：画板与周边

**20. 画板重做**
底部横排工具栏（画笔/直线/箭头/矩形/圆/文字/橡皮）。六色 + 线宽滑块 + 撤销/重做。毛玻璃底。WebView 预热。

**22. 搜索页**

**23. 设置页**
竖排标题行 + 横排说明 + 云灰细线分隔分组。

**24. 音乐播放器**
ExoPlayer + FFmpeg 全格式。AAudio 独占直通听羽 f1。底部迷你播放条。Musopen 内置公版曲包。
