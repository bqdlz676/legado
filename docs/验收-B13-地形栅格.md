## 三、判据 1 与判据 6 独立验算

**3×3 / 1×1 反滤波边界推演**（bpp=channels，stride=width*channels）：
- Sub(1) i<bpp：`left=0`（L302）；Up(2) 首行 `up=prev[i]`，prev 初始全 0（L233,303）；Paeth(4) i=0：a=0、c=0，`paeth(0,b,0)` 取 b=up（L304,316-325），与 PNG 规范首像素预测上方一致。
- 索引安全：`prev[i]` 两边长均为 stride；`curr[i-bpp]`/`prev[i-bpp]` 均有 `i>=bpp` 守卫；无越界路径。
- 1×1 全零灰度：行 filter=0、像素字节 0 → `reconstruct(0,0,1,0,…)=0` → `gray[0]=0` → `0/255f=0.0`（L251），与测试期望一致。
- 编码器字节合法性：签名 8 字节 ✓；IHDR 13 字节、bitDepth=8、interlace=0 ✓；`Deflater()` 默认 zlib 封装，匹配 `Inflater(false)`（L220）✓；CRC 写 0 占位，解码器不校验 CRC（L157 注释），对本自测口径不假绿。
- 残留风险：L219-229 单次 `inflater.inflate(raw)` 后比对 `n != raw.size`，未写 `needsInput()/finished()` 循环；多块 deflate 短读场景存在误拒可能（静态未能排除）。
