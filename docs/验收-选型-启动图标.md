## 3. 选型结论：**选中 A · 绢帛墨山**

**A 最符合全 App**：绢帛底 + 墨爆碎屑 + 双层 3D 隆起山 + 暖金笔意线，四重对齐项目美学口径（绢帛军图 / 墨爆粒子 / 地形隆起 / 暖金辉光）；CardTokens 五色全部出场，噪点参数直取卡片基座；圆角端点语言对齐 77 图标；双层山剪影在 72px 仍可辨；两个派生色均有 lerp 血缘、无裸 HEX。

- **淘汰 B**：① 启动器再放第三枚五角星，与既有书签星、党史星家族识别冲突；② 黑金金星徽章重踏已被 F-73 废除的旧主图标"玻璃金星"造型空间；③ 山体/地形语义缺席，气质偏通用徽章，偏离绢帛水墨书卷主线；④ 卡片阴影 token `shadowHover` 越界复用。
- **淘汰 C**：① 8 层 + 半透明玻璃 + 柔边光斑，合成链路最长、返工面最大；② 72px 下磨砂与光斑坍缩后质感落差最大，旧版自适应图标玻璃渲染一致性尚待真机验证（对比表:19 自陈）；③ 金边青玉牌偏通用玉牌，与水墨册页主线关联弱于 A。

## 4. 第③段写码前置硬点（摘自 A 规格）

1. 画布 108×108dp，背景层铺满四边；前景主体收进 72×72dp 安全区 [18,90]dp；主峰与金点再收进圆心 (54,54)、r=33dp 可见圆。
2. 五档密度精确 48 / 72 / 96 / 144 / 192 px，正方形，矢量按 108dp 等比缩放，不按密度重画造型。
3. 色值仅取 `cardPaper 0xFFF7F1E6 / ink 0xFF1A1410 / stoneBlue 0xFF3A6B66 / cloudGray 0xFF9B9687 / warmGold 0xFFD4A54A`；派生 `iconMountainFar=stoneBlue→cloudGray lerp35%`、`iconMountainNear=ink→stoneBlue lerp20%`；禁表外裸 HEX；`cinnabar` 不取用。
4. 坐标：主峰顶 (54,40)、左足 (26,80)、右足 (82,80)；远山峰位 (36,64)、(66,62)；金线 (22,60)→(50,58)→(76,56)，线宽 1.2dp，圆角端点/拐点，末端金点 (78,55) r=1.4dp。
5. 墨爆碎屑 8–10 粒、半径 0.8–2.0dp 固定种子；细丝 3–6dp×0.6dp、alpha 0.5；噪点复用 `noiseGrid 2dp / noiseAlpha 0.03f / noiseSeed 4102517L`。
6. monochrome 层：仅留近山剪影 alpha 1.0、远山剪影 0.55、金线点 0.8；丢弃纹理/碎屑/薄雾/渐变辉光；中性墨色由系统主题着色。
7. 三态：正常全量；按压由启动器压暗 10% 后近山与绢帛底轮廓仍可辨；主题单色模式形状不变、不自带第二套配色。
8. 48px 坍缩：碎屑 ≤3 粒或整组丢弃，纹理/薄雾丢弃，两山并双层实心剪影；金线不足 1.5px 简化为暖金实心折线；不重做 `ic_launcher_small`。
9. 对比度：近山墨 vs 绢帛底 ≥7:1，远山青 vs 绢帛底 ≥4.5:1，金线局部 ≥3:1；背景固定纸白兜底。
10. 收口判据：主体外包络 ≤72dp 不越安全区；squircle/正圆/圆角方三掩膜四角不露透明底；全图无红日、月牙、印刷/楷体字标、圆形印章、A~M 字母标、副图标。
