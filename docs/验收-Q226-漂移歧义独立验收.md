## 三、二阶影响：AMBIGUOUS 不计失联是否会掩盖"改代码导致锚点失效"

### 3.1 反例构造

- 场景：engine 那份 `Pathfinder.kt` 里的 `RoutePlanner` 被后续重构删除，但报告锚点一直写短名 `Pathfinder.kt`（行 5）（仓内另有 terrain 同名文件）。
- 现状代码路径：`resolve()` 在基名歧义时直接返回 `AMBIGUOUS:` 串，`check_anchor` `:141-142` 短路返回，**两份候选文件都不打开**，符号是否还在根本不核对。
- 对照实验（副本内直测）：同一个已消失符号 `LostSymbol`，分别走全路径锚点与短名歧义锚点：

```
全路径 engine + 无 LostSymbol -> ('MISSING', '符号全文件失联')
全路径 SoloResolver + 无 NopeSymbol -> ('MISSING', '符号全文件失联')
短名 Pathfinder + 无 LostSymbol -> ('AMBIGUOUS', '同名多文件需写全路径：app/src/main/java/map/crossing/engine/Pathfinder.kt / app/src/main/java/map/crossing/terrain/Pathfinder.kt:Pathfinder.kt')
```

### 3.2 结论

会掩盖，且掩盖有两条路径：

1. **符号双失被歧义吞掉**：两份同名文件里的目标符号都被删，短名锚点仍记 AMBIGUOUS，不进 MISSING、不计失联；棘轮看不出符号已失效。全路径锚点同样的情况会判 MISSING 并计入失联（对照实验第一行）。
2. **单份删失也无法定位**：符号只在真实目标文件被删、另一份同名文件仍有同名符号时，短名同样停在 AMBIGUOUS，雷达不会指出"engine 那份已无此符号"，只给"补全路径"的通用提示。

改动方向是对的——旧实现静默取首条会假 OK / 假 MISSING；但 AMBIGUOUS 目前只解决"名字分不清"，没有顺带做"候选文件符号 triage"。建议（待总控裁决，本单不改脚本）：歧义时遍历候选文件核符号，全部候选均缺该符号则降级 MISSING；至少一份存在则保留 AMBIGUOUS；或把 AMBIGUOUS 数量纳入棘轮第二道护栏，允许上涨告警而非完全不设防。

## 五、新发现问题

1. AMBIGUOUS 短路不核符号，符号双失可被掩盖（待裁）：`:141-142` 歧义分支直接返回，两份候选均不打开；目标符号在两份候选全被删仍记 AMBIGUOUS，不进 MISSING、不计失联（对照 3.1 反例）。建议歧义时遍历候选做符号 triage，全缺降级 MISSING；或 AMBIGUOUS 单列入棘轮告警。
2. AMBIGUOUS 数量增长不被棘轮护栏拦截（待裁）：`:353` 棘轮只比 `bad = MISSING + DEADFILE`，`:358-364` 不看 AMBIGUOUS；同名文件增多或存量锚点短名化导致 AMBIGUOUS 上涨时 CI 仍 PASS。建议基线增设 ambiguous 上限或单列增长告警。
3. `check-drift.py` 无内置 `--selftest` 回归夹具（已入队）：脚本内 grep 不到 selftest 分支，OK / DRIFT / MISSING / DEADFILE / AMBIGUOUS / narrowed 六条通路无机内夹具；本次验收样本只留在 `/tmp/q226`，主仓无回归保护。属 `check-selftest-coverage.py` 报告的 26 条历史欠账之一，建议补六条双向夹具。
4. 后缀消歧按 `endswith` 比对，未做路径段对齐（待裁）：`:128` `h.endswith(path)` 以字符串后缀收敛；若锚点路径段书写不完整或存在互为后缀的目录名，可能误收敛到非预期候选。当前合成样本未复现误收敛，列观察项；建议消歧按路径段拆分后逐段对齐。
5. 跨模块并发改造留痕：验收期间门禁 56 `check-lock-rule.py` 工作区一度出现 `_whitelisted` 未定义 NameError，复测已由并发改造方收口为 `LOCK-RULE: PASS（现行规则无旧锁口径裸句）`（已闭环）；本单未改 56，仅记录该瞬态，后续以 56 属主单为准。
