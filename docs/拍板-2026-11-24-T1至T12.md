## 3. T6 硬指标专节（本次核心：两项都必须可机械核验）

### 3.1 子项①【地球仪太阳镜面高光】

- **条文出处**：`切片-19-3D地球仪细节.md:32`（镜面高光＝太阳光在海面上的反射，shader 算太阳方向 × 法线，高光区一道白色镜面亮斑，位置随太阳移动）；`切片-19-3D地球仪细节.md:51-52`（太阳位置按真实 UTC 时间自动算）；`切片-20-3D沙盘与地球仪合并.md:39-40`（太阳光方向 × 法线 → Phong 漫反射 + specular；海洋格 → 基于太阳方向的镜面高光）；`切片-20-3D沙盘与地球仪合并.md:59`（镜面高光＝太阳反光）。
- **验收级别**：L1 接线（太阳方位参数真进 shader 光照计算）＋ L2 单测/渲染帧断言 ＋ L3 契约（specular 项＝太阳方向×法线逐字对上 `切片-20:39-40`）；L4 真机不强制（`立项规则.md:12`，用户已定不用真机）。
- **可测断言**：①给定太阳方位角与仰角输入，渲染帧高光中心像素落在指定经纬窗口内（窗口阈值随地球仪投影换算，写入 DoD）；②帧亮度峰值角向断言：高光峰值角向与太阳方位角偏差 ≤ 阈值；③太阳移动后高光随之移动，两帧峰值位移方向与太阳方位变化一致。
- **失败即 FAIL**：高光位置不随太阳方向/时间变化；峰值角向偏差超阈值；海洋格无 specular 项；任一断言不成立即 FAIL。
- **兜底要求**：shader 采样失败或低帧率时降级为静态高亮斑（对标 `切片-03-设计token与四层框架.md:322`「保持 60fps，否则降级到静态」）；夜间暗半球不强行画高光；不得空白、不得崩溃。

### 3.2 子项②【章节氛围剪影/粒子】

- **条文出处**：`切片-03-设计token与四层框架.md:101`（章节氛围 `particle field` 水墨轮廓粒子，《城濮》→ 战场剪影）；`切片-09-阅读页竖排.md:7`（读《城濮之战》→ 远处极淡水墨战场轮廓粒子，不是图是粒子勾勒）；`切片-09-阅读页竖排.md:14`；`切片-09-阅读页竖排.md:19`；`切片-03-设计token与四层框架.md:322`（阅读页背景水墨氛围粒子，极淡、不高于 #000 8%；保持 60fps，否则降级到静态）；`落文-原文-05-缺项清单.md:46`；`落文-原文-07-四层框架应用.md:20`。**郑伯克段母子对峙轮廓**：切片无独立轮廓条文，系本轮用户点名的第二例；条文粒度＝按章节配氛围轮廓粒子，母子轮廓素材随该章节数据兜底。
- **验收级别**：L1 接线（切章 → 氛围层切换）＋ L2 截帧断言 ＋ L3 契约（氛围层＝粒子勾勒非位图，对上 `切片-09:7`）；L4 真机不强制。
- **可测断言**：①进入点名章节（城濮之战 / 郑伯克段）后截帧，帧内该章氛围层可见像素占比 ≥ 阈值（极淡水墨，不高于 #000 8%，对上 `切片-03:322`）；②轮廓匹配：粒子勾勒轮廓与该章氛围层参考轮廓匹配度 ≥ 阈值；③切到无氛围层配置的章节时回落通用淡水墨背景，不留上一章残留。
- **失败即 FAIL**：进入点名章节后帧内无该章氛围层可见像素；氛围层用整幅位图而非粒子；上一章轮廓残留到下一章；占比超 8% 抢夺正文注意力；任一成立即 FAIL。
- **兜底要求**：章节轮廓数据缺失/离线时，回落通用淡水墨粒子层或静态背景（`切片-03:322` 静态降级）；素材缺失走占位粒子云，不空白、不崩溃；低端机帧率掉线时降级静态，不得拖垮正文 60fps 排版。

### 3.3 为什么这两项必须机械核验（机制解释）

用户原话：「如果不进验收，等于灰色地带，后面大概率不做。」不进验收硬指标的效果项，排期压缩时首先被砍；而「观感好不好」是主观描述，验收代理无法机械复核，等于没有 DoD。故两项必须落成截帧/像素/单测可断言的硬指标：有输入（太阳方位 / 章节标识）、有帧证据（像素占比 / 峰值角向 / 轮廓匹配）、有明确 FAIL 判据与兜底迂回，不留灰色地带。
