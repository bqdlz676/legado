# 片段 15 · 根构建文件 + app/src 包树抽样

## 这个目录有什么
- 模块（settings.gradle）：`:app`、`:modules:book`（Java epublib，EPUB 解析保留）、`:modules:rhino`（18 kt，JS 引擎保留）、`:modules:screenshot`（5 kt，Paparazzi 独立模块）；`modules/web` 是 21 vue + 30 ts 的旧 WebView 管理前端，未进 Gradle include。
- 规模实测：main 1393 kt / 约 23.7 万行；test 588 kt、androidTest 64 kt；`@Test` 源码计数 3370，CI 基线断言 3185。ui 746 文件 14.5 万行（book 251/5.96 万、widget 90、map 104、main 65、rss 35、association 39…）；help 208 文件 3.67 万行；model 66、data 76、service 25。
- 新栈包：help/bubble（C2 气泡解析）、help/chrono（C1 纪年纯逻辑）、help/dict(D1)/person(D2)/place(D3)/allusion(D4)；ui/components（Ink 系列组件 + token 收口 + compat/contract）；ui/book/read/vertical（V1 分页引擎 11 文件 1099 行）；ui/card 14 张卡；ui/map 拆 crossing/globe/replay/sandbox/terrain；globe 下 render 含 SoftwareRasterizer/RenderPipeline/Framebuffer（JVM 软渲染）+ host/mesh/scene/terrain/offline。
- 保留的旧 Legado 引擎：ui/book/read/page（PageView/ContentTextView/AutoPager/entities/HighlightDraw）；model/analyzeRule、jsSource、webBook、localBook、remote、rss；data/dao + AppDatabase（DB/DAO 允许复用）。

## 发现的问题
- 新旧双轨并存：assets/map 仍留 three.html/battle.html/relation WebView 页，globe 又另起一套 JVM 软渲染；54 个 Activity 继承 AppCompatActivity/BaseActivity，177 个文件引用 Binding，194 个 XML layout，50 个文件触 WebView；MainActivity 仍用 FragmentStatePagerAdapter（已废弃）+ ViewPager + Material BottomNavigationView，文件头 `@file:Suppress("DEPRECATION")`。
- 占位/契约空壳：ui/splash、ui/motion、ui/perf 各只有 contract 子目录与参数对象，无实现；modules/book 仅 Java 解析、modules/web 是不参与编译的 Vue 工程；197 处 TODO/FIXME/legacy 标记散在 main。
- 构建残留：release/debug 均 `minifyEnabled false`（R8 从未在开启态跑，proguard 反射/JS 桥裁剪风险未解）；viewBinding 仍开；签名口令 `luowen2026` 明文写进 app/build.gradle；assets 116M 全量进包，与"按需下载+预缓存"目标未对齐。
- 空模块/死目录：settings 列了 `:modules:book` 与 `:modules:rhino`，book 是 Java 库、web 未 include；build 产物未入库（git ls-files 中 /build/ 为 0），属干净项。

## 值得肯定
- 新栈数据层边界干净：D1~D4/C1/C2 全部纯 Kotlin/JVM、不依赖 Context、不碰 UI，对外签名冻结（getChar/wordAt/Chronology/layout/hitTest 等），单测可直接跑；每条档案强制带来源 PersonSource/PlaceSource，无出处注册即拒。
- 组件 token 收口在 ComponentTokens/ComponentPalette/ComponentState，不包裹 MaterialTheme、不取 Material colorScheme，颜色显式传入；分页引擎门面只暴露 layout/hitTest/invalidateCache，测量/缓存/分页内聚在 vertical 包，不反向依赖旧 page 引擎。
- 地球仪门面 GlobeController 收口手势/回放/网络/快照，场景逻辑与渲染后端解耦，注释明示后续可换后端；高程采样对空栅格/尺寸不符/NaN 全兜底返回 0.0，不抛异常不出 NaN。
- 保留范围克制：明确复用 DB/DAO、网络、规则解析、偏好、model；丢弃的是旧 XML 界面与编排，解析/分章/分页内核留下，符合规格 §3.4。
