# 规格候选-启动图标-C · 磨砂墨玉

> 流水线位置：F-73 三段流水线第①段「设计候选」。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；现有 `res/mipmap-*/ic_launcher*` 资产维持作废状态，待选型通过后由新链路替换。

## 1. 目的与用户可感效果

- **设计主张**：一枚磨砂毛玻璃墨玉牌悬浮在绢白卡纸上，牌内一座隆起山丘、脊线描金——把全 App 的「backdrop-blur 毛玻璃」材质与 3D 地形隆起口径收进图标，是三候选中材质层次最丰富的一枚。
- **第一眼像什么**：在桌面/设置列表里，像一方半透的青玉镇纸压在宣纸上方，能看到玻璃厚度、磨砂颗粒与一道斜光，温润而不张扬。

## 2. 画布几何

| 项 | 口径 |
|---|---|
| 自适应图标画布 | 108×108dp，背景层铺满整幅，不留透明角 |
| 安全区 | 玻璃方块外包络约束在中央 72×72dp（x/y ∈ [18, 90]dp）；牌内山丘与金脊线收进 r=33dp 可见圆内 |
| 掩膜口径 | 兼容 squircle / 正圆 / 圆角方；纸白背景铺到四边；玻璃方块自身圆角 14dp 与系统掩膜拉开层次，避免被圆掩膜切成整圆 |
| 密度实拍尺寸 | mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 px；矢量坐标按 108dp 等比缩放 |
| 圆角 | 牌体圆角 14dp（对齐 `CardTokens.cardRadius` 16dp 口径略收）；内部山丘脊线转角圆角 |

## 3. 造型逐部件坐标（108dp 画布，原点左上）

**背景层（background）**
- B1 纸白衬底：整幅 108×108 矩形，填 `CardTokens.cardPaper`；覆 `CardTokens.ink` @ `CardTokens.noiseAlpha` 的 2dp 网格绢粒，种子复用 `CardTokens.noiseSeed`。

**前景层（foreground）**
- F1 磨砂玻璃牌：圆角矩形 x=22, y=22, 宽 64, 高 64，四角半径 14dp；填 `iconJadeGlass`（§4 派生色）；牌内覆磨砂颗粒：`CardTokens.cloudGray` @ `CardTokens.noiseAlpha`，仅在牌体裁剪区内出现。
- F2 牌体描边：沿 F1 圆角矩形路径描边，线宽 1.2dp，`CardTokens.warmGold`，alpha 0.9；不画外投影。
- F3 后山脊：石青色山丘剪影，双峰位 (44, 48)、(64, 52)，山脚 y=72，左右足 (28, 72)、(76, 72)；填 `CardTokens.stoneBlue`。
- F4 前山脊：墨色主山丘，峰顶 (52, 44)，左足 (30, 76)，右足 (74, 76)，坡面贝塞尔收出 3D 隆起；填 `CardTokens.ink`。
- F5 金脊线：路径 (44, 47) → (52, 43) → (60, 48)，线宽 1.1dp，`CardTokens.warmGold`，圆角端点/拐点；只描前山脊受光棱线，不绕整座山。
- F6 斜向光斑：椭圆位于牌体右上区，中心 (66, 36)，长轴 26dp、短轴 10dp，旋转 -30°；填 `CardTokens.warmGold`，alpha 0.18，柔边衰减；模拟毛玻璃上的一道斜光。

## 4. 色值（全部挂既有 token；新增色写明派生关系）

| 部件 | 色名 / token | 取值与派生关系 |
|---|---|---|
| 衬底 B1 | `CardTokens.cardPaper` | 既有 `0xFFF7F1E6` |
| 绢粒 B1 | `CardTokens.ink` @ `CardTokens.noiseAlpha` | 既有 `0xFF1A1410`，alpha 0.03f |
| 玻璃牌 F1 | **新增** `iconJadeGlass` | 由 `CardTokens.stoneBlue`（`0xFF3A6B66`）向 `CardTokens.ink` lerp 25% 得到：石青压暗成青玉色，保留玻璃半透明的冷润感，不新造裸 HEX |
| 磨砂颗粒 F1 | `CardTokens.cloudGray` @ `CardTokens.noiseAlpha` | 既有 `0xFF9B9687`，alpha 0.03f |
| 描边 F2 | `CardTokens.warmGold` @ 0.9 | 既有 `0xFFD4A54A` |
| 后山 F3 | `CardTokens.stoneBlue` | 既有 `0xFF3A6B66` |
| 前山 F4 | `CardTokens.ink` | 既有 `0xFF1A1410` |
| 金脊线 F5 | `CardTokens.warmGold` | 既有 `0xFFD4A54A` |
| 光斑 F6 | `CardTokens.warmGold` @ 0.18 | 既有 `0xFFD4A54A` |
| 禁用色 | — | 不取 `CardTokens.cinnabar`；玻璃不做白色高光反射，不引入色板外的青绿亮色 |

## 5. monochrome 单色层派生规则（Android 13+ 主题图标）

- **保留形状**：F1 玻璃牌圆角矩形轮廓（转为同色描边或半填充块）、F2 描边、F3/F4 双层山丘剪影、F5 金脊线转为同色实心棱线。
- **丢弃**：F1 磨砂颗粒、F6 斜向光斑、玻璃半透明层次、所有柔边衰减。
- **层次用 alpha 表达**：牌体填充 alpha 0.25（暗示玻璃块）；前山 alpha 1.0；后山 alpha 0.55；描边与脊线 alpha 0.8。单色层为中性墨色，由系统主题着色。
- 单色层几何与前景层一致；系统着色后牌体轮廓与前山主峰仍须可辨。

## 6. 三态

| 态 | 处理 |
|---|---|
| 正常态 | 按 §3/§4 全量绘制 |
| 长按/按压态 | 启动器系统自动压暗，本候选不另画按压造型；声明：压暗 10% 后玻璃牌与纸白衬底仍可分辨，前山轮廓不丢 |
| 主题图标单色模式 | 形状不变（§5 单色层），颜色全部由系统主题提供 |

## 7. 边界与降级

- **mdpi 48px 坍缩处理**：F1 磨砂颗粒丢弃；F6 光斑丢弃；F3 后山与 F4 前山合并为双层实心剪影；F5 金脊线若不足 1.5px 宽则简化为峰顶一小段暖金实心折线；F2 描边保留（牌体边缘识别依赖它）。对照预览 `C-preview-72.png`。
- **超小尺寸（通知栏 24px）**：不复用本全量图标；副图标 `ic_launcher_small` 按 F-46 作废不重做；后续若需要，另立规格取牌体 + 前山单色剪影。
- **对比度下限**：前山墨 vs 玻璃青玉 ≥ 4.5:1；玻璃牌 vs 纸白衬底 ≥ 3:1（保证牌体轮廓在浅桌面上成立）；金脊线 vs 前山墨 ≥ 3:1。深浅主题下衬底固定纸白；若系统强制深底，牌体描边与前山剪影兜底识别。
- **空数据/异常**：静态资产，无运行时数据依赖；生成失败不得回退现有作废 PNG。

## 8. 与全 App 的一致性对照

| 对照项 | 结论 |
|---|---|
| CardTokens 六色 | 复用 `cardPaper / ink / stoneBlue / cloudGray / warmGold` 五色；`cinnabar` 不取用；一个派生色 `iconJadeGlass` 写明由石青向墨 lerp 25% |
| 77 枚功能图标风格 | 复用圆角端点/拐点口径（金脊线、描边转角）；牌体描边 1.2dp 对齐图标细线语言；填充式牌体属自适应图层资产，不套用线性图标「无填充」铁律，差异显式声明 |
| 启动动画 / 沙盘口径 | 双层山丘呼应 3D 地形隆起与沙盘高程层次；金脊线呼应启动动画「细暖金线扫过」的笔意；磨砂颗粒与卡片宣纸颗粒同参数 |
| 卡片基座材质 | 毛玻璃方向对齐切片-03「backdrop-blur 茶色毛玻璃遮罩」；牌体圆角 14dp 对齐 `cardRadius 16dp`；噪点复用 `noiseGrid / noiseAlpha / noiseSeed` |
| 动效血缘 | 静态图标不自带动画；后续入场 spring 沿用 `cardSpringDamping 0.80f / cardSpringStiffness 360f` |
| 不冲突项 | 主体不用暗铜 `#8B6914`；牌内不出现文字；山形不与 A 候选共用同一条山脊路径（A 为单层主脊 + 远山，C 为牌内双层剪影） |

## 9. 逐条可测验收判据

1. 玻璃牌外包络 64×64dp，落在 [22, 86]dp 区间，整体不越出 72dp 安全区；牌内山丘全部收进 r=33dp 可见圆。
2. 牌体圆角半径 14dp；描边线宽 1.2dp，沿圆角矩形闭合路径无断点。
3. 全图色值仅取自 §4 表：既有 token 五个 + 派生 token 一个；逐色可回查 `CardTokens.kt`；无表外裸 HEX。
4. 五档密度图尺寸精确为 48 / 72 / 96 / 144 / 192 px，正方形。
5. 背景层铺满 108×108dp，三种掩膜下四角不透透明底。
6. monochrome 层只含牌体轮廓、双层山剪影、脊线；无颗粒、无光斑；牌体 alpha 0.25、后山 0.55、描边/脊线 0.8 可量。
7. 48px 档预览（`C-preview-72.png`）中牌体与前山轮廓可辨，颗粒/光斑已按 §7 丢弃。
8. 前山墨 vs 玻璃青玉 ≥ 4.5:1；玻璃牌 vs 纸白 ≥ 3:1；金脊线 vs 前山墨 ≥ 3:1。
9. 全图无被否决元素：无红日、无月牙、无印刷体/楷体字标、无圆形印章、无 A~M 字母标、无副图标。
10. 金脊线端点/拐点圆角；光斑为柔边椭圆，无硬边轮廓；牌内不画外投影。
