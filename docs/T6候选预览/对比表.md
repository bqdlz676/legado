## 二、同 pair 真实差异（非换色版）

### 地球仪高光 A vs B

| 维度 | A 离线贴图 | B 实时片元 |
|---|---|---|
| 光照计算位置 | 打包期烘焙粗糙度 / 微法线灰度图，运行时按太阳经度旋移 UV | 设备端逐像素 `Blinn-Phong specular + Fresnel`，半程向量 / 视线向量逐片元算 |
| 近距表现 | 碎闪弱，海面偏平滑 | 微法线扰动碎闪 + 掠射边薄光，真实感强 |
| 前置依赖 | 无新渲染层，宿主画布叠层即可落地 | 依赖真机片元渲染层先行（现状查证 #3：软渲染目前只做覆盖+深度） |
| 失败回退 | 本身即 B 掉线 / 低端机的回退目标 | 降档顺序终点回到 A 的静态光斑 |

### 章节剪影 A vs B

| 维度 | A 分层位图 | B 程序化 Path |
|---|---|---|
| 轮廓来源 | 每章预切分层位图（远山 / 中景 / 尘烟），mask 可比对 | 地标点表 + 关键词程序化生成折线 / 多边形，固定种子 |
| 叙事辨识度 | 高：车阵、双人对位为实心剪影，IoU 可核验 | 中：抽象折线 + 飞白，复杂场景只能概括 |
| 资产成本 | 每章一张位图，长尾章节只能落通用层 | 零位图，变体按标题无限生成，包体零增长 |
| 粒子角色 | 沿轮廓游走的视差微粒 | 墨爆迸出 → 回聚线周，继承启动动画墨爆语义 |

## 三、72px 小尺寸坍缩观察（对照 `-72.png`）

- A 高光：球体与金白斑点仍可辨，雾青环坍缩为边缘薄雾；辉光细节需 1024 档辨认。
- B 高光：球体与边缘菲涅尔薄光可辨，碎闪细节坍缩；丝带背景在小尺寸下偏灰带。
- A 剪影：山脊与战场密集块面可辨，车阵 / 单人细节坍缩为墨块；尘烟金色保留。
- B 剪影：两侧人物簇与山脊线可辨，飞白细丝与单粒金点基本丢失。

## 四、选型代理可直接追问的点

1. 片元渲染层排期是否先于高光 B 落地；若否，高光 A 是否作为远距 / 首版路径先行。
2. 首批章节资产预算：剪影 A 能覆盖几章具名轮廓；长尾章节通用层辨识度是否可验收。
3. 两例点名场景（城濮 / 克段）在 72px 与低端机档下的轮廓可辨性，需目检 `-72.png`。
4. 高光落在陆地的误亮斑用例（残缺覆盖图）、剪影同名章消歧失败用例，是否进验收集。
