## 一、三项逐条

### 1. clearWarnings 接生产复位点

**验收原文**（验收-回放分发返工.md §三.1 / 判据 4，原文 :64、:118）：`clearWarnings` 无生产调用方——全 main 树 grep 仅命中定义与 KDoc，唯一调用点是测试；外部注入导演实例跨战役复用时，旧告警残留在台账内，壳层 `lastOrNull()` 可能展示上一场战役的旧告警。

**复用路径排查**：全 main 树 grep `ReplayDirector(` / `ReplayScreenHost`，回放域内唯一持有导演的生产入口是 `ReplayScreenHost`（`ReplayScreen.kt:46`）。内部兜底导演由 `remember(resolvedElevation)` 新建（`ReplayScreen.kt:57-59`），一场战役一个导演；外部注入参数 `director`（`ReplayScreen.kt:47`）是唯一可能跨战役复用同一实例的路径。main 内当前尚无导航装配方（既有 F-73 骨架观察，验收 §三.3），故宿主装配层暂无第二入口可挂。

**改动**：
- 入口 `app/src/main/java/io/legado/app/ui/map/replay/ReplayScreen.kt:46`（`ReplayScreenHost`）→ 导演解析 `ReplayScreen.kt:46-59` → 复位调用 `ReplayScreen.kt:46`（`activeDirector.clearWarnings()`，位于 `LaunchedEffect(activeDirector)` `:64` 首句）。
- 修法：effect 以导演实例为键，仅在首次挂接或实例替换时复位台账；同实例重组不重启 effect，帧循环内累计的告警不会被每帧清空。内部 remember 新建的导演台账本为空，复位为 no-op。

### 2. SET_INTENT 非法标签记告警 + 明确落实

**验收原文**（验收-回放分发返工.md §三.4，原文 :121）：`Intent.fromLabel` 对 null / 未知标签回落 ADVANCE，`SET_INTENT` 分支未对非法标签记告警，与本批「不许静默」口径存在落差，属静默降级。

**改动**：
- `app/src/main/java/io/legado/app/ui/map/replay/BattleModels.kt:46-54`：删除旧 `fromLabel` 的 ADVANCE 静默兜底，改为 `fromLabelOrNull`（`:49`），未知 / 缺失标签返回 null；标签先 `trim()` 再 `lowercase()`。
- `app/src/main/java/io/legado/app/ui/map/replay/ReplayDirector.kt:279-290`：`SET_INTENT` 分支取 `Intent.fromLabelOrNull(event.value)`；返回 null 时记告警「事件「…」：SET_INTENT 意图标签非法（value=…），目标 … 未生效」，棋子原样返回（保留原意图，不写 ADVANCE）；合法标签照常 `withIntent` 落实。
- 修法口径与既有 `SET_TARGET` / `STRENGTH_CHANGE` 非法值分支一致：告警进台账、棋子状态不变、事件仍登记为已点燃不重复结算。
