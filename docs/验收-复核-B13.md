### 2.3 判据 3：合成兜底场真伪（PASS）

- 算法（`HeightRaster.kt:78-87`，纯函数，无 `Random` / 时钟 / 网络 / 外部状态）：
  - `x=col/n, y=row/n`
  - `layerA = sin(x·2π + seed)·0.5 + 0.5`
  - `layerB = sin(y·3π + seed·0.7)·0.5 + 0.5`
  - `valley = 1 - |y-0.5|·1.6`
  - `v = clamp(0.25·A + 0.25·B + 0.5·valley, 0.05, 0.95)`，像素 `= (v·255).toInt()`
- 种子：`CrossingRasterBridge.kt:110` `RASTER_SEED = 1207L`；`:107` 显式 `degraded = true` 传入。

- 口径备注：seed 进入的是正弦**相位偏移**，不是伪随机数种子；产出是平滑两层正弦缓丘谷地，与注释「两层正弦缓丘谷地」一致，不是噪声场。确定性成立。
