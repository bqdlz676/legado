## 维护规则

- 新建派单：先写本表再 `create_agent`；若 `create_agent` 返回并发已满，**状态改 PENDING 并保留原样范围**（不许缩范围）。
- 槽释放：每次 `wait_agent` 返回后第一动作＝取队首 PENDING 重派，重派前把状态改 RUNNING 并写实际 agent id。
- 完成：状态改 DONE，补"回执文件"列值（回执路径），不删行（留档防重复派）。
- 禁止：把 PENDING 项合并进其它派单；把"暂缓"写成状态（唯一合法状态＝PENDING/RUNNING/DONE/BLOCKED，BLOCKED 必须写阻塞原因与解除条件）。
