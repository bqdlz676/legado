## 一、裁决依据：暴露是「本回合行为事实」，下一回合重算，不粘性保留

### 1.1 规格原文回源

### 1.3 工程常识裁决

暴露（被看见 / 被接战 / 被诱出）是本回合发生的行为事实，其唯一消费面是两处「本回合要不要给伏击资格 / 伏击加成」的当场判定：

- 关隘设伏闸门：`IntentResolver.kt:58`，裁决本回合意图；
- 遭遇伏击闸门：`CampaignController.kt:615`，结算本回合遭遇战。

两处都是回合内决策，不扣兵力、不扣士气、不改移动力（已复核 `MoraleSystem.kt`、`CombatResolver.kt` 均不读 `exposed`）。粘性保留会让一支仅在历史某回合穿越过一次视线的军队永久失去伏击资格，与 B8R6「纯地形兜底保留隐蔽姿态」的分级意图直接冲突。

**裁决：采用「每回合开头复位 + 本回合事实重算」，不采用粘性保留。** 复位点放在回合推进入口 `step()`，与既有回合级临时状态 `moraleDowngradedThisRound` 的清零口径同位。

### 1.4 备选方案与反例评估

- 备选 A（粘性保留，现状）：反例——军队上回合误入视野环，本回合退入水带 / 密林纯地形兜底，`crossedSight=false`，却仍被旧 `exposed=true` 废掉伏击资格；分级收紧后的「地形-only 保隐蔽」在第二回合即失效。否决。
- 备选 B（每回合复位 + 本回合重算，本单采用）：反例「敌军持续在视线内盯梢，军队原地未动，下回合是否还算暴露？」——本口径下，只要本回合仍处于被观察事实中，行动链路会在本回合重新置真：FLANK 寻路 `crossedSight=true` 再置暴露；接战 `resolveEncounters` 每回合再置真；佯退由触发器每回合点燃才置真。持续暴露由「重复发生的事实」维持，不靠粘性标志。
- 已知粒度边界（不属本单扩面）：原地 HOLD 且仍在敌军视野环内的军队，当前三个置真源（降级穿越 / 接战 / 佯退）都不会为其置暴露；这是既有入账粒度，本单不改，登记到第八节未验证 / 挂账项。
- 反例「复位会不会冲掉本回合刚点燃的佯退暴露？」——复位在 `fireTriggeredEvents()` 之前执行（见第二节行号），触发器在复位之后点燃，本回合事件置真不会被清零冲掉。
- 反例「终局后再调 `step()` 会不会误复位？」——`step()` 开头 `status != ONGOING` 即早返回快照（`CampaignController.kt:263`），不进入复位块，终局快照保持最后姿态。

## 六、二阶 / 三阶推演

### 6.1 伏击 / 遭遇判定的跨回合行为变化

- 关隘设伏资格可逐回合恢复：上回合穿越视线暴露的军队，本回合脱离视线、退入地形兜底后，复位即重新满足 `IntentResolver.kt:58` 的 `!corps.exposed`，可再次转 AMBUSH；旧粘性口径下该资格被永久吊销。
- 遭遇伏击加成逐回合重算：`CampaignController.kt:615` 的 `ambushed` 只反映本回合姿态；上回合接战暴露不剥夺本回合的伏击 2× 首击资格。
- 持续暴露不靠粘性：敌军仍在视野内时，本回合 FLANK 路径 `crossedSight=true` 再置真；持续相邻则 `resolveEncounters` 每回合再置真；佯退只在事件点燃回合置真（`firedEvents` 去重，不重复点燃）。
- 三阶影响（决策链）：意图裁决在寻路之前执行，本回合 FLANK 路线穿越视线所置的暴露，本回合意图闸门已先行读完；这一既有回合内顺序本单未调整，复位不改变该顺序。暴露恢复后，军队可能在下一回合重新进入设伏 / 据守决策，敌方遭遇时面对的伏击概率回升——属预期行为修正，不构成平衡回归（暴露仍不扣兵力 / 士气 / 移动力）。

### 6.2 存档恢复后首回合暴露语义

- `saveBranch()`（`:765`）走 `Corps.copy()` 深拷贝，`exposed` 随分支存档整表回滚；`restoreBranch()`（`:776`）按存档拷贝回运行态（`:778`）。存档记录的是保存时刻的历史姿态，属历史快照字段，本单不在恢复路径强行清空。
- 恢复后首次 `step()` 开头即执行 `:273` 复位，首回合伏击闸门按「复位后的干净姿态 + 本回合事实」裁决；不会把旧时间线的暴露带回新回合。
- 视图层 `Corps.toView()`（`:968` 起）不下发 `exposed` 字段，存档 / 快照视图无可回滚的暴露标识；恢复路径无视图侧残留问题。

### 6.3 UI 名册视觉变化

- `grep -n "暴露|隐蔽|伏击" CrossingShell.kt` 仅命中节拍分类关键词表 `:1199`；名册标识只有 `routeDegraded` 驱动的「降级·绕行」，无独立暴露标识（既有设计，与 `docs/修复-降级暴露语义分级.md:157` 口径一致）。
