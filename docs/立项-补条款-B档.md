### 边界 1 · 数据缺失（战役 JSON / 高度图 / 回合数据为空或损坏）

- 命中判断：**工程推定，需用户拍板**。切片-07 全篇为视觉编排描述，未写数据为空/损坏时的回落路径；登记册:133 已列此缺口。
- 期望行为：战役数据缺失或解析失败时，回放页停在第一帧网格出生状态（`切片-07:23`「0-400ms：黑底上浮出金色网格线」），不进入棋子/箭头渲染循环；给出可回退到 2D 地图的入口，不白屏、不崩溃。
- 禁止做法：禁止用空棋子/空箭头占位硬渲染；禁止弹出系统级崩溃对话框；禁止在数据未就位时播溃散光屑（`切片-07:135`）或交战冲击环（`切片-07:173`）。
- 验收判据：构造空 JSON、缺高度图、回合列表为空三类用例，页面均不崩溃、不白屏，且可见 2D 地图回退入口；日志可回源到缺失的数据键。
- 证据锚点：`规格登记册.md:133`「S-07 战役数据/低帧率/断网回放降级边界」；`立项草案-批次B.md:27`「无战役数据/低帧率/断网回放的降级边界切片无原文」；`切片-07-3D战役回放.md:23`「0-400ms：黑底上浮出金色网格线（经纬网），线从暗到亮，像蚕丝被光照透」。

- 禁止做法：禁止超长文本一次性全量排版进内存；禁止为容纳长词条突破内存红线（词典 ≤15MB，`切片-08:78`）。
- 验收判据：构造超长章节与超长词条用例，阅读缓存峰值 ≤60MB、词典内存 ≤15MB；单页扫描 ≤80ms；界面无溢出截断崩溃。

- 验收判据：构造含子集外生僻字/异体字的文本，缺字以系统字体可见，无豆腐块，段落排版不塌。
- 证据锚点：`立项草案-批次B.md:31`「缺字回退、字体加载失败降级路径无原文」；`切片-14-字体系统.md:7`「CJK subset：unicode-range 分片，正文常用 2500 字首屏子集 ≤ 200KB。」

### 边界 2 · 权限拒绝 / 文件损坏（字体加载失败降级）

- 命中判断：**工程推定，需用户拍板**。草案B:31 明列字体加载失败降级路径无原文。
- 期望行为：子集字体文件缺失、损坏或读取被拒时，按 font-display: swap 口径先用系统字体排版，子集到位后再替换；标题 SemiBold 虽为首屏阻塞档，加载失败也必须落系统粗体，不允许 FOIT 白屏等待。
- 禁止做法：禁止字体未就位时长时间阻塞首屏（FOIT）；禁止单个子集失败拖垮其余四枚字体加载。
- 验收判据：摘除/损坏各子集文件用例，首屏均以系统字体可见，无白屏等待；字体到位后正文可回切 Noto 子集。
- 证据锚点：`立项草案-批次B.md:31`「字体加载失败降级路径无原文」；`切片-14-字体系统.md:7`「正文（宋体）Noto Serif SC font-display: swap，预载首屏子集 ≤ 200KB」；`切片-14-字体系统.md:7`「标题思源宋体 SemiBold 首屏阻塞，swap 不允许 FOIT」。

### 边界 3 · 并发点击 / 并发加载（启动期多子集并发与交互抢占）

- 命中判断：**工程推定，需用户拍板**。切片:7 分了首屏阻塞/延迟加载/按需加载三档，未写并发加载与用户先行交互时的抢占口径。

- 禁止做法：禁止延迟子集就位后引发整页 reflow 跳动；禁止按需字体在首次出现编号/数字时同步阻塞主线程。

- 证据锚点：`切片-14-字体系统.md:7`「注音小字 Noto Sans SC Light 10sp 延迟加载」；`切片-14-字体系统.md:7`「等宽（ID/编号）JetBrains Mono 按需加载」；`切片-14-字体系统.md:7`「数字/年份 Inter Tabular Nums 极小子集 only numbers」。

### 边界 4 · 极端尺寸（超大字号 / 超长数字编号串的字形回落）

## 六、S-15 · 全局动效铁律（spring）

### 边界 1 · 帧率掉线（含省电模式降级）

- 命中判断：**工程推定，需用户拍板**。草案B:32 明列低帧率/省电降级边界无原文；省电降级并入本类。
- 期望行为：低帧率或省电模式下，按优先级削减动效——先停 stagger 逐张延迟与悬浮微粒类装饰动画，保留点触反馈与页面转场最短时长；不可削减到无反馈状态。降级档位与帧率阈值拍板前不写死。
- 禁止做法：禁止掉帧时所有动画直接跳变无过渡；禁止省电模式下保留全量 stagger 拖垮续航。
- 验收判据：模拟低帧率/省电档，动效削减项可枚举回源；点触 120ms 反馈仍在；主线程无动画帧堆积。
- 证据锚点：`立项草案-批次B.md:32`「低帧率/省电动效降级边界无原文」；`切片-15-全局动效铁律.md:7`「点触反馈（InkButton）120ms」；`切片-15-全局动效铁律.md:7`「卡片浮入 stagger350ms each」。

### 边界 2 · 并发点击（快速重复点按的动效重入与打断）

- 命中判断：**工程推定，需用户拍板**。切片给了各项时长曲线，未写快速连点时动效重入/打断口径。
- 期望行为：点触 120ms 反馈可被下一次点按重置；气泡 250ms overshoot 弹出途中再次触发时，从当前进度衔接重放，不从零堆叠；Sheet/遮罩进出互斥，不并存两层。
- 禁止做法：禁止连点叠加多份气泡/遮罩实例；禁止 overshoot 回弹未结束又起新动画导致位移越界。
- 验收判据：快速连点 InkButton、气泡弹出途中重复触发、Sheet 快速开关三组用例，动效单路衔接，无多层残留。

### 边界 3 · 超长内容（超长列表 stagger 累积时长）

- 命中判断：**工程推定，需用户拍板**。切片:7 给 stagger 350ms each，未规定列表超长时的累积总时长上限。
- 期望行为：超长列表首屏可见项按 stagger 入场，屏外项不参与逐张延迟；可见项超过一定数量后 stagger 退化为批量同帧入场，总入场时长不无限叠加；数量阈值拍板前不写死。
- 禁止做法：禁止长列表数百张卡片按 350ms each 排到末尾长时间不入画；禁止滚动回看时重复播放入场 stagger。
- 验收判据：构造超长列表，首屏入场总时长有上限；滚动回顶不重复触发浮入动画。
- 证据锚点：`切片-15-全局动效铁律.md:7`「卡片浮入 stagger350ms each cubic-bezier(0.22,0.61,0.36,1)」。

### 边界 4 · 极端尺寸（大尺寸 Sheet / 遮罩的动效位移口径）

- 命中判断：**工程推定，需用户拍板**。切片给时长曲线，未规定大尺寸面板在大屏上的位移距离与形变口径。
