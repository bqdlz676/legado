## 四、二阶 / 三阶影响推演

### 4.1 二阶（引擎模块内）

- **降级粒度再细化**：改前 `rivers` 字段整体错位静默回落空表；改后补字段级 warning，`degraded` 由 warnings 非空驱动（`parser:90`），该场景从"静默降级"收紧为"明示降级"。行为方向是收紧，不影响既有合法素材：合法 JSON 不触发任何新分支。
- **装配链分层**：`assemble` / `assembleDegraded` 拆分后，正常路径构造参数与改前逐行一致（栅格兜底、投影、地形、寻路、己方阵营回退顺序未变）；`load` 签名、返回类型、`demo()` 入口均未动。
- **降级态可出快照**：`assembleDegraded` 空军队 → `instantiateCorps()` 空转、`seedIntel()` 空转；`snapshot()` 对空 corps map 出空列表，不 NPE（静态推演，真机未验）。
- **`degraded` 口径**：`controller.degraded = definition.degraded || raster.degraded || corps.isEmpty()`（`:93`）；空战役 corps 为空，降级标志必真；`warnings` 直通壳层（`:95`）。

### 4.2 三阶（跨模块 / 行为链）

- **调用方**：`grep` 全仓 main 源码，`CampaignController` 仅 `shell/CrossingShell.kt` 经 `demo()` 持有，当前无生产代码直接调 `load`；`load` 的兜底返回值主要服务测试源集与后续壳层接入。空战役下壳层若按 `corps` 非空假设渲染，需壳层域复核空态绘制（见交接 1）。

- **下游消费**：空河流 / 空山脊进 `TerrainMap` 与改前"整地形 catch 回退"形态一致；空军队不触发寻路 / 遭遇 / 情报播种。

### 4.3 反例与边界（先假设本单方案错误）

- **超长点列**：`ptsEl.asJsonArray.forEach` 逐点走 `guardedPoint`，**未设点数上限**；成千上万点的极端素材按 O(N) 累积 `Geo` 列表，内存随点数线性涨。`TerrainMap.rasterizeRivers` 同样逐条栅格化。本单未加点数护栏，列为遗留边界（交接 2）；现有守卫只保证单条畸形点不抛，不保证超大数组不耗内存。
- **OOM / 资源型错误**：`catch (t: Throwable)` 语法上覆盖 `Error`，但 OOM 发生后 JVM 堆状态不可靠，`assembleDegraded` 再申请 32×32 合成栅格也可能失败；本单不承诺 OOM 场景可恢复。降级装配的栅格尺寸固定 `GRID_N=32`，不随输入放大，是可控的最小分配。
- **UTF-8 乱码 / 非法编码**：`JsonParser.parseString` 对语法非法走顶层 catch 回落 fallback；乱码字符作为字符串值（title / reason 等）不影响解析，`strOrNull` 仅 trim 不做转码。若传入的 `String` 本身已在解码层损坏，属上游读文件 / 网络层职责，不在 parser 域。
- **坐标越界 0..1 / 经纬度越界**：守卫不钳制，沿用既有口径，越界由 `GeoProjection` 回收边缘格、地形层消费。
- **深层嵌套 COMPOUND 胜利条件**：`parseVictoryDef` 递归深度防护仍是既有遗留（验收报告 3.3 第 2 条），本单未展开。
- **合法素材误降级反例**：混合样例与六类畸形用例锁定降级方向；既有"合法最小战役"用例（`:182` 旧编号）仍断言 `degraded=false`、warnings 空，双向防漂移。

### 4.4 认知成本

- 新增两个私有装配函数：`assemble`（正常链）/ `assembleDegraded`（降级链），命名直白，分层理由写在函数注释；未引入新抽象类型、未改公开签名。
- parser 河流段由二态 if 改四态 `when`（缺失 / JsonNull / 非数组 / 数组），多一个分支，注释逐态写明回落文案；接手人对照 `guardedPoint` 注释即可理解点级守卫与条级守卫的分工。
- 剩余概念债：`jsonArray` 守卫本身不记 warning，字段级 warning 由各调用方自行补；目前仅 rivers 补齐，sides / diplomacy / events / ridges 仍静默（交接 3）。
