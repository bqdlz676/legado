# 规格候选-T6-B · 章节氛围剪影（程序化轮廓 Path + 墨爆粒子场）

> 流水线：F-73 三段流水线第①段设计候选。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；既有 `InkMoodView` 仅作参考、不复用（B7）。
> 硬指标归属（用户口径，非切片引文）：T6=A 档两项之二——章节氛围剪影/粒子：城濮战场轮廓、郑伯克段母子对峙轮廓。
> 规格锚点（逐字）：`切片-09:7`「远处极淡水墨战场轮廓粒子，不是图是粒子勾勒」；`切片-03:101`「水墨轮廓粒子（《城濮》→ 战场剪影）」；`切片-01:24`：炸开 40–50 粒「墨色碎屑」，「粒子飞散半径最大」60dp；`切片-03:322` 阅读页粒子 ≤40、60fps「否则降级到静态」；`切片-08`「笔画完成时一次性硬化成」Path 缓存，onDraw 耗时 ×10。

## 1. 作用域与触发条件

- **屏幕**：阅读页竖排正文层之下、宣纸底之上；中央 0.82 列宽保护区不进轮廓线。
- **时机**：切章回调到达后程序化重建 Path，硬化缓存；旧 Path 200ms 淡出、新 Path 250ms 淡入；离开阅读页释放 Path 点表与粒子场。
- **生命周期**：无位图资产；Path 在切章时一次性生成并缓存，翻页不重建。

## 2. 视觉描述（形态 / 层次 / 动效曲线 / 时长）

- 墨色折线勾出山脊 / 车阵 / 双人对位轮廓，笔画飞白断续，像毛笔在绢帛上扫出的草稿线；墨爆粒子从轮廓线迸出、飞到半径上限后缓慢回聚到线周，呼应启动动画炸散后回聚的瞬间。
- 暖金尘粒 2–3 粒点缀在轮廓转折点，不铺金面；线条圆角端点，对齐图标集线宽语言。
- 点名两例：**城濮**——旷野脊线 + 两侧车阵折角 + 战旗竖线；**克段**——高台横线 + 左右两个双人对位多边形，中间留白。
- 动效：迸出 / 回聚循环 3.2s 一轮；淡入 250ms `cubic-bezier(0.34,1.56,0.64,1)`，退场 200ms `cubic-bezier(0.4,0,0.6,1)`。

## 3. 逐部件参数

| 部件 | 尺寸 / 归一化位置 | 透明度 | 色值（回挂 token） |
|---|---|---|---|
| 山脊 / 车阵 Path | 节点 12–16 个；跨度 ≥ 屏宽 60%；线宽 1.2–1.6dp，圆角端点 | 峰值 0.30 | `CardTokens.ink`（`0xFF1A1410`） |
| 双人对位多边形 | 两个剪影高 ≤ 屏高 10%；中心距 ∈ 屏宽 25%–55% | 0.30 | `CardTokens.ink` |
| 墨爆粒子 | ≤32 粒；迸出半径上限 60dp；半径 1.0–2.6dp | 峰值 0.28 | `CardTokens.ink` |
| 暖金尘粒 | ≤8 粒；贴轮廓转折点缓慢漂移 | 0.20 | `CardTokens.warmGold`（`0xFFD4A54A`） |
| 高台 / 雾基线 | 一条横线，高 1dp | 0.12 | `CardTokens.cloudGray`（`0xFF9B9687`） |
| 飞白细丝 | 每轮廓 ≤3 条，长 3–6dp、宽 0.6dp | 0.50 | `CardTokens.ink` |

- 粒子配比：墨粒 : 金粒 ∈ [3:1, 5:1]；总数 ≤40（`切片-03:322`）。

## 4. 与太阳 / 章节数据的绑定方式

- **数据源**：`TextChapter.title` 关键词 + 内置地标点表（城濮：旷野脊线三点 + 两翼车阵点；克段：高台一点 + 双人两点）。
- **生成规则**：命中战场关键词 → 山脊 + 车阵折角；命中对峙关键词 → 高台 + 双人多边形；地标点不足 → 由标题字符数 + 固定种子生成伪随机山脊，种子固定不闪烁。
- **缺数据兜底**：无标题 → 不挂轮廓，仅纸底 + 噪点 + 暖光；地标点表缺失 → 退化为一条云灰脊线；Path 节点生成失败 → 不抛异常，落通用脊线。

## 5. 性能预算（明确上限）

- 每帧 draw：Path ≤3 条 + 粒子 ≤40 个圆点；无位图解码。
- 内存：Path 点表 ≤1KB/章；粒子场对象复用，零每帧分配；同时缓存当前章 Path 1 份。
- 生成预算：Path 重建仅在切章时发生，≤5ms；运行时只做位移动画。
- 帧预算：氛围层单帧 ≤2ms；阅读页 60fps 底线（`切片-03:322`）。

## 6. 降级与兜底（四种边界，不允许空白态）

- **无网络**：程序化生成不依赖网络；地标点表随包内置。
- **无章节数据**：标题缺失 → 静默保留纸底；点表缺失 → 云灰脊线兜底。
- **低端机**（线程数 <4 或 Android ≤8）：粒子减半至 20，墨爆迸出关闭，只留静态 Path。
- **帧率掉线**：连续 3 帧 <50fps → 粒子停摆、Path 静态；idle 3 秒无滚动 → 暂停动画，滚动恢复（`切片-03:330`）。Path 硬化缓存不随降级重建。

## 7. 可测断言（机械核验）

- D-1 城濮章山脊线跨度 ≥ 屏宽 60%；车阵折角 ≥2 处。
- D-2 克段章两轮廓中心距 ∈ 屏宽 25%–55%；中间留白带无墨色填充。
- D-3 粒子迸出半径 ≤60dp；墨粒 : 金粒 ∈ [3:1, 5:1]；总数 ≤40。
- D-4 轮廓线不进入正文 0.82 列宽区，保护区内氛围像素 ≤1%。
- D-5 切章后 12 帧内新 Path 可见；淡入 250ms 内 alpha 0 → 0.30。

## 9. 可测判据（P1…P10，含 FAIL 条件）

- P1 山脊跨度：城濮章脊线 ≥60% 屏宽；FAIL = 跨度 <60% 或无车阵折角。
- P2 对峙间距：克段章双人中心距 25%–55% 屏宽；FAIL = 重叠 / 间距 >55% / 中间被填充。
- P3 粒子上限：总数 ≤40、迸出半径 ≤60dp；FAIL = 超粒或半径超限。
- P4 金墨配比：墨 : 金 ∈ [3:1, 5:1]；FAIL = 金粒盖过墨色。
- P5 正文保护区：0.82 列宽内氛围像素 ≤1%；FAIL = 线条侵入正文。
- P6 Path 缓存：切章一次硬化，翻页不重建；FAIL = 每帧重新生成 Path 点表。
- P7 零分配：粒子对象复用；FAIL = 每帧新建粒子 / 路径对象。
- P8 idle 暂停：3 秒无滚动停摆；FAIL = 静置持续重绘。
- P9 掉线降级：3 帧 <50fps 冻结静态；FAIL = 掉线后仍跑墨爆循环。
- P10 token 合规：无色板外 HEX；FAIL = 出现未声明 lerp 的新十六进制。

## 10. 自我论证：为什么它最符合全 App

- 零位图资产、包体零增长，变体可按标题无限生成；Path 硬化缓存后运行时开销极低，最贴合阅读页 90% 停留时长的 60fps 红线。
- 墨爆语义直接继承启动动画的炸散后回聚，全站动效语言统一；程序化地标点把两例具名场景转成可测几何约束（跨度 / 间距 / 配比），验收可机械核验。

## 11. 它最可能被否掉的地方（自证反例）

- 反例一：程序化折线对城濮车阵、母子对峙的具象还原度天然弱于位图，远看可能只剩一条折线，辨识度争议最大；验收若要求一眼认出场景，本候选不达标。
- 反例二：伪随机山脊依赖固定种子，不同书名字数生成的轮廓差异小，长尾章节可能千篇一律。
- 反例三：墨爆回聚循环 3.2s 在静态阅读场景里仍属持续动画，idle 暂停若被用户翻页动作频繁打断，可能出现粒子状态跳变；需在交接清单标注状态恢复用例。
