- **cancelled ≠ failure**：实际样本 `711bf87` Verify `45873405915` 结论 `cancelled`（0 job、无测试结论）；历史 failure 样本如 `52a2ece` Verify `45816690884` 结论 `failure`。若把 cancelled 误判成 failure，会带队去查并不存在的失败用例；若把 failure 误判成 cancelled，则会把真红灯当成链路取消而漏修。
- **in_progress ≠ success**：实际样本 Package `45875636324` 在轮询 #0~#4（`18:32:39Z`~`18:38:34Z`）均为 `in_progress`，直到轮询 #5（`18:40:43Z`）才 `completed/success`。在飞期间写成「已通过」即假绿；边界口径：未终态必须写「仍在飞 + 最后状态与时间戳」，不许把在飞报成绿。
- 其他边界：`skipped` 不是失败（闸门未放行，无产物）；`success` 的 Package artifact 不等于已验真机可用性；Aggregate 计数 3658 不含 slow-bench 23 条，与 XML 全量 3681 是两个口径，不可混用。
