# 规格候选-启动图标-A · 绢帛墨山（绢帛墨印）

> 流水线位置：F-73 三段流水线第①段「设计候选」。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；现有 `res/mipmap-*/ic_launcher*` 资产维持作废状态，待选型通过后由新链路替换。
> 命名澄清：本候选名中的「墨印」**不是** F-46 作废的印章/墨印类圆形图标。全图无圆形印章、无印文、无文字；「墨」指水墨山峦与墨爆碎屑，方向属「绢帛军图 + 墨爆粒子 + 3D 地形隆起」。

## 1. 目的与用户可感效果

- **设计主张**：一张摊开的绢帛上，远山如黛、近山隆起，一道暖金笔意扫过山腰——把启动动画里「墨滴触底炸散 → 金粉回聚成山」的瞬间凝固成一枚静态图标。
- **第一眼像什么**：在桌面/设置列表里，像一方装裱在浅绢色卡纸上的微型水墨山水册页，安静、有纸感，而不是一枚通用几何 logo。

## 2. 画布几何

| 项 | 口径 |
|---|---|
| 自适应图标画布 | 108×108dp（Android Adaptive Icon 标准），背景层铺满整幅 108×108，不留透明角 |
| 安全区 | 前景全部内容约束在中央 72×72dp 方形内（x/y ∈ [18, 90]dp）；关键识别元素（主峰、金线端点）进一步收进以 (54,54) 为圆心、r=33dp 的可见圆内，保证 circle/squircle/rounded-square 掩膜下不被裁掉 |
| 掩膜口径 | 兼容系统 squircle（默认）、正圆、圆角方三种掩膜；背景层必须延伸到画布四边，掩膜外沿不露桌面壁纸 |
| 密度实拍尺寸 | mdpi 48px（@1x）/ hdpi 72px（@1.5x）/ xhdpi 96px（@2x）/ xxhdpi 144px（@3x）/ xxxhdpi 192px（@4x）；所有矢量坐标按 108dp 等比缩放，不按密度重画造型 |
| 圆角 | 图标外形圆角由系统掩膜决定，前景自身不画外框圆角；玻璃/卡纸感只通过底色与纹理表达 |

## 3. 造型逐部件坐标（108dp 画布，原点左上，圆心/峰心均相对画布）

**背景层（background）**
- B1 绢帛底：整幅 108×108 矩形，填 `CardTokens.cardPaper`（纸白 `0xFFF7F1E6`）。
- B2 绢丝纹理：复用 `CardTokens.noiseGrid`（2dp 网格）撒点，墨色 `CardTokens.ink`，不透明度 `CardTokens.noiseAlpha`（0.03f），固定种子沿用 `CardTokens.noiseSeed`；纹理只铺背景层，不压到山体上。

**前景层（foreground）**
- F1 远山脊：路径沿 y≈62→74 起伏，x 从 18 到 90，山体下沿落到 y=80；填「远山青」（见 §4 派生色 `iconMountainFar`）。整体高约 20dp，峰位 (36, 64)、(66, 62)。
- F2 近山主脊：主峰顶点 (54, 40)，左足 (26, 80)，右足 (82, 80)，坡面以两段贝塞尔收出 3D 隆起体积（左坡略缓、右坡略陡）；填「近山墨」（`iconMountainNear`）。山体最大外径：宽 56dp、高 40dp，完全落在 72dp 安全区内。
- F3 墨爆碎屑：8–10 粒墨色散点，分布在近山两坡 y∈[70, 84]、x∈[24, 84] 一带；圆粒半径 0.8–2.0dp 随机（固定种子），填 `CardTokens.ink`；其中 2–3 粒为飞白细丝，长 3–6dp、宽 0.6dp，`CardTokens.ink` alpha 0.5。碎屑总数对齐启动动画墨爆口径（40–50 粒为全屏量，图标内按比例缩到 ≤10 粒）。
- F4 暖金笔意线：路径 (22, 60) → (50, 58) → (76, 56)，线宽 1.2dp，`CardTokens.warmGold`，圆角端点/拐点（对齐 77 图标 1.5 线宽圆角口径，图标内略收细到 1.2dp）；线末端 (78, 55) 一粒金点 r=1.4dp，`CardTokens.warmGold`。
- F5 山脚薄雾：远山脚下 y∈[76, 82] 一条横向柔边带，`CardTokens.cloudGray` alpha 0.18，高度 4dp，只在远山与近山交界处出现。

## 4. 色值（全部挂既有 token；新增色写明派生关系）

| 部件 | 色名 / token | 取值与派生关系 |
|---|---|---|
| 绢帛底 B1 | `CardTokens.cardPaper` | 既有 `0xFFF7F1E6`，直接复用 |
| 纹理点 B2 | `CardTokens.ink` @ `CardTokens.noiseAlpha` | 既有 `0xFF1A1410`，alpha 0.03f |
| 远山 F1 | **新增** `iconMountainFar` | 由 `CardTokens.stoneBlue`（`0xFF3A6B66`）向 `CardTokens.cloudGray`（`0xFF9B9687`）lerp 35% 得到；用于后退层次，不新造裸 HEX |
| 近山 F2 | **新增** `iconMountainNear` | 由 `CardTokens.ink`（`0xFF1A1410`）向 `CardTokens.stoneBlue` lerp 20% 得到；比纯墨略偏青，保留墨的重量感 |
| 墨爆碎屑 F3 | `CardTokens.ink` | 既有 `0xFF1A1410`；细丝 alpha 0.5 |
| 金线/金点 F4 | `CardTokens.warmGold` | 既有 `0xFFD4A54A` |
| 薄雾 F5 | `CardTokens.cloudGray` @ 0.18 | 既有 `0xFF9B9687` |
| 禁用色 | — | 不使用 `CardTokens.cinnabar`（朱砂留给按压态阴影与阅读批注语义，图标不抢色）；不引入色板外的红/蓝/紫 |

## 5. monochrome 单色层派生规则（Android 13+ 主题图标）

- **保留形状**：F2 近山主脊实心剪影、F1 远山剪影（简化为一条脊线轮廓）、F4 金线与金点转为同色实心条/点。
- **丢弃**：B2 绢丝纹理、F3 墨爆碎屑（小尺寸下是噪点）、F5 薄雾柔边带、所有渐变与辉光。
- **层次用 alpha 表达**：近山剪影 alpha 1.0；远山剪影 alpha 0.55；金线/点 alpha 0.8；单色层整体为中性墨色（由系统主题着色，本层不写死颜色）。
- 单色层画布几何与前景层完全一致，不另起构图；系统着色后主峰轮廓仍须可辨。

## 6. 三态

| 态 | 处理 |
|---|---|
| 正常态 | 按 §3/§4 全量绘制 |
| 长按/按压态 | 由启动器系统自动压暗（标准 press overlay），本候选不另画按压造型；声明：前景主体在整体压暗 10% 后，近山与绢帛底之间仍保持可辨轮廓，不依赖额外描边 |
| 主题图标单色模式 | 形状不变（§5 单色层），颜色全部由系统主题提供；本候选不自带第二套配色 |

## 7. 边界与降级

- **mdpi 48px 坍缩处理**：F3 碎屑只保留 ≤3 粒或整组丢弃；B2 纹理丢弃；F5 薄雾丢弃；F1 远山与 F2 近山合并为双层实心剪影；F4 金线若渲染后不足 1.5px 宽，简化为山脊上一段暖金实心折线。对照预览 `A-preview-72.png`。
- **超小尺寸（通知栏 24px）**：不复用本全量图标；F-46 已作废的副图标 `ic_launcher_small` 不重做。若后续通知栏需要小图标，另立规格，仅取 F2 主峰单色剪影。
- **对比度下限**：近山墨 vs 绢帛底 ≥ 7:1（目标值，WCAG AAA 级文字对比度口径借用）；远山青 vs 绢帛底 ≥ 4.5:1；金线在山体上的局部对比 ≥ 3:1。深色/浅色主题下背景层均为纸白固定底，不随系统深浅色翻转；若系统强制深色壁纸，掩膜外沿由背景层纸白兜底。
- **空数据/异常**：图标为静态资产，无运行时数据依赖；生成脚本失败时不得回退到现有作废 PNG。

## 8. 与全 App 的一致性对照

| 对照项 | 结论 |
|---|---|
| CardTokens 六色 | 复用 `cardPaper / ink / stoneBlue / cloudGray / warmGold` 五色；`cinnabar` 刻意不取用（语义留给批注与按压阴影）。无新造裸 HEX，两个中间色均按 §4 由既有色 lerp 派生 |
| 77 枚功能图标风格 | 复用其「圆角端点/拐点」口径；金线 1.2dp 线宽对齐图标 1.5dp 的细线语言；本图标为填充式山水，不套用 77 图标的「无填充、无阴影、无渐变」铁律——该铁律约束的是 24×24dp 线性矢量图标，启动图标属自适应图层资产，差异在此显式声明 |
| 启动动画口径 | 墨爆碎屑数量/形态（圆粒 + 飞白细丝）呼应切片-01「墨滴炸散 40–50 粒」；暖金笔意线与金点呼应「金粉回聚、金线收束成点」；山体隆起呼应 3D 地形口径 |
| 卡片基座材质 | 绢丝纹理复用 `noiseGrid / noiseAlpha / noiseSeed`，与 `CardBase` 宣纸颗粒同一套参数，不在图标里另造噪点 |
| 动效血缘 | 图标静态不自带动画；进入桌面后的入场 spring 沿用 `cardSpringDamping 0.80f / cardSpringStiffness 360f`（属后续写码阶段口径，本规格不实现） |
| 不冲突项 | 不使用 77 图标默认暗铜 `#8B6914` 做主体色（该色留给线性图标默认态）；不与书架/发现/设置三 Tab 图标造型雷同 |

## 9. 逐条可测验收判据

1. 前景主体（F1+F2 合成外包络）最大外径 ≤ 72dp，任一像素不越出安全区 [18,90]dp 方形。
2. 主峰顶点 (54,40) 与金点 (78,55) 均落在圆心 (54,54)、r=33dp 的可见圆内。
3. 全图色值仅取自 §4 表：既有 token 五个 + 派生 token 两个；逐色可回查 `CardTokens.kt` 原值；不存在表外裸 HEX。
4. 五档密度图尺寸精确为 48 / 72 / 96 / 144 / 192 px，正方形，无拉伸变形。
5. 背景层铺满 108×108dp，squircle/正圆/圆角方三种掩膜下四角均不透出透明底。
6. monochrome 层只含 F1/F2/F4 形状剪影，无纹理、无柔边带、无彩色；远山 alpha 0.55、金线 alpha 0.8 可量。
7. 48px 档预览（`A-preview-72.png`）中主峰轮廓可辨，碎屑与纹理已按 §7 简化丢弃。
8. 近山墨 vs 绢帛底对比度 ≥ 7:1，远山青 vs 绢帛底 ≥ 4.5:1（取主色对底色实测）。
9. 全图无被否决元素：无红日、无月牙、无印刷体/楷体字标、无圆形印章、无 A~M 字母标、无副图标 `ic_launcher_small`。
10. 金线端点/拐点为圆角；线宽 1.2dp，与 77 图标圆角线口径一致。
