## 一页纸速览

1. 做什么：3D 沙盘/地球仪继续往上缩，进入天球星空；星官与星座双体系可切；点星出信息；点星宿在地球上对应州域亮起；两套视角（天外上帝视角 + 地上抬头）。
2. 多深：Tycho-2 到 11.5 等，内置 mag ≤6.5 约 9,100 行，按需金字塔到 11.5。
3. 多大：内置 <2MB，按需 <60MB 可删可重建，Tycho 派生素材不进 APK/CI 产物。
4. 几步：登记 → 选型 → 契约 → 接线 → 数据 → 渲染交互 → 独立验收，共 4 写 + 1 验。
5. 三条硬阻断：相机上限 6R 导致地球缩不到星点；`FrameSnapshot` 无星空字段导致"画了但画不出"；S-19 的 DoD 与新口令正面冲突且未登记。

## 〇、裁决与口径

用户已拍板（不可改）：

1. 深度 11.5 等推荐档，星表走 Tycho-2。
2. 星官 + 星座两套都要、可切、默认星官。
3. 缩放线性连续、不设档数；既有档数制一并改造。
4. 双视角：天外观 + 地上观，可切换。
5. 精致视觉（美学总纲六要素全适用）。

用户未否决、按建议默认推定（选型代理可Challenge）：

6. 分野主表取《史记·天官书》二十八舍十二州 + 国别；《淮南子》《汉书》异说标"一作"，不合并、不仲裁。
7. 地上观一期固定 J2000 + 可拖时间轴；行星/彗星/岁差/大气折射归二期。
8. 分野层注册为地图第九入口（P-06 六主二附之外）。

技术口径（本文件相对旧稿的修正，必须按此实现）：

9. 天球不是世界里的固定球，是**跟随相机的 2D 投影背景**。理由：固定球在相机推到 9R 时会站到球外，看到球壳外表面，模型本身不成立。
10. 连续缩放 = 相机 10R + `skyBlend` 连续标量；**不做连续细分 icosphere**。理由：`LodSelector.kt:13-25` 已有 morph 底座，扩展为连续权重成本低；重造连续细分网格要重写 mesh 生成器，成本高一个量级。
11. 视觉连续 ≠ 几何连续：本规格做到"任意缩放位置有唯一混合比例"，几何仍是三档常驻。这句必须写进验收报告，不许冒充几何连续。

## 一、① 目标与用户可感效果

验收要复现的动作序列：

1. 长安城视图双指捏合，穿过州、国、地球仪。
2. 继续捏合，地球连续缩成金点，星空从四边连续浮上来，全程无一次跳变、无一次整层淡入。
3. 先见银河暗带与暖白核心，再见成片暗星，最后亮星浮出四芒。
4. 头顶出现二十八宿名沿黄道带排一圈；切「星座」换成 88 星座连线，切回「星官」恢复。
5. 点一颗星：暖金呼吸光环 + 半屏 Sheet（古名/今名/星官/宿序/星等/距离（有才显示）/古籍原文）。
6. 点井宿：天球井宿八星连金；地球雍州整片暖金脉冲 + 州名竖排。反向点雍州，天球转向井宿。
7. 切「地上」：镜头落长安城头，地平线压暗、上方 5° 暖辉，抬头看到同一片星，位置与天外观严格对应。
8. 拖时间轴推两个时辰，星空整体西移，北斗绕北极转过去。

五条可感判据：

9. 连续——手指不抬、画面不断，中间没有任何一帧是"换了一张图"。
10. 深——放大到局部天区，暗星一层层长出来，最后密到 11.5 等。
11. 可读——每颗星点了有话说，每句能追到古籍原文或星表字段。
12. 有根——星宿对应地上的州，点哪边另一边都应。
13. 美——暖墨夜空、沉金连线、纸白星点；不冷、不蓝、不黑、不亮闪闪。

## 四、数据源、许可与 schema

许可（两条并存，照实登记）：

1. CDS VizieR I/259，`https://cdsarc.cds.unistra.fr/viz-bin/cat/I/259`；2,539,913 行；Høg/Fabricius/Makarov et al.；bibcode 2000A&A...355L..27H；标 CC-BY-NC-3.0 IGO。
2. NASA Open Data Portal 镜像页标 usa.gov/government-works。
3. 取 CDS 分发副本；NC 边界如实记录；**派生素材不进 APK、不进 CI artifact、不进仓库**，做首启可选下载 + 许可确认页。理由：NC 数据随构建产物分发会把"非商用"粘到 APK 上。

字段细分（禁混）：

4. 位置/自行/BT-VT 星等/HD/HIP/Bayer/Flamsteed：全部 Tycho-2 一源到底。
5. 距离：只对"星官成员星 + 最亮 150 颗"注 Hipparcos 视差（标 ESA 1997）；其余显示"未收录"，不编。
6. 光谱/B-V：只对精选子集查证；其余不着色温，按星等映射暖白段。
7. 星名：古名取公版古籍（《史记·天官书》《晋书·天文志》《步天歌》）逐条带出处；IAU 约 450 名取 WGSN；西名中文译名自拟，不抄有版权星表。
8. 星座边界为 IAU 事实（Davenhall & Leggett 1989，VizieR 条款非商用可标用）；连线自绘，署名"参考 IAU/Sky & Telescope"。
9. 分野表取公版原文，出处逐条标（《史记·天官书》卷二十七）。

schema 四族（禁自造字段）：

10. `star`：id、tychoId、raDeg/decDeg（J2000 Double 必填）、magVt、bayer、flamsteed、hip、hd、colorBv、spectralType、distanceLy、constellation（88 之一必填）。后三者可空是有意设计——空字段不渲染对应行。
11. `star_name`：starId、name、lang（zh-xingguan / zh-modern / en-iau）、source、isPrimary。
12. `asterism`（星官与星座**分表**，理由：成员判定与样式完全不同，合并会造"一套数据两个语义"）、`asterism_member`（memberIndex 如"井宿一"、linkToNext）、`constellation_line`（fromStarId、toStarId、constellationId、style）。
13. `field_allocation`：asterismId、regionName（雍州）、stateName（秦，可空）、source、isVariant（异说 true + "一作"来源）。

体积：star+star_name <1.5MB；其余 <150KB；金字塔按需 <60MB 可删可重建。

## 五、② 尺寸 / 间距 / 圆角 / 字号

总原则：**字号不随缩放变小，只随缩放显隐**。理由：`机制-观感UX验收-回执.md:29` 最小字号 14.0sp，`audit_ux()` 扫全 `*.kt`，低于即 FAIL。远处只留 28 宿名，近处显示全部星官名，字号恒定 14sp。

星点直径（屏幕 **px** 非 dp，随星等 Pogson 插值）：

1. mag ≤−1.5 → 9px；0 → 5px；2 → 3px；4.5 → 1.5px；6.5 → 1px；>6.5（金字塔层）→ 0.8px 不再小，用 alpha 补偿。
2. 理由：星点是光点不是控件，用 px 才能在任何 dpi 下保持同一张星图观感。

线宽：

3. 星座 0.8px alpha 0.45；星官 1.0px alpha 0.55；分野边 1.5px 虚线 dash 6/gap 4。
4. 网格：赤经/赤纬 0.8px；黄道 1.0px；天赤道 1.0px。理由：三套线必须一眼分层——星座最淡（参考）、星官次之（内容）、分野最重（联动锚）。

字号（全部 ≥14sp）：

5. 星官名/宿名 14sp 竖排；星座名 14sp 横排（拉丁名与中文名两行）；Sheet 标题 16sp、正文 14sp、出处 14sp（用 `textTertiary` 弱化不缩字号）。

间距与圆角（全引既有常量）：

6. 标签距星点 8dp（`BUBBLE_GAP_DP` 同值）；可点标签热区 ≥48dp×48dp（UX-03 下限，视觉 14sp 高，透明外扩）；顶部切换条视觉 28dp、热区 48dp；右上「天外/地上」同。
7. Sheet 圆角 20dp（`SHEET_RADIUS_DP`）；星名印框 2dp（刻意硬边，像印章，不套 16dp 卡片圆角）；列表 `spacedBy` 8dp；Sheet 三段 30/60/90%（`SHEET_DETENT_*`），关闭阈值 0.12。

宿主：

8. `GlobeScreenHost.kt` 实测 603 行 > 600（`机制-总控必读.md:157`），星空绘制必须落 `SkyCanvasRenderer.kt`，宿主净增 ≤5 行。理由：不拆则 S4 lint 与 oversized 债务棘轮必红。

## 六、③ 色值

分层原则（照既有先例，不叫"例外"叫"分类"）：

1. **UI 叠加层**（标签/连线/Sheet/网格/分野）只用 12 色 token + 石青增补。依据 `ComponentPalette.kt:16-66`、`docs/落文-模块契约索引.md:63`。
2. **天文内容色**（星点本身、银河亮度）走 `SkySpecColor`。依据 `GlobeTokens.kt:55-62` `GlobeSpecSurface` 先例——"地貌数据色，不是 UI 配色；12 色 token 约束的是界面叠加层，纹理色来自规格表格本身"。星色同构：来自 B-V 物理量，禁用于任何 UI 控件。
3. **派生色集中**：扩 `GlobeTokens`，单测断言"派生值 = 基础 token 明度偏移可复现"（`索引:77` 红线）。

UI 层逐条（禁写 hex）：

4. 夜空底 = `textPrimary` 压暗 40% → `GlobeTokens.skyNightBase`，结果由函数算，不写死。理由：墨色偏暖（R26>G20>B16），压暗仍暖墨，天然"暗处偏暖、禁纯黑"。
5. 地平暖辉 = `brandCopper` 0.10 → `skyHorizonGlow`。
6. 星官线 = `brandGold` 0.55；星座线 = `textTertiary` 0.45。理由：星座是辅助参考层，云灰正是"辅助"语义，且不抢金。**不借石青**——石青已登记为"Toast 提示 + 沙盘敌方势力"，第三用途会语义污染。
7. 星官名标签：字 `brandGold`、底 `bgOverlay` 0.45、边 1px `brandCopper`。理由：不用朱砂边框——朱砂语义是失败/删除/强调，常驻星名会误读。
8. 选中星/分野填充 = `colorGlow`；分野边 = `brandGold` 虚线。
9. 网格 = `textTertiary` 0.12；黄道 = `brandGold` 0.30；天赤道 = `stoneBlue` 0.30（"基准线专用"，须在切片-26 声明用途）。
10. 禁用 = `textTertiary` 0.30（`DISABLED_OPACITY`）。
11. Sheet 全走 `bgSurface`/`textPrimary`/`textSecondary`/`textTertiary`/`colorDivider`。

内容色 `SkySpecColor`（数据色）：

12. 星色四锚（B-V 连续插值）：早型 `#D8E4F0`（低饱和月白）→ 中间 `#FFFDF6` → 晚型 `#FFEED8` → 极晚 `#FFB37A`。
13. 为什么"去蓝化"不是完全去蓝：早型星确实偏蓝，但纯蓝白在暖绢底上会"跳"；降饱和后只作点缀（全天约 5%、集中在最亮几颗），整体仍"暖夜微芒"。
14. 无 B-V 的星按星等映射"纸白→暖白"，不猜色温。
15. 银河：暖白核心 `#FFFDF6` 0.10 + `brandGold` 0.06；冷蓝外围取消，改暖灰 `textTertiary` 0.04。尘粒 `textTertiary` 0.15。流星 `#FFFDF6` 头部。

派生三出口：`skyNightBase`（darken TEXT_PRIMARY 0.40）、`skyHorizonGlow`（BRAND_COPPER 0.10）、`skyStarWarm`（星色暖端，仅供图例/Sheet 小圆点，星点本体走 `SkySpecColor`）。

硬禁：

16. 禁 `#000000`、禁 `#FFFFFF`、禁 Material 默认色、禁第 14 基础色。
17. 判据：`grep -rn "#[0-9A-Fa-f]{6}" ui/map/globe/` 只允许命中 `SkySpecColor.kt` 与 `GlobeSpecSurface` 既有表；其余命中即 FAIL。

## 八、渲染（3 pass，不超预算）

预算事实：`DrawBudget.kt:9` "≤15 draw call；LOD0 ≤10"，`GlobeConfig.kt:126` `MAX_DRAW_CALLS=15`。9 层顺序会顶破，必须合并。

1. **星空底 pass**（1 张离屏位图）：夜空渐变 + 银河 + 密度底图（当前层与相邻层 alpha 连续混合）+ 参考网格；只在视角/缩放变化时重绘，静止帧复用。
2. **线框 pass**（1 条 Path）：星座线 + 星官线 + 分野边 + 选中光环，单条 Path 一次描边。
3. **星点 pass**（1 次 sprite 批绘）：实体星 + 尘粒 + 流星，预烘焙 4 档 atlas（1/3/5/9px），禁逐帧 `drawCircle`。先例：`索引:23` 噪点"单张 tile + 缓存表，禁逐帧 drawCircle"。
4. 几何模型：天球是跟随相机的 2D 投影，**不做球壳网格**。星点方向由 RA/Dec + 恒星时 + 相机姿态算出屏幕坐标。理由：软渲染（C3 裁决）下 2D 投影比球壳省一个量级顶点/像素运算。
5. `SKY_PROJECTION_FAR = 900` 只是投影深度常量（遮挡排序基准），不是几何球半径。

视觉参数：

6. 夜空渐变天顶 `skyNightBase` → 地平叠 `skyHorizonGlow` 0.10，禁纯黑。
7. 银河：暗带掩膜 + 三层 fbm，opacity 0.25，核心暖白外围暖灰。
8. 光晕三层（1.0/0.35/0.12 倍率）；四芒只 mag<0.5；闪烁只 mag<2.5、独立相位、0.6–1.4Hz、±8%。
9. 尘粒 32 颗 1px alpha 0.15 缓慢漂移；流星 90–240s、1.2s 划 8–14°、尾迹 0.4s。

双视角：

10. 天外观：赤道坐标 + 自由旋转，地球悬中央，星空为背景。
11. 地上观：地平坐标，视场 60°（`GROUND_VIEW_FOV_DEG`），地平线下压暗，上方 5° 辉光（`OBSERVER_HORIZON_GLOW_DEG`），观测点金针，可开山影。
12. 过渡：天外↔地上 800ms（`VIEW_SWITCH_MS`），spring 收尾，禁 linear（美学总纲）。

## 十、连续缩放（本规格的核心）

1. 相机上限 6.0R → 10.0R（`GlobeConfig.kt:106`）。
2. 为什么必须放宽：6R 时地球角径约 18.9°，60° 视场/1080px 下约 340px，缩不到 40px 的星点。只放宽相机还不够。
3. 10R 之后不再推相机，改由手势驱动 `skyBlend: Float`（0→1）：地球视觉半径 200px→40px 连续缩，星空 alpha 连续升；反向完全对称。
4. 为什么这样才对：`skyBlend` 是连续标量，无枚举无阈值档，天然满足"线性不设档"；且避免"相机退到无穷远"这种做不到的事。
5. 40px（`SKY_ENTER_EARTH_DIAMETER_PX`）只是 `skyBlend` 的终点锚，不是开关。
6. 地球 LOD：三档网格常驻，`LodSelector` 输出连续 `blendWeight`，渲染层按权重插值顶点。
7. 不做连续细分 icosphere：复用已有 morph 底座（`framesLeft`/`morphProgress`/`isMorphing`），改造成本低；重造 mesh 生成器成本高一个量级且回滚难。
8. 诚实边界：做到"视觉连续"，几何仍三档；验收不得要求"几何连续"，若后续要，另立缺陷升级。
9. 星空侧天然无档：星点数由 `magLimit = f(zoom)` 连续函数决定，金字塔层间 alpha 连续混合。
10. `DrawBudget` 增条款：blend 过渡期两档同时绘制，临时上限 +1，否则 bench 偶发红。
11. 旧 bench 中"LOD 三档切换"断言同步更新，不留测旧档位的死代码。
