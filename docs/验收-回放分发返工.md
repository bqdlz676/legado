2. **拒绝动作断言未锁字段名（判据 2 测试缺口）**：`ReplayDispatchTest.kt:284-287` 只守「显式拒绝」子串，未守 `alive` / `surrendered` / `exposed` 字段名；文案被泛化改写时测试不会红。
3. **派生视觉无画布消费方（既有骨架观察，非本单引入）**：`visuals()` / `arrows()` 在 main 零调用，`ReplayScreen` 未绘制棋子 / 箭头 / 交战效果；F-73 冻结头注 `ReplayScreen.kt:3` 已声明该模块暂停扩写。本批派生层接线在 UI 画布 pass 落地前，真机上仍不可见；后续 UI 单须把 `visuals()` / `arrows()` / `clashes` / `encounters` 接进 Compose 画布。
4. **`SET_INTENT` 非法标签静默回落 ADVANCE（口径轻微不一致）**：`Intent.fromLabel`（`BattleModels.kt:46-52`）对 null / 未知标签回落 `ADVANCE`，`SET_INTENT` 分支（`ReplayDirector.kt:279-280`）未对非法标签记告警。与本批「不许静默」的处置口径存在轻微落差；该回落是既有 `fromLabel` 行为，非本批新引入。
5. **告警行无换行 / 省略号约束（观感挂账）**：`ReplayScreen.kt:153-163` `BasicText` 未设 `maxLines`，超长告警文案可能横向溢出。
