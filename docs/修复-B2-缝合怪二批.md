## 1. sweep 方法与口径

- 主命令：`grep -rnE "\b<类名>\b" app/src/main app/src/test app/src/androidTest screenshot/src modules app/src/main/res`，词边界匹配，防 `RssFragment` 命中 `RssArticlesFragment` 这类子串误判。
- 补充通道：三份 `AndroidManifest.xml`（main/cronetRuntime/pdfRuntime）、`proguard-rules.pro`、`cronet-proguard-rules.pro`、`app/src/main/assets`、`--include=*.java`；反射通道 `Class.forName|loadClass|findFragmentByTag` 复查；菜单枚举/动作字符串（`ReaderMenuItem.kt`、`ReaderMenuConfig.kt`）单独复查。
- 命中分三类：① 主源码存活代码引用（import / 继承 / 强转 / 实例化 / 类型判断 / 常量或接口消费）；② 测试编译锁（test/androidTest 类型 import、实例化、`filterIsInstance`、同包 internal 调用）或源码契约锁（`readText()`/路径常量读本文件断言）；③ 注释 / 文档提及（KDoc、行内注释、台账问题清单）。
- 判定规则：①②任一存在即不可硬删；③不构成存活链路，但随宿主一并保留。改道前提是仓内已存在同功能 Ink 页 / 浮层入口；无既有目标则进余项，不假装完成。
