# 规格候选-T6-B · 地球仪镜面高光（实时片元高光 + 菲涅尔边缘提亮）

> 流水线：F-73 三段流水线第①段设计候选。本文只出规格与预览，不含任何 `.kt`/`.xml`/资源代码；既有软渲染器只做覆盖+深度，片元层为新建，不复用旧实现（B7）。
> 硬指标归属（用户口径，非切片引文）：T6=A 档两项之一——地球仪太阳镜面高光：大西洋镜面高光随太阳移动，太阳方向驱动。
> 规格锚点（逐字）：`切片-20:39`「太阳光方向 × 法线 → Phong 漫反射 + specular」；`切片-19:32`「高光区一道白色镜面亮斑，位置随太阳移动」；`切片-19` 性能表：大气 shader 「fragment shader ≤ 20 行 GLSL」、ocean shader 「fragment shader ≤ 15 行 GLSL」、draw call 「≤ 15」、frame 「55fps」。

## 1. 作用域与触发条件

- **屏幕**：3D 地球仪页；近距 LOD1 / LOD2 档位为主战场，远距 LOD0 回退 T6-A 的离线贴图静态光斑（本候选不重复远距路径）。
- **时机**：每帧把 `sunDir` 与视线向量传入片元；海洋格才计算 specular；离开页面释放 shader 与缓冲。
- **生命周期**：页面可见 → 片元常驻；不可见 → shader pass 摘除，缓冲回收。

## 2. 视觉描述（形态 / 层次 / 动效曲线 / 时长）

- 逐像素 Blinn-Phong 镜面高光：半程向量 H 与法线 N 点积乘高次幂，形成随太阳滑移的锐亮斑；叠加菲涅尔项，球面掠射边缘泛一圈纸白薄光，正面透明（呼应 `切片-19` 大气内圈「正对镜头完全透明，边缘泛淡蓝白光」的层次语言，但色取石青系）。
- 海面微法线扰动让亮斑内有细碎闪烁，不是一块匀色圆斑；扰动幅度克制，保持绢帛水墨的安静感。
- 动效：亮斑连续跟随太阳角；菲涅尔边随相机环绕缓慢呼吸；淡入 / 退场 200ms `cubic-bezier(0.4,0,0.6,1)`。

## 3. 逐部件参数

| 部件 | 参数 | 透明度 / 强度 | 色值（回挂 token） |
|---|---|---|---|
| specular 核心 | 半程向量 `H`，`pow(max(dot(N,H),0), shininess)`，shininess = 24 | specular 强度 0.6，峰值 alpha ≤0.8 | 派生金白高光：`CardTokens.warmGold` 70% + `CardTokens.cardPaper` 30% lerp |
| 菲涅尔边 | `f = pow(1 - max(dot(N,V),0), 3)`，边缘增益 0.25 | 边光 alpha ≤0.25 | `CardTokens.stoneBlue`（`0xFF3A6B66`）；正面 `dot(N,V)→1` 时透明 |
| 微法线扰动 | 高度图既有微法线链路，扰动幅度 0.35 | 只影响亮斑碎闪，不改底色 | 不引入新色 |
| 海面底色 | 既有海洋层 | — | `GlobeTokens.OCEAN_DEEP` / `OCEAN_SHALLOW` 既有 token |
| 夜侧衰减 | specular × `Sun.nightBrightness(dayFactor)` | 夜侧增益 ≤0.05 | 不叠加新色 |

- 坐标口径：N 为施加地轴倾斜后的世界空间法线（沿用 `Sun.worldNormal` 口径，避免模型 / 世界两套坐标系混用）；V 为相机视线向量。

## 4. 与太阳 / 章节数据的绑定方式

- **数据源**：`Sun.direction(utcMillis)` 逐帧传入；法线取既有高度图 / 微法线；海洋格判别取覆盖图水格。
- **缺数据兜底**：无微法线贴图 → 退回球面解析法线（N = 归一化顶点位置）；覆盖图缺失 → 泛化海洋环带（同 T6-A §4）；UTC 缺失 → 沿用缓存方向并标 `stale`。
- **shader 规模**：ocean 片元 ≤15 行 GLSL；大气菲涅尔 ≤20 行；超行数即判规格漂移。

## 5. 性能预算（明确上限）

- draw call：不新增独立 pass，specular / 菲涅尔并入既有海洋片元 pass；全局 draw call ≤15（`切片-19` 上限）。
- 片元耗时预算：海洋片元 ≤3ms/帧；shininess 幂次运算固定 24 次 / 像素，不开循环。
- 内存：不新增离屏高光贴图；微法线复用既有高度图缓冲；增量内存 ≤64KB（uniform 与扰动表）。
- 帧率底线：球面 55fps（A8）；近距档位 45fps 不跌破 `切片-03:323` 地图档底线。

## 6. 降级与兜底（四种边界，不允许空白态）

- **无网络**：高度图 / 覆盖图走 `OfflineFallback` 三档缓存（`FULL_TEXTURES / CACHED_MIX / PROCEDURAL_ONLY`）；纯程序档下用解析法线，高光仍可算。
- **无海洋 / 法线数据**：泛化环带 + 解析法线；无数据格不画 specular，只留球面底色。
- **低端机**（线程数 <4 或 Android ≤8）：整条片元高光路径切回 T6-A 离线贴图路径；扰动关闭、菲涅尔关闭。
- **帧率掉线**：连续 3 帧 <50fps → 降档顺序：关微法线扰动 → 关菲涅尔边 → specular 降为漫反射级亮斑；仍不达标则退静态光斑（同 T6-A §6）。不允许靠砍海洋底色绕过。

## 7. 可测断言（机械核验）

- B-1 specular 亮度 ∝ `max(dot(N,H),0)^24`；给定 N/L/V 后亮度误差 ≤5%。
- B-2 掠射角 80° 处菲涅尔边亮度 ≥ 正视方向（掠射角 0°）的 1.6 倍。
- B-3 陆地像素 specular 增益 ≤0.05。
- B-4 夜侧 specular 经 `nightBrightness` 衰减后峰值 ≤0.05。
- B-5 ocean 片元 GLSL ≤15 行；全局 draw call ≤15。

## 8. 与 12 类卡片 / 77 图标 / 色板一致性对照

| 对照项 | 结论 | 理由 |
|---|---|---|
| 12 类卡片 token | 一致 | 金白核心由 warmGold / cardPaper 派生；菲涅尔边取 stoneBlue；无第三套蓝 |
| 卡片辉光口径 | 一致 | 边光 0.25 透，与 `COLOR_GLOW` 暖金辉光同属薄光不铺底口径 |
| 77 图标 | 不适用（已声明差异） | 渲染叠层非图标资产；不新增 `ic_*` 文件 |
| 色板 | 一致 | 无 HEX 外色；派生色写明 lerp 比例；朱砂不参与高光 |
| 大气层既有口径 | 一致 | 菲涅尔正面透明、边缘泛光，沿用 `切片-19` 大气内圈语义，色归石青系而非规格外蓝紫 |

## 9. 可测判据（P1…P10，含 FAIL 条件）

- P1 半程向量公式：片元输出与 `pow(max(dot(N,H),0),24)` 偏差 ≤5%；FAIL = 用错漫反射点积或幂次。
- P2 菲涅尔倍率：80° 掠射边亮度 ≥1.6× 正视；FAIL = 边缘不提亮或正面泛白。
- P3 陆地隔离：陆地 specular 增益 ≤0.05；FAIL = 陆地出现高光斑。
- P4 夜侧衰减：夜侧峰值 ≤0.05；FAIL = 夜侧亮斑未衰减。
- P5 shader 行数：ocean ≤15 行 GLSL；FAIL = 超行或拆出第二个海洋 pass。
- P6 draw call：全局 ≤15；FAIL = 高光新增独立 draw call 导致超限。
- P7 内存增量：≤64KB；FAIL = 新增离屏贴图或缓冲未回收。
- P8 低端机回退：低端档切贴图路径；FAIL = 低端机仍跑片元 specular。
- P9 掉线降档顺序：扰动 → 菲涅尔 → 漫反射亮斑 → 静态；FAIL = 一步砍光海洋底色或无降级路径。
- P10 token 合规：无色板外 HEX；FAIL = 出现未声明 lerp 的新十六进制。

## 10. 自我论证：为什么它最符合全 App

- 直接落地 `切片-20:39` 的 Phong + specular 管线口径，是规格原文描述的主路径；菲涅尔边与既有大气圈层次语言同源，近距观感最接近「不是蓝色塑料球」的要求。
- 降档链路把实时计算逐级退回静态，每一级都有明确开关，符合 A8「可度量的硬指标」与掉线降级要求。

## 11. 它最可能被否掉的地方（自证反例）

- 反例一：片元着色层在当前仓库尚未落地（现状查证 #3：软渲染只做覆盖+深度），本候选依赖后续真机渲染层先行；若渲染层排期靠后，本候选无可运行落点。
- 反例二：菲涅尔石青边在纸白 / 浅色系球面上可能对比不足，边缘泛光看不清；需多壁纸 / 多光照目检。
- 反例三：高次幂 shininess=24 在低分辨率屏幕上亮斑易锯齿；若无 MSAA，近距边缘可能出现硬边，验收需加边缘柔化用例。
