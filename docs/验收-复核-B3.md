## 四、核查 3：NEUTRAL 口径 —— 口径缺口（不判 FAIL）

### 4.1 中立方实际走向的证据链【L1-铁证】

1. `alliedSidesWith`（`:440-446`）只收集 `Relation.ALLIED`；`Relation.HOSTILE` 与 `Relation.NEUTRAL` 都不进盟约集。
2. `enemiesOf`（`:530-534`）：`sideId != 本方 && sideId !in 盟约集 && combatReady()` —— **NEUTRAL 阵营满足全部条件，被计入敌军集**。
3. `alliesOf`（`:536-541`）：非同阵营、非盟约 —— NEUTRAL 不进盟友集。
4. `isFriendlySide`（`:553-555`）：NEUTRAL 返回 false。

### 4.2 行为后果推演【L1-推断，链路为 L1-铁证】

- **遭遇**：`resolveEncounters`（`:382`）把相邻 / 同格中立方当敌军选中，进入 `CombatResolver.resolve` 双方扣兵力 —— 中立方被主动攻击；中立方回合同理攻击回来。
- **意图**：`resolveIntent`（`:341`）把中立方计入 `enemies`，驱动 FIGHT / ADVANCE / ROUT 远离判定；中立方不进 `allies`，不会被支援、不进补给撤退点。
- **侧翼路径**：`:355` 把中立方阵位当作敌军避让格。
- **情报快照**：`:459` 中立方不被跳过，进 `observedIds` 侦察；`:464` 非友方，未观测时坐标置空，按敌军雾处理。
- **胜利判定**：`VictoryChecker.kt:115` ROUT 敌军同样只排盟友，中立方士气崩溃计入"敌方全溃"胜利条件。

### 4.3 规格回源与偏差认定

规格原文（`docs/落文-原文/落文-原文-历史附件.md:771`，同文 `:6044` 复现）：

> diplomacy：每两方之间一个 relation——hostile（敌对，遭遇即战）、allied（盟友，共享视野、不触发战斗）、**neutral（中立，不共享视野、不主动攻击）**。

即规格对中立态有明确定义：**不主动攻击**。当前实现把 NEUTRAL 并入敌军集，与"不主动攻击"存在行为偏差；写码方自述文档 `docs/修复-B3-外交盟友.md` 5.2.3 / 七.3 已自承"NEUTRAL 当前按敌军处理，留总控裁决"。

**判定**：属口径缺口，**不判 B3 FAIL**——B3 缺陷条目（`docs/问题清单.md:51`）范围是"ALLIED 异阵营被当敌军"，中立偏差为既有口径、非本单引入；但需总控在规格层裁决后派单修复。

### 4.4 附带发现（跨模块，记录交接）

- `FactionRole.fromSideIds`（`model/Enums.kt:216-221`）：非 own、非 allies 一律标 `ENEMY`，`NEUTRAL` 枚举桶仅在 `sideId == null` 时可达；中立方棋子在壳层会被标成敌方灰青，与规格"中立白色"（历史附件 `:673`）不符。【L1-铁证】
- 未在 `diplomacy` 表中声明关系的两方，当前默认按敌军处理；规格未明确"缺省关系"是 hostile 还是 neutral，需一并裁决。【L1-推断】

### 4.5 修复建议（供总控派单参考，本单不改产品代码）

1. 三态分桶：`relationsOf(side)` 分别返回 allied / hostile / neutral 集合；`enemiesOf` 仅取 HOSTILE（缺省态按裁决结果定），NEUTRAL 不进遭遇集、不驱动主动 FIGHT / ADVANCE、不进追击与溃逃避让计算。
2. 中立方视野：不共享盟友视野，但也不按敌军雾强制隐藏（按规格"不共享视野"口径另定）。
3. 补 NEUTRAL 专项单测：相邻中立不触发战斗、不转 FIGHT、不进支援集、ROUT 落点不把中立当追兵。
4. 对齐 `FactionRole` 标签与 `VictoryChecker` ROUT 敌军口径，三处同源。

- 不确定点：① 经纬度边界取整（`.toInt()` 截断）可能让某支军队落到相邻格；② `Pathfinder.find` 在 A* 无解时退化 `straightPath`，末格未必等于目标格；③ `farthestFromEnemies` 同距时按 `neighbors8` 遍历次序（dc 外层 -1→1、dr 内层 -1→1）取首个最大值，若东西同距可能取到西侧。静态推演未触发上述任一退化，但**未经实跑不能排除**。L2 必须实跑 4 条新测试确认落点断言成立。

## 七、这一级（L1 静态验收）证明不了什么

1. **证明不了编译通过**：无 SDK / kotlinc / gradle，类型推断、`internal` 可见性跨包访问、import 完整性、Kotlin 语法合法性均未验证。
2. **证明不了测试通过**：断言语句存在 ≠ 断言成立；4 条新测试未在 JVM 执行，可能编译失败或断言失败。
3. **证明不了基线无回归**：既有 `F2 外交盟友不进入伤害结算`（`CampaignControllerTest.kt:132`）、`F8 视野外敌军不上报实时坐标`（`:155`）等用例未实跑；快照口径改动对 F8 雾测的影响仅做了静态等价推演（无盟约时 `isFriendlySide` 与旧 `sideId` 比较等价）。
4. **证明不了壳层与真机表现**：盟友棋子着色、实时坐标下发渲染、视野雾效果未上荣耀 WIN 真机验证。
5. **证明不了规格全量对齐**：本单只核 B3 缺陷条目范围；NEUTRAL 三态、DEFEND 据点盟友口径、观察者盟友共享视野等均未在本单闭合。
6. 字符级配平扫描不能替代类型系统与编译器；字符串 / 注释剔除为启发式处理，极端字面量写法可能造成计数偏差。
