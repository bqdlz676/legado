## 2. JSON Schema（换仗只换数据，不换代码）

解析器：`CampaignJsonParser.parse(json: String?): CampaignDefinition`。字段缺失给保守默认；类型错位做数值强转；整条 army/event 无法解析则跳过并记 warning；根节点非法返回 `degraded = true` 的最小中立定义。

### 2.1 顶层

| 字段 | 类型 | 语义 | 缺省 / 兜底 |
|---|---|---|---|
| `id` | string | 战役标识 | `"unknown"` |
| `title` | string | 战役标题（壳层顶栏） | `"未名之战"` |
| `era` | string | 年代 / 纪年 | `""` |
| `context` | string | 背景说明 | `""` |
| `terrainFocus` | object | 地形聚焦范围，见 2.2 | 原点 50km 并记 warning |
| `heightMap` | string? | 高程图资源名（字段留存；PNG 解码由壳层注入栅格，见第 7 节） | `null` |
| `duration` | int | 推演回合上限 | 30，下限钳到 1 |
| `weather` | object? | 天候块，见 2.3；缺省晴朗，引擎不因缺块崩 | `null` |
| `victory` | object | 胜利条件，见 2.4 | ANNIHILATE 无目标并记 warning |
| `sides` | array | 阵营列表，见 2.5 | 空列表 |
| `diplomacy` | array | 外交关系，见 2.6 | 空列表 |
| `armies` | array | 军队列表，见 2.7；为空记 warning | 空列表 |
| `events` | array | 条件事件列表，见 2.8 | 空列表 |
| `terrain` | object | 程序化地形附加定义，见 2.9 | 纯程序化空定义 |

### 2.2 `terrainFocus`

| 字段 | 类型 | 语义 |
|---|---|---|
| `center` | `[lng: number, lat: number]` | 焦点中心经纬度 |
| `radius` | number | 焦点半径（公里），钳制 5..500 |

### 2.3 `weather`

| 字段 | 类型 | 语义 |
|---|---|---|
| `condition` | string | `clear / rain / snow / fog / wind`（大小写不敏感）；其余按晴朗 |
| `wind` | number | 风速 m/s（留存，当前仅 condition 参与代价） |
| `temperature` | number | 气温 ℃（留存；赤壁火攻变量后续战役扩展） |

### 2.4 `victory`

| 字段 | 类型 | 语义 |
|---|---|---|
| `type` | string | `annihilate / capture / defend / escape / reachPoint / rout / compound` |
| `target` | string? | 目标军队 id（annihilate / escape） |
| `side` | string? | 判定阵营 id |
| `point` | `[lng, lat]`? | 目标据点 / 逃脱点（capture / escape / reachPoint） |
| `holdTurns` | int | 连续占领回合数（capture），缺省 3 |
| `op` | string | COMPOUND 组合算子 `AND`（默认）/ `OR` |
| `sub` | array | COMPOUND 子条件（同 2.4 结构；当前解析一层） |

### 2.5 `sides[]`

| 字段 | 类型 | 语义 |
|---|---|---|
| `id` | string | 阵营 id（armies.side 引用） |
| `name` | string | 阵营名 |
| `color` | string? | 数据留存；壳层一律按势力角色取 token，不读此值 |

### 2.6 `diplomacy[]`

| 字段 | 类型 | 语义 |
|---|---|---|
| `a` / `b` | string | 两方阵营 id |
| `relation` | string | `hostile / allied / neutral` |

### 2.7 `armies[]`

| 字段 | 类型 | 语义 | 缺省 / 兜底 |
|---|---|---|---|
| `id` | string | 军队唯一标识 | `army_<index>` |
| `name` | string | 军队名 / 将名 | 同 id |
| `side` | string | 所属阵营 id | `""` |
| `initialPos` | `[lng, lat]` | 开局坐标；越界回收到边缘格，压到不可通行格再钳制到最近可通行邻格 | 原点 |
| `strength` | number | 相对战斗力（不搞人数），钳制 0..100 | 5.0 |
| `type` | string | `elite / regular / militia / cavalry` | `regular` |
| `fatigue` | number | 开局疲劳 0..5 | 0.0，钳制 0..5 |
| `morale` | string | `high / steady / wavering / broken` | `steady` |
| `intent` | string | 开局意图，见 2.10 | `hold`（最保守） |
| `target` | `[lng, lat]`? | 初始目标点 | `null` |
| `supply` | int | 补给等级 0..5 | 5 |

### 2.8 `events[]`（条件触发器，不硬编码回合数）

| 字段 | 类型 | 语义 |
|---|---|---|
| `trigger` | object | 条件块，见 2.9；全部条件 AND，`null` 不约束 |
| `action` | string | `moraleChange / surrender / supplyCut / setIntent / setTarget / strengthChange / rout`；未知动作跳过并记 warning |
| `target` | string? | 作用军队 id |
| `value` | string? | 动作参数：moraleChange=士气标签；setIntent=意图标签；strengthChange=数值串 |
| `targetPos` | `[lng, lat]`? | setTarget 目标点 |
| `reason` | string | 事件缘由（写入事件日志） |

`trigger` 条件：

| 字段 | 类型 | 语义 |
|---|---|---|
| `turn` | int? | 当前回合 ≥ 声明回合即满足（一次性，晚补不漏） |
| `army` | string? | 绑定军队 id |
| `strengthBelow` | number? | 目标兵力 < 阈值 |
| `morale` | string? | 目标士气标签命中 |
| `atPoint` | `[lng, lat]`? | 目标距该点 ≤1.5 格 |

### 2.9 `terrain`

| 字段 | 类型 | 语义 |
|---|---|---|
| `procedural` | bool | 是否启用程序化附加地形 |
| `ridges[]` | object | `{x, y, h, w}` 归一化 0..1 山脊（留存分析层） |
| `rivers[]` | object | `{pts: [[x, y], ...]}` 归一化 0..1 河流折线，栅格化为河面单元 |

### 2.10 意图标签

`fight / rout / breakout / ambush / retreat / support / advance / flank / seize / rapid / continue / hold`（含别名 `engage / flee / ambush 埋伏 / fallback / reinforce / march / outflank / occupy / rush / forced / 急行军 / guard / defend`）；未知兜底 `hold`。

> 注：既有资产 JSON 中的 `phases` 字段解析器当前不读取（预留），不影响推演。

## 5. 兜底与不变量

### 5.1 异常路径兜底（全部不抛、不空白、不崩）

| 场景 | 兜底行为 | 降级标志 |
|---|---|---|
| JSON 为空 / 非法 / 根节点非对象 | 返回最小中立定义，军队为空 | `degraded = true`，warnings 记原因 |
| 高程图缺失 / 尺寸退化 / 长度不符 | `HeightRaster.create / synthetic` 生成两层正弦 + 谷地缓丘合成场 | `raster.degraded = true` |
| 字段缺失 / 类型错位 | 各字段保守默认（见 §2 schema）；无法解析的 army/event 跳过并记 warning | 并入 `degraded` |
| 断网 / 无外部资源 | 引擎纯离线，无任何网络调用；演示数据内置常量 | 同上 |
| 初始坐标压在不可通行格 | 初始化钳制到最近可通行邻格（半径 6 格内搜索） | 不另置标志 |
| A* 搜不到通路 | 退回逐格钳制直线折线，被堵侧向绕行；目标深水格落点钳制到可通行格 | — |

### 5.2 推进不变量（单测把守）

- **河道不可越**：移动落点、退却落点、初始落点均经 `TerrainMap.passable` 校验；非渡口水面不上人。测试 `河道不可越：每支存活军队落点都可通行`。

## 8. 未验证项与已知简化

### 8.1 未验证（不得当作已完成）

1. **编译未过编译器**：所有 Kotlin 文件未经历 `gradle assemble` / kotlinc；可能存在类型推断、签名匹配、导入遗漏等编译期问题，需首次编译复核。
2. **测试未实跑**：不变量断言、兜底分支、bench 预算均未在 JVM 执行通过；报告结论不含「测试绿」。
3. **真机 / 渲染性能未验**：壳层 Canvas 32×32 栅格 + 棋子 / 线路绘制帧率、首开耗时未测；弹簧动效参数已对齐 `ComponentPalette` 但未接实际 spring 动画（见 8.2）。
4. **PNG 高程图解码未接线**：引擎只接受壳层解码后的 `HeightRaster`；`heightMap` 字段当前仅留存，Android `Bitmap → 0..255 栅格` 的转换通路未实现（引擎层刻意不引 Android 位图类型）。
5. **未接主导航**：壳为独立 `@Composable`，未挂 Activity / Fragment / 路由入口（任务书不要求）。
6. **大圆距离**：haversine 已接入 `GeoProjection.distanceMeters`；寻路启发式仍用网格 octile 直线口径，geo 级大圆距离供情报 / 据点判定使用。

### 8.2 已知简化（规格允许范围内，后续可补）

1. **情报模糊半径**：看不到的敌军记录 `lastKnown` 坐标，但决策层未按模糊半径扩圈搜索。
2. **COMPOUND 胜利条件**：子条件只解析一层，嵌套组合未递归。
3. **天候变量**：`weather.condition` 参与速度 / 路况系数；风向 / 气温对火攻、水军的影响未实现（规格列为赤壁后续战役扩展项）。
4. **分支并列对比**：存档 / 恢复已实现；两条历史线并排对比视图未做。
5. **手动拖拽**：壳层以点按循环意图（HOLD→ADVANCE→RETREAT→FIGHT→AMBUSH）替代拖拽手势；`step(overrides)` 接口已支持任意意图覆盖。
6. **山脊 / 雪线**：`ridges` 定义留存于地形附加层，当前高程分类以米制阈值（海面 0m / 雪线 3500m）为准，山脊几何未叠加隆起。
7. **事件 `setTarget`**：动作已接线，演示 JSON 未使用该动作。
