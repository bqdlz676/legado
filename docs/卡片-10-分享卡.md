- 改前：3 处十六进制色值字面量——`ShareDarkBg 0xFF1E1A15`、`ShareEyeCareBg 0xFFE7ECE0`、`ShareRiceBg 0xFFF3EAD9`，均不在判据 2 例外清单（边框色 / 朱砂进度线 / 金点），验收判 FAIL。

## 判据 7 落码
- 函数签名：`suspend fun exportShareCardPng(context: Context, bitmap: Bitmap, book: String, date: String): Uri?`（:248）；文件名一律走 `shareCardFileName(book, date)`（:250）。
- Q 分支（API 29+，:281 `exportViaMediaStore`）：`MediaStore.Downloads.EXTERNAL_CONTENT_URI` insert；`DISPLAY_NAME`=文件名、`MIME_TYPE`=`image/png`、`RELATIVE_PATH`=`Download/落文卡片`(:291)、`IS_PENDING=1`(:292) → `openOutputStream` 写 PNG → `IS_PENDING=0`(:301)；异常时 `delete` 回滚 pending 占位(:305)。
- 低版本分支（<29，:317 `exportViaLegacyFile`）：`Environment.getExternalStoragePublicDirectory(DIRECTORY_DOWNLOADS)` + `落文卡片` 子目录 `mkdirs()`，`FileOutputStream` 写 PNG，返回 `Uri.fromFile`。
- 降级链：公共目录创建失败 → `context.getExternalFilesDir(DIRECTORY_DOWNLOADS)/落文卡片` 应用私有目录(:327/:329)，落点写 `Log.w`(:326)；主函数三级 catch（IOException :261 / SecurityException :265 / Exception :269），失败一律 `Log.w` 返回 `null`，不抛 UI。
- grep 回证：`MediaStore`(:10/:288/:289/:291/:292/:294/:301)、`RELATIVE_PATH`(:291)、`IS_PENDING`(:292/:301)、`DIRECTORY_DOWNLOADS`(:322/:327)、`getExternalFilesDir`(:327)、`catch`(:261/:265/:269/:304) 全部命中；`grep -c "0x"` 仍为 **0**；括号配平 0/0/0；35 个 import 逐个对照全命中。
- Manifest 现状：`app/src/main/AndroidManifest.xml`:22 已声明 `WRITE_EXTERNAL_STORAGE`，但**未带** `android:maxSdkVersion="28"`；待宿主模块补声明：需要 `maxSdkVersion=28` 的 `WRITE_EXTERNAL_STORAGE`（Q+ 走 MediaStore 不需要该权限，全版本保留属越界声明）。本卡未改 Manifest（属其他模块域）。
