## ④ 三节分析

### 二阶三阶影响

- **直接效果**：两条 `List<TurnSnapshot>` 回放线可并排逐回合对照，差异行暖金描边 + 标签。
- **连带影响**：数据层新增类型均为不可变 data class / 纯函数，不被既有 `CampaignController`、parser、terrain 引用；单快照壳 `CrossingCampaignShell` 未改签名、未改状态机，存档恢复路径（`BranchSnapshot` → controller）不经过 `SnapshotDiff`，不受影响。
- **二阶**：`runToEnd()` 返回的序列不含第 0 回合快照；首回合对照需调用方前置一次 `snapshot()`（已在组件 KDoc 注明）。未来接线方（B7 分支存档 / B11 意图面板）只需把两条线喂给 `BranchCompareShell`，无需改 diff 层。
- **三阶 / 维护成本**：diff 维度集中在 `DiffField` 枚举，新增维度（如据点 `HOLDING`）只动枚举 + `diffCorps` 一处；壳层标签自动从 `label` 渲染，无需改 UI 分支。

### 反例与边界

1. **回合数不一致**：两线长度不同，短线超出自身长度的回合 `getOrNull` 返回 null → 该栏出占位卡，不崩溃；`maxTurns` 取较长线长度，步进边界按 `maxTurns-1` 钳制。
2. **一侧加载失败 / 线为 null**：`leftLine.orEmpty()` 兜底；两侧皆空时 `maxTurns=0`，按钮禁用，两栏均占位，回合号回落 -1（单测覆盖）。
3. **快速连点步进**：下标钳制在读取处与 `onStep` 双保险；高亮走 spring 而非固定 delay，连点时弹簧按目标值自然衰减，不产生硬切跳帧；`coerceIn` 下限用 `coerceAtLeast(0)` 避免 `maxTurns=0` 时区间反转抛异常。
4. **军 id 对不上**（一侧改名 / 溃散出局）：并集比对，缺编侧标 `STATUS`，不误标兵力 / 位置；同名异军的消歧属引擎层问题，diff 层按 id 对齐是当前口径。
5. **浮点抖动**：兵力 0.05 内、坐标 0.0005 度内视为同值，单测覆盖容差边界。
